# 12-modul. Standart shablonlar kutubxonasi (STL)

!img banner12.png | | 5.5

STL (Standard Template Library) — C++ bilan birga keladigan tayyor "asboblar qutisi". Unda ma'lumotlarni saqlash uchun **konteynerlar**, ular bo'ylab yurish uchun **iteratorlar** va ular ustida ishlash uchun **algoritmlar** bor. STL ni bilgan dasturchi murakkab masalalarni bir necha qator kod bilan yecha oladi. Bu modulda eng muhim konteynerlarni birma-bir o'rganamiz.

## C++ dagi konteyner turlari va ketma-ketliklar

!img c_containers.png | STL — tayyor konteynerlar qutisi | 6.2

**Bu mavzuda nimani bilib olasan:**

- konteyner nima ekanini va STL qanday qismlardan iboratligini;
- konteynerlarning uchta guruhini;
- iterator nima ekanini;
- qaysi vazifa uchun qaysi konteynerni tanlashni.

### Umumiy ma'lumot

Uyingda narsalarni saqlash uchun turli idishlar bor: kitoblar javonda, kiyimlar shkafda, oziq-ovqat muzlatgichda, pullar hamyonda. Har bir idish o'z vazifasiga mos.

Dasturda ham ma'lumotlarni saqlash uchun "idishlar" kerak. STL da ular **konteynerlar** deyiladi. Konteyner — bu ko'p elementlarni saqlaydigan va ular bilan ishlash uchun qulay metodlarga ega obyekt. Barcha konteynerlar shablon (11-modul) bo'lgani uchun istalgan turdagi ma'lumotni saqlay oladi: `vector<int>`, `vector<string>`, `set<char>`...

!img m12_family.png | STL konteynerlarining uchta guruhi | 6.3

### STL ning uchta asosiy qismi

| Qism | Vazifasi | Misollar |
|---|---|---|
| **Konteynerlar** | Ma'lumotlarni saqlaydi | `vector`, `list`, `set`, `map` |
| **Iteratorlar** | Konteyner elementlari bo'ylab "yuradi" | `begin()`, `end()` |
| **Algoritmlar** | Elementlar ustida amallar bajaradi | `sort`, `find`, `count`, `reverse` |

### Konteynerlar guruhlari

**1. Ketma-ket konteynerlar** — elementlar siz qo'ygan tartibda saqlanadi:

| Konteyner | Xususiyati |
|---|---|
| `vector` | Dinamik massiv; oxiriga qo'shish va indeks bo'yicha murojaat tez |
| `deque` | Ikki tomonlama navbat; boshiga ham, oxiriga ham tez qo'shiladi |
| `list` | Ikki tomonlama bog'langan ro'yxat; istalgan joyga tez qo'shiladi |
| `array` | O'lchami qat'iy massiv (oddiy massivning xavfsiz varianti) |

**2. Assotsiativ konteynerlar** — elementlar avtomatik saralanadi va tez qidiriladi:

| Konteyner | Xususiyati |
|---|---|
| `set` | Takrorlanmas qiymatlar to'plami |
| `multiset` | Takrorlanishi mumkin bo'lgan qiymatlar to'plami |
| `map` | Kalit → qiymat juftliklari (kalitlar takrorlanmaydi) |
| `multimap` | Kalit → qiymat (kalitlar takrorlanishi mumkin) |

Ularning saralanmagan, yanada tezroq variantlari ham bor: `unordered_set`, `unordered_map`.

**3. Konteyner adapterlari** — boshqa konteynerlarga cheklangan, maxsus interfeys beradi:

| Adapter | Tamoyili |
|---|---|
| `stack` | Oxirgi kelgan — birinchi ketadi (LIFO) |
| `queue` | Birinchi kelgan — birinchi ketadi (FIFO) |
| `priority_queue` | Eng muhimi birinchi ketadi |

### Iteratorlar — konteyner bo'ylab yuruvchi "barmoq"

Kitob o'qiyotganda barmog'ing bilan qatorlarni ko'rsatib borasan. **Iterator** ham shunday — u konteynerdagi biror elementni ko'rsatadi va keyingisiga o'ta oladi. U ko'rsatkichga (7-modul) juda o'xshaydi:

| Ifoda | Ma'nosi |
|---|---|
| `c.begin()` | Birinchi elementni ko'rsatadi |
| `c.end()` | Oxirgi elementdan **keyingi** joyni ko'rsatadi (chegara belgisi) |
| `*it` | Iterator ko'rsatayotgan element |
| `++it` | Keyingi elementga o'tish |

```cpp
#include <iostream>
#include <vector>
#include <algorithm>
using namespace std;

int main() {
    vector<int> sonlar = {42, 7, 19, 3, 25};

    // Iterator bilan yurish
    for (auto it = sonlar.begin(); it != sonlar.end(); ++it) {
        cout << *it << " ";
    }
    cout << endl;

    // STL algoritmlari iteratorlar bilan ishlaydi
    sort(sonlar.begin(), sonlar.end());
    reverse(sonlar.begin(), sonlar.end());
    for (int s : sonlar) cout << s << " ";          // qisqa usul
    cout << endl;
    cout << "Eng kattasi: " << *max_element(sonlar.begin(), sonlar.end()) << endl;
    return 0;
}
```

```output
42 7 19 3 25 
42 25 19 7 3 
Eng kattasi: 42
```

!fakt Iteratorlarning siri shundaki, bitta algoritm (masalan, `sort` yoki `find`) **istalgan konteyner** bilan ishlay oladi. Algoritm konteyner ichida nima borligini bilmaydi — u faqat iteratorlar bilan "gaplashadi". Bu abstraksiyaning ajoyib namunasi!

### Qaysi konteynerni tanlash kerak?

| Vazifa | Konteyner |
|---|---|
| Oddiy ro'yxat, indeks bo'yicha murojaat | `vector` (ko'p hollarda eng yaxshi tanlov) |
| Takrorlanmas elementlar, tez "bormi?" tekshiruvi | `set` |
| Kalit bo'yicha qiymat topish (lug'at) | `map` |
| Bekor qilish (Undo), qavslarni tekshirish | `stack` |
| Navbat, vazifalar ketma-ketligi | `queue` |
| Eng muhim/eng katta elementni tez olish | `priority_queue` |
| Ikki uchidan qo'shish-olish | `deque` |
| O'rtaga tez-tez qo'shish/o'chirish | `list` |

!maslahat Qaysi konteynerni tanlashni bilmasang — `vector` ni tanla. U eng tez va eng ko'p ishlatiladigan konteyner.

### Ichkarida nima bo'ladi?

Har bir konteyner ichkarida turli **ma'lumotlar tuzilmasi**dan foydalanadi:

| Konteyner | Ichki tuzilma |
|---|---|
| `vector` | Xotirada ketma-ket joylashgan dinamik massiv |
| `list` | Bir-biriga ko'rsatkichlar bilan bog'langan tugunlar |
| `deque` | Kichik massivlar bo'laklari |
| `set`, `map` | Muvozanatlangan ikkilik qidiruv daraxti ("qizil-qora daraxt") |
| `unordered_set/map` | Xesh-jadval |

Shuning uchun ularning tezligi har xil amallar uchun farq qiladi. Bu haqda kitob oxiridagi algoritmlar modulida batafsil gaplashamiz.

### Boshqa tillarda

| C++ STL | Python | Java | JavaScript |
|---|---|---|---|
| `vector` | `list` | `ArrayList` | `Array` |
| `set` | `set` | `TreeSet` / `HashSet` | `Set` |
| `map` | `dict` | `TreeMap` / `HashMap` | `Map` / obyekt |
| `stack` | `list` (`append`/`pop`) | `Stack` / `ArrayDeque` | `Array` (`push`/`pop`) |
| `queue` | `collections.deque` | `Queue` / `LinkedList` | `Array` (`push`/`shift`) |

Konteyner tushunchalari barcha tillarda bir xil — faqat nomlari farq qiladi. STL ni bilsang, boshqa tillarning kolleksiyalarini darhol tushunasan!

### O'zingni tekshir

1. STL qanday uchta asosiy qismdan iborat?
2. Konteynerlarning qanday uch guruhi bor?
3. `end()` qayerni ko'rsatadi?
4. Agar qaysi konteynerni tanlashni bilmasang, qaysi birini tanlash tavsiya etiladi?

### Xulosa

- STL — konteynerlar, iteratorlar va algoritmlardan iborat tayyor kutubxona.
- Konteynerlar ketma-ket, assotsiativ va adapterlarga bo'linadi.
- Iteratorlar konteyner elementlari bo'ylab yuradi va algoritmlarni konteynerlar bilan bog'laydi.
- Ko'p hollarda eng yaxshi tanlov — `vector`.

## C++ da vector

!img c_vector.png | vector — o'sib boradigan poyezd | 6.2

**Bu mavzuda nimani bilib olasan:**

- `vector` yaratish va unga element qo'shish/o'chirishni;
- elementlarga murojaat qilish usullarini;
- `size` va `capacity` farqini;
- ikki o'lchovli `vector` ni.

### Umumiy ma'lumot

`vector` — o'lchami avtomatik o'zgaradigan massiv. U oddiy massivning barcha afzalliklariga (tez murojaat, ketma-ket joylashuv) ega, lekin kamchiliklari yo'q: o'lchamini oldindan bilish shart emas, chegarani tekshirish mumkin va xotirani o'zi boshqaradi.

!img m12_vector.png | push_back yangi "vagon" qo'shadi | 6.0

### Asosiy amallar

```cpp
#include <iostream>
#include <vector>
using namespace std;

int main() {
    vector<int> ballar;                  // bo'sh vector
    ballar.push_back(85);                // oxiriga qo'shish
    ballar.push_back(92);
    ballar.push_back(78);
    cout << "Elementlar soni: " << ballar.size() << endl;
    cout << "Birinchisi: " << ballar.front() << ", oxirgisi: " << ballar.back() << endl;

    ballar[1] = 95;                      // o'zgartirish
    ballar.pop_back();                   // oxirgisini o'chirish
    ballar.insert(ballar.begin(), 100);  // boshiga qo'yish

    for (int b : ballar) cout << b << " ";
    cout << endl;
    cout << "Bo'shmi? " << (ballar.empty() ? "ha" : "yo'q") << endl;
    ballar.clear();                      // hammasini o'chirish
    cout << "Tozalangandan keyin: " << ballar.size() << endl;
    return 0;
}
```

```output
Elementlar soni: 3
Birinchisi: 85, oxirgisi: 78
100 85 95 
Bo'shmi? yo'q
Tozalangandan keyin: 0
```

### `vector` yaratish usullari

```cpp
vector<int> a;                    // bo'sh
vector<int> b(5);                 // 5 ta element, hammasi 0
vector<int> c(5, 7);              // 5 ta element, hammasi 7
vector<string> d = {"olma", "nok", "uzum"};   // ro'yxat bilan
vector<int> e(d.size());          // boshqasining o'lchami bilan
```

### Asosiy metodlar jadvali

| Metod | Vazifasi |
|---|---|
| `push_back(x)` | Oxiriga qo'shish |
| `pop_back()` | Oxirgisini o'chirish |
| `size()` | Elementlar soni |
| `empty()` | Bo'shmi? |
| `v[i]` | i-element (tekshiruvsiz, tez) |
| `v.at(i)` | i-element (chegara tekshiriladi) |
| `front()`, `back()` | Birinchi va oxirgi element |
| `insert(it, x)` | Iterator joyiga qo'yish |
| `erase(it)` | Iterator joyidagini o'chirish |
| `clear()` | Hammasini o'chirish |

### `[]` va `at()` farqi

```cpp
#include <iostream>
#include <vector>
#include <stdexcept>
using namespace std;

int main() {
    vector<int> v = {1, 2, 3};
    try {
        cout << v.at(10) << endl;        // chegaradan tashqari
    } catch (const out_of_range& e) {
        cout << "Xato ushlandi: indeks chegaradan tashqarida" << endl;
    }
    return 0;
}
```

```output
Xato ushlandi: indeks chegaradan tashqarida
```

`v[10]` esa hech narsa tekshirmaydi va xavfli. O'rganish davrida `at()` ishlatish xavfsizroq.

### Ikki o'lchovli `vector`

```cpp
#include <iostream>
#include <vector>
using namespace std;

int main() {
    vector<vector<int>> jadval(3, vector<int>(4, 0));   // 3x4, hammasi 0
    for (int i = 0; i < 3; i++)
        for (int j = 0; j < 4; j++)
            jadval[i][j] = (i + 1) * (j + 1);
    for (const auto& qator : jadval) {
        for (int x : qator) cout << x << "\t";
        cout << endl;
    }
    return 0;
}
```

```output
1	2	3	4
2	4	6	8
3	6	9	12
```

### Ichkarida nima bo'ladi? `size` va `capacity`

`vector` ichida ikki muhim son bor: **size** (nechta element bor) va **capacity** (nechta elementga joy ajratilgan). Joy tugaganda `vector` taxminan **ikki barobar** kattaroq yangi xotira oladi, eski elementlarni u yerga ko'chiradi va eski joyni bo'shatadi:

```cpp
#include <iostream>
#include <vector>
using namespace std;

int main() {
    vector<int> v;
    for (int i = 1; i <= 9; i++) {
        v.push_back(i);
        cout << "size: " << v.size() << ", capacity: " << v.capacity() << endl;
    }
    return 0;
}
```

```output
size: 1, capacity: 1
size: 2, capacity: 2
size: 3, capacity: 4
size: 4, capacity: 4
size: 5, capacity: 8
size: 6, capacity: 8
size: 7, capacity: 8
size: 8, capacity: 8
size: 9, capacity: 16
```

Har safar ikki barobar kattalashgani uchun ko'chirishlar kam bo'ladi va `push_back` o'rtacha juda tez ishlaydi. Agar elementlar soni oldindan ma'lum bo'lsa, `v.reserve(1000);` bilan joyni bir yo'la ajratib qo'yish mumkin.

### Ko'p uchraydigan xatolar

| Xato | Muammo | To'g'risi |
|---|---|---|
| Bo'sh vector da `v[0] = 5;` | Element yo'q — xavfli | `v.push_back(5);` |
| `for (int i = 0; i <= v.size(); i++)` | Oxirgi qadamda chegaradan chiqish | `i < v.size()` |
| Tsikl ichida elementlarni o'chirish | Iteratorlar buziladi | `erase` qaytargan iteratordan foydalan |
| Katta vectorni funksiyaga qiymat bo'yicha berish | Sekin nusxalash | `const vector<int>&` |

### Boshqa tillarda

**Python** (`list`):

```python
ballar = [85, 92]
ballar.append(78)
ballar.pop()
print(len(ballar), ballar)
```

**Java** (`ArrayList`):

```java
ArrayList<Integer> ballar = new ArrayList<>();
ballar.add(85);
System.out.println(ballar.size());
```

| Amal | C++ `vector` | Python `list` | Java `ArrayList` |
|---|---|---|---|
| Qo'shish | `push_back(x)` | `append(x)` | `add(x)` |
| Uzunlik | `size()` | `len(v)` | `size()` |
| Murojaat | `v[i]` | `v[i]` | `get(i)` |

!mashq "Xaridlar ro'yxati" dasturini yoz: foydalanuvchi mahsulot nomlarini kiritsin ("tamom" deb yozguncha). Keyin ro'yxatni alifbo tartibida saralab chiqar va nechta mahsulot borligini ayt.

### O'zingni tekshir

1. `vector` oddiy massivdan nimasi bilan afzal?
2. `push_back` va `pop_back` nima qiladi?
3. `v[i]` va `v.at(i)` ning farqi nimada?
4. `size` va `capacity` ning farqi nimada?

### Xulosa

- `vector` — o'lchami avtomatik o'zgaradigan massiv; STL dagi eng ko'p ishlatiladigan konteyner.
- `push_back` qo'shadi, `pop_back` o'chiradi, `size` elementlar sonini beradi.
- `at()` chegarani tekshiradi, `[]` tekshirmaydi.
- Joy tugaganda vector ikki barobar kattalashadi.

## C++ da list

!img c_list.png | list — halqalar zanjiri | 6.2

**Bu mavzuda nimani bilib olasan:**

- bog'langan ro'yxat (`list`) qanday tuzilganini;
- `list` bilan ishlash metodlarini;
- `list` va `vector` ning farqini.

### Umumiy ma'lumot

Bolalar qo'l ushlashib zanjir hosil qilishgan deb tasavvur qil. Har bir bola faqat o'ng va chap qo'shnisini biladi. Agar zanjir o'rtasiga yangi bola qo'shilmoqchi bo'lsa, faqat ikki qo'shni qo'lini qo'yib yuborib, yangi bolaning qo'lidan ushlaydi — qolganlar joyidan qimirlamaydi!

`list` — **ikki tomonlama bog'langan ro'yxat**. Har bir element (tugun) o'z qiymatidan tashqari oldingi va keyingi elementning manzilini saqlaydi.

!img m12_list.png | Har bir tugun qo'shnilarining manzilini biladi | 6.0

### `list` bilan ishlash

```cpp
#include <iostream>
#include <list>
using namespace std;

int main() {
    list<string> navbat = {"Ali", "Vali", "Laylo"};
    navbat.push_front("Malika");          // boshiga qo'shish
    navbat.push_back("Jasur");            // oxiriga qo'shish

    auto it = navbat.begin();
    ++it; ++it;                           // 3-o'ringa boramiz
    navbat.insert(it, "Sardor");          // o'rtaga qo'shish — tez!

    navbat.remove("Vali");                // qiymat bo'yicha o'chirish
    for (const auto& ism : navbat) cout << ism << " ";
    cout << endl;

    navbat.sort();                        // list ning o'z sort metodi
    navbat.reverse();
    for (const auto& ism : navbat) cout << ism << " ";
    cout << endl;
    return 0;
}
```

```output
Malika Ali Sardor Laylo Jasur 
Sardor Malika Laylo Jasur Ali 
```

### `list` ning maxsus metodlari

| Metod | Vazifasi |
|---|---|
| `push_front(x)`, `pop_front()` | Boshiga qo'shish / boshidan olish |
| `push_back(x)`, `pop_back()` | Oxiriga qo'shish / oxiridan olish |
| `insert(it, x)` | Iterator joyiga qo'shish (tez) |
| `remove(x)` | Barcha `x` qiymatli elementlarni o'chirish |
| `sort()` | Saralash (umumiy `sort` list bilan ishlamaydi!) |
| `unique()` | Ketma-ket takrorlanganlarni o'chirish |
| `reverse()` | Teskari tartibga keltirish |
| `merge(boshqa)` | Ikki saralangan ro'yxatni birlashtirish |

### `list` va `vector`

| | `vector` | `list` |
|---|---|---|
| `v[i]` indeks bo'yicha murojaat | Bor, juda tez | Yo'q (boshidan yurish kerak) |
| Oxiriga qo'shish | Tez | Tez |
| Boshiga yoki o'rtaga qo'shish | Sekin (qolganlarini surish kerak) | Tez |
| Xotira | Ixcham, ketma-ket | Har bir element uchun qo'shimcha 2 ta ko'rsatkich |
| Ko'p hollarda | Tezroq | Faqat o'rtaga ko'p qo'shish/o'chirishda |

!eslatma Zamonaviy kompyuterlarda `vector` ko'pincha `list` dan tezroq ishlaydi, hatto o'rtaga qo'shishda ham — chunki protsessor ketma-ket joylashgan ma'lumotni juda tez o'qiydi. `list` ni faqat haqiqatan kerak bo'lganda ishlat.

### Ichkarida nima bo'ladi?

Har bir tugun xotirada alohida joyda (uyumda) yashaydi va taxminan shunday tuzilmaga ega:

```cpp
struct Tugun {
    string qiymat;
    Tugun* oldingi;     // chap qo'shni
    Tugun* keyingi;     // o'ng qo'shni
};
```

O'rtaga yangi element qo'shish uchun faqat 4 ta ko'rsatkichni o'zgartirish kifoya — qolgan elementlar joyidan qimirlamaydi. Lekin 100-elementga yetish uchun boshidan 99 qadam yurish kerak.

### Ko'p uchraydigan xatolar

| Xato | Muammo | To'g'risi |
|---|---|---|
| `navbat[2]` | `list` da `[]` yo'q | Iterator bilan yur yoki `vector` ishlat |
| `sort(l.begin(), l.end())` | Kompilyatsiya xatosi | `l.sort();` |
| `it + 3` | `list` iteratorlari sakray olmaydi | `advance(it, 3);` |

### Boshqa tillarda

| Til | Bog'langan ro'yxat |
|---|---|
| C++ | `std::list` |
| Java | `LinkedList` |
| C# | `LinkedList<T>` |
| Python | O'rnatilgan yo'q; `collections.deque` ga o'xshash ishlatiladi |

### O'zingni tekshir

1. `list` qanday tuzilgan?
2. `list` da `[]` operatori bormi?
3. `list` ni qaysi holatlarda `vector` dan afzal ko'rish mumkin?
4. `list` ni qanday saralash kerak?

### Xulosa

- `list` — ikki tomonlama bog'langan ro'yxat; har bir tugun qo'shnilarining manzilini saqlaydi.
- Istalgan joyga qo'shish va o'chirish tez, lekin indeks bo'yicha murojaat yo'q.
- `list` ning o'z `sort`, `remove`, `reverse` metodlari bor.
- Ko'p hollarda `vector` tezroq.

## C++ da deque

!img c_deque.png | deque — ikki eshikli vagon | 6.2

**Bu mavzuda nimani bilib olasan:**

- `deque` (ikki tomonlama navbat) nima ekanini;
- uning metodlarini;
- `deque` qachon foydali ekanini.

### Umumiy ma'lumot

`deque` (o'qilishi: "dek", **d**ouble-**e**nded **que**ue — ikki uchli navbat) — boshiga ham, oxiriga ham juda tez element qo'shish va olish mumkin bo'lgan konteyner. U `vector` va `list` ning yaxshi tomonlarini birlashtiradi: indeks bo'yicha murojaat ham bor, boshiga tez qo'shish ham bor.

!img m12_deque.png | deque ikkala uchidan ham ochiq | 6.0

### `deque` bilan ishlash

```cpp
#include <iostream>
#include <deque>
using namespace std;

int main() {
    deque<int> d = {4, 7};
    d.push_back(2);         // oxiriga
    d.push_front(9);        // boshiga
    d.push_front(1);

    cout << "deque: ";
    for (int x : d) cout << x << " ";
    cout << endl;
    cout << "d[2] = " << d[2] << endl;     // indeks bo'yicha murojaat bor!

    d.pop_front();
    d.pop_back();
    cout << "Olingandan keyin: ";
    for (int x : d) cout << x << " ";
    cout << endl;
    return 0;
}
```

```output
deque: 1 9 4 7 2 
d[2] = 4
Olingandan keyin: 9 4 7 
```

### Amaliy misol: "So'nggi ko'rilganlar" ro'yxati

Brauzer yoki ilovalardagi "so'nggi 3 ta ko'rilgan" ro'yxati — `deque` uchun ideal masala: yangisi boshiga qo'shiladi, eng eskisi oxiridan olib tashlanadi:

```cpp
#include <iostream>
#include <deque>
#include <string>
using namespace std;

int main() {
    deque<string> songgi;
    const int MAX = 3;
    string korilgan[] = {"Multfilm", "Ertak", "Musiqa", "O'yin", "Kitob"};
    for (const string& s : korilgan) {
        songgi.push_front(s);
        if (songgi.size() > MAX) songgi.pop_back();
    }
    cout << "So'nggi ko'rilganlar: ";
    for (const auto& s : songgi) cout << s << " | ";
    cout << endl;
    return 0;
}
```

```output
So'nggi ko'rilganlar: Kitob | O'yin | Musiqa | 
```

### Uchta ketma-ket konteynerni taqqoslash

| Amal | `vector` | `deque` | `list` |
|---|---|---|---|
| `[i]` murojaat | Tez | Tez | Yo'q |
| Oxiriga qo'shish | Tez | Tez | Tez |
| Boshiga qo'shish | Sekin | **Tez** | Tez |
| O'rtaga qo'shish | Sekin | Sekin | Tez |

### Ichkarida nima bo'ladi?

`deque` bitta katta massiv emas, balki bir xil o'lchamdagi **kichik massivlar (bloklar)** to'plami va ularni ko'rsatuvchi "xarita"dan iborat. Boshiga element qo'shilsa va birinchi blokda joy qolmasa, oldiga yangi blok qo'shiladi — mavjud elementlarni surish shart emas. Shuning uchun ikkala uchida ham amallar tez.

### Ko'p uchraydigan xatolar

| Xato | Muammo | To'g'risi |
|---|---|---|
| Bo'sh `deque` da `pop_front()` | Aniqlanmagan xatti-harakat | Avval `empty()` ni tekshir |
| `deque` elementlari xotirada ketma-ket deb o'ylash | Bloklarga bo'lingan | Ketma-ketlik kerak bo'lsa — `vector` |

### Boshqa tillarda

**Python** (`collections.deque`):

```python

d.appendleft(9)
d.append(2)
print(d)            # deque([9, 4, 7, 2])
```

**Java:** `ArrayDeque<Integer> d = new ArrayDeque<>(); d.addFirst(9); d.addLast(2);`

3. `deque` da indeks bo'yicha murojaat bormi?

### Xulosa

- `deque` — ikki uchidan ham tez qo'shish va olish mumkin bo'lgan konteyner.
- Unda `[]` bilan indeks bo'yicha murojaat ham bor.
- Ichkarida bloklardan iborat, shuning uchun boshiga qo'shish tez.

## C++ da pair

!img c_pair.png | pair — ikki qiymatli quti | 6.2

**Bu mavzuda nimani bilib olasan:**

- `pair` nima ekanini va qanday yaratilishini;
- `first` va `second` bilan ishlashni;
- funksiyadan ikki qiymat qaytarishni;
- `pair` larni saralashni.

### Umumiy ma'lumot

Ba'zan ikki qiymat doim birga yuradi: o'quvchining ismi va bahosi, nuqtaning x va y koordinatasi, so'z va uning tarjimasi. Ular uchun alohida klass yozish ortiqcha. Buning uchun `<utility>` dagi oddiy **`pair`** (juftlik) bor.

!img m12_pair.png | pair ning ikki maydoni: first va second | 5.8

### `pair` yaratish va ishlatish

```cpp
#include <iostream>
#include <utility>
#include <string>
using namespace std;

int main() {
    pair<string, int> oquvchi("Malika", 98);
    cout << oquvchi.first << ": " << oquvchi.second << " ball" << endl;

    auto nuqta = make_pair(3, 5);           // tur avtomatik
    pair<double, double> p = {1.5, 2.5};    // figurali qavs bilan
    cout << "Nuqta: (" << nuqta.first << ", " << nuqta.second << ")" << endl;

}
```

```output
Nuqta: (3, 5)
Yangi ball: 100
```

### Funksiyadan ikki qiymat qaytarish

```cpp
#include <iostream>
#include <vector>
#include <utility>
using namespace std;

pair<int, int> engKichikVaKatta(const vector<int>& v) {
    int mn = v[0], mx = v[0];
    for (int x : v) {
        if (x < mn) mn = x;
        if (x > mx) mx = x;
    }
    return {mn, mx};
}

int main() {
    vector<int> harorat = {12, -3, 25, 8, 17};
    auto [kichik, katta] = engKichikVaKatta(harorat);    // C++17: qismlarga ajratish
    cout << "Eng sovuq: " << kichik << ", eng issiq: " << katta << endl;
    return 0;
}
```

```output
Eng sovuq: -3, eng issiq: 25
```

`auto [kichik, katta] = ...` — **tuzilmani bog'lash** (structured binding). U `pair` ni darhol ikkita nomli o'zgaruvchiga ajratadi.

### `pair` larni saralash

`pair` lar avval `first`, teng bo'lsa `second` bo'yicha taqqoslanadi. Shuning uchun ularni `sort` bilan oson saralash mumkin:

```cpp
#include <iostream>
#include <vector>
#include <algorithm>
using namespace std;

int main() {
    vector<pair<int, string>> natijalar = {{85, "Ali"}, {98, "Malika"}, {85, "Jasur"}, {72, "Vali"}};
    sort(natijalar.rbegin(), natijalar.rend());          // kamayish tartibida
    int joy = 1;
    for (const auto& [ball, ism] : natijalar) {
        cout << joy++ << ". " << ism << " — " << ball << endl;
    }
    return 0;
}
```

```output
1. Malika — 98
2. Jasur — 85
3. Ali — 85
4. Vali — 72
```

!eslatma `rbegin()` va `rend()` — teskari iteratorlar. Ular bilan `sort` kamayish tartibida saralaydi. Ballar teng bo'lganda (85) ismlar ham teskari alifbo bo'yicha tartiblandi.

### Ichkarida nima bo'ladi?

`pair` — juda oddiy shablon struktura, taxminan:

```cpp
template <typename T1, typename T2>
struct pair {
    T1 first;
    T2 second;
};
```

Ya'ni u 8-moduldagi oddiy `struct` va 11-moduldagi shablonlarning birikmasi. Ikkitadan ko'p qiymat uchun `tuple` bor: `tuple<string, int, double>`.

### Ko'p uchraydigan xatolar

| Xato | Muammo | To'g'risi |
|---|---|---|
| `p.first()` | `first` — maydon, metod emas | `p.first` |
| Ko'p qiymatlar uchun ichma-ich `pair` | O'qish qiyin | `tuple` yoki o'z `struct` ing |

**Python** (kortej — tuple):

```python

ism, ball = oquvchi
```

**Java:** maxsus `Pair` yo'q; `Map.entry("Malika", 98)` yoki `record` ishlatiladi.

1. `pair` nima?
2. `pair` ning ikki maydoni qanday nomlanadi?
3. `pair` lar qanday tartibda taqqoslanadi?
4. Ikkitadan ko'p qiymatni birga saqlash uchun nima bor?

### Xulosa

- `pair` ikki qiymatni bitta obyektda saqlaydi: `first` va `second`.

## C++ da set

!img c_set.png | set — takrorlanmas kolleksiya | 6.2

**Bu mavzuda nimani bilib olasan:**

- `set` nima ekanini va uning ikki asosiy xususiyatini;
- element qo'shish, o'chirish va qidirishni;
- `set` dan amaliy masalalarda foydalanishni.

### Umumiy ma'lumot

Marka yig'ayotgan bola bir xil markadan ikkitasini kolleksiyaga qo'ymaydi. Va u markalarni albomga tartib bilan joylaydi.

`set` (to'plam) ham shunday ikki xususiyatga ega:

1. **Har bir element faqat bir marta** saqlanadi (takrorlanmaydi).
2. Elementlar **avtomatik saralanadi**.

!img m12_set.png | Takrorlanganlar olib tashlandi, qolgani saralandi | 5.8

### `set` bilan ishlash

```cpp
#include <iostream>
#include <set>
using namespace std;

int main() {
    set<int> s = {5, 2, 8, 2, 5, 1};      // takrorlanganlar avtomatik olib tashlanadi
    s.insert(4);
    s.insert(8);                          // 8 allaqachon bor — hech narsa o'zgarmaydi

    cout << "set: ";
    for (int x : s) cout << x << " ";
    cout << endl;
    cout << "Elementlar soni: " << s.size() << endl;

    if (s.count(4)) cout << "4 to'plamda bor" << endl;
    if (s.find(7) == s.end()) cout << "7 to'plamda yo'q" << endl;

    s.erase(2);
    cout << "2 o'chirildi: ";
    for (int x : s) cout << x << " ";
    cout << endl;
    return 0;
}
```

```output
set: 1 2 4 5 8 
Elementlar soni: 5
4 to'plamda bor
7 to'plamda yo'q
2 o'chirildi: 1 4 5 8 
```

### Asosiy metodlar

| Metod | Vazifasi |
|---|---|
| `insert(x)` | Qo'shish (agar yo'q bo'lsa) |
| `erase(x)` | O'chirish |
| `count(x)` | Bor bo'lsa 1, yo'q bo'lsa 0 |
| `find(x)` | Iterator (yo'q bo'lsa — `end()`) |
| `size()`, `empty()` | O'lcham, bo'shmi? |
| `begin()`, `rbegin()` | Eng kichik va eng katta element |

### Amaliy misol: matndagi noyob so'zlar

```cpp

#include <set>
#include <sstream>
#include <string>
using namespace std;

int main() {
    string matn = "olma nok olma uzum nok anor olma";
    set<string> sozlar;
    stringstream ss(matn);
    string soz;
    while (ss >> soz) sozlar.insert(soz);

    cout << "Noyob so'zlar (" << sozlar.size() << " ta): ";
    for (const auto& w : sozlar) cout << w << " ";
    cout << endl;
    return 0;
}
```

```output
Noyob so'zlar (4 ta): anor nok olma uzum 
```

### Ichkarida nima bo'ladi? Ikkilik qidiruv daraxti

`set` ichkarida **muvozanatlangan ikkilik qidiruv daraxti**dan foydalanadi. Har bir tugunning chap tomonida kichikroq, o'ng tomonida kattaroq qiymatlar turadi. Element qidirilganda har qadamda yarmi chetga tashlanadi — xuddi "o'yladim son topish" o'yinida "kattami-kichikmi?" deb so'ragandek!

Natijada 1 000 000 ta elementli `set` da ham biror elementni taxminan 20 ta qadamda topish mumkin. `vector` da esa eng yomon holatda 1 000 000 ta qadam kerak bo'lardi.

!fakt Agar tartib muhim bo'lmasa va tezlik juda muhim bo'lsa, `unordered_set` ishlat. U xesh-jadvalga asoslangan va o'rtacha hisobda yanada tezroq — deyarli 1 qadamda topadi!

### Ko'p uchraydigan xatolar

| Xato | Muammo | To'g'risi |
|---|---|---|
| `s[0]` | `set` da indeks yo'q | `*s.begin()` |
| Elementni iterator orqali o'zgartirish | Ruxsat yo'q (tartib buziladi) | O'chirib, yangisini qo'sh |
| Takrorlanishlar kerak bo'lganda `set` | Takrorlanganlar yo'qoladi | `multiset` |

### Boshqa tillarda

**Python:**


| Tez (saralanmagan) | `unordered_set` | `set` | `HashSet` |
| Bormi? | `s.count(x)` | `x in s` | `s.contains(x)` |

4. `set` ichkarida qanday tuzilmadan foydalanadi?

### Xulosa

- `set` — takrorlanmas va avtomatik saralangan elementlar to'plami.

- Ichkarida ikkilik qidiruv daraxti, shuning uchun qidirish juda tez.
- Tartib kerak bo'lmasa — yanada tezroq `unordered_set`.

## C++ da multiset

!img c_multiset.png | multiset — takrorlanishlarga ruxsat bor | 6.2

**Bu mavzuda nimani bilib olasan:**

- `multiset` ning `set` dan farqini;
- takrorlanishlarni sanash va o'chirishni.

### Umumiy ma'lumot

`multiset` — `set` ning "ukasi". U ham elementlarni **avtomatik saralaydi**, lekin **takrorlanishlarga ruxsat beradi**. Masalan, sinfdagi barcha baholar, zar tashlash natijalari, imtihon ballari — bularda bir xil qiymatlar ko'p uchraydi.

### `multiset` bilan ishlash

```cpp
#include <iostream>
#include <set>
using namespace std;

int main() {
    multiset<int> zarlar = {3, 5, 3, 6, 1, 3, 5};
    cout << "Barcha natijalar: ";
    for (int z : zarlar) cout << z << " ";
    cout << endl;

    cout << "3 soni " << zarlar.count(3) << " marta tushdi" << endl;
    cout << "Eng kichik: " << *zarlar.begin() << ", eng katta: " << *zarlar.rbegin() << endl;

    zarlar.erase(zarlar.find(3));     // faqat BITTA 3 ni o'chiradi
    cout << "Bitta 3 o'chirildi: ";
    for (int z : zarlar) cout << z << " ";
    cout << endl;

    zarlar.erase(5);                  // BARCHA 5 larni o'chiradi
    cout << "Barcha 5 lar o'chirildi: ";
    for (int z : zarlar) cout << z << " ";
    cout << endl;
    return 0;
}
```

```output
Barcha natijalar: 1 3 3 3 5 5 6 
3 soni 3 marta tushdi
Eng kichik: 1, eng katta: 6
Bitta 3 o'chirildi: 1 3 3 5 5 6 
Barcha 5 lar o'chirildi: 1 3 3 6 
```

!diqqat `erase(qiymat)` shu qiymatli **barcha** elementlarni o'chiradi! Faqat bittasini o'chirish uchun `erase(find(qiymat))` yoz.

### `set` va `multiset`

| | `set` | `multiset` |
|---|---|---|
| Takrorlanishlar | Yo'q | Bor |
| Saralangan | Ha | Ha |
| `count(x)` | 0 yoki 1 | 0, 1, 2, ... |
| `erase(x)` | Bittasini (borini) o'chiradi | Hammasini o'chiradi |

### Amaliy misol: o'rtacha ball (eng past va eng yuqorisisiz)

Sport musobaqalarida hakamlarning eng past va eng yuqori bahosi tashlab yuboriladi:

```cpp
#include <iostream>
#include <set>
using namespace std;

int main() {
    multiset<double> baholar = {9.5, 8.0, 9.0, 9.5, 6.5, 9.0};
    baholar.erase(baholar.begin());                   // eng pastini
    baholar.erase(prev(baholar.end()));               // eng yuqorisini
    double jami = 0;
    for (double b : baholar) jami += b;
    cout << "Yakuniy baho: " << jami / baholar.size() << endl;
    return 0;
}
```

```output
Yakuniy baho: 8.875
```

### Ichkarida nima bo'ladi?

`multiset` ham `set` kabi ikkilik qidiruv daraxtidan foydalanadi, faqat teng elementlarni ham daraxtga qo'yishga ruxsat beradi. Teng elementlar daraxtda yonma-yon joylashadi.

### Boshqa tillarda

| Til | Multiset |
|---|---|
| C++ | `multiset` |
| Python | `collections.Counter` (har bir element necha marta borligini sanaydi) |
| Java | Standart yo'q (`TreeMap<Integer, Integer>` bilan qilinadi) |

**Python:**

```python
from collections import Counter
zarlar = Counter([3, 5, 3, 6, 1, 3, 5])
print(zarlar[3])      # 3
```

### O'zingni tekshir

1. `multiset` va `set` ning farqi nimada?
2. `multiset` da elementlar saralanadimi?
3. `erase(5)` va `erase(find(5))` ning farqi nimada?

### Xulosa

- `multiset` — takrorlanishlarga ruxsat beruvchi saralangan to'plam.
- `count(x)` element necha marta borligini beradi.
- `erase(x)` barcha nusxalarni, `erase(find(x))` faqat bittasini o'chiradi.

## C++ da map

!img c_map.png | map — haqiqiy lug'at | 6.2

**Bu mavzuda nimani bilib olasan:**

- `map` (lug'at) nima ekanini;
- kalit va qiymat tushunchalarini;
- element qo'shish, topish, o'zgartirish va o'chirishni;
- `map` yordamida sanash masalalarini yechishni.

### Umumiy ma'lumot

Lug'atda har bir so'zning (kalitning) ma'nosi (qiymati) bor. So'zni bilsang, uning ma'nosini tez topasan. Telefon kitobchasida ism bo'yicha raqam topiladi, maktab jurnalida o'quvchi ismi bo'yicha baho.

`map` — **kalit → qiymat** juftliklarini saqlaydigan konteyner. Har bir kalit **takrorlanmaydi** va kalitlar avtomatik saralanadi. Kalit bo'yicha qiymatni topish juda tez.

!img m12_map.png | map: har bir kalitga bitta qiymat | 5.8

### `map` bilan ishlash

```cpp
#include <iostream>
#include <map>
#include <string>
using namespace std;

int main() {
    map<string, int> narxlar;
    narxlar["olma"] = 8000;            // qo'shish
    narxlar["banan"] = 15000;
    narxlar["nok"] = 12000;
    narxlar["olma"] = 9000;            // mavjud kalit — qiymat yangilanadi

    cout << "Olma narxi: " << narxlar["olma"] << endl;

    if (narxlar.count("uzum") == 0) {
        cout << "Uzum ro'yxatda yo'q" << endl;
    }
    narxlar.erase("banan");

    cout << "Barcha narxlar:" << endl;
    for (const auto& [meva, narx] : narxlar) {
        cout << "  " << meva << ": " << narx << " so'm" << endl;
    }
    return 0;
}
```

```output
Olma narxi: 9000
Uzum ro'yxatda yo'q
Barcha narxlar:
  nok: 12000 so'm
  olma: 9000 so'm
```

E'tibor ber: `map` ni aylanib chiqqanda kalitlar alifbo tartibida chiqdi. Har bir element — `pair<kalit, qiymat>`.

### Asosiy metodlar

| Metod | Vazifasi |
|---|---|
| `m[k] = v` | Qo'shish yoki yangilash |
| `m[k]` | Qiymatni olish (kalit yo'q bo'lsa — **yaratib yuboradi**!) |
| `m.at(k)` | Qiymatni olish (kalit yo'q bo'lsa — istisno) |
| `m.count(k)` | Kalit bormi? (0 yoki 1) |
| `m.find(k)` | Iterator (yo'q bo'lsa — `end()`) |
| `m.erase(k)` | Kalitni o'chirish |
| `m.size()` | Juftliklar soni |

!diqqat `m["uzum"]` deb o'qishga urinsang va "uzum" kaliti bo'lmasa, `map` uni **0 qiymat bilan yaratib qo'yadi**! Faqat tekshirish kerak bo'lsa, `count` yoki `find` ishlat.

### Klassik masala: harflar va so'zlarni sanash

`map` ning eng mashhur foydalanishi — biror narsani **sanash**:

```cpp
#include <iostream>
#include <map>
#include <string>
using namespace std;

int main() {
    string matn = "assalomu alaykum";
    map<char, int> sanoq;
    for (char c : matn) {
        if (c != ' ') sanoq[c]++;          // yo'q bo'lsa 0 dan boshlanadi — bu yerda foydali!
    }
    for (const auto& [harf, soni] : sanoq) {
        cout << harf << ": " << string(soni, '*') << " (" << soni << ")" << endl;
    }
    return 0;
}
```

```output
a: **** (4)
k: * (1)
l: ** (2)
m: ** (2)
o: * (1)
s: ** (2)
u: ** (2)
y: * (1)
```

### Ichkarida nima bo'ladi?

`map` ham `set` kabi ikkilik qidiruv daraxtidan foydalanadi, faqat daraxt tugunlarida kalitdan tashqari qiymat ham saqlanadi. Tartiblash va qidirish **faqat kalit bo'yicha** amalga oshiriladi. Shuning uchun kalit bo'yicha qidirish juda tez, qiymat bo'yicha qidirish esa hamma elementlarni ko'rib chiqishni talab qiladi.

`unordered_map` esa xesh-jadvaldan foydalanadi: kalitdan maxsus formula yordamida "katak raqami" hisoblanadi va qiymat to'g'ridan-to'g'ri o'sha katakdan olinadi. U tartibni saqlamaydi, lekin odatda tezroq.

### Ko'p uchraydigan xatolar

| Xato | Muammo | To'g'risi |
|---|---|---|
| `if (m["x"] == 0)` tekshirish uchun | Yangi kalit yaratiladi | `if (m.count("x") == 0)` |
| Bitta kalitga ikki qiymat saqlash | Eskisi yangisi bilan almashadi | `multimap` |
| `const map` da `m[k]` | Kompilyatsiya xatosi | `m.at(k)` |

### Boshqa tillarda

**Python** (`dict`):

```python
narxlar = {"olma": 8000, "banan": 15000}
narxlar["nok"] = 12000
for meva, narx in narxlar.items():
    print(meva, narx)
```

**Java** (`HashMap` / `TreeMap`):

```java

narxlar.put("olma", 8000);
System.out.println(narxlar.get("olma"));
```

**JavaScript:**

```javascript

narxlar.set("olma", 8000);
console.log(narxlar.get("olma"));
```

Lug'at tushunchasi dasturlashda shunchalik muhimki, deyarli barcha tillarda u o'rnatilgan holda bor!

### O'zingni tekshir

1. `map` qanday ma'lumotlarni saqlaydi?
2. `map` da kalitlar takrorlanishi mumkinmi?
3. `m[k]` va `m.at(k)` ning farqi nimada?
4. Kalit borligini xavfsiz qanday tekshirish mumkin?

### Xulosa

- `map` — kalit → qiymat juftliklari; kalitlar takrorlanmaydi va saralanadi.
- `m[k] = v` qo'shadi yoki yangilaydi; `count` va `find` tekshiradi.
- `m[k]` mavjud bo'lmagan kalitni yaratib yuboradi — ehtiyot bo'l!
- Sanash masalalari uchun `map` juda qulay.

## C++ da multimap

!img c_multimap.png | multimap — bitta kalitga bir nechta qiymat | 6.2

**Bu mavzuda nimani bilib olasan:**

- `multimap` ning `map` dan farqini;
- bitta kalitga tegishli barcha qiymatlarni topishni.

### Umumiy ma'lumot

Telefon kitobchasida bitta odamning bir nechta raqami bo'lishi mumkin. Yoki dars jadvalida bitta kunda bir nechta fan bor. `map` da bitta kalitga faqat bitta qiymat mos keladi, `multimap` da esa **bitta kalit bir necha marta** takrorlanishi mumkin.

### `multimap` bilan ishlash

```cpp
#include <iostream>
#include <map>
#include <string>
using namespace std;

int main() {
    multimap<string, string> jadval;
    jadval.insert({"Dushanba", "Matematika"});
    jadval.insert({"Dushanba", "Ona tili"});
    jadval.insert({"Seshanba", "Ingliz tili"});
    jadval.insert({"Dushanba", "Informatika"});
    jadval.insert({"Seshanba", "Tarix"});

    cout << "Dushanbadagi darslar soni: " << jadval.count("Dushanba") << endl;

    auto [bosh, oxir] = jadval.equal_range("Dushanba");
    cout << "Dushanba: ";
    for (auto it = bosh; it != oxir; ++it) cout << it->second << "; ";
    cout << endl;

    cout << "\nButun jadval:" << endl;
    for (const auto& [kun, fan] : jadval) cout << "  " << kun << " — " << fan << endl;
    return 0;
}
```

```output
Dushanbadagi darslar soni: 3
Dushanba: Matematika; Ona tili; Informatika; 
 
Butun jadval:
  Dushanba — Matematika
  Dushanba — Ona tili
  Dushanba — Informatika
  Seshanba — Ingliz tili
  Seshanba — Tarix
```

`equal_range(k)` — shu kalitga tegishli barcha elementlarning boshi va oxirini ko'rsatuvchi ikkita iteratorni (`pair` ko'rinishida) qaytaradi.

### `map` va `multimap`

| | `map` | `multimap` |
|---|---|---|
| Kalit takrorlanishi | Yo'q | Bor |
| `m[k]` operatori | Bor | **Yo'q** (qaysi qiymat? — noaniq) |
| Qo'shish | `m[k] = v` yoki `insert` | Faqat `insert` |
| Kalit bo'yicha barcha qiymatlar | Bitta | `equal_range(k)` |

### Ichkarida nima bo'ladi?

`multimap` ham daraxtga asoslangan; bir xil kalitli elementlar daraxtda yonma-yon, **qo'shilgan tartibda** joylashadi. Shuning uchun `equal_range` ularni bir yo'la topib beradi.

### Ko'p uchraydigan xatolar

| Xato | Muammo | To'g'risi |
|---|---|---|
| `mm["Dushanba"]` | `multimap` da `[]` yo'q | `insert` va `equal_range` |
| `erase(kalit)` bilan bitta qiymatni o'chirmoqchi bo'lish | Shu kalitning hammasi o'chadi | Iterator bo'yicha `erase(it)` |

### Boshqa tillarda

Ko'p tillarda maxsus multimap yo'q — o'rniga "kalit → ro'yxat" ishlatiladi:

**Python:**

```python

jadval = defaultdict(list)
jadval["Dushanba"].append("Matematika")
jadval["Dushanba"].append("Ona tili")
```

C++ da ham bu usul mumkin: `map<string, vector<string>>`.

2. `multimap` da `[]` operatori bormi? Nima uchun?
3. Bitta kalitga tegishli barcha qiymatlarni qanday topish mumkin?

### Xulosa

- `multimap` bitta kalitga bir nechta qiymat bog'lashga imkon beradi.
- Unda `[]` yo'q; elementlar `insert` bilan qo'shiladi.
- `count(k)` va `equal_range(k)` bilan bitta kalitning barcha qiymatlari topiladi.

## C++ da stack

!img c_stack.png | stack — likopchalar taxlami | 6.2

**Bu mavzuda nimani bilib olasan:**

- stek (LIFO) tamoyilini;
- `push`, `pop`, `top` amallarini;
- stekning qiziqarli qo'llanishlarini (qavslarni tekshirish, so'zni teskari aylantirish).

### Umumiy ma'lumot

Likopchalar taxlamini, kitoblar ustunini yoki Pringles chipslar qutisini esla: faqat **eng ustidagisini** olish mumkin va yangisini ham faqat **eng ustiga** qo'yasan. Bu tamoyil **LIFO** — "Last In, First Out" — "oxirgi kelgan, birinchi ketadi" deyiladi.

`stack` — aynan shu tamoyilda ishlaydigan konteyner adapteri.

!img m12_stack.png | Faqat eng ustki element bilan ishlanadi | 5.5

### `stack` amallari

| Amal | Vazifasi |
|---|---|
| `push(x)` | Eng ustiga qo'yish |
| `pop()` | Eng ustidagini olib tashlash (qiymat qaytarmaydi!) |
| `top()` | Eng ustidagini ko'rish |
| `empty()` | Bo'shmi? |
| `size()` | Elementlar soni |

```cpp
#include <iostream>
#include <stack>
using namespace std;

int main() {
    stack<string> kitoblar;
    kitoblar.push("Matematika");
    kitoblar.push("Ona tili");
    kitoblar.push("Ingliz tili");
    cout << "Eng ustidagi kitob: " << kitoblar.top() << endl;

    while (!kitoblar.empty()) {
        cout << "Olindi: " << kitoblar.top() << endl;
        kitoblar.pop();
    }
    return 0;
}
```

```output
Eng ustidagi kitob: Ingliz tili
Olindi: Ingliz tili
Olindi: Ona tili
Olindi: Matematika
```

### Klassik masala: qavslar to'g'ri yopilganmi?

Kompilyatorlar kodingdagi qavslarni tekshirish uchun aynan stekdan foydalanadi:

```cpp
#include <iostream>
#include <stack>
#include <string>
using namespace std;

bool qavslarTogrimi(const string& s) {
    stack<char> st;
    for (char c : s) {
        if (c == '(' || c == '[' || c == '{') st.push(c);
        else if (c == ')' || c == ']' || c == '}') {
            if (st.empty()) return false;
            char ochiq = st.top(); st.pop();
            if ((c == ')' && ochiq != '(') || (c == ']' && ochiq != '[') || (c == '}' && ochiq != '{'))
                return false;
        }
    }
    return st.empty();
}

int main() {
    string sinovlar[] = {"{[()]}", "([)]", "((())", "a*(b+c)"};
    for (const auto& s : sinovlar)
        cout << s << " -> " << (qavslarTogrimi(s) ? "to'g'ri" : "noto'g'ri") << endl;
    return 0;
}
```

```output
{[()]} -> to'g'ri
([)] -> noto'g'ri
((()) -> noto'g'ri
a*(b+c) -> to'g'ri
```

### Stek qayerda ishlatiladi?

| Qayerda | Qanday |
|---|---|
| "Bekor qilish" (Ctrl+Z) | Har bir amal stekka qo'yiladi; Ctrl+Z eng oxirgisini qaytaradi |
| Brauzerdagi "Orqaga" tugmasi | Ko'rilgan sahifalar steki |
| Funksiya chaqiruvlari | Chaqiruvlar steki (6-modul, rekursiya) |
| Kalkulyatorlar | Ifodalarni hisoblash |
| Labirintdan chiqish | Bosib o'tilgan yo'lni eslab qolish |

### Ichkarida nima bo'ladi?

`stack` — **adapter**: u o'zi ma'lumot saqlamaydi, ichkarida boshqa konteynerdan (standart holatda `deque`) foydalanadi va unga faqat "eng ustki element" bilan ishlash imkonini beradi. Bu cheklov ataylab qilingan — u xatolardan saqlaydi va kod nima qilayotganini aniq ko'rsatadi.

### Ko'p uchraydigan xatolar

| Xato | Muammo | To'g'risi |
|---|---|---|
| `int x = st.pop();` | `pop()` hech narsa qaytarmaydi | Avval `top()`, keyin `pop()` |
| Bo'sh stekda `top()` yoki `pop()` | Aniqlanmagan xatti-harakat | `empty()` ni tekshir |
| Stek ichidagi elementlarni aylanib chiqish | `stack` da iterator yo'q | Kerak bo'lsa `vector` ishlat |

### Boshqa tillarda

**Python** (oddiy ro'yxat stek sifatida):

```python
st = []
st.append("Matematika")   # push
st.append("Ona tili")
print(st.pop())           # Ona tili
```

**Java:** `Deque<String> st = new ArrayDeque<>(); st.push("A"); st.pop();`

### O'zingni tekshir

1. LIFO nima degani?
2. `pop()` va `top()` ning farqi nimada?
3. Stek hayotda va dasturlashda qayerlarda uchraydi? Ikki misol keltir.

### Xulosa

- `stack` — LIFO tamoyilida ishlaydigan adapter.
- `push` qo'yadi, `top` ko'radi, `pop` olib tashlaydi.
- Qavslarni tekshirish, bekor qilish va funksiya chaqiruvlarida ishlatiladi.

## C++ da queue

!img c_queue.png | queue — adolatli navbat | 6.2

**Bu mavzuda nimani bilib olasan:**

- navbat (FIFO) tamoyilini;
- `push`, `pop`, `front`, `back` amallarini;
- navbatning amaliy qo'llanishini.

### Umumiy ma'lumot

Do'kondagi kassa oldida navbat: kim birinchi kelsa, o'sha birinchi xizmat oladi. Yangi kelganlar navbatning oxiriga turadi. Bu tamoyil **FIFO** — "First In, First Out" — "birinchi kelgan, birinchi ketadi" deyiladi.

`queue` — aynan shu tamoyilda ishlaydigan adapter.

!img m12_queue.png | Navbatning oldi (front) va orqasi (back) | 5.8

### `queue` amallari

| Amal | Vazifasi |
|---|---|
| `push(x)` | Navbat oxiriga qo'shish |
| `pop()` | Navbat boshidagini olib tashlash |
| `front()` | Navbat boshidagini ko'rish |
| `back()` | Navbat oxiridagini ko'rish |
| `empty()`, `size()` | Bo'shmi? Nechta? |

```cpp
#include <iostream>
#include <queue>
#include <string>
using namespace std;

int main() {
    queue<string> navbat;
    navbat.push("Ali");
    navbat.push("Malika");
    navbat.push("Jasur");
    cout << "Navbatda " << navbat.size() << " kishi. Birinchi: " << navbat.front()
         << ", oxirgi: " << navbat.back() << endl;

    int raqam = 1;
    while (!navbat.empty()) {
        cout << raqam++ << ". " << navbat.front() << " xizmat oldi" << endl;
        navbat.pop();
    }
    return 0;
}
```

```output
Navbatda 3 kishi. Birinchi: Ali, oxirgi: Jasur
1. Ali xizmat oldi
2. Malika xizmat oldi
3. Jasur xizmat oldi
```

### Amaliy misol: "Issiq kartoshka" o'yini

Bolalar davra qurib, kartoshkani bir-biriga uzatishadi. Har 3-uzatishda kartoshka kimda qolsa, o'yindan chiqadi. Oxirgi qolgan g'olib:

```cpp
#include <iostream>
#include <queue>
#include <string>
using namespace std;

int main() {
    queue<string> davra;
    for (string ism : {"Ali", "Vali", "Malika", "Laylo", "Jasur"}) davra.push(ism);
    const int QADAM = 3;
    while (davra.size() > 1) {
        for (int i = 1; i < QADAM; i++) {      // kartoshkani uzatamiz
            davra.push(davra.front());
            davra.pop();
        }
        cout << davra.front() << " o'yindan chiqdi" << endl;
        davra.pop();
    }
    cout << "G'olib: " << davra.front() << "!" << endl;
    return 0;
}
```

```output
Malika o'yindan chiqdi
Ali o'yindan chiqdi
Jasur o'yindan chiqdi
Vali o'yindan chiqdi
G'olib: Laylo!
```

### Navbat qayerda ishlatiladi?

| Qayerda | Qanday |
|---|---|
| Printer | Hujjatlar navbat bilan chop etiladi |
| Klaviatura | Bosilgan tugmalar navbatda turadi va tartib bilan qayta ishlanadi |
| Onlayn o'yinlar | O'yinchilar navbati (matchmaking) |
| Xabar almashish | Xabarlar yuborilgan tartibda yetkaziladi |
| Graflarda kenglik bo'yicha qidiruv (BFS) | Eng qisqa yo'lni topish algoritmi |

### Ichkarida nima bo'ladi?

`queue` ham adapter: standart holatda ichkarida `deque` ishlatadi, chunki `deque` oxiriga qo'shish va boshidan olishni tez bajaradi. `queue` faqat shu ikki amalga ruxsat beradi.

### Ko'p uchraydigan xatolar

| Xato | Muammo | To'g'risi |
|---|---|---|
| `q.top()` | `queue` da `top` yo'q | `q.front()` |
| Bo'sh navbatda `front()` | Aniqlanmagan xatti-harakat | `empty()` tekshir |
| Navbat o'rtasidagi elementga murojaat | Mumkin emas | `deque` ishlat |

### Boshqa tillarda

**Python:**

```python
from collections import deque
navbat = deque(["Ali", "Malika"])
navbat.append("Jasur")       # push
print(navbat.popleft())      # Ali
```

**Java:** `Queue<String> q = new LinkedList<>(); q.offer("Ali"); q.poll();`

### O'zingni tekshir

1. FIFO nima degani?
2. Stek va navbatning farqi nimada?
3. `front()` va `back()` nimani qaytaradi?

### Xulosa

- `queue` — FIFO tamoyilida ishlaydigan adapter.
- `push` oxiriga qo'shadi, `pop` boshidan oladi, `front`/`back` ko'rsatadi.
- Printer, klaviatura, xabarlar va ko'plab algoritmlarda ishlatiladi.

## C++ da priority_queue

!img c_pq.png | Eng muhimi birinchi! | 6.2

**Bu mavzuda nimani bilib olasan:**

- ustuvor navbat nima ekanini;
- `priority_queue` bilan ishlashni;
- eng kichik elementni birinchi chiqarishni;
- o'z ustuvorlik qoidangni berishni.

### Umumiy ma'lumot

Shifoxonaning shoshilinch bo'limida bemorlar kelgan tartibda emas, **holatining og'irligi** bo'yicha qabul qilinadi. Aeroportda biznes-klass yo'lovchilari birinchi chiqariladi. Bunday navbat **ustuvor navbat** (priority queue) deyiladi.

`priority_queue` — har doim **eng katta** (yoki eng muhim) elementni birinchi beradigan adapter.

!img m12_pq.png | priority_queue: top() har doim eng muhimini beradi | 6.0

### `priority_queue` bilan ishlash

```cpp
#include <iostream>
#include <queue>
using namespace std;

int main() {
    priority_queue<int> pq;
    for (int x : {30, 10, 50, 20, 40}) pq.push(x);

    cout << "Eng kattasi: " << pq.top() << endl;
    cout << "Tartib bilan: ";
    while (!pq.empty()) {
        cout << pq.top() << " ";
        pq.pop();
    }
    cout << endl;
    return 0;
}
```

```output
Eng kattasi: 50
Tartib bilan: 50 40 30 20 10 
```

### Eng kichigini birinchi chiqarish

Uchinchi shablon parametri sifatida `greater<int>` berilsa, eng kichik element birinchi chiqadi:

```cpp
#include <iostream>
#include <queue>
#include <vector>
using namespace std;

int main() {
    priority_queue<int, vector<int>, greater<int>> pq;
    for (int x : {30, 10, 50, 20, 40}) pq.push(x);
    while (!pq.empty()) { cout << pq.top() << " "; pq.pop(); }
    cout << endl;
    return 0;
}
```

```output
10 20 30 40 50 
```

### `pair` bilan: shifoxona navbati

```cpp
#include <iostream>
#include <queue>
#include <string>
using namespace std;

int main() {
    priority_queue<pair<int, string>> bemorlar;     // (og'irlik darajasi, ism)
    bemorlar.push({3, "Vali (shamollash)"});
    bemorlar.push({9, "Ali (singan qo'l)"});
    bemorlar.push({5, "Laylo (yuqori harorat)"});
    bemorlar.push({1, "Jasur (tekshiruv)"});

    while (!bemorlar.empty()) {
        auto [daraja, ism] = bemorlar.top();
        cout << "Qabulga: " << ism << " — daraja " << daraja << endl;
        bemorlar.pop();
    }
    return 0;
}
```

```output
Qabulga: Ali (singan qo'l) — daraja 9
Qabulga: Laylo (yuqori harorat) — daraja 5
Qabulga: Vali (shamollash) — daraja 3
Qabulga: Jasur (tekshiruv) — daraja 1
```

### Ichkarida nima bo'ladi? "Uyum" (heap) tuzilmasi

`priority_queue` ichkarida **uyum** (binary heap) deb ataladigan maxsus daraxtdan foydalanadi (bu xotiradagi "heap" bilan bog'liq emas, faqat nomi bir xil). Uyumda har bir ota tugun o'z bolalaridan katta bo'ladi, shuning uchun eng katta element doim tepada turadi.

| Amal | Qadamlar soni (n ta element uchun) |
|---|---|
| `top()` | 1 qadam — tepadagini ko'rish |
| `push()` | Taxminan log₂(n) — yangi element o'z joyiga "suzib chiqadi" |
| `pop()` | Taxminan log₂(n) — tartib qayta tiklanadi |

1 000 000 ta elementda ham `push` va `pop` taxminan 20 qadamda bajariladi!

### Ko'p uchraydigan xatolar

| Xato | Muammo | To'g'risi |
|---|---|---|
| `pq.front()` | `priority_queue` da `front` yo'q | `pq.top()` |
| Eng kichigi birinchi chiqadi deb o'ylash | Standart holatda eng **kattasi** | `greater<T>` qo'sh |
| Elementlarni tartib bilan aylanib chiqmoqchi bo'lish | Iterator yo'q | Birma-bir `top`/`pop` |

### Boshqa tillarda

**Python** (`heapq` — eng kichigi birinchi):

```python
import heapq
pq = []
for x in [30, 10, 50]:
    heapq.heappush(pq, x)
print(heapq.heappop(pq))     # 10
```

**Java:** `PriorityQueue<Integer> pq = new PriorityQueue<>();` (eng kichigi birinchi).

!fakt E'tibor ber: C++ da standart holatda eng **katta**, Python va Java da esa eng **kichik** element birinchi chiqadi. Boshqa tilga o'tganda bu farqni unutma!

### O'zingni tekshir

1. `priority_queue` oddiy `queue` dan nimasi bilan farq qiladi?
2. Standart holatda qaysi element birinchi chiqadi?
3. Eng kichik elementni birinchi chiqarish uchun nima qilish kerak?
4. `priority_queue` ichkarida qanday tuzilmadan foydalanadi?

### Xulosa

- `priority_queue` har doim eng katta (eng muhim) elementni birinchi beradi.
- `greater<T>` bilan eng kichik element birinchi chiqadi.
- `pair` bilan ustuvorlik va ma'lumotni birga saqlash qulay.
- Ichkarida "uyum" (binary heap) daraxti ishlaydi.

## 12-modul uchun mini-loyiha: Sinf jurnali

STL konteynerlarini birlashtirib, kichik "elektron jurnal" yaratamiz:

```cpp
#include <iostream>
#include <map>
#include <vector>
#include <set>
#include <string>
#include <algorithm>
using namespace std;

int main() {
    map<string, vector<int>> jurnal;
    jurnal["Malika"] = {5, 5, 4, 5};
    jurnal["Jasur"]  = {4, 3, 5, 4};
    jurnal["Laylo"]  = {5, 4, 5, 5};
    jurnal["Sardor"] = {3, 4, 3, 4};
    jurnal["Jasur"].push_back(5);              // yangi baho

    vector<pair<double, string>> reyting;
    set<int> barchaBaholar;
    for (const auto& [ism, baholar] : jurnal) {
        double jami = 0;
        for (int b : baholar) { jami += b; barchaBaholar.insert(b); }
        reyting.push_back({jami / baholar.size(), ism});
    }
    sort(reyting.rbegin(), reyting.rend());

    cout << "=== SINF REYTINGI ===" << endl;
    int joy = 1;
    for (const auto& [ortacha, ism] : reyting) {
        cout << joy++ << ". " << ism << " — " << ortacha;
        if (ortacha >= 4.5) cout << "  (a'lochi!)";
        cout << endl;
    }
    cout << "Sinfda qo'yilgan turli baholar: ";
    for (int b : barchaBaholar) cout << b << " ";
    cout << endl;
    return 0;
}
```

```output
=== SINF REYTINGI ===
1. Malika — 4.75  (a'lochi!)
2. Laylo — 4.75  (a'lochi!)
3. Jasur — 4.2
4. Sardor — 3.5
Sinfda qo'yilgan turli baholar: 3 4 5 
```

!mashq Jurnalga qo'shimcha imkoniyatlar qo'sh: (1) har bir fan uchun alohida `map` (masalan, `map<string, map<string, vector<int>>>`); (2) eng ko'p "5" olgan o'quvchini top; (3) foydalanuvchi o'quvchi ismini kiritganda uning barcha baholarini chiqar (ism topilmasa — xabar ber).
