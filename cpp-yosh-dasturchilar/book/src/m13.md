## C++ da lambda ifodalar

!img c_lambdafx.png | Lambda — joyida yoziladigan kichik funksiya | 6.2

**Bu mavzuda nimani bilib olasan:**

- lambda ifoda nima ekanini va uning qismlarini;
- lambdalarni STL algoritmlari bilan ishlatishni;
- tashqi o'zgaruvchilarni "ushlash" (capture) usullarini.

### Umumiy ma'lumot

Ba'zan juda kichik, faqat bir marta kerak bo'ladigan funksiya kerak bo'ladi. Masalan, `sort` ga "kamayish tartibida sarala" deyish uchun. Buning uchun alohida nomli funksiya yozish ortiqcha — xuddi bir marta ishlatish uchun bolg'a sotib olgandek.

**Lambda ifoda** — bu **nomsiz funksiya** bo'lib, u kerakli joyning o'zida yoziladi. Lambdalar C++11 da qo'shilgan va zamonaviy C++ da juda ko'p ishlatiladi.

!img m13_lambda.png | Lambda ifodaning to'rt qismi | 6.0

### Lambda tuzilishi

```cpp
[ushlash](parametrlar) -> qaytish_turi { tana }
```

| Qism | Vazifasi | Majburiymi? |
|---|---|---|
| `[ ]` | Tashqi o'zgaruvchilarni ushlash | Ha (bo'sh bo'lsa ham) |
| `( )` | Parametrlar | Parametr yo'q bo'lsa tushirish mumkin |
| `-> tur` | Qaytish turi | Yo'q (odatda avtomatik aniqlanadi) |
| `{ }` | Funksiya tanasi | Ha |

### Birinchi lambdalar

```cpp
#include <iostream>
using namespace std;

int main() {
    auto salom = []() { cout << "Salom, lambda!" << endl; };
    salom();

    auto kvadrat = [](int x) { return x * x; };
    cout << "7 ning kvadrati: " << kvadrat(7) << endl;

    auto qosh = [](int a, int b) -> int { return a + b; };
    cout << "3 + 4 = " << qosh(3, 4) << endl;

    // Darhol chaqirish
    cout << [](int x) { return x * 10; }(5) << endl;
    return 0;
}
```

```output
Salom, lambda!
7 ning kvadrati: 49
3 + 4 = 7
50
```

### Lambdalar va STL — ajoyib juftlik

Lambdalarning asl kuchi STL algoritmlari bilan ishlaganda ko'rinadi:

```cpp
#include <iostream>
#include <vector>
#include <algorithm>
using namespace std;

int main() {
    vector<int> v = {5, 12, 3, 18, 7, 10};

    sort(v.begin(), v.end(), [](int a, int b) { return a > b; });   // kamayish
    cout << "Kamayish tartibida: ";
    for (int x : v) cout << x << " ";
    cout << endl;

    int juftlar = count_if(v.begin(), v.end(), [](int x) { return x % 2 == 0; });
    cout << "Juft sonlar soni: " << juftlar << endl;

    auto it = find_if(v.begin(), v.end(), [](int x) { return x < 6; });
    cout << "6 dan kichik birinchi son: " << *it << endl;

    for_each(v.begin(), v.end(), [](int& x) { x *= 2; });          // hammasini 2 ga
    cout << "Ikki barobar: ";
    for (int x : v) cout << x << " ";
    cout << endl;
    return 0;
}
```

```output
Kamayish tartibida: 18 12 10 7 5 3 
Juft sonlar soni: 3
6 dan kichik birinchi son: 5
Ikki barobar: 36 24 20 14 10 6 
```

### Ushlash (capture): tashqi o'zgaruvchilardan foydalanish

Lambda o'zi yaratilgan joydagi o'zgaruvchilardan foydalanishi uchun ularni `[ ]` ichida "ushlashi" kerak:

| Yozuv | Ma'nosi |
|---|---|
| `[]` | Hech narsani ushlamaydi |
| `[x]` | `x` ni nusxa sifatida (qiymat bo'yicha) |
| `[&x]` | `x` ni havola orqali (asl o'zgaruvchini o'zgartira oladi) |
| `[=]` | Hammasini nusxa sifatida |
| `[&]` | Hammasini havola orqali |
| `[=, &x]` | Hammasini nusxa, faqat `x` ni havola orqali |

```cpp
#include <iostream>
#include <vector>
#include <algorithm>
using namespace std;

int main() {
    vector<int> ballar = {45, 78, 92, 60, 85, 33};
    int otishBali = 60;                       // tashqi o'zgaruvchi

    int otganlar = count_if(ballar.begin(), ballar.end(),
                            [otishBali](int b) { return b >= otishBali; });
    cout << otganlar << " ta o'quvchi o'tdi" << endl;

    int jami = 0;
    for_each(ballar.begin(), ballar.end(), [&jami](int b) { jami += b; });   // havola orqali
    cout << "Jami ball: " << jami << endl;
    return 0;
}
```

```output
4 ta o'quvchi o'tdi
Jami ball: 393
```

### Ichkarida nima bo'ladi?

Kompilyator har bir lambdani yashirin **klass**ga aylantiradi! Ushlangan o'zgaruvchilar bu klassning maydonlari bo'ladi, lambda tanasi esa maxsus `operator()` metodiga aylanadi. Taxminan:

```cpp
// [otishBali](int b) { return b >= otishBali; }  quyidagiga aylanadi:
class Lambda_123 {
    int otishBali;                      // ushlangan o'zgaruvchi
public:
    Lambda_123(int o) : otishBali(o) {}
    bool operator()(int b) const { return b >= otishBali; }
};
```

Ya'ni lambda — 11-modulda o'rgangan operatorlarni qayta yuklashning qulay ko'rinishi. Shuning uchun lambdalar oddiy funksiyalar kabi tez ishlaydi.

### Ko'p uchraydigan xatolar

| Xato | Muammo | To'g'risi |
|---|---|---|
| Tashqi o'zgaruvchini ushlamasdan ishlatish | `is not captured` xatosi | `[x]` yoki `[&x]` |
| `[x]` bilan ushlab, `x` ni o'zgartirish | Nusxa — o'zgartirib bo'lmaydi | `[&x]` |
| Lambda oxirida `;` ni unutish | Sintaksis xatosi | `auto f = [](){ ... };` |
| Havola orqali ushlangan o'zgaruvchi yo'q bo'lgandan keyin lambdani chaqirish | Xavfli | Uzoq yashaydigan lambdalarda nusxa ishlat |

### Boshqa tillarda

| Til | Lambda |
|---|---|
| C++ | `[](int x) { return x * x; }` |
| Python | `lambda x: x * x` |
| Java | `x -> x * x` |
| JavaScript | `x => x * x` |
| C# | `x => x * x` |

**Python:**

```python
sonlar = [5, 12, 3, 18]
sonlar.sort(key=lambda x: -x)
juftlar = list(filter(lambda x: x % 2 == 0, sonlar))
```

**JavaScript:**

```javascript
const sonlar = [5, 12, 3, 18];
const juftlar = sonlar.filter(x => x % 2 === 0);
```

Lambdalar barcha zamonaviy tillarda bor va dasturchilar ulardan har kuni foydalanishadi!

!mashq O'quvchilar ismlaridan iborat `vector<string>` yarat. Lambda yordamida: (1) ismlarni uzunligi bo'yicha sarala; (2) "a" harfi bilan tugaydigan ismlar sonini top; (3) barcha ismlarni katta harflarga aylantir.

### O'zingni tekshir

1. Lambda ifoda nima?
2. Lambdaning qanday to'rt qismi bor?
3. `[x]` va `[&x]` ning farqi nimada?
4. Kompilyator lambdani ichkarida nimaga aylantiradi?

### Xulosa

- Lambda — kerakli joyning o'zida yoziladigan nomsiz funksiya.
- Tuzilishi: `[ushlash](parametrlar) -> tur { tana }`.
- STL algoritmlari (`sort`, `count_if`, `find_if`, `for_each`) bilan juda qulay.
- `[ ]` orqali tashqi o'zgaruvchilar nusxa yoki havola sifatida ushlanadi.

## C++ da lvalue va rvalue

!img c_lrvalue.png | Ko'chirish nusxalashdan tezroq | 6.2

**Bu mavzuda nimani bilib olasan:**

- lvalue va rvalue nima ekanini;
- rvalue havolalarni (`&&`);
- ko'chirish semantikasi va `std::move` ni;
- nima uchun bu dasturni tezlashtirishini.

### Umumiy ma'lumot

`x = 5 + 3;` ifodasiga qara. Chap tomonda `x` — bu xotirada **joyi** bor, nomli o'zgaruvchi. O'ng tomonda `5 + 3` — bu hisoblash natijasi, **vaqtinchalik** qiymat; u hech qayerda nom bilan saqlanmaydi va ifoda tugashi bilan yo'q bo'ladi.

- **lvalue** (left value — "chap qiymat") — nomi va doimiy manzili bor ifoda. Unga qiymat berish mumkin. Masalan: o'zgaruvchilar, massiv elementlari.
- **rvalue** (right value — "o'ng qiymat") — vaqtinchalik, nomsiz qiymat. Masalan: `5`, `a + b`, funksiya qaytargan vaqtinchalik natija.

!img m13_lrvalue.png | Chap tomonda — joy, o'ng tomonda — qiymat | 6.0

### Oddiy test: `&` bilan manzilini olsa bo'ladimi?

| Ifoda | lvalue/rvalue | Sabab |
|---|---|---|
| `x` | lvalue | `&x` — mumkin |
| `arr[2]` | lvalue | Massiv elementining manzili bor |
| `5` | rvalue | `&5` — mumkin emas |
| `x + 1` | rvalue | Vaqtinchalik natija |
| `string("Salom")` | rvalue | Vaqtinchalik obyekt |

```cpp
int x = 10;
x = 20;          // to'g'ri: x — lvalue
// 20 = x;       // XATO: 20 — rvalue, unga qiymat berib bo'lmaydi
// (x + 1) = 5;  // XATO: x + 1 — rvalue
```

### lvalue havola (`&`) va rvalue havola (`&&`)

| | lvalue havola `T&` | rvalue havola `T&&` |
|---|---|---|
| Nimaga bog'lanadi | lvalue ga | rvalue ga (vaqtinchalik) |
| Misol | `int& r = x;` | `int&& r = 5;` |

```cpp
#include <iostream>
#include <string>
using namespace std;

void tekshir(const string& s) { cout << "lvalue (nomli): " << s << endl; }
void tekshir(string&& s)      { cout << "rvalue (vaqtinchalik): " << s << endl; }

int main() {
    string ism = "Malika";
    tekshir(ism);                   // ism — lvalue
    tekshir(string("Kodi"));        // vaqtinchalik — rvalue
    tekshir(ism + "!");             // birlashtirish natijasi — rvalue
    return 0;
}
```

```output
lvalue (nomli): Malika
rvalue (vaqtinchalik): Kodi
rvalue (vaqtinchalik): Malika!
```

### Nima uchun bu muhim? Ko'chirish semantikasi

Tasavvur qil, do'sting yangi uyga ko'chyapti. Ikki yo'l bor:

1. **Nusxalash:** har bir buyumning aynan nusxasini yasab, yangi uyga qo'yish, eskisini esa tashlab yuborish. Bu juda uzoq va qimmat!
2. **Ko'chirish:** buyumlarni shunchaki eski uydan yangisiga olib o'tish. Tez va oson!

Agar obyekt vaqtinchalik bo'lsa (rvalue), u baribir tez orada yo'q bo'ladi. Uning ichidagi ma'lumotlarni nusxalash o'rniga shunchaki **"o'g'irlab"** olish mumkin. Bu **ko'chirish semantikasi** (move semantics) deyiladi va C++11 dagi eng muhim yangiliklardan biri.

```cpp
#include <iostream>
#include <string>
#include <utility>
using namespace std;

int main() {
    string a = "Juda uzun matn, unda minglab harflar bo'lishi mumkin...";
    string b = a;              // nusxalash: a o'zgarmaydi
    string c = move(a);        // ko'chirish: a ning ichi c ga o'tdi
    cout << "b: " << b << endl;
    cout << "c: " << c << endl;
    cout << "a endi bo'shmi? " << (a.empty() ? "ha" : "yo'q") << endl;
    return 0;
}
```

```output
b: Juda uzun matn, unda minglab harflar bo'lishi mumkin...
c: Juda uzun matn, unda minglab harflar bo'lishi mumkin...
a endi bo'shmi? ha
```

`std::move` hech narsani ko'chirmaydi! U shunchaki lvalue ni rvalue ga "aylantirib", kompilyatorga "bu obyekt endi kerak emas, uning ichini olsang bo'ladi" deb ishora beradi.

### Ko'chirish konstruktori

O'z klassingda ham ko'chirishni qo'llab-quvvatlash mumkin. 11-moduldagi `Sumka` misolini esla:

```cpp
#include <iostream>
#include <utility>
using namespace std;

class Sumka {
    int* narsalar;
    int soni;
public:
    Sumka(int n) : narsalar(new int[n]), soni(n) { cout << "Yaratildi (" << n << ")" << endl; }
    ~Sumka() { delete[] narsalar; }

    Sumka(const Sumka& b) : narsalar(new int[b.soni]), soni(b.soni) {     // nusxalash
        for (int i = 0; i < soni; i++) narsalar[i] = b.narsalar[i];
        cout << "Nusxalandi (sekin)" << endl;
    }
    Sumka(Sumka&& b) noexcept : narsalar(b.narsalar), soni(b.soni) {     // ko'chirish
        b.narsalar = nullptr;     // eski egasidan "olib qo'yamiz"
        b.soni = 0;
        cout << "Ko'chirildi (tez!)" << endl;
    }
};

int main() {
    Sumka a(1000000);
    Sumka b = a;              // nusxalash — million elementni ko'chirib yozish
    Sumka c = move(a);        // ko'chirish — faqat ko'rsatkichni olish
    return 0;
}
```

```output
Yaratildi (1000000)
Nusxalandi (sekin)
Ko'chirildi (tez!)
```

Ko'chirishda million elementli massiv nusxalanmadi — faqat bitta ko'rsatkich o'tkazildi!

### Ichkarida nima bo'ladi?

`vector`, `string`, `unique_ptr` kabi barcha STL vositalari ko'chirish semantikasini qo'llab-quvvatlaydi. Masalan, funksiya katta `vector` qaytarganda yoki `vector` kattalashib, elementlarini yangi joyga o'tkazganda — ular nusxalanmaydi, balki ko'chiriladi. Shuning uchun zamonaviy C++ dasturlari eski kodga nisbatan ancha tez ishlaydi, sen buni sezmasang ham!

### Ko'p uchraydigan xatolar

| Xato | Muammo | To'g'risi |
|---|---|---|
| `move` dan keyin eski obyektni ishlatish | Uning holati noma'lum (odatda bo'sh) | Ko'chirilgan obyektga faqat yangi qiymat ber |
| `const` obyektni `move` qilish | Baribir nusxalanadi | `const` bo'lmagan obyektni ko'chir |
| Ko'chirish konstruktorida eski ko'rsatkichni `nullptr` qilmaslik | Ikki marta o'chirish | `b.ptr = nullptr;` |

### Boshqa tillarda

Bu tushuncha asosan C++ va Rust ga xos. Rust da ko'chirish hatto **standart** xatti-harakat: `let b = a;` dan keyin `a` ni ishlatib bo'lmaydi. Java, Python, C# da obyektlar havola orqali uzatilgani uchun bunday muammo yo'q, lekin buning evaziga axlat yig'uvchi kerak bo'ladi.

### O'zingni tekshir

1. lvalue va rvalue ning farqi nimada?
2. `x + 1` lvalue mi yoki rvalue mi?
3. `std::move` aslida nima qiladi?
4. Ko'chirish nima uchun nusxalashdan tezroq?

### Xulosa

- lvalue — nomi va manzili bor ifoda; rvalue — vaqtinchalik, nomsiz qiymat.
- `T&` lvalue ga, `T&&` rvalue ga bog'lanadi.
- Ko'chirish semantikasi vaqtinchalik obyektlarning ichini nusxalamasdan "olib qo'yadi".
- `std::move` obyektni ko'chirish mumkinligini bildiradi; STL konteynerlari ko'chirishni qo'llab-quvvatlaydi.

## Parallel va past darajali dasturlash

!img c_concurrency.png | Bir nechta oshpaz — tezroq tayyor ovqat | 6.2

**Bu mavzuda nimani bilib olasan:**

- parallel (concurrent) dasturlash nima ekanini;
- C++ da oqimlar (`thread`) yaratishni;
- "poyga holati" muammosi va `mutex` ni;
- past darajali dasturlash va C++ ning bu sohadagi o'rnini.

### Umumiy ma'lumot

Oshxonada bitta oshpaz osh pishirishi uchun avval sabzi to'g'raydi, keyin piyoz, keyin go'sht... Agar uchta oshpaz bo'lsa, ular bir vaqtda turli ishlarni bajarib, ovqatni ancha tez tayyorlashadi.

Zamonaviy kompyuter protsessorlarida bir nechta **yadro** bor — har biri alohida "oshpaz" kabi. **Parallel dasturlash** — dasturning turli qismlarini bir vaqtning o'zida, turli yadrolarda bajarish. Har bir parallel bajariladigan ish **oqim** (thread) deyiladi.

!img m13_threads.png | Uchta oqim bir vaqtda ishlaydi | 6.0

Masalan, o'yinda bir oqim musiqani chaladi, ikkinchisi grafikani chizadi, uchinchisi tugmalar bosilishini kuzatadi.

### Birinchi oqimlar

```cpp
#include <iostream>
#include <thread>
using namespace std;

void sanash(string nom, int n) {
    int yigindi = 0;
    for (int i = 1; i <= n; i++) yigindi += i;
    cout << nom + ": 1 dan " + to_string(n) + " gacha yig'indi = " + to_string(yigindi) + "\n";
}

int main() {
    thread t1(sanash, "1-oqim", 100);     // yangi oqim ishga tushdi
    thread t2(sanash, "2-oqim", 1000);    // yana biri
    t1.join();                            // t1 tugashini kutamiz
    t2.join();                            // t2 tugashini kutamiz
    cout << "Hamma oqimlar tugadi" << endl;
    return 0;
}
```

```output
1-oqim: 1 dan 100 gacha yig'indi = 5050
2-oqim: 1 dan 1000 gacha yig'indi = 500500
Hamma oqimlar tugadi
```

!eslatma Oqimlar bir vaqtda ishlagani uchun ularning natijalari ekranda **har safar boshqa tartibda** chiqishi mumkin! Kompilyatsiya qilishda Linux da `-pthread` bayrog'i kerak bo'lishi mumkin: `g++ dastur.cpp -pthread`.

`join()` — "bu oqim tugashini kut" degani. Agar `main` oqimlarni kutmasdan tugasa, dastur xato bilan to'xtaydi.

### Muammo: poyga holati (race condition)

Ikki oqim bir vaqtda **bitta o'zgaruvchini** o'zgartirsa, muammo yuz beradi. Tasavvur qil: ikki kishi bir vaqtda bitta doskaga yozmoqchi — yozuvlar aralashib ketadi!

`hisob++` amali aslida uch qadamdan iborat: (1) qiymatni o'qi, (2) 1 qo'sh, (3) qaytib yoz. Agar ikki oqim bir vaqtda 1-qadamni bajarsa, ikkalasi ham bir xil eski qiymatni o'qiydi va bitta qo'shish yo'qoladi.

### Yechim: `mutex` (qulf)

`mutex` — xuddi hojatxona eshigidagi qulf kabi: bir vaqtda faqat bitta oqim "ichkariga" kira oladi, qolganlari navbat kutadi:

```cpp
#include <iostream>
#include <thread>
#include <mutex>
#include <vector>
using namespace std;

int hisob = 0;
mutex qulf;

void oshir() {
    for (int i = 0; i < 100000; i++) {
        lock_guard<mutex> q(qulf);    // qulfni oladi; blok tugaganda avtomatik qo'yib yuboradi
        hisob++;
    }
}

int main() {
    vector<thread> oqimlar;
    for (int i = 0; i < 4; i++) oqimlar.emplace_back(oshir);
    for (auto& t : oqimlar) t.join();
    cout << "Natija: " << hisob << " (kutilgan: 400000)" << endl;
    return 0;
}
```

```output
Natija: 400000 (kutilgan: 400000)
```

`lock_guard` — yana RAII! U konstruktorda qulfni oladi va destruktorda avtomatik qo'yib yuboradi. Agar `mutex` ishlatilmasa, natija har safar har xil va 400000 dan kam chiqishi mumkin edi.

Oddiy hisoblagichlar uchun undan ham soddaroq yo'l bor — `atomic<int> hisob;` — u qulfsiz, lekin xavfsiz ishlaydi.

### Parallel dasturlash vositalari

| Vosita | Vazifasi |
|---|---|
| `std::thread` | Yangi oqim yaratish |
| `std::mutex`, `lock_guard` | Umumiy ma'lumotni himoyalash |
| `std::atomic<T>` | Oddiy o'zgaruvchilarni qulfsiz, xavfsiz o'zgartirish |
| `std::async`, `std::future` | Vazifani fonda bajarib, natijasini keyinroq olish |
| `thread_local` | Har bir oqim uchun alohida o'zgaruvchi (9-modul) |

### Past darajali dasturlash

**Past darajali** dasturlash — kompyuter "temiri" (apparat qismi)ga yaqin ishlash: xotira manzillari, bitlar, protsessor registrlari bilan bevosita ishlash. C++ bu sohada juda kuchli, chunki u:

- ko'rsatkichlar orqali xotirani to'g'ridan-to'g'ri boshqarishga (7-modul);
- bitli operatorlar bilan alohida bitlarni o'zgartirishga (4-modul);
- assembler kodini qo'shishga;
- ortiqcha "yashirin" ishlarsiz, maksimal tezlikda ishlashga imkon beradi.

Masalan, mikrokontrollerda chiroqni yoqish uchun ma'lum bir xotira manzilidagi ma'lum bitni 1 qilish kerak:

```cpp
#include <iostream>
#include <bitset>
using namespace std;

int main() {
    unsigned char port = 0b00000000;     // 8 ta chiroq, hammasi o'chiq
    port |= (1 << 3);                    // 3-chiroqni yoqamiz
    port |= (1 << 6);                    // 6-chiroqni yoqamiz
    cout << "Chiroqlar: " << bitset<8>(port) << endl;
    port &= ~(1 << 3);                   // 3-chiroqni o'chiramiz
    cout << "Chiroqlar: " << bitset<8>(port) << endl;
    bool yoniqmi = port & (1 << 6);
    cout << "6-chiroq yoniqmi? " << (yoniqmi ? "ha" : "yo'q") << endl;
    return 0;
}
```

```output
Chiroqlar: 01001000
Chiroqlar: 01000000
6-chiroq yoniqmi? ha
```

Arduino kabi kichik platalarda dasturlar aynan shunday yoziladi!

### Ichkarida nima bo'ladi?

Agar yadrolar oqimlardan kam bo'lsa, operatsion tizim oqimlarni juda tez **almashtirib** turadi — har biriga bir necha millisoniya vaqt beradi. Bu shunchalik tez sodir bo'ladiki, bizga hammasi bir vaqtda ishlayotgandek tuyuladi. Ko'p yadroli protsessorlarda esa oqimlar haqiqatan ham parallel bajariladi.

### Ko'p uchraydigan xatolar

| Xato | Muammo | To'g'risi |
|---|---|---|
| `join()` ni unutish | Dastur `terminate` bilan to'xtaydi | Har bir oqim uchun `join()` |
| Umumiy o'zgaruvchini himoyasiz o'zgartirish | Poyga holati, noto'g'ri natija | `mutex` yoki `atomic` |
| Ikki oqim bir-birining qulfini kutishi | "O'lik qulf" (deadlock) — dastur qotadi | Qulflarni har doim bir xil tartibda ol |

### Boshqa tillarda

| Til | Parallel dasturlash |
|---|---|
| C++ | `std::thread`, `mutex`, `async` |
| Java | `Thread`, `synchronized`, `ExecutorService` |
| Python | `threading`, `multiprocessing`, `asyncio` |
| Go | `go` kalit so'zi (goroutines) — juda oson |
| JavaScript | `async`/`await`, Web Workers |

**Python:**

```python

    print(nom, "ishlayapti")
```

### Xulosa

- Parallel dasturlash — dastur qismlarini bir vaqtda, turli oqimlarda bajarish.
- `std::thread` oqim yaratadi, `join()` uning tugashini kutadi.
- Umumiy ma'lumotlar `mutex` yoki `atomic` bilan himoyalanishi kerak.
- Past darajali dasturlashda C++ xotira va bitlar bilan bevosita ishlash imkonini beradi.

## C++ da new operatori

!img c_newop.png | new operatorining ichki sirlari | 6.2

**Bu mavzuda nimani bilib olasan:**

- `new` operatori aslida qanday ikki ishni bajarishini;
- `new` ning turli shakllarini;
- xotira yetmaganda nima bo'lishini;
- `new` va `malloc` farqini.

### Umumiy ma'lumot

`new` operatori bilan 11-modulda tanishgan edik. Endi uni chuqurroq ko'rib chiqamiz, chunki uning ichida qiziq sirlar bor.

`new` ni restoranga buyurtma berishga o'xshatish mumkin. "Bitta stol va unga osh!" desang, ofitsiant ikki ishni qiladi: (1) bo'sh **stol topadi** va (2) unga **oshni tortadi**. `new` ham ikki ish qiladi:

1. Uyumdan kerakli hajmda **xotira ajratadi** (`operator new` funksiyasi orqali).
2. Shu xotirada obyektni **konstruktor** yordamida yaratadi.

`delete` esa teskari ikki ish qiladi: (1) **destruktorni** chaqiradi, (2) xotirani **qaytaradi**.

### `new` ning shakllari

```cpp
#include <iostream>
#include <string>
using namespace std;

struct Mehmon {
    string ism;
    Mehmon(string i = "Noma'lum") : ism(i) { cout << "  " << ism << " keldi" << endl; }
    ~Mehmon() { cout << "  " << ism << " ketdi" << endl; }
};

int main() {
    cout << "1. Bitta obyekt:" << endl;
    Mehmon* a = new Mehmon("Ali");
    delete a;

    cout << "2. Massiv:" << endl;
    Mehmon* guruh = new Mehmon[2];               // standart konstruktor 2 marta
    delete[] guruh;

    cout << "3. Qiymat bilan initsializatsiya:" << endl;
    int* x = new int(42);
    int* y = new int[3]{10, 20, 30};
    cout << "  *x = " << *x << ", y[2] = " << y[2] << endl;
    delete x;
    delete[] y;
    return 0;
}
```

```output
1. Bitta obyekt:
  Ali keldi
  Ali ketdi
2. Massiv:
  Noma'lum keldi
  Noma'lum keldi
  Noma'lum ketdi
  Noma'lum ketdi
3. Qiymat bilan initsializatsiya:
  *x = 42, y[2] = 30
```

### Xotira yetmasa nima bo'ladi?

Agar `new` kerakli xotirani topa olmasa, u `std::bad_alloc` istisnosini otadi. Uni ushlash mumkin:

```cpp
#include <iostream>
#include <new>
using namespace std;

int main() {
    try {
        long long* juda_katta = new long long[1000000000000LL];   // ~8 terabayt!
        delete[] juda_katta;
    } catch (const bad_alloc& e) {
        cout << "Xotira yetmadi! (" << e.what() << ")" << endl;
    }

    int* p = new (nothrow) int[10];              // istisno o'rniga nullptr qaytaradi
    if (p != nullptr) cout << "Kichik xotira muvaffaqiyatli ajratildi" << endl;
    delete[] p;
    return 0;
}
```

```output
Xotira yetmadi! (std::bad_alloc)
Kichik xotira muvaffaqiyatli ajratildi
```

### Joylashtiruvchi `new` (placement new)

Bu ilg'or usul: obyektni **allaqachon mavjud** xotiraga joylashtirish (yangi xotira olmasdan). U o'yin dvigatellari va tezlik juda muhim bo'lgan dasturlarda ishlatiladi:

```cpp
#include <iostream>
#include <new>
using namespace std;

struct Nuqta {
    int x, y;
    Nuqta(int a, int b) : x(a), y(b) {}
};

int main() {
    alignas(Nuqta) unsigned char joy[sizeof(Nuqta)];   // oldindan tayyorlangan xotira
    Nuqta* n = new (joy) Nuqta(3, 7);                 // xotira olinmaydi, faqat konstruktor
    cout << "(" << n->x << ", " << n->y << ")" << endl;
    n->~Nuqta();                                      // destruktorni qo'lda chaqiramiz
    return 0;
}
```

```output
(3, 7)
```

### `new` va `malloc` taqqoslash

| | `new` (C++) | `malloc` (C) |
|---|---|---|
| Konstruktor chaqiriladimi | Ha | Yo'q |
| Natija turi | To'g'ri tur (`int*`) | `void*` (aylantirish kerak) |
| Hajmni hisoblash | Avtomatik | Qo'lda: `malloc(n * sizeof(int))` |
| Xato bo'lsa | `bad_alloc` istisnosi | `NULL` qaytaradi |
| Qaytarish | `delete` | `free` |
| Qayta yuklash mumkinmi | Ha (`operator new`) | Yo'q |

!diqqat `new` bilan olingan xotirani `free` bilan, `malloc` bilan olinganini `delete` bilan qaytarma — bu aniqlanmagan xatti-harakat!

### Ichkarida nima bo'ladi?

`new Mehmon("Ali")` kompilyator tomonidan taxminan shunday ikki qadamga ajratiladi:

```cpp
void* xotira = operator new(sizeof(Mehmon));     // 1. xotira olish (malloc ga o'xshash)
Mehmon* a = new (xotira) Mehmon("Ali");           // 2. konstruktor (placement new)
```

`operator new` ni o'z klassing uchun qayta yuklash ham mumkin — masalan, xotira qancha ishlatilayotganini kuzatish uchun. Professional o'yin dvigatellari aynan shunday qilib, xotirani o'zlari boshqarishadi.

!maslahat Kundalik dasturlashda `new` ni kam ishlat. `make_unique`, `make_shared` va STL konteynerlari xotirani xavfsiz boshqaradi. `new` ning ichki tuzilishini bilish esa C++ qanday ishlashini chuqur tushunishga yordam beradi.

### Boshqa tillarda

| Til | `new` |
|---|---|
| C++ | Xotira + konstruktor; `delete` bilan qaytariladi |
| Java, C# | Faqat obyekt yaratish; xotirani axlat yig'uvchi tozalaydi |
| JavaScript | `new Klass()` — obyekt yaratish |
| Python | `new` yo'q — `Klass()` deb chaqirish kifoya |

### O'zingni tekshir

1. `new` qanday ikki ishni bajaradi?
2. `delete` qanday tartibda ishlaydi?
3. Xotira yetmasa `new` nima qiladi?
4. `new` va `malloc` ning asosiy farqi nimada?

### Xulosa

- `new` avval xotira ajratadi, keyin konstruktorni chaqiradi; `delete` — teskari tartibda.
- Xotira yetmasa `bad_alloc` istisnosi otiladi (`nothrow` bilan — `nullptr`).
- Placement new obyektni mavjud xotiraga joylashtiradi.
- `new` `malloc` dan farqli ravishda konstruktorni chaqiradi va to'g'ri tur qaytaradi.
