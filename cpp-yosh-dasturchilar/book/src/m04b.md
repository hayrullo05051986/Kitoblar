## UNICODE va ASCII o'rtasidagi farq

### Umumiy ma'lumot

Kompyuter aslida faqat sonlarni tushunadi. Unda qanday qilib harflar, so'zlar va hatto smayliklar saqlanadi? Javob oddiy: **har bir belgiga maxsus raqam beriladi**. Xuddi sinf jurnalida har bir o'quvchining tartib raqami bo'lganidek.

Qaysi belgiga qaysi raqam berilishini belgilovchi "jadval" **kodlash** (inglizcha *encoding*) deb ataladi. Eng mashhur ikki kodlash — **ASCII** va **Unicode**.

!img m4_ascii.png | ASCII va Unicode jadvallaridagi ba'zi belgilar va ularning kodlari | 6.3

### ASCII

**ASCII** (American Standard Code for Information Interchange) 1963-yilda yaratilgan. Unda atigi **128 ta belgi** bor:

- lotin alifbosining katta va kichik harflari (A–Z, a–z),
- raqamlar (0–9),
- tinish belgilari va maxsus belgilar (`!`, `?`, `+`, `@` ...),
- ko'rinmaydigan boshqaruv belgilari (masalan, yangi qator).

| Belgi | ASCII kodi | Belgi | ASCII kodi |
|---|---|---|---|
| `'A'` | 65 | `'a'` | 97 |
| `'B'` | 66 | `'b'` | 98 |
| `'Z'` | 90 | `'z'` | 122 |
| `'0'` | 48 | `' '` (probel) | 32 |
| `'9'` | 57 | `'!'` | 33 |

!fakt Katta va kichik harf kodlari o'rtasidagi farq doim 32 ga teng. Masalan, `'a'` (97) − `'A'` (65) = 32. Dasturchilar bundan harflarni katta-kichikka aylantirishda foydalanishadi.

### C++ da belgining kodini ko'rish

C++ da `char` aslida kichik butun son. Shuning uchun uni `int` ga aylantirsak, belgining kodini ko'ramiz:

```cpp
#include <iostream>
using namespace std;

int main() {
    char harf = 'A';
    cout << harf << " ning kodi: " << int(harf) << endl;

    int kod = 98;
    cout << kod << " kodli belgi: " << char(kod) << endl;

    char kichik = 'm';
    char katta = kichik - 32;
    cout << kichik << " -> " << katta << endl;
    return 0;
}
```

```output
A ning kodi: 65
98 kodli belgi: b
m -> M
```

### Unicode

ASCII ingliz tili uchun yetarli edi. Lekin dunyoda yuzlab tillar bor: kirill, arab, xitoy, yapon yozuvlari, matematik belgilar va smayliklar! 128 ta joy ularga sig'maydi. Shu muammoni hal qilish uchun **Unicode** yaratildi.

Unicode da **bir milliondan ortiq** belgi uchun joy bor. U dunyodagi deyarli barcha yozuvlarni o'z ichiga oladi. Eng muhimi, Unicode ning birinchi 128 ta belgisi aynan ASCII bilan bir xil — ya'ni Unicode ASCII ning kengaytirilgan "katta akasi".

### Unicode qanday saqlanadi: UTF-8, UTF-16, UTF-32

Unicode belgilarini xotirada saqlashning bir nechta usuli bor:

| Kodlash | Bitta belgi uchun joy | Xususiyati |
|---|---|---|
| UTF-8 | 1 dan 4 baytgacha | Eng mashhur; internet sahifalarining aksariyati shu kodlashda |
| UTF-16 | 2 yoki 4 bayt | Windows va Java ichida ko'p ishlatiladi |
| UTF-32 | Doim 4 bayt | Oddiy, lekin ko'p joy egallaydi |

### Taqqoslash

| Xususiyat | ASCII | Unicode |
|---|---|---|
| Belgilar soni | 128 | 1 milliondan ortiq |
| Tillar | Faqat ingliz | Deyarli barcha tillar |
| Bitta belgi hajmi | 7 bit (odatda 1 bayt) | 1–4 bayt |
| Smayliklar | Yo'q | Bor |
| Yaratilgan | 1963 | 1991 |

!eslatma C++ da Unicode belgilar uchun `wchar_t`, `char16_t` va `char32_t` turlari mavjud. Boshlang'ich darajada oddiy `char` va `string` yetarli.

!mashq O'z isming harflarining ASCII kodlarini ekranga chiqaruvchi dastur yoz. Masalan, "ALI" uchun: 65 76 73.

### Xulosa

- Kompyuter belgilarni raqamlar ko'rinishida saqlaydi.
- ASCII — 128 ta belgidan iborat eski va kichik jadval.
- Unicode — dunyoning deyarli barcha yozuvlarini o'z ichiga olgan katta jadval; uning boshi ASCII bilan bir xil.

## C++ da sonning ikkilik ko'rinishi

### Umumiy ma'lumot

Biz kundalik hayotda **o'nlik sanoq sistemasi**dan foydalanamiz: unda 10 ta raqam bor (0 dan 9 gacha). Ehtimol, buning sababi qo'llarimizda 10 ta barmoq borligidir.

Kompyuter esa **ikkilik sanoq sistemasi**da ishlaydi: unda faqat 2 ta raqam bor — **0** va **1**. Nega? Chunki kompyuter ichidagi millionlab kichik "kalitlar" faqat ikki holatda bo'ladi: tok bor (1) yoki tok yo'q (0). Xuddi chiroqni yoqish va o'chirishga o'xshaydi.

!img m4_binary.png | 13 sonining ikkilik ko'rinishi: 1101 | 5.8

### Ikkilik son qanday o'qiladi?

O'nlik sistemada har bir xona 10 marta katta: birlar, o'nlar, yuzlar... Ikkilik sistemada esa har bir xona **2 marta** katta: 1, 2, 4, 8, 16, 32...

`1101` sonini o'nlikka aylantiramiz:

| Xona qiymati | 8 | 4 | 2 | 1 |
|---|---|---|---|---|
| Raqam | 1 | 1 | 0 | 1 |
| Hissasi | 8 | 4 | 0 | 1 |

8 + 4 + 0 + 1 = **13**

### O'nlikdan ikkilikka aylantirish

Sonni ketma-ket 2 ga bo'lib, qoldiqlarni yozib boramiz. Keyin qoldiqlarni **pastdan yuqoriga** o'qiymiz. 13 misolida:

| Bo'linma | 2 ga bo'lish | Qoldiq |
|---|---|---|
| 13 | 13 ÷ 2 = 6 | 1 |
| 6 | 6 ÷ 2 = 3 | 0 |
| 3 | 3 ÷ 2 = 1 | 1 |
| 1 | 1 ÷ 2 = 0 | 1 |

Pastdan yuqoriga o'qiymiz: **1101**.

### C++ da: tsikl yordamida

```cpp
#include <iostream>
#include <string>
using namespace std;

int main() {
    int son = 13;
    string ikkilik = "";
    int n = son;
    while (n > 0) {
        int qoldiq = n % 2;                          // qoldiq: 0 yoki 1
        ikkilik = to_string(qoldiq) + ikkilik;       // oldiga qo'shamiz
        n = n / 2;
    }
    cout << son << " = " << ikkilik << endl;
    return 0;
}
```

```output
13 = 1101
```

### C++ da: tayyor `bitset` yordamida

C++ da buni avtomatik bajaradigan tayyor vosita — `bitset` bor:

```cpp
#include <iostream>
#include <bitset>
using namespace std;

int main() {
    int son = 13;
    bitset<8> b(son);              // 8 xonali ikkilik son
    cout << son << " = " << b << endl;
    cout << "Birlar soni: " << b.count() << endl;
    return 0;
}
```

```output
13 = 00001101
Birlar soni: 3
```

### C++ da ikkilik sonni to'g'ridan-to'g'ri yozish

C++14 dan boshlab sonni ikkilik ko'rinishda yozish mumkin — uning oldiga `0b` qo'yiladi:

```cpp
int x = 0b1101;    // bu 13 ga teng
```

### Bit va bayt

| Atama | Ma'nosi |
|---|---|
| Bit | Bitta ikkilik raqam: 0 yoki 1 |
| Bayt | 8 bit; masalan `00001101` |
| Kilobayt (KB) | 1024 bayt |
| Megabayt (MB) | 1024 KB |
| Gigabayt (GB) | 1024 MB |

!fakt 8 bitli bayt yordamida 0 dan 255 gacha bo'lgan 256 xil sonni yozish mumkin. Kompyuterdagi har bir rangning qizil, yashil va ko'k qismlari aynan shunday 0–255 oralig'idagi sonlar bilan saqlanadi.

!mashq Qog'ozda 5, 10 va 25 sonlarini ikkilikka aylantir. Keyin javobingni `bitset` yordamida dasturda tekshir.

### Xulosa

- Kompyuter faqat 0 va 1 dan iborat ikkilik sistemada ishlaydi.
- Ikkilik sonning har bir xonasi 1, 2, 4, 8, 16... qiymatga ega.
- O'nlikdan ikkilikka o'tish uchun sonni 2 ga bo'lib, qoldiqlarni teskari tartibda yozamiz.
- C++ da `bitset` va `0b` bu ishni osonlashtiradi.

## C++ da turlarni o'zgartirish

### Umumiy ma'lumot

Ba'zan bir turdagi qiymatni boshqa turga aylantirish kerak bo'ladi. Masalan, butun sonni kasr songa yoki kasr sonni butun songa. Buni **turlarni o'zgartirish** (inglizcha *type conversion* yoki *type casting*) deyiladi.

Buni suvni stakanlarga quyishga o'xshatish mumkin: kichik stakandagi suvni katta stakanga quysang, hammasi sig'adi. Lekin katta stakandagi suvni kichik stakanga quysang, bir qismi to'kilib ketishi mumkin.

!img m4_conversion.png | int → double xavfsiz; double → int da kasr qism yo'qoladi | 5.8

### 1. Avtomatik (yashirin) o'zgartirish

Kompilyator ba'zan turlarni o'zi, so'ramasdan o'zgartiradi:

```cpp
#include <iostream>
using namespace std;

int main() {
    int butun = 7;
    double kasr = butun;        // int -> double, avtomatik
    cout << kasr << endl;        // 7

    double narx = 3.99;
    int qism = narx;             // double -> int, kasr qism yo'qoladi!
    cout << qism << endl;        // 3

    double natija = 5 + 2.5;     // 5 avval double ga aylanadi
    cout << natija << endl;      // 7.5
    return 0;
}
```

```output
7
3
7.5
```

!diqqat Kasr son butun songa aylantirilganda **yaxlitlanmaydi**, kasr qismi shunchaki tashlab yuboriladi. 3.99 ham, 3.01 ham 3 ga aylanadi.

### Butun sonlarni bo'lish tuzog'i

Bu boshlovchilar eng ko'p tushadigan tuzoqlardan biri:

```cpp
#include <iostream>
using namespace std;

int main() {
    int a = 7, b = 2;
    cout << a / b << endl;              // 3, 3.5 emas!
    cout << (double)a / b << endl;      // 3.5
    return 0;
}
```

```output
3
3.5
```

Ikkala son ham `int` bo'lganda, natija ham `int` bo'ladi va kasr qismi yo'qoladi. To'g'ri javob olish uchun hech bo'lmaganda bitta sonni `double` ga aylantirish kerak.

### 2. Qo'lda (aniq) o'zgartirish

Dasturchi turni o'zi aniq ko'rsatishi mumkin. Buning bir necha usuli bor:

**C uslubi** (eski usul):

```cpp
double x = 9.8;
int y = (int)x;      // 9
```

**Funksiya uslubi:**

```cpp
int y = int(x);      // 9
```

**`static_cast`** — zamonaviy C++ da tavsiya etilgan usul:

```cpp
int y = static_cast<int>(x);      // 9
```

!maslahat `static_cast` uzunroq yozilsa ham, u xavfsizroq va kodni o'qiyotgan odamga "bu yerda tur ataylab o'zgartirilgan" ekanini aniq ko'rsatadi.

### C++ dagi to'rtta cast operatori

| Operator | Qachon ishlatiladi |
|---|---|
| `static_cast` | Oddiy, mantiqiy o'zgartirishlar (masalan, `double` → `int`) |
| `dynamic_cast` | Klasslar ierarxiyasida xavfsiz o'zgartirish (11-modulda) |
| `const_cast` | `const` xususiyatini olib tashlash (kam ishlatiladi) |
| `reinterpret_cast` | Xotirani butunlay boshqa tur sifatida o'qish (xavfli, juda kam) |

### Yaxlitlash

Agar kasr sonni to'g'ri yaxlitlash kerak bo'lsa, `<cmath>` dagi funksiyalardan foydalan:

```cpp
#include <iostream>
#include <cmath>
using namespace std;

int main() {
    double x = 3.7;
    cout << "round: " << round(x) << endl;   // eng yaqin butun: 4
    cout << "floor: " << floor(x) << endl;   // pastga: 3
    cout << "ceil:  " << ceil(x) << endl;    // yuqoriga: 4
    return 0;
}
```

```output
round: 4
floor: 3
ceil:  4
```

!mashq Foydalanuvchidan uchta baho so'rab (butun sonlar), o'rtacha bahoni kasr son ko'rinishida to'g'ri hisoblab chiqar. Maslahat: butun sonlarni bo'lish tuzog'ini esla!

### Xulosa

- Turlarni o'zgartirish avtomatik (kompilyator tomonidan) yoki qo'lda bo'lishi mumkin.
- Kasr son butun songa aylanganda kasr qismi tashlab yuboriladi.
- Ikkita `int` ni bo'lganda natija ham `int` bo'ladi.
- Zamonaviy C++ da qo'lda o'zgartirish uchun `static_cast` ishlatiladi.

## C++ da operatorlar

### Umumiy ma'lumot

Matematika darsida `+`, `−`, `×`, `÷` kabi belgilardan foydalanasan. C++ da ham shunday belgilar bor, ular **operatorlar** deb ataladi. Operator — qiymatlar ustida biror amal bajaradigan belgi. Operator ishlaydigan qiymatlar esa **operandlar** deyiladi.

`5 + 3` ifodasida `+` — operator, `5` va `3` — operandlar.

!img m4_operators.png | C++ operatorlarining asosiy guruhlari | 6.3

### 1. Arifmetik operatorlar

| Operator | Nomi | Misol | Natija |
|---|---|---|---|
| `+` | Qo'shish | `7 + 3` | `10` |
| `-` | Ayirish | `7 - 3` | `4` |
| `*` | Ko'paytirish | `7 * 3` | `21` |
| `/` | Bo'lish | `7 / 3` | `2` (butun sonlarda) |
| `%` | Qoldiq | `7 % 3` | `1` |

`%` (modul) operatori bo'lishdan qolgan qoldiqni beradi. U juda foydali: masalan, son juftmi yoki toqmi ekanini bilish uchun:

```cpp
#include <iostream>
using namespace std;

int main() {
    int son = 17;
    cout << "17 / 5 = " << 17 / 5 << endl;
    cout << "17 % 5 = " << 17 % 5 << endl;
    cout << "17 juftmi? " << (son % 2 == 0) << endl;   // 0 = yo'q
    return 0;
}
```

```output
17 / 5 = 3
17 % 5 = 2
17 juftmi? 0
```

### 2. O'zlashtirish (qiymat berish) operatorlari

| Operator | Misol | Ma'nosi |
|---|---|---|
| `=` | `x = 5` | x ga 5 ni beramiz |
| `+=` | `x += 3` | `x = x + 3` |
| `-=` | `x -= 3` | `x = x - 3` |
| `*=` | `x *= 3` | `x = x * 3` |
| `/=` | `x /= 3` | `x = x / 3` |
| `%=` | `x %= 3` | `x = x % 3` |

!diqqat `=` va `==` butunlay boshqa narsalar! `=` — qiymat berish ("x ga 5 ni sol"), `==` — taqqoslash ("x 5 ga tengmi?").

### 3. Oshirish va kamaytirish: `++` va `--`

```cpp
int x = 5;
x++;    // x = 6
x--;    // x = 5
```

Ularning ikki shakli bor: **prefiks** (`++x`) va **postfiks** (`x++`). Farqi ular boshqa ifoda ichida ishlatilganda seziladi:

```cpp
#include <iostream>
using namespace std;

int main() {
    int a = 5;
    int b = a++;    // avval b = 5, keyin a = 6
    cout << "a = " << a << ", b = " << b << endl;

    int c = 5;
    int d = ++c;    // avval c = 6, keyin d = 6
    cout << "c = " << c << ", d = " << d << endl;
    return 0;
}
```

```output
a = 6, b = 5
c = 6, d = 6
```

### 4. Taqqoslash operatorlari

Natijasi doim `true` (1) yoki `false` (0):

| Operator | Ma'nosi | Misol | Natija |
|---|---|---|---|
| `==` | Teng | `5 == 5` | `true` |
| `!=` | Teng emas | `5 != 3` | `true` |
| `>` | Katta | `5 > 3` | `true` |
| `<` | Kichik | `5 < 3` | `false` |
| `>=` | Katta yoki teng | `5 >= 5` | `true` |
| `<=` | Kichik yoki teng | `4 <= 3` | `false` |

### 5. Mantiqiy operatorlar

Bir nechta shartni birlashtirish uchun:

| Operator | Nomi | Qachon `true` |
|---|---|---|
| `&&` | VA | Ikkala shart ham rost bo'lsa |
| `\|\|` | YOKI | Kamida bitta shart rost bo'lsa |
| `!` | EMAS | Shart yolg'on bo'lsa (teskarisini beradi) |

Hayotiy misol: "Agar uy vazifasi tayyor **VA** soat 9 dan oshmagan bo'lsa, multfilm ko'rish mumkin."

```cpp
#include <iostream>
using namespace std;

int main() {
    bool vazifaTayyor = true;
    int soat = 8;
    bool mumkin = vazifaTayyor && soat < 9;
    cout << boolalpha;
    cout << "Multfilm ko'rish mumkinmi? " << mumkin << endl;
    cout << "Teskarisi: " << !mumkin << endl;
    return 0;
}
```

```output
Multfilm ko'rish mumkinmi? true
Teskarisi: false
```

### 6. Bitli operatorlar

Bu operatorlar sonlarning ikkilik ko'rinishidagi har bir bit bilan ishlaydi:

| Operator | Nomi | Misol (5 = 0101, 3 = 0011) | Natija |
|---|---|---|---|
| `&` | Bitli VA | `5 & 3` | `1` (0001) |
| `\|` | Bitli YOKI | `5 \| 3` | `7` (0111) |
| `^` | Bitli XOR | `5 ^ 3` | `6` (0110) |
| `~` | Bitli EMAS | `~5` | `-6` |
| `<<` | Chapga surish | `5 << 1` | `10` (1010) |
| `>>` | O'ngga surish | `5 >> 1` | `2` (0010) |

!fakt Sonni chapga 1 bitga surish uni 2 ga ko'paytirishga, o'ngga surish esa 2 ga bo'lishga teng. Kompyuter buni juda tez bajaradi.

### 7. Boshqa operatorlar

| Operator | Vazifasi | Misol |
|---|---|---|
| `sizeof` | Tur yoki o'zgaruvchi o'lchami | `sizeof(int)` |
| `? :` | Shartli (ternar) operator | `x > 0 ? "musbat" : "manfiy"` |
| `,` | Vergul operatori | `a = 1, b = 2;` |
| `&` | Manzilni olish | `&x` |
| `*` | Manzildagi qiymat | `*p` |
| `.` va `->` | Obyekt a'zosiga murojaat | `obj.nom`, `ptr->nom` |
| `::` | Ko'lam operatori | `std::cout` |

Ternar operator — qisqa `if-else`:

```cpp
#include <iostream>
using namespace std;

int main() {
    int baho = 4;
    string natija = (baho >= 3) ? "o'tdi" : "o'tmadi";
    cout << natija << endl;
    return 0;
}
```

```output
o'tdi
```

### Operatorlar ustuvorligi

Matematikadagi kabi, C++ da ham ba'zi amallar boshqalaridan oldin bajariladi. Masalan, `2 + 3 * 4` ifodasida avval ko'paytirish bajariladi va natija `14` bo'ladi.

| Ustuvorlik | Operatorlar |
|---|---|
| Eng yuqori | `()` qavslar, `++`, `--`, `!` |
| ↓ | `*`, `/`, `%` |
| ↓ | `+`, `-` |
| ↓ | `<`, `>`, `<=`, `>=` |
| ↓ | `==`, `!=` |
| ↓ | `&&` |
| ↓ | `\|\|` |
| Eng past | `=`, `+=`, `-=` ... |

!maslahat Ustuvorlik jadvalini yodlash shart emas. Agar shubhang bo'lsa, qavslardan foydalan: `(2 + 3) * 4`. Bu kodni ham o'qishga osonlashtiradi.

!mashq Foydalanuvchi kiritgan son 10 dan katta **va** juft ekanini tekshiruvchi dastur yoz. Natijani `true` yoki `false` ko'rinishida chiqar.

### Xulosa

- Operatorlar qiymatlar ustida amal bajaradi: arifmetik, taqqoslash, mantiqiy, bitli va boshqalar.
- `%` — qoldiq, `==` — taqqoslash, `=` — qiymat berish.
- `x++` va `++x` ifoda ichida turlicha ishlaydi.
- Shubha bo'lsa, qavs qo'y!

## C++ da ifodalar

### Umumiy ma'lumot

**Ifoda** (inglizcha *expression*) — bu operatorlar va operandlarning birikmasi bo'lib, hisoblanganda **bitta qiymat** beradi. `2 + 3` — ifoda, uning qiymati 5. `yosh > 10` ham ifoda, uning qiymati `true` yoki `false`.

Ifodani matematik misolga o'xshatish mumkin: unda sonlar va amallar bor, oxirida esa bitta javob chiqadi.

!img m4_expr.png | (2 + 3) * 4 ifodasining hisoblanish daraxti | 4.8

### Ifodalar turlari

| Turi | Misol | Natija turi |
|---|---|---|
| O'zgarmas ifoda | `5`, `3 + 4` | Doim bir xil qiymat |
| Butun sonli ifoda | `a + b * 2` (a, b — int) | `int` |
| Kasr sonli ifoda | `x / 2.0` | `double` |
| Mantiqiy ifoda | `a > b && b > 0` | `bool` |
| Ko'rsatkichli ifoda | `&x`, `p + 1` | Manzil |
| Bitli ifoda | `a << 2`, `a & b` | Butun son |

### Ifoda qanday hisoblanadi?

Kompyuter ifodani operatorlar ustuvorligi asosida, bosqichma-bosqich hisoblaydi:

```cpp
#include <iostream>
using namespace std;

int main() {
    int natija = 10 + 6 / 2 * 3 - 1;
    // 1-qadam: 6 / 2 = 3
    // 2-qadam: 3 * 3 = 9
    // 3-qadam: 10 + 9 = 19
    // 4-qadam: 19 - 1 = 18
    cout << natija << endl;
    return 0;
}
```

```output
18
```

### Aralash turlardagi ifodalar

Agar ifodada turli turdagi qiymatlar bo'lsa, "kichik" tur avtomatik ravishda "kattaroq" turga aylantiriladi:

```cpp
int a = 5;
double b = 2.0;
double c = a / b;    // a avval 5.0 ga aylanadi, natija 2.5
```

### Mantiqiy ifodalar va "qisqa tutashuv"

`&&` va `||` operatorlarida qiziq xususiyat bor: agar javob birinchi qismdanoq ma'lum bo'lsa, ikkinchi qism umuman hisoblanmaydi.

- `false && ...` — natija baribir `false`, shuning uchun ikkinchi qism tekshirilmaydi.
- `true || ...` — natija baribir `true`, shuning uchun ikkinchi qism tekshirilmaydi.

```cpp
#include <iostream>
using namespace std;

int main() {
    int x = 0;
    // x == 0 bo'lgani uchun 10 / x hisoblanmaydi va xato bo'lmaydi
    if (x != 0 && 10 / x > 1) {
        cout << "Katta" << endl;
    } else {
        cout << "x nolga teng, bo'lib bo'lmaydi" << endl;
    }
    return 0;
}
```

```output
x nolga teng, bo'lib bo'lmaydi
```

!eslatma Nolga bo'lish matematikada ham, C++ da ham mumkin emas. Yuqoridagi "qisqa tutashuv" xususiyati bunday xatoning oldini olishga yordam beradi.

### Ifoda va ko'rsatma farqi

Ifoda — qiymat beradigan narsa. Ko'rsatma — bajariladigan buyruq. Ifodaning oxiriga `;` qo'ysang, u **ifoda ko'rsatmasi**ga aylanadi:

```cpp
x + 1        // ifoda (qiymat beradi, lekin hech qayerga saqlanmaydi)
```

```cpp

using namespace std;

int main() {
    double boy, eni;
    cout << "Bo'yini kirit: ";
    cin >> boy;
    cout << "Enini kirit: ";
    cin >> eni;

    double yuza = boy * eni;
    double perimetr = 2 * (boy + eni);
    bool kvadratmi = (boy == eni);

    cout << "Yuzasi: " << yuza << endl;
    cout << "Perimetri: " << perimetr << endl;
    cout << boolalpha << "Kvadratmi? " << kvadratmi << endl;
    return 0;
}
```

### Xulosa

- Ifoda — hisoblanganda bitta qiymat beradigan operatorlar va operandlar birikmasi.
- Ifodalar operatorlar ustuvorligi bo'yicha hisoblanadi.
- `&&` va `||` "qisqa tutashuv" xususiyatiga ega.
- Ifoda oxiriga `;` qo'yilsa, u ko'rsatmaga aylanadi.
