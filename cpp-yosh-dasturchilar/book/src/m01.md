## C++ kelib chiqishi va falsafasi

### Umumiy ma'lumot

Har bir dasturlash tilining o'z hikoyasi bor. C++ ning hikoyasi 1979-yilda AQShdagi mashhur **Bell Labs** laboratoriyasida boshlangan. U yerda Daniyadan kelgan yosh olim **Bjarne Stroustrup** (Byorne Strausstrup deb o'qiladi) ishlardi. U katta va murakkab dasturlar yozishi kerak edi, lekin o'sha paytdagi tillar unga to'liq yoqmasdi: ba'zilari juda sekin, ba'zilari esa katta loyihalar uchun noqulay edi.

Bjarne o'sha davrning eng tez va kuchli tillaridan biri bo'lgan **C** tilini oldi va unga yangi imkoniyatlar qo'sha boshladi. Eng muhimi, u **klasslar** (sinflar) degan tushunchani qo'shdi. Klasslar yordamida dasturdagi narsalarni hayotdagi buyumlarga o'xshatib tasvirlash mumkin bo'ldi: masalan, "Mashina", "O'quvchi", "O'yin qahramoni" kabi.

!fakt Bjarne Stroustrup hozir ham C++ tilining rivojlanishida faol ishtirok etadi. U C++ haqida bir nechta mashhur kitoblar yozgan.

### C++ dan oldingi tillar

C++ birdaniga paydo bo'lmagan. U bir qator tillar zanjirining davomidir. Har bir yangi til avvalgisidan nimanidir o'rganib, yaxshiroq bo'lishga harakat qilgan.

### "C++" nomi qayerdan kelgan?

Dastlab yangi til **"C with Classes"**, ya'ni "Klassli C" deb atalgan. 1983-yilda unga **C++** degan nom berildi. Bu nom aslida dasturchilarcha hazil!

C tilida `++` belgisi "bittaga oshir" degan ma'noni bildiradi. Masalan, `x++` yozilsa, x ning qiymati bittaga ko'payadi. Demak, **C++** degani "C dan bir pog'ona yuqori", ya'ni "yaxshilangan C" degan ma'noni anglatadi.

```cpp
int x = 5;
x++;        // endi x = 6 bo'ldi
```

### C++ versiyalari

C++ bir marta yaratilib, shundayligicha qolib ketmagan. Mutaxassislar qo'mitasi uni muntazam yangilab boradi. Har bir versiya nomidagi raqam chiqqan yilni bildiradi:

| Versiya | Nima qo'shildi (qisqacha) |
|---|---|
| C++98 | Birinchi rasmiy standart, STL kutubxonasi |
| C++11 | `auto`, lambda ifodalar, aqlli ko'rsatkichlar — juda katta yangilanish |
| C++14, C++17 | Qulayliklar va kichik yaxshilanishlar |
| C++20 | Modullar, konseptlar va boshqa zamonaviy imkoniyatlar |
| C++23 | Eng so'nggi standartlardan biri |

### C++ falsafasi: til qanday qoidalarga asoslangan?

Bjarne Stroustrup C++ ni yaratishda bir nechta asosiy tamoyillarga amal qilgan. Ularni bilsang, C++ dagi ko'p narsalar nima uchun aynan shunday ekanini tushunasan:

1. **Erkinlik.** Dasturchi o'ziga qulay uslubni tanlay oladi: oddiy buyruqlar ketma-ketligimi, klass va obyektlarmi yoki boshqa usulmi.
2. **C bilan do'stlik.** C tilida yozilgan kodning katta qismi C++ da ham ishlaydi. Bu C dasturchilariga yangi tilga o'tishni osonlashtirgan.
3. **Tezlik.** "Ishlatmagan narsang uchun to'lamaysan". Agar biror imkoniyatdan foydalanmasang, u dasturingni sekinlashtirmaydi.
4. **Dasturchiga ishonch.** C++ dasturchiga ko'p narsani o'zi hal qilish imkonini beradi, masalan xotirani qanday ishlatishni. Bu kuchli, lekin ehtiyotkorlikni talab qiladi.
5. **Hamma joyda ishlash.** C++ da yozilgan kod kompyuterda ham, telefonda ham, hatto kir yuvish mashinasidagi kichik kompyuterda ham ishlashi mumkin.

!maslahat C++ ni o'rganish velosiped haydashni o'rganishga o'xshaydi: dastlab biroz qiyin tuyuladi, lekin bir marta o'rganib olsang, boshqa tillar (Java, C#, Python) ancha oson ko'rinadi.

### C++ qayerlarda ishlatiladi?

- **Kompyuter o'yinlari** — mashhur o'yin dvigatellari (masalan, Unreal Engine) C++ da yozilgan.
- **Brauzerlar** — Chrome va Firefox ning katta qismi C++ da.
- **Operatsion tizimlar** — Windows ning ko'p qismlari.
- **Robotlar va qurilmalar** — dronlar, avtomobillar, tibbiy uskunalar.
- **Kosmos** — kosmik kemalar va marsoxodlar dasturlarida ham C++ ishlatiladi.

!mashq Ota-onangdan yoki internetdan o'zing yaxshi ko'rgan biror o'yin qaysi tilda yozilganini so'rab bil. Ehtimol, u C++ bo'lib chiqar!

### Xulosa

- C++ ni 1979-yilda Bjarne Stroustrup Bell Labs da yaratishni boshlagan.
- U C tiliga klasslar va boshqa imkoniyatlar qo'shish orqali paydo bo'lgan.
- "C++" nomi "C dan bir pog'ona yuqori" degan hazilomuz ma'noga ega.
- C++ tez, kuchli va erkin til bo'lib, o'yinlardan tortib kosmik kemalargacha ishlatiladi.

## C va C++ o'rtasidagi farq

### Umumiy ma'lumot

C va C++ — aka-uka kabi. C++ C dan o'sib chiqqan, shuning uchun ular juda o'xshash. Lekin C++ ko'p yangi narsalarni o'rgangan "zamonaviyroq uka". Keling, ularning o'xshash va farqli tomonlarini ko'rib chiqamiz.

!img m1_venn.png | C va C++: umumiy tomonlari va farqlari | 5.8

### Asosiy farq: protsedurali va obyektga yo'naltirilgan uslub

**C** — protsedurali til. Unda dastur "avval buni qil, keyin buni qil" tarzidagi buyruqlar (funksiyalar) ketma-ketligidan iborat bo'ladi. Xuddi ovqat retsepti kabi.

**C++** esa ham protsedurali, ham **obyektga yo'naltirilgan** til. Unda dasturni "obyektlar" — ya'ni o'z xususiyatlari va harakatlariga ega narsalar to'plami sifatida qurish mumkin. Masalan, o'yindagi har bir qahramon alohida obyekt: uning ismi, kuchi bor va u yugura oladi, sakray oladi.

### Bir xil dastur — ikki tilda

Ekranga "Salom, dunyo!" yozuvini chiqaruvchi dasturni ikkala tilda yozib ko'raylik.

C tilida:

```cpp
#include <stdio.h>

int main() {
    printf("Salom, dunyo!\n");
    return 0;
}
```

C++ tilida:

```cpp
#include <iostream>

int main() {
    std::cout << "Salom, dunyo!" << std::endl;
    return 0;
}
```

```output
Salom, dunyo!
```

Ko'rib turganingdek, natija bir xil, lekin yozilishi biroz farq qiladi. C da `printf` funksiyasi, C++ da esa `cout` ishlatiladi.

### Farqlar jadvali

| Xususiyat | C | C++ |
|---|---|---|
| Uslub | Protsedurali | Protsedurali va obyektga yo'naltirilgan |
| Klass va obyektlar | Yo'q | Bor |
| Ekranga chiqarish | `printf()` | `cout` |
| Klaviaturadan o'qish | `scanf()` | `cin` |
| Xotira ajratish | `malloc()`, `free()` | `new`, `delete` |
| Funksiyalarni qayta yuklash | Yo'q | Bor |
| Nomlar fazosi (namespace) | Yo'q | Bor |
| Xatolarni ushlash (exception) | Yo'q | Bor (`try`, `catch`) |
| Tayyor kutubxona (STL) | Yo'q | Bor |
| Fayl kengaytmasi | `.c` | `.cpp` |

### Qaysi biri yaxshiroq?

Bu savol "bolg'a yaxshimi yoki otvyortkami?" degan savolga o'xshaydi. Har birining o'z o'rni bor:

- **C** juda kichik qurilmalar (masalan, mikrokontrollerlar) va operatsion tizim yadrolari uchun ko'p ishlatiladi.
- **C++** katta loyihalar — o'yinlar, dasturlar, brauzerlar uchun qulayroq, chunki klasslar katta kodni tartibli saqlashga yordam beradi.

!eslatma C++ deyarli butun C tilini o'z ichiga oladi. Shuning uchun C++ ni o'rgansang, C ni ham ko'p jihatdan bilib olasan!

!mashq Yuqoridagi jadvaldan uchta farqni tanlab, ularni o'z so'zlaring bilan daftaringga yozib qo'y.

### Xulosa

- C++ C tilidan kelib chiqqan va uning deyarli barcha imkoniyatlarini saqlab qolgan.
- C — protsedurali, C++ esa obyektga yo'naltirilgan dasturlashni ham qo'llaydi.
- C++ da klasslar, `cin`/`cout`, `new`/`delete`, namespace, exception va STL kabi qo'shimcha imkoniyatlar bor.
