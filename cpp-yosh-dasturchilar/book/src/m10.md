### Protsedurali dasturlash

Dastur — bu bir-birini chaqiradigan **funksiyalar** (protseduralar) to'plami. Ma'lumotlar alohida saqlanadi va funksiyalarga uzatiladi. Biz hozirgacha aynan shu uslubda yozdik.

```cpp
#include <iostream>
#include <string>
using namespace std;

// Ma'lumotlar alohida
string ism = "Mosh";
int ochlik = 7;

// Funksiyalar alohida
void ovqatlantir(int& o) { o = 0; }
void holat(const string& i, int o) {
    cout << i << " ochligi: " << o << endl;
}

int main() {
    holat(ism, ochlik);
    ovqatlantir(ochlik);
    holat(ism, ochlik);
    return 0;
}
```

```output
Mosh ochligi: 7
Mosh ochligi: 0
```

Kichik dasturlar uchun bu juda yaxshi. Lekin o'yinda 100 ta mushuk, 50 ta it va 20 ta qush bo'lsa-chi? Yuzlab o'zgaruvchilar va ularni to'g'ri funksiyaga berish — chalkashlik boshlanadi!

### Obyektga yo'naltirilgan dasturlash (OOP)

OOP da dastur **obyektlar** to'plamidan iborat. Har bir obyekt o'z **ma'lumotlari** (xususiyatlari) va **harakatlari** (metodlari)ga ega — xuddi haqiqiy hayotdagi narsalar kabi.

Masalan, mushuk:

- **xususiyatlari:** ismi, rangi, yoshi, ochligi;
- **harakatlari:** miyovlash, ovqatlanish, uxlash, o'ynash.

```cpp
#include <iostream>
#include <string>
using namespace std;

class Mushuk {
public:
    string ism;
    int ochlik;

    void ovqatlan() { ochlik = 0; }
    void holat() { cout << ism << " ochligi: " << ochlik << endl; }
};

int main() {
    Mushuk m1, m2;
    m1.ism = "Mosh";   m1.ochlik = 7;
    m2.ism = "Laylak"; m2.ochlik = 3;
    m1.holat();
    m2.holat();
    m1.ovqatlan();
    m1.holat();
    return 0;
}
```

```output
Mosh ochligi: 7
Laylak ochligi: 3
Mosh ochligi: 0
```

Har bir mushuk o'z ma'lumotini o'zida olib yuradi va `m1.ovqatlan()` faqat birinchi mushukni to'ydiradi. Ikkinchi mushuk yaratish uchun yangi o'zgaruvchilar o'ylab topish shart emas — shunchaki `Mushuk m3;` yoziladi.

### Ichkarida nima bo'ladi?

Qiziq fakt: protsessor OOP haqida hech narsa bilmaydi! Kompilyator klasslarni oddiy tuzilmalar va funksiyalarga aylantiradi. Masalan, `m1.ovqatlan()` chaqiruvi ichkarida taxminan `Mushuk_ovqatlan(&m1)` ko'rinishiga keladi — ya'ni obyektning manzili funksiyaga yashirin tarzda beriladi. Bu yashirin parametr `this` deb ataladi va u haqida shu modulda alohida gaplashamiz.

OOP — bu kompyuter uchun emas, **odamlar uchun** yaratilgan uslub. U katta dasturlarni tushunish va boshqarishni osonlashtiradi.

## C++ da klasslar va obyektlar

!img c_class.png | Klass — qolip, obyekt — pechenye | 6.2

**Bu mavzuda nimani bilib olasan:**

- klass va obyekt nima ekanini;
- klass yaratish, unga maydon va metodlar qo'shishni;
- `public` va `private` kirish modifikatorlarini;
- getter va setter metodlarini.

### Umumiy ma'lumot

Uy qurishdan oldin arxitektor **chizma** chizadi: unda nechta xona, qayerda eshik, qayerda deraza bo'lishi ko'rsatilgan. Chizmaning o'zida yashab bo'lmaydi, lekin uning asosida xohlagancha uy qurish mumkin.

- **Klass** — chizma (shablon). U obyekt qanday xususiyatlar va harakatlarga ega bo'lishini tasvirlaydi.
- **Obyekt** — chizma asosida qurilgan haqiqiy uy. Har bir obyekt o'z qiymatlariga ega.

!img m10_class.png | Bitta klassdan uchta turli obyekt | 6.3

### Klass yaratish

```cpp
class KlassNomi {
public:
    // maydonlar (xususiyatlar)
    // metodlar (harakatlar)
};    // <- nuqtali vergul shart!
```

```cpp
#include <iostream>
#include <string>
using namespace std;

class Oquvchi {
public:
    string ism;          // maydon
    int sinf;            // maydon
    double ortachaBaho;  // maydon

    void tanishtir() {   // metod
        cout << "Men " << ism << ", " << sinf << "-sinfda o'qiyman. "
             << "O'rtacha bahoyim: " << ortachaBaho << endl;
    }
};

int main() {
    Oquvchi a;                // obyekt yaratish
    a.ism = "Malika";
    a.sinf = 6;
    a.ortachaBaho = 4.8;
    a.tanishtir();            // metodni chaqirish

    Oquvchi b{"Jasur", 7, 4.5};   // qisqa usul
    b.tanishtir();
    return 0;
}
```

```output
Men Malika, 6-sinfda o'qiyman. O'rtacha bahoyim: 4.8
Men Jasur, 7-sinfda o'qiyman. O'rtacha bahoyim: 4.5
```

**Nuqta operatori** `.` obyektning maydon va metodlariga murojaat qilish uchun ishlatiladi: `a.ism`, `a.tanishtir()`.

### Kirish modifikatorlari: `public` va `private`

Klass a'zolarini kim ko'ra olishini belgilash mumkin:

| Modifikator | Kim foydalana oladi |
|---|---|
| `public` | Hamma: klass ichidan ham, tashqaridan ham |
| `private` | Faqat klassning o'z metodlari |
| `protected` | Klass va undan meros olgan klasslar (11-modul) |

Nima uchun yashirish kerak? Tasavvur qil, `BankHisobi` klassida `balans` maydoni `public` bo'lsa, istalgan kod `hisob.balans = -1000000;` deb yozib qo'yishi mumkin! Buning oldini olish uchun maydonlar `private` qilinadi va ularga faqat maxsus metodlar orqali xavfsiz murojaat qilinadi. Bu **inkapsulyatsiya** deyiladi.

```cpp
#include <iostream>
using namespace std;

class BankHisobi {
private:
    double balans = 0;          // tashqaridan ko'rinmaydi

public:
    void qoshish(double summa) {
        if (summa > 0) balans += summa;
        else cout << "Noto'g'ri summa!" << endl;
    }
    bool yechish(double summa) {
        if (summa > 0 && summa <= balans) {
            balans -= summa;
            return true;
        }
        cout << "Mablag' yetarli emas!" << endl;
        return false;
    }
    double balansniKorish() const { return balans; }
};

int main() {
    BankHisobi h;
    h.qoshish(50000);
    h.yechish(20000);
    h.yechish(100000);
    h.qoshish(-500);
    // h.balans = 1000000;   // XATO: balans — private
    cout << "Balans: " << h.balansniKorish() << " so'm" << endl;
    return 0;
}
```

```output
Mablag' yetarli emas!
Noto'g'ri summa!
Balans: 30000 so'm
```

### Getter va setter

`private` maydonni o'qish uchun **getter**, o'zgartirish uchun **setter** metodlari yoziladi. Setter ichida qiymatni tekshirish mumkin:

```cpp
#include <iostream>
using namespace std;

class Oquvchi {
private:
    int yosh;
public:
    int getYosh() const { return yosh; }
    void setYosh(int y) {
        if (y >= 6 && y <= 18) yosh = y;
        else cout << "Noto'g'ri yosh: " << y << endl;
    }
};

int main() {
    Oquvchi o;
    o.setYosh(12);
    o.setYosh(150);
    cout << "Yosh: " << o.getYosh() << endl;
    return 0;
}
```

```output
Noto'g'ri yosh: 150
Yosh: 12
```

!eslatma Metod oxiridagi `const` (`int getYosh() const`) — bu metod obyektni o'zgartirmasligini bildiradi. O'qiydigan metodlarga `const` qo'yish yaxshi odat.

### Metodni klassdan tashqarida yozish

Katta klasslarda metodlar odatda klass ichida faqat e'lon qilinadi, tanasi esa tashqarida `::` yordamida yoziladi:

```cpp
class Doira {
public:
    double r;
    double yuza();            // e'lon
};

double Doira::yuza() {        // amalga oshirish
    return 3.14159 * r * r;
}
```

### `struct` va `class` farqi

C++ da `struct` va `class` deyarli bir xil! Yagona farq — standart kirish darajasi:

| | `struct` | `class` |
|---|---|---|
| Standart kirish | `public` | `private` |
| Odatda nima uchun | Oddiy ma'lumotlar to'plami | Murakkab obyektlar |

### Ichkarida nima bo'ladi? Obyekt xotirada

Obyekt xotirada faqat **maydonlar** uchun joy egallaydi. Metodlar esa obyektlar ichida saqlanmaydi — ular hamma obyektlar uchun bitta nusxada, kod hududida turadi. Shuning uchun 1000 ta `Oquvchi` obyekti yaratsang ham, `tanishtir()` funksiyasining kodi xotirada faqat bitta bo'ladi.

```cpp
#include <iostream>
using namespace std;

class Nuqta {
public:
    int x, y;
    void chiz() { cout << "(" << x << ", " << y << ")" << endl; }
    void sur(int dx, int dy) { x += dx; y += dy; }
};

int main() {
    cout << "sizeof(Nuqta) = " << sizeof(Nuqta) << endl;   // faqat 2 ta int
    return 0;
}
```

```output
sizeof(Nuqta) = 8
```

### Ko'p uchraydigan xatolar

| Xato | Muammo | To'g'risi |
|---|---|---|
| Klass oxirida `;` yo'q | Juda chalkash xato xabarlari | `};` |
| `private` maydonga tashqaridan murojaat | `is private within this context` | Getter/setter ishlat |
| `Oquvchi.ism = "Ali";` | Klassga emas, obyektga murojaat qilish kerak | `a.ism = "Ali";` |
| `a.tanishtir;` (qavssiz) | Metod chaqirilmaydi | `a.tanishtir();` |
| Hamma maydonlarni `public` qilish | Himoya yo'q | Maydonlar — `private`, metodlar — `public` |

**Python:**

```python
class Oquvchi:
    def __init__(self, ism, sinf):
        self.ism = ism
        self.sinf = sinf
    def tanishtir(self):
        print(f"Men {self.ism}, {self.sinf}-sinfda o'qiyman")

a = Oquvchi("Malika", 6)
```

**Java:**

```java

```

| | C++ | Java | Python |
|---|---|---|---|
| Klass | `class A { };` | `class A { }` | `class A:` |
| Obyekt | `A a;` | `A a = new A();` | `a = A()` |
| Yopiq maydon | `private:` | `private` | `_nom` (kelishuv bo'yicha) |
| Metod chaqirish | `a.f()` | `a.f()` | `a.f()` |

!mashq `Kitob` klassini yarat: maydonlari — `nom`, `muallif`, `sahifalar` (private), `oqilganSahifa` (private). Metodlari — `oqi(int n)` (n sahifa o'qiydi, sahifalar sonidan oshmasin), `foiz()` (necha foiz o'qilganini qaytaradi), `malumot()` (hammasini chiqaradi).

## C++ da konstruktor va destruktor

!img c_ctor.png | Konstruktor — tug'ilish, destruktor — xayrlashuv | 6.2

**Bu mavzuda nimani bilib olasan:**

- konstruktor nima ekanini va u qachon chaqirilishini;
- standart, parametrli va nusxalash konstruktorlarini;
- initsializatsiya ro'yxatini;
- destruktor va obyektning "hayot yo'li"ni.

### Umumiy ma'lumot

Yangi telefon sotib olganingda, uni birinchi marta yoqqanda u sozlanadi: til, sana, vaqt o'rnatiladi. Telefonni sotib yuborishdan oldin esa undagi shaxsiy ma'lumotlarni o'chirasan.

Obyektlar bilan ham shunday:

- **Konstruktor** — obyekt yaratilayotganda **avtomatik** chaqiriladigan maxsus metod. U obyektni "sozlaydi": maydonlarga boshlang'ich qiymat beradi.
- **Destruktor** — obyekt yo'q qilinayotganda **avtomatik** chaqiriladigan maxsus metod. U "tozalash" ishlarini bajaradi.

!img m10_ctor.png | Obyektning hayot yo'li | 6.0

### Konstruktor qoidalari

1. Nomi klass nomi bilan **bir xil**.
2. Qaytaruvchi turi **yo'q** (hatto `void` ham emas).
3. Obyekt yaratilganda **avtomatik** chaqiriladi.
4. Qayta yuklanishi mumkin (bir nechta konstruktor bo'lishi mumkin).

### 1. Standart konstruktor (parametrsiz)

```cpp
#include <iostream>
#include <string>
using namespace std;

class Robot {
public:
    string ism;
    int quvvat;

    Robot() {                         // standart konstruktor
        ism = "Nomsiz";
        quvvat = 100;
        cout << "Robot yaratildi!" << endl;
    }
};

int main() {
    Robot r;                          // konstruktor avtomatik ishlaydi
    cout << r.ism << ", quvvat: " << r.quvvat << "%" << endl;
    return 0;
}
```

```output
Robot yaratildi!
Nomsiz, quvvat: 100%
```

### 2. Parametrli konstruktor

```cpp
#include <iostream>
#include <string>
using namespace std;

class Robot {
public:
    string ism;
    int quvvat;

    Robot() : ism("Nomsiz"), quvvat(100) {}            // standart
    Robot(string i, int q) : ism(i), quvvat(q) {}      // parametrli

    void holat() { cout << ism << ": " << quvvat << "%" << endl; }
};

int main() {
    Robot r1;
    Robot r2("Kodi", 85);
    Robot r3{"Bit", 40};
    r1.holat();
    r2.holat();
    r3.holat();
    return 0;
}
```

```output
Nomsiz: 100%
Kodi: 85%
Bit: 40%
```

### Initsializatsiya ro'yxati

Yuqoridagi `: ism(i), quvvat(q)` qismi **initsializatsiya ro'yxati** deyiladi. U maydonlarga konstruktor tanasi bajarilishidan **oldin** qiymat beradi. Bu usul:

- tezroq (maydon avval yaratilib, keyin qayta qiymat olmaydi);
- `const` maydonlar va havola maydonlar uchun **majburiy**.

### 3. Nusxalash konstruktori

Obyekt boshqa obyektdan nusxa olib yaratilganda chaqiriladi:

```cpp
#include <iostream>
#include <string>
using namespace std;

class Robot {
public:
    string ism;
    Robot(string i) : ism(i) {}
    Robot(const Robot& boshqa) : ism(boshqa.ism + " (nusxa)") {
        cout << "Nusxalash konstruktori ishladi" << endl;
    }
};

int main() {
    Robot a("Kodi");
    Robot b = a;            // nusxalash konstruktori
    cout << b.ism << endl;
    return 0;
}
```

```output
Nusxalash konstruktori ishladi
Kodi (nusxa)
```

Agar nusxalash konstruktorini o'zing yozmasang, kompilyator avtomatik ravishda barcha maydonlarni nusxalaydigan versiyasini yaratadi. Ko'p hollarda bu yetarli.

### Destruktor

Destruktor nomi klass nomi oldiga to'lqin belgisi `~` qo'yib yoziladi. Uning parametrlari va qaytaruvchi turi yo'q, va har bir klassda faqat bitta bo'ladi:

```cpp
#include <iostream>
#include <string>
using namespace std;

class Shar {
    string rang;
public:
    Shar(string r) : rang(r) { cout << rang << " shar puflandi" << endl; }
    ~Shar() { cout << rang << " shar yorildi" << endl; }
};

int main() {
    Shar a("Qizil");
    {
        Shar b("Ko'k");
        cout << "Ichki blok tugayapti..." << endl;
    }                                 // b shu yerda yo'q bo'ladi
    Shar c("Yashil");
    cout << "main tugayapti..." << endl;
    return 0;
}                                     // c, keyin a yo'q bo'ladi
```

```output
Qizil shar puflandi
Ko'k shar puflandi
Ichki blok tugayapti...
Ko'k shar yorildi
Yashil shar puflandi
main tugayapti...
Yashil shar yorildi
Qizil shar yorildi
```

!fakt E'tibor ber: obyektlar yaratilish tartibiga **teskari** tartibda yo'q qilinadi — oxirgi yaratilgan birinchi o'chiriladi. Bu stek tamoyili ("oxirgi kelgan — birinchi ketadi")!

### Ichkarida nima bo'ladi? RAII — C++ ning sehrli tamoyili

Konstruktor va destruktorning avtomatik chaqirilishi C++ ning eng kuchli g'oyalaridan birini yaratadi: **RAII** (Resource Acquisition Is Initialization — "resursni olish — bu initsializatsiya").

G'oya oddiy: biror resurs (xotira, fayl, tarmoq ulanishi) kerak bo'lsa, uni **konstruktorda** olasan va **destruktorda** qaytarasan. Shunda obyekt yo'q bo'lganda resurs har doim, avtomatik ravishda qaytariladi — hatto xato yuz bersa ham!

7-moduldagi aqlli ko'rsatkichlar, keyinroq ko'radigan `vector`, `string`, `fstream` — hammasi aynan shu tamoyil asosida ishlaydi.

### Ko'p uchraydigan xatolar

| Xato | Muammo | To'g'risi |
|---|---|---|
| `void Robot() { }` | Bu konstruktor emas, oddiy metod | Qaytaruvchi tur yozilmaydi: `Robot() { }` |
| `Robot r();` | Bu funksiya e'loni deb tushuniladi! | `Robot r;` yoki `Robot r{};` |
| Parametrli konstruktor yozib, `Robot r;` deb yaratish | Standart konstruktor endi avtomatik yaratilmaydi | Standart konstruktorni ham yoz |
| Destruktorga parametr berish | Xato | `~Robot()` — parametrsiz |
| Initsializatsiya ro'yxatida maydonlar tartibi | Maydonlar klassda e'lon qilingan tartibda yaratiladi | Ro'yxatni ham shu tartibda yoz |

### Boshqa tillarda

| | C++ | Java | Python | C# |
|---|---|---|---|---|
| Konstruktor | `Robot() { }` | `Robot() { }` | `def __init__(self):` | `Robot() { }` |
| Destruktor | `~Robot() { }` | Yo'q (axlat yig'uvchi) | `def __del__(self):` (kam ishlatiladi) | `~Robot()` (kam ishlatiladi) |

**Python:**

```python
class Robot:
    def __init__(self, ism, quvvat=100):
        self.ism = ism
        self.quvvat = quvvat

r = Robot("Kodi", 85)
```

Java va Python da destruktor deyarli ishlatilmaydi, chunki xotirani axlat yig'uvchi tozalaydi. Lekin u qachon ishlashini aniq bilib bo'lmaydi. C++ da esa destruktor **aniq** vaqtda — obyekt ko'lamdan chiqqanda ishlaydi. Bu C++ ning muhim ustunligi.

!mashq `Taymer` klassini yarat: konstruktor "Taymer boshlandi: [nom]" deb, destruktor "Taymer tugadi: [nom]" deb yozsin. `main` da ichma-ich bloklarda bir nechta taymer yaratib, ular qanday tartibda boshlanib-tugashini kuzat.

### O'zingni tekshir

1. Konstruktor qachon chaqiriladi?
2. Konstruktorning qaytaruvchi turi qanday?
3. Destruktor nomi qanday yoziladi?
4. Initsializatsiya ro'yxati nima va u nima uchun yaxshi?
5. Uchta obyekt ketma-ket yaratilsa, ular qanday tartibda yo'q qilinadi?

### Xulosa

- Konstruktor obyekt yaratilganda avtomatik chaqiriladi va uni sozlaydi.
- Konstruktorlar standart, parametrli va nusxalash turlariga bo'linadi.
- Destruktor (`~Nom()`) obyekt yo'q bo'layotganda avtomatik chaqiriladi.
- Obyektlar yaratilish tartibiga teskari tartibda yo'q qilinadi.
- RAII — resursni konstruktorda olib, destruktorda qaytarish tamoyili.

## C++ da abstraksiya

!img c_abstraction.png | Mashina haydash uchun dvigatelni bilish shart emas | 6.2

**Bu mavzuda nimani bilib olasan:**

- abstraksiya nima ekanini;
- abstraksiyaning inkapsulyatsiyadan farqini;
- klasslarda abstraksiyani qanday amalga oshirishni.

### Umumiy ma'lumot

Telefonda qo'ng'iroq qilish uchun nima qilasan? Raqamni terib, yashil tugmani bosasan. Bu paytda telefon ichida signal antennaga uzatiladi, raqamga aylantiriladi, minoralarga yuboriladi... Lekin bularning hech biri seni qiziqtirmaydi — sen faqat "qo'ng'iroq qilish" tugmasini ko'rasan.

**Abstraksiya** — bu murakkab tizimning faqat **muhim va kerakli** qismlarini ko'rsatib, qolgan tafsilotlarni yashirish. Foydalanuvchi obyekt **nima qilishini** biladi, lekin **qanday qilishini** bilishi shart emas.

!img m10_abstraction.png | Foydalanuvchi faqat tugmalarni ko'radi, ichki mexanizm yashirin | 6.0

### Klassda abstraksiya

```cpp
#include <iostream>
#include <string>
using namespace std;

class Kofemashina {
private:
    // Murakkab ichki tafsilotlar — foydalanuvchi ko'rmaydi
    int suvHarorati = 20;
    void suvniIsit()   { suvHarorati = 92; cout << "  [suv isitildi]" << endl; }
    void donniMaydala(){ cout << "  [don maydalandi]" << endl; }
    void bosimBer()    { cout << "  [bosim berildi]" << endl; }

public:
    // Oddiy interfeys — bitta tugma!
    void kofeTayyorla(string tur) {
        cout << tur << " tayyorlanmoqda..." << endl;
        suvniIsit();
        donniMaydala();
        bosimBer();
        cout << tur << " tayyor!" << endl;
    }
};

int main() {
    Kofemashina k;
    k.kofeTayyorla("Kapuchino");
    // k.suvniIsit();   // XATO: bu ichki tafsilot, private
    return 0;
}
```

```output
  [don maydalandi]
  [bosim berildi]
Kapuchino tayyor!
```

## C++ da umumlashgan (generic) dasturlash

!img c_generic.png | Bitta funksiya — istalgan tur uchun | 6.2

**Bu mavzuda nimani bilib olasan:**

- generic dasturlash nima ekanini va qanday muammoni hal qilishini;
- funksiya shablonlarini yaratishni;
- C++ da generic dasturlash qayerlarda ishlatilishini.

### Umumiy ma'lumot

Ikki sondan kattasini topadigan funksiya yozdik deylik:

```cpp
int kattasi(int a, int b) { return (a > b) ? a : b; }
```

Endi xuddi shu ishni `double` lar uchun ham, `char` lar uchun ham, `string` lar uchun ham qilish kerak. Har biri uchun alohida funksiya yozamizmi? Ularning kodi bir xil, faqat turi farq qiladi!

**Generic (umumlashgan) dasturlash** — bu **turdan mustaqil** kod yozish usuli. Biz kodni bir marta, "qandaydir T turi uchun" yozamiz, kompilyator esa kerakli turlar uchun versiyalarni o'zi yaratadi. C++ da bu **shablonlar** (templates) yordamida amalga oshiriladi.

!img m10_generic.png | Bitta shablon — har xil turlar uchun funksiyalar | 6.0

### Funksiya shabloni

```cpp
#include <iostream>
#include <string>
using namespace std;

template <typename T>
T kattasi(T a, T b) {
    return (a > b) ? a : b;
}

int main() {
    cout << kattasi(3, 7) << endl;                         // T = int
    cout << kattasi(2.5, 1.5) << endl;                     // T = double
    cout << kattasi('a', 'z') << endl;                     // T = char
    cout << kattasi(string("olma"), string("nok")) << endl; // T = string
    return 0;
}
```

```output
7
2.5
z
olma
```

`template <typename T>` — "quyidagi kod T degan har qanday tur uchun" degani. `T` — **tur parametri**; uni istalgan nom bilan atash mumkin, lekin odatda `T` ishlatiladi.

### Yana bir misol: massivni chiqarish

```cpp
#include <iostream>
#include <string>
using namespace std;

template <typename T>
void chiqar(T massiv[], int n) {
    for (int i = 0; i < n; i++) cout << massiv[i] << " ";
    cout << endl;
}

template <typename T>
T yigindi(T massiv[], int n) {
    T jami = T();        // T ning "nol" qiymati
    for (int i = 0; i < n; i++) jami += massiv[i];
    return jami;
}

int main() {
    int a[] = {1, 2, 3, 4};
    double b[] = {1.5, 2.5};
    string c[] = {"C", "+", "+"};
    chiqar(a, 4);
    chiqar(c, 3);
    cout << "Yig'indi: " << yigindi(a, 4) << endl;
    cout << "Yig'indi: " << yigindi(b, 2) << endl;
    cout << "Birlashma: " << yigindi(c, 3) << endl;
    return 0;
}
```

```output
1 2 3 4 
C + + 
Yig'indi: 10
Yig'indi: 4
Birlashma: C++
```

E'tibor ber: `yigindi` satrlar uchun ham ishladi, chunki `string` da ham `+=` amali bor!

### Turni aniq ko'rsatish

Ba'zan kompilyator turni o'zi aniqlay olmaydi. Masalan, `kattasi(3, 7.5)` da biri `int`, biri `double`. Bunda turni aniq ko'rsatish kerak:

```cpp
cout << kattasi<double>(3, 7.5) << endl;   // 7.5
```

### Generic dasturlash hamma joyda!

Sen buni bilmagan holda allaqachon generic kod ishlatgansan:

| Siz ishlatgan narsa | Generic shakli |
|---|---|
| `sort(a, a + n)` | Istalgan turdagi massivni saralaydi |
| `max(a, b)`, `min(a, b)` | Istalgan turdagi qiymatlar uchun |
| `swap(a, b)` | Istalgan turdagi ikki o'zgaruvchini almashtiradi |
| `vector<int>`, `vector<string>` | Istalgan turdagi dinamik massiv (12-modul) |
| `unique_ptr<Robot>` | Istalgan turga aqlli ko'rsatkich |

C++ ning butun standart kutubxonasi — **STL** (Standard Template Library — "Standart shablonlar kutubxonasi") — generic dasturlashga asoslangan. Uni 12-modulda batafsil o'rganamiz.

### Ichkarida nima bo'ladi? Shablon — kod yasaydigan "muhr"

Shablonning o'zi kod emas — u kod yasash uchun **retsept**. Kompilyator `kattasi(3, 7)` ni ko'rganda shablondan `int` uchun haqiqiy funksiya yasaydi. `kattasi(2.5, 1.5)` ni ko'rganda — `double` uchun boshqasini. Bu jarayon **shablonni nusxalash** (instantiation) deyiladi.

Natijada tayyor dasturda go'yo sen qo'lda yozgandek bir nechta alohida funksiya bo'ladi. Shuning uchun shablonlar dasturni sekinlashtirmaydi — hammasi kompilyatsiya paytida hal qilinadi.

### Ko'p uchraydigan xatolar

| Xato | Muammo | To'g'risi |
|---|---|---|
| `kattasi(3, 7.5)` | T `int` mi yoki `double` mi — noaniq | `kattasi<double>(3, 7.5)` |
| Shablonni turga mos kelmaydigan amal bilan ishlatish | Masalan, `>` amali yo'q klass uchun `kattasi` | Kerakli amallarni klassda aniqla |
| Shablonni `.cpp` faylda yozib, boshqa faylda ishlatish | Linker xatosi | Shablonlar odatda to'liq `.h` faylda yoziladi |
| Juda uzun xato xabarlari | Shablon xatolari chalkash ko'rinadi | Birinchi xato qatoriga e'tibor ber |

### Boshqa tillarda

| Til | Generic sintaksis |
|---|---|
| C++ | `template <typename T> T f(T x)` |
| Java | `<T> T f(T x)` |
| C# | `T F<T>(T x)` |
| TypeScript | `function f<T>(x: T): T` |
| Python | Kerak emas — dinamik turlar tufayli funksiya istalgan tur bilan ishlaydi |

**Java:**

```java
static <T extends Comparable<T>> T kattasi(T a, T b) {
    return a.compareTo(b) > 0 ? a : b;
}
```

**Python** (generic avtomatik):

```python
def kattasi(a, b):
    return a if a > b else b

print(kattasi(3, 7), kattasi("olma", "nok"))
```

!mashq `almashtir` shablon funksiyasini yoz: u istalgan turdagi ikki o'zgaruvchining qiymatini almashtirsin (havola orqali). Uni `int`, `double` va `string` bilan sinab ko'r.

### O'zingni tekshir

1. Generic dasturlash qanday muammoni hal qiladi?
2. `template <typename T>` nimani bildiradi?
3. Kompilyator shablondan qachon haqiqiy funksiya yasaydi?
4. Biz allaqachon ishlatgan qaysi funksiyalar generic?

### Xulosa

- Generic dasturlash — turdan mustaqil kod yozish usuli.
- C++ da u shablonlar (`template`) yordamida amalga oshiriladi.
- Kompilyator kerakli turlar uchun shablondan haqiqiy funksiyalar yasaydi.
- STL — generic dasturlashning eng katta namunasi.

## C++ da `this` ko'rsatkichi

!img c_this.png | this — "men" degani | 6.2

**Bu mavzuda nimani bilib olasan:**

- `this` ko'rsatkichi nima ekanini;
- nomlar bir xil bo'lganda `this` dan foydalanishni;
- metodlar zanjirini (`obj.a().b().c()`) yaratishni.

### Umumiy ma'lumot

Sinfda o'qituvchi "Qo'lingizni ko'taring!" desa, har bir o'quvchi **o'zining** qo'lini ko'taradi. Har kim "mening qo'lim" deganda o'zini nazarda tutadi.

Klass metodlari ham shunday. Bitta `tanishtir()` metodi barcha obyektlar uchun umumiy, lekin `ali.tanishtir()` chaqirilganda Alining ma'lumotlarini, `vali.tanishtir()` da esa Valinikini chiqaradi. Metod qaysi obyekt uchun chaqirilganini qanday biladi? Javob — **`this`** ko'rsatkichi.

`this` — har bir metod ichida mavjud bo'lgan maxsus ko'rsatkich. U metod chaqirilgan **obyektning o'zini** ko'rsatadi. Ya'ni `this` — "men" degani.

!img m10_this.png | Har bir chaqiruvda this o'sha obyektni ko'rsatadi | 6.0

### `this` ni ko'rib chiqamiz

```cpp
#include <iostream>
#include <string>
using namespace std;

class Oquvchi {
public:
    string ism;
    Oquvchi(string i) : ism(i) {}
    void kimman() {
        cout << "Men " << this->ism << ", manzilim: " << this << endl;
    }
};

int main() {
    Oquvchi ali("Ali"), vali("Vali");
    ali.kimman();
    cout << "ali ning manzili:   " << &ali << endl;
    vali.kimman();
    cout << "vali ning manzili:  " << &vali << endl;
    return 0;
}
```

```output
Men Ali, manzilim: 0x7ffc8a1b2c40
ali ning manzili:   0x7ffc8a1b2c40
Men Vali, manzilim: 0x7ffc8a1b2c60
vali ning manzili:  0x7ffc8a1b2c60
```

Ko'rib turganingdek, `this` aynan metod chaqirilgan obyektning manzili. `this->ism` — "mening ismim". Odatda `this->` yozish shart emas: `ism` deb yozsang ham, kompilyator uni `this->ism` deb tushunadi.

### 1-foydalanish: nomlar bir xil bo'lganda

Agar parametr nomi maydon nomi bilan bir xil bo'lsa, ularni ajratish uchun `this` kerak:

```cpp
#include <iostream>
using namespace std;

class Tortburchak {
public:
    int eni, boyi;
    void olcham(int eni, int boyi) {
        this->eni = eni;     // maydon = parametr
        this->boyi = boyi;
    }
    int yuza() { return eni * boyi; }
};

int main() {
    Tortburchak t;
    t.olcham(4, 6);
    cout << "Yuza: " << t.yuza() << endl;
    return 0;
}
```

```output
Yuza: 24
```

Agar `this->` yozilmasa, `eni = eni;` parametrning o'ziga o'zini berish bo'lib qolardi va maydon o'zgarmasdi.

### 2-foydalanish: metodlar zanjiri

Metod `*this` ni (obyektning o'zini) havola sifatida qaytarsa, metodlarni zanjir qilib chaqirish mumkin:

```cpp
#include <iostream>
#include <string>
using namespace std;

class Pitsa {
    string tarkib = "Pitsa:";
public:
    Pitsa& pishloq()  { tarkib += " pishloq"; return *this; }
    Pitsa& pomidor()  { tarkib += " pomidor"; return *this; }
    Pitsa& qoziqorin(){ tarkib += " qo'ziqorin"; return *this; }
    void tayyor() { cout << tarkib << endl; }
};

int main() {
    Pitsa p;
    p.pishloq().pomidor().qoziqorin().tayyor();
    return 0;
}
```

```output
Pitsa: pishloq pomidor qo'ziqorin
```

Bu usul juda chiroyli va ko'p kutubxonalarda ishlatiladi. Masalan, `cout << a << b << c;` ham aynan shunday ishlaydi — har bir `<<` `cout` ning o'zini qaytaradi!

### 3-foydalanish: o'zini o'zi bilan solishtirish

```cpp
bool tengmi(const Oquvchi& boshqa) {
    if (this == &boshqa) return true;   // aynan o'sha obyektmi?
    return ism == boshqa.ism;
}
```

### Ichkarida nima bo'ladi?

Kompilyator har bir metodga **yashirin birinchi parametr** qo'shadi — bu `this`. Sen yozgan:

```cpp
void Oquvchi::kimman() { cout << ism; }
ali.kimman();
```

kompilyator uchun taxminan shunday ko'rinadi:

```cpp
void Oquvchi_kimman(Oquvchi* this) { cout << this->ism; }
Oquvchi_kimman(&ali);
```

Mana shuning uchun bitta metod kodi barcha obyektlar bilan ishlay oladi: har safar unga kerakli obyektning manzili yashirincha beriladi.

### Ko'p uchraydigan xatolar

| Xato | Muammo | To'g'risi |
|---|---|---|
| `this.ism` | `this` — ko'rsatkich, nuqta emas | `this->ism` |
| `eni = eni;` (bir xil nomlar) | Maydon o'zgarmaydi | `this->eni = eni;` |
| `static` metodda `this` ishlatish | `static` metodlarda `this` yo'q | Oddiy metodga o'tkaz |
| Zanjir uchun `Pitsa` (havolasiz) qaytarish | Har safar nusxa qaytadi, asl obyekt o'zgarmaydi | `Pitsa&` qaytar |

### Boshqa tillarda

| Til | "Men" so'zi |
|---|---|
| C++ | `this` (ko'rsatkich: `this->x`) |
| Java, C#, JavaScript | `this` (havola: `this.x`) |
| Python | `self` (har bir metodda birinchi parametr sifatida aniq yoziladi) |
| Swift, Kotlin | `self` / `this` |

**Python** da `self` ni har doim o'zing yozasan — bu C++ dagi yashirin `this` ning ochiq ko'rinishi:

```python
class Oquvchi:
    def __init__(self, ism):
        self.ism = ism          # self.ism — maydon, ism — parametr
    def kimman(self):
        print("Men", self.ism)
```

!mashq `Hisoblagich` klassini yarat: `qosh(int n)`, `ayir(int n)`, `kopaytir(int n)` metodlari `*this` ni qaytarsin. Keyin `h.qosh(5).kopaytir(3).ayir(2).natija()` kabi zanjir yozib, 13 chiqishini tekshir.

### O'zingni tekshir

1. `this` nima?
2. `this->ism` va `ism` farq qiladimi?
3. Qachon `this->` yozish majburiy?
4. Metodlar zanjirini yaratish uchun metod nimani qaytarishi kerak?

### Xulosa

- `this` — metod chaqirilgan obyektni ko'rsatuvchi yashirin ko'rsatkich.
- U nomlar bir xil bo'lganda maydon va parametrni ajratadi.
- `*this` ni havola sifatida qaytarib, metodlar zanjirini yaratish mumkin.
- Kompilyator `this` ni har bir metodga yashirin parametr sifatida beradi.

## C++ da statik a'zolar

!img c_static.png | static a'zo — hamma uchun umumiy doska | 6.2

**Bu mavzuda nimani bilib olasan:**

- statik maydon va statik metod nima ekanini;
- ular oddiy a'zolardan qanday farq qilishini;
- obyektlar sonini sanash kabi amaliy misollarni.

### Umumiy ma'lumot

Sinfda har bir o'quvchining o'z daftari bor — unga faqat o'zi yozadi. Lekin sinf doskasi **bitta** va u hamma uchun umumiy: biror o'quvchi doskaga yozsa, hamma ko'radi.

Klasslarda ham shunday:

- **Oddiy maydonlar** — har bir obyektning o'z nusxasi bor (shaxsiy daftar).
- **Statik maydonlar** — klassning **barcha obyektlari uchun bitta** umumiy nusxa (sinf doskasi).

!img m10_static.png | Statik maydon barcha obyektlar uchun bitta | 6.0

### Statik maydon

```cpp
#include <iostream>
#include <string>
using namespace std;

class Oquvchi {
public:
    string ism;
    static int soni;                 // e'lon: hamma uchun bitta

    Oquvchi(string i) : ism(i) {
        soni++;
        cout << ism << " qo'shildi. Jami: " << soni << endl;
    }
    ~Oquvchi() { soni--; }
};

int Oquvchi::soni = 0;               // ta'rif: klassdan tashqarida

int main() {
    Oquvchi a("Malika");
    Oquvchi b("Jasur");
    {
        Oquvchi c("Laylo");
        cout << "Blok ichida: " << Oquvchi::soni << endl;
    }
    cout << "Blokdan keyin: " << Oquvchi::soni << endl;
    return 0;
}
```

```output
Malika qo'shildi. Jami: 1
Jasur qo'shildi. Jami: 2
Laylo qo'shildi. Jami: 3
Blok ichida: 3
Blokdan keyin: 2
```

!eslatma Statik maydon klass ichida faqat **e'lon** qilinadi. Uni klassdan tashqarida alohida **ta'riflash** kerak: `int Oquvchi::soni = 0;`. C++17 dan boshlab `inline static int soni = 0;` deb klass ichida ham yozish mumkin.

Statik maydonga murojaat qilish uchun obyekt shart emas — klass nomi orqali murojaat qilinadi: `Oquvchi::soni`.

### Statik metod

Statik metod ham klassga tegishli, alohida obyektga emas. U obyekt yaratmasdan chaqirilishi mumkin:

```cpp
#include <iostream>
using namespace std;

class Matematika {
public:
    static int kvadrat(int x) { return x * x; }
    static int kub(int x) { return x * x * x; }
    static const double PI;
};

const double Matematika::PI = 3.14159;

int main() {
    cout << Matematika::kvadrat(5) << endl;     // obyektsiz chaqiramiz
    cout << Matematika::kub(3) << endl;
    cout << Matematika::PI << endl;
    return 0;
}
```

```output
25
27
3.14159
```

**Statik metodning cheklovlari:**

- uning ichida `this` yo'q (chunki u alohida obyektga bog'lanmagan);
- u faqat **statik** maydonlar va boshqa statik metodlarga to'g'ridan-to'g'ri murojaat qila oladi.

### Amaliy misol: noyob ID raqamlar

```cpp
#include <iostream>
#include <string>
using namespace std;

class Oyinchi {
    static int keyingiId;
    int id;
    string ism;
public:
    Oyinchi(string i) : id(keyingiId++), ism(i) {}
    void korsat() const { cout << "#" << id << " " << ism << endl; }
    static int jamiYaratilgan() { return keyingiId - 1; }
};

int Oyinchi::keyingiId = 1;

int main() {
    Oyinchi a("Malika"), b("Jasur"), c("Laylo");
    a.korsat(); b.korsat(); c.korsat();
    cout << "Jami o'yinchilar: " << Oyinchi::jamiYaratilgan() << endl;
    return 0;
}
```

```output
#1 Malika
#2 Jasur
#3 Laylo
Jami o'yinchilar: 3
```

### Oddiy va statik a'zolarni taqqoslash

| | Oddiy a'zo | Statik a'zo |
|---|---|---|
| Nechta nusxa | Har bir obyektda bittadan | Butun klass uchun bitta |
| Murojaat | `obyekt.a'zo` | `Klass::a'zo` (yoki `obyekt.a'zo`) |
| Qachon yaratiladi | Obyekt bilan birga | Dastur boshlanganda |
| Metodda `this` | Bor | Yo'q |
| Misol | O'quvchining ismi | O'quvchilar umumiy soni |

### Ichkarida nima bo'ladi?

Statik maydon obyekt ichida saqlanmaydi! U 9-modulda o'rgangan **statik ma'lumotlar hududida** — global o'zgaruvchilar bilan birga yashaydi. Aslida u "klass nomi bilan o'ralgan global o'zgaruvchi". Shuning uchun `sizeof(Oquvchi)` ga statik maydon o'lchami qo'shilmaydi va u dastur boshidan oxirigacha mavjud bo'ladi.

### Ko'p uchraydigan xatolar

| Xato | Muammo | To'g'risi |
|---|---|---|
| Statik maydonni klassdan tashqarida ta'riflamaslik | Linker xatosi: `undefined reference` | `int Klass::maydon = 0;` |
| Statik metodda oddiy maydonga murojaat | `invalid use of member in static function` | Faqat statik a'zolar yoki obyekt orqali |
| Statik metodda `this` | Xato | `this` faqat oddiy metodlarda |

### Boshqa tillarda

| | C++ | Java | Python |
|---|---|---|---|
| Statik maydon | `static int soni;` | `static int soni;` | Klass atributi: `soni = 0` |
| Statik metod | `static void f()` | `static void f()` | `@staticmethod` |
| Murojaat | `Klass::soni` | `Klass.soni` | `Klass.soni` |

**Java** dagi mashhur `main` ham statik metod:

```java
public static void main(String[] args) { }
```

**Python:**

```python
class Oquvchi:
    soni = 0                    # barcha obyektlar uchun umumiy
    def __init__(self, ism):
        self.ism = ism
        Oquvchi.soni += 1
```

!mashq `Mashina` klassini yarat. Statik maydon — `jamiMashinalar`, statik metod — `statistika()` (nechta mashina yaratilganini chiqaradi). Har bir mashina yaratilganda va yo'q qilinganda hisoblagich o'zgarsin.

### O'zingni tekshir

2. Statik maydonga qanday murojaat qilinadi?
3. Statik metodda `this` bormi? Nima uchun?

### Xulosa

- Statik maydon — klassning barcha obyektlari uchun bitta umumiy o'zgaruvchi.
- Statik metod obyekt yaratmasdan, klass nomi orqali chaqiriladi.
- Statik metodlarda `this` yo'q va ular faqat statik a'zolar bilan ishlaydi.
- Statik maydon klassdan tashqarida ta'riflanishi kerak.

## 10-modul uchun mini-loyiha: Virtual uy hayvoni (Tamagochi)

OOP ning barcha o'rganilgan imkoniyatlarini birlashtirib, o'zingning virtual uy hayvoningni yarat! Unga qarash kerak: ovqatlantirish, o'ynash va uxlatish.

```cpp
#include <iostream>
#include <string>
using namespace std;

class UyHayvoni {
private:
    string ism;
    int ochlik;     // 0 - to'q, 10 - juda och
    int baxt;       // 0 - xafa, 10 - juda xursand
    int charchoq;   // 0 - tetik, 10 - juda charchagan
    static int jamiHayvonlar;

    void chegarala(int& q) { if (q < 0) q = 0; if (q > 10) q = 10; }
    void vaqtOtdi() {
        ochlik++; charchoq++; baxt--;
        chegarala(ochlik); chegarala(charchoq); chegarala(baxt);
    }

public:
    UyHayvoni(string i) : ism(i), ochlik(5), baxt(5), charchoq(3) {
        jamiHayvonlar++;
        cout << ism << " tug'ildi! Unga yaxshi qara." << endl;
    }
    ~UyHayvoni() { cout << ism << " bilan xayrlashdik." << endl; }

    UyHayvoni& ovqatlantir() {
        ochlik -= 4; baxt += 1; chegarala(ochlik); chegarala(baxt);
        cout << ism << " mazza qilib ovqatlandi." << endl;
        return *this;
    }
    UyHayvoni& oyna() {
        if (charchoq > 7) { cout << ism << " juda charchagan, o'ynay olmaydi." << endl; return *this; }
        baxt += 3; charchoq += 2; ochlik += 1;
        chegarala(baxt); chegarala(charchoq); chegarala(ochlik);
        cout << ism << " zavq bilan o'ynadi!" << endl;
        return *this;
    }
    UyHayvoni& uxla() {
        charchoq = 0; ochlik += 2; chegarala(ochlik);
        cout << ism << " shirin uxladi. Zzz..." << endl;
        return *this;
    }
    void holat() {
        vaqtOtdi();
        cout << "[" << ism << "] ochlik: " << ochlik << "/10, baxt: " << baxt
             << "/10, charchoq: " << charchoq << "/10";
        if (baxt >= 7) cout << "  :-D";
        else if (baxt <= 3) cout << "  :-(";
        else cout << "  :-|";
        cout << endl;
    }
    static int jami() { return jamiHayvonlar; }
};

int UyHayvoni::jamiHayvonlar = 0;

int main() {
    UyHayvoni p("Momiq");
    p.holat();
    p.ovqatlantir().oyna().oyna();
    p.holat();
    p.uxla().ovqatlantir();
    p.holat();
    cout << "Jami hayvonlar: " << UyHayvoni::jami() << endl;
    return 0;
}
```

```output
Momiq tug'ildi! Unga yaxshi qara.
[Momiq] ochlik: 6/10, baxt: 4/10, charchoq: 4/10  :-|
Momiq mazza qilib ovqatlandi.
Momiq zavq bilan o'ynadi!
Momiq zavq bilan o'ynadi!
[Momiq] ochlik: 5/10, baxt: 9/10, charchoq: 9/10  :-D
Momiq shirin uxladi. Zzz...
Momiq mazza qilib ovqatlandi.
[Momiq] ochlik: 4/10, baxt: 9/10, charchoq: 1/10  :-D
Jami hayvonlar: 1
Momiq bilan xayrlashdik.
```

!mashq Dasturni interaktiv qil: `while` tsikli ichida foydalanuvchidan buyruq so'ra (1 — ovqatlantir, 2 — o'yna, 3 — uxlat, 0 — chiqish). Agar ochlik 10 ga yetsa yoki baxt 0 ga tushsa, "Hayvoning kasal bo'lib qoldi!" deb ogohlantir.
