## C++ da massivlar

!img c_array.png | Massiv — raqamlangan shkafchalar | 6.2

**Bu mavzuda nimani bilib olasan:**

- massiv nima ekanini va u nima uchun kerakligini;
- massiv yaratish, elementlarga murojaat qilish va ularni o'zgartirishni;
- massivni tsikl bilan ko'rib chiqishni;
- ikki o'lchovli massivlarni (jadvallarni).

### Umumiy ma'lumot

Maktab koridoridagi shkafchalarni tasavvur qil: ular bir qatorda turadi, hammasi bir xil o'lchamda va har birining o'z raqami bor. Agar senga "5-shkafchani och" deyishsa, darhol topasan.

**Massiv** (inglizcha *array*) — bu bir xil turdagi bir nechta qiymatni **bitta nom** ostida, xotirada **ketma-ket** saqlaydigan tuzilma. Har bir qiymat **element** deyiladi, uning tartib raqami esa **indeks** deyiladi.

!img m8_array.png | Besh elementli massiv: indekslar 0 dan 4 gacha | 6.0

### Massiv yaratish

```cpp
tur nomi[o'lcham];
```

```cpp
int baholar[5];                         // 5 ta int uchun joy
int ballar[5] = {90, 85, 77, 100, 68};  // qiymatlar bilan
int sonlar[] = {1, 2, 3};               // o'lchamni kompilyator o'zi hisoblaydi (3)
int nollar[10] = {};                    // hammasi 0
double narxlar[3] = {1.5, 2.0};         // qolgani 0.0
```

### Elementlarga murojaat: indeks 0 dan boshlanadi!

Bu juda muhim: C++ da birinchi elementning indeksi **0**, oxirgisiniki esa **o'lcham − 1**.

```cpp
#include <iostream>
using namespace std;

int main() {
    int baholar[5] = {5, 4, 5, 3, 5};
    cout << "Birinchi baho: " << baholar[0] << endl;
    cout << "Uchinchi baho: " << baholar[2] << endl;
    cout << "Oxirgi baho: " << baholar[4] << endl;

    baholar[3] = 4;     // 4-elementni (indeks 3) o'zgartiramiz
    cout << "Tuzatilgan baho: " << baholar[3] << endl;
    return 0;
}
```

```output
Birinchi baho: 5
Uchinchi baho: 5
Oxirgi baho: 5
Tuzatilgan baho: 4
```

!fakt Nega 0 dan? Chunki indeks aslida "boshidan necha qadam narida" degani. Birinchi element boshida turadi — undan 0 qadam narida. Ikkinchisi — 1 qadam narida va hokazo.

### Massivni tsikl bilan ko'rib chiqish

Massivlar va tsikllar — eng yaqin do'stlar:

```cpp
#include <iostream>
using namespace std;

int main() {
    int ballar[] = {72, 95, 61, 88, 79};
    int n = 5;

    int yigindi = 0, eng = ballar[0];
    for (int i = 0; i < n; i++) {
        yigindi += ballar[i];
        if (ballar[i] > eng) eng = ballar[i];
    }
    cout << "Yig'indi: " << yigindi << endl;
    cout << "O'rtacha: " << (double)yigindi / n << endl;
    cout << "Eng yuqori ball: " << eng << endl;
    return 0;
}
```

```output
Yig'indi: 395
O'rtacha: 79
Eng yuqori ball: 95
```


### Ikki o'lchovli massivlar — jadvallar

Ikki o'lchovli massiv — qatorlar va ustunlardan iborat jadval. Masalan, kino zalidagi o'rindiqlar yoki "Krestik-nolik" o'yin maydoni:

```cpp
#include <iostream>
using namespace std;

int main() {
    char maydon[3][3] = {
        {'X', 'O', 'X'},
        {' ', 'X', 'O'},
        {'O', ' ', 'X'}
    };
    for (int i = 0; i < 3; i++) {
        for (int j = 0; j < 3; j++) {
            cout << " " << maydon[i][j] << " ";
            if (j < 2) cout << "|";
        }
        cout << endl;
        if (i < 2) cout << "---+---+---" << endl;
    }
    return 0;
}
```

```output
 X | O | X 
---+---+---
   | X | O 
---+---+---
 O |   | X 
```

`maydon[i][j]` — i-qator, j-ustundagi element. Birinchi indeks — qator, ikkinchisi — ustun.

### Ichkarida nima bo'ladi? Massiv xotirada qanday joylashadi?

Massiv elementlari xotirada **bir-biriga yopishgan holda, ketma-ket** joylashadi. `int a[4]` uchun (har bir `int` — 4 bayt):

| Element | `a[0]` | `a[1]` | `a[2]` | `a[3]` |
|---|---|---|---|---|
| Manzil | 1000 | 1004 | 1008 | 1012 |

Kompyuter `a[i]` ning manzilini juda tez hisoblaydi: **boshlanish manzili + i × element o'lchami**. Masalan, `a[3]` = 1000 + 3 × 4 = 1012. Shuning uchun massivning istalgan elementiga murojaat qilish bir xil, juda tez vaqt oladi — u 1-elementmi yoki 1 000 000-elementmi, farqi yo'q!

Ikki o'lchovli massiv ham xotirada aslida bitta uzun qator: avval 0-qator, keyin 1-qator va hokazo.

### Ko'p uchraydigan xatolar

| Xato | Muammo | To'g'risi |
|---|---|---|
| `int a[5]; a[5] = 1;` | Massiv chegarasidan chiqish! `a[5]` mavjud emas | Oxirgi indeks — `a[4]` |
| `for (int i = 1; i <= 5; i++)` | `a[0]` o'tkazib yuboriladi, `a[5]` — chegaradan tashqari | `for (int i = 0; i < 5; i++)` |
| `int n = 5; int a[n];` | Standart C++ da o'lcham o'zgarmas bo'lishi kerak | `const int n = 5;` yoki `vector` |
| `a = b;` (massivlarni nusxalash) | Massivlarni bunday nusxalab bo'lmaydi | Tsikl bilan yoki `vector` ishlat |
| Massivni `cout << a;` bilan chiqarish | Manzil chiqadi | Tsikl bilan har bir elementni chiqar |

!diqqat C++ massiv chegarasini tekshirmaydi! `a[100]` deb yozsang, kompilyator xato bermaydi, lekin dastur xotiraning begona joyini o'qiydi yoki buzadi. Bu eng xavfli xatolardan biri. Zamonaviy C++ da xavfsizroq `std::array` va `std::vector` (12-modul) bor.

## C++ da satrlar

!img c_string.png | Satr — ipga terilgan harflar | 6.2

**Bu mavzuda nimani bilib olasan:**

- satr (string) nima ekanini;
- C uslubidagi satrlar va C++ ning `string` klassini;
- satrlarni birlashtirish, solishtirish, qidirish va o'zgartirishni;
- butun qatorni o'qishni (`getline`).

### Umumiy ma'lumot

**Satr** (inglizcha *string*) — bu belgilar ketma-ketligi: so'z, gap yoki butun matn. `"Salom"`, `"Men 12 yoshdaman"`, `"C++ zo'r!"` — bularning hammasi satrlar. Satrlar qo'shtirnoq `" "` ichida yoziladi.

C++ da satrlar bilan ishlashning ikki usuli bor:

1. **C uslubidagi satrlar** — `char` massivlari (eski usul).
2. **`std::string`** — zamonaviy, qulay va xavfsiz klass (tavsiya etiladi).

!img m8_string.png | "Salom" xotirada: har bir belgi alohida katakda, oxirida maxsus \0 belgisi | 6.0

### 1. C uslubidagi satrlar

Bu shunchaki `char` lar massivi, oxirida maxsus **nol belgi** `'\0'` bor. Bu belgi "satr shu yerda tugadi" degan ma'noni bildiradi:

```cpp
#include <iostream>
#include <cstring>
using namespace std;

int main() {
    char ism[] = "Malika";           // aslida 7 ta belgi: M a l i k a \0
    cout << ism << endl;
    cout << "Uzunligi: " << strlen(ism) << endl;
    cout << "Massiv o'lchami: " << sizeof(ism) << endl;
    return 0;
}
```

```output
Malika
Uzunligi: 6
Massiv o'lchami: 7
```

### 2. `std::string` — zamonaviy usul

`string` dan foydalanish uchun `<string>` ni ulash kerak. U o'lchamini o'zi boshqaradi va ko'plab foydali funksiyalarga ega:

```cpp
#include <iostream>
#include <string>
using namespace std;

int main() {
    string ism = "Malika";
    string familiya = "Karimova";
    string toliq = ism + " " + familiya;       // birlashtirish

    cout << "To'liq ism: " << toliq << endl;
    cout << "Harflar soni: " << toliq.length() << endl;
    cout << "Birinchi harf: " << toliq[0] << endl;
    cout << "Oxirgi harf: " << toliq.back() << endl;
    return 0;
}
```

```output
To'liq ism: Malika Karimova
Harflar soni: 15
Birinchi harf: M
Oxirgi harf: a
```

### `string` ning eng foydali funksiyalari

| Funksiya | Vazifasi | Misol (`s = "dasturlash"`) | Natija |
|---|---|---|---|
| `s.length()` yoki `s.size()` | Uzunlik | `s.length()` | `10` |
| `s[i]` | i-belgi | `s[0]` | `'d'` |
| `s + t` | Birlashtirish | `s + "!"` | `"dasturlash!"` |
| `s.substr(i, n)` | i-dan boshlab n ta belgi | `s.substr(0, 6)` | `"dastur"` |
| `s.find(t)` | t ni qidirish (indeksini beradi) | `s.find("lash")` | `6` |
| `s.empty()` | Bo'shmi? | `s.empty()` | `false` |
| `s.push_back(c)` | Oxiriga belgi qo'shish | `s.push_back('!')` | `"dasturlash!"` |
| `s.insert(i, t)` | i-joyga qo'yish | `s.insert(0, "C++ ")` | `"C++ dasturlash"` |
| `s.erase(i, n)` | i-dan n ta belgini o'chirish | `s.erase(6, 4)` | `"dastur"` |
| `s.replace(i, n, t)` | Almashtirish | `s.replace(0, 6, "o'yin")` | `"o'yinlash"` |

```cpp
#include <iostream>
#include <string>
using namespace std;

int main() {
    string gap = "Men C++ ni o'rganyapman";
    size_t joy = gap.find("C++");
    if (joy != string::npos) {
        cout << "\"C++\" " << joy << "-indeksda topildi" << endl;
    }
    gap.replace(joy, 3, "Python");
    cout << gap << endl;
    cout << "Birinchi so'z: " << gap.substr(0, 3) << endl;
    return 0;
}
```

```output
"C++" 4-indeksda topildi
Men Python ni o'rganyapman
Birinchi so'z: Men
```

!eslatma `find` hech narsa topa olmasa, maxsus qiymat `string::npos` ni qaytaradi. Shuning uchun natijani doim shu bilan solishtirib tekshir.

### Satrlarni solishtirish

`string` larni `==`, `!=`, `<`, `>` bilan solishtirish mumkin. `<` va `>` lug'atdagi (alifbo) tartib bo'yicha ishlaydi:

```cpp
#include <iostream>
#include <string>
using namespace std;

int main() {
    string a = "olma", b = "anor";
    if (a == b) cout << "Bir xil" << endl;
    else if (a < b) cout << a << " lug'atda oldin keladi" << endl;
    else cout << b << " lug'atda oldin keladi" << endl;
    return 0;
}
```

```output
anor lug'atda oldin keladi
```

```cpp
#include <iostream>
```

### Ichkarida nima bo'ladi? `string` qanday ishlaydi?

`std::string` ichida uchta asosiy narsa saqlanadi:

1. Belgilar joylashgan xotiraga **ko'rsatkich**.
2. Satrning joriy **uzunligi**.
3. Ajratilgan joy hajmi (**sig'im**, capacity).

Sen satrga yangi harflar qo'shganingda va joy yetmay qolganda, `string` avtomatik ravishda kattaroq xotira oladi, eski harflarni u yerga ko'chiradi va eski joyni bo'shatadi. Buni sen umuman sezmaysan! C uslubidagi satrlarda esa bularning hammasini qo'lda qilish kerak edi.

Qiziq fakt: ko'p kompilyatorlarda qisqa satrlar (taxminan 15 belgigacha) alohida xotira olmasdan, to'g'ridan-to'g'ri `string` obyektining o'zida saqlanadi. Bu "kichik satr optimallashtirishi" deyiladi va dasturni tezlashtiradi.

### C uslubi va `string` taqqoslash

| | C uslubi (`char[]`) | `std::string` |
|---|---|---|
| Uzunlik | `strlen(s)` | `s.length()` |
| Birlashtirish | `strcat(a, b)` (joy yetishiga ishonch kerak) | `a + b` |
| Nusxalash | `strcpy(a, b)` | `a = b` |
| Solishtirish | `strcmp(a, b) == 0` | `a == b` |
| O'lcham | Qat'iy | Avtomatik o'zgaradi |
| Xavfsizlik | Chegaradan chiqish xavfi | Xavfsiz |

### Ko'p uchraydigan xatolar

| Xato | Muammo | To'g'risi |

## C++ da union va enum

!img c_enum.png | enum — raqamlarga chiroyli nomlar | 6.2

**Bu mavzuda nimani bilib olasan:**

- `enum` (sanab o'tiladigan tur) nima ekanini va uni qachon ishlatishni;
- zamonaviy `enum class` ni;
- `union` nima ekanini va u `struct` dan qanday farq qilishini.

### Umumiy ma'lumot

Bu ikkala tur ham **foydalanuvchi turlari** — ya'ni dasturchi ularni o'zi yaratadi. Ular har xil vazifani bajaradi:

- **`enum`** — cheklangan sondagi variantlarga **nom** berish uchun. Masalan, hafta kunlari, svetofor ranglari, o'yindagi qiyinlik darajalari.
- **`union`** — bir nechta turli o'zgaruvchilarni **bitta xotira joyida** saqlash uchun (ulardan bir vaqtda faqat bittasi ishlatiladi).

### 1. `enum` — sanab o'tiladigan tur

Tasavvur qil, o'yinda qahramon to'rt tomonga yura oladi. Yo'nalishni `0, 1, 2, 3` sonlari bilan belgilash mumkin, lekin keyin "2 qaysi tomon edi?" deb o'ylab qolasan. `enum` bu muammoni hal qiladi:

!img m8_enum.png | enum har bir nomga avtomatik raqam beradi | 5.5

```cpp
#include <iostream>
using namespace std;

enum Svetofor { QIZIL, SARIQ, YASHIL };   // QIZIL=0, SARIQ=1, YASHIL=2

int main() {
    Svetofor chiroq = QIZIL;
    if (chiroq == QIZIL) {
        cout << "To'xta!" << endl;
    }
    chiroq = YASHIL;
    cout << "YASHIL ning qiymati: " << chiroq << endl;
    return 0;
}
```

```output
To'xta!
YASHIL ning qiymati: 2
```

Qiymatlarni o'zing ham berishing mumkin:

```cpp
enum Baho { IKKI = 2, UCH, TORT, BESH };   // UCH=3, TORT=4, BESH=5
enum Oy { YANVAR = 1, FEVRAL, MART };       // FEVRAL=2, MART=3
```

### `enum` va `switch` — ajoyib juftlik

```cpp

enum Daraja { OSON, ORTA, QIYIN };

int main() {
    Daraja d = ORTA;
    switch (d) {

        case ORTA:  cout << "Dushmanlar o'rtacha tezlikda" << endl; break;
        case QIYIN: cout << "Dushmanlar juda tez!" << endl; break;
    }
    return 0;
}
```

```output
Dushmanlar o'rtacha tezlikda
```

### 2. `enum class` — zamonaviy va xavfsiz enum

Oddiy `enum` ning ikki kamchiligi bor: uning nomlari butun dasturga "tarqalib ketadi" va u avtomatik ravishda songa aylanadi. C++11 dan boshlab xavfsizroq **`enum class`** paydo bo'ldi:

```cpp
#include <iostream>
using namespace std;

enum class Rang { QIZIL, YASHIL, KOK };
enum class Meva { OLMA, NOK, QIZIL };    // QIZIL — Rang dagi bilan to'qnashmaydi

int main() {
    Rang r = Rang::KOK;                   // nomi bilan birga yoziladi
    Meva m = Meva::QIZIL;
    if (r == Rang::KOK) cout << "Rang — ko'k" << endl;
    cout << "KOK raqami: " << static_cast<int>(r) << endl;
    return 0;
}
```

```output
Rang — ko'k
KOK raqami: 2
```

| | `enum` | `enum class` |
|---|---|---|
| Murojaat | `QIZIL` | `Rang::QIZIL` |
| Nomlar to'qnashuvi | Bo'lishi mumkin | Yo'q |
| Avtomatik songa aylanadi | Ha | Yo'q (`static_cast` kerak) |
| Tavsiya | Eski kod | Zamonaviy C++ |

### 3. `union` — bitta joyda bir nechta tur

`union` ham `struct` kabi bir nechta maydonga ega bo'ladi. Lekin `struct` da har bir maydonga alohida joy ajratilsa, `union` da **barcha maydonlar bitta xotira joyini baham ko'radi**. Uning o'lchami eng katta maydon o'lchamiga teng.

!img m8_union.png | struct da har bir maydonga alohida joy; union da hammasi bitta joyda | 6.3

```cpp
#include <iostream>
using namespace std;

struct S { int i; double d; char c; };
union  U { int i; double d; char c; };

int main() {
    cout << "struct o'lchami: " << sizeof(S) << endl;
    cout << "union o'lchami:  " << sizeof(U) << endl;

    U u;
    u.i = 65;
    cout << "u.i = " << u.i << endl;
    u.c = 'Z';                       // endi i ning qiymati buzildi
    cout << "u.c = " << u.c << endl;
    return 0;
}
```

```output
struct o'lchami: 24
union o'lchami:  8
u.i = 65
u.c = Z
```

!eslatma `struct` o'lchami 4 + 8 + 1 = 13 emas, 24 chiqdi. Sababi — kompilyator maydonlarni tezroq o'qish uchun ular orasiga bo'sh joy ("to'ldiruvchi baytlar") qo'yadi. Bu "tekislash" (alignment) deyiladi.

`union` qachon kerak? Xotira juda cheklangan joylarda (masalan, mikrokontrollerlarda) yoki ma'lumot bir vaqtda faqat bitta ko'rinishda bo'lishi aniq bo'lganda. Odatda `union` ni qaysi maydon hozir "faol" ekanini bildiruvchi `enum` bilan birga ishlatishadi:

```cpp
#include <iostream>
using namespace std;

enum class Tur { BUTUN, KASR };

struct Qiymat {
    Tur tur;
    union { int butun; double kasr; };
};

void chiqar(const Qiymat& q) {
    if (q.tur == Tur::BUTUN) cout << "Butun son: " << q.butun << endl;
    else cout << "Kasr son: " << q.kasr << endl;
}

int main() {
    Qiymat a{Tur::BUTUN};  a.butun = 42;
    Qiymat b{Tur::KASR};   b.kasr = 3.14;
    chiqar(a);
    chiqar(b);
    return 0;
}
```

```output
Butun son: 42
Kasr son: 3.14
```

!maslahat Zamonaviy C++ (C++17) da `union` o'rniga xavfsizroq `std::variant` bor — u qaysi tur saqlanayotganini o'zi eslab qoladi.

### Ichkarida nima bo'ladi?

- **`enum`** dastur ishlayotganda oddiy butun son sifatida saqlanadi. Nomlar (`QIZIL`, `SARIQ`) faqat dasturchi uchun — kompilyator ularni raqamlarga almashtiradi. Shuning uchun `enum` dasturni sekinlashtirmaydi, lekin kodni ancha tushunarli qiladi.
- **`union`** ning barcha maydonlari bir xil manzildan boshlanadi. Bitta maydonga yozilgan baytlar boshqa maydon orqali o'qilganda "boshqacha tushuniladi" — shuning uchun faqat oxirgi yozilgan maydonni o'qish kerak.

### Ko'p uchraydigan xatolar

| Xato | Muammo | To'g'risi |
|---|---|---|
| `enum class` qiymatini `cout` bilan chiqarish | Kompilyatsiya xatosi | `static_cast<int>(r)` |
| `Rang r = KOK;` (`enum class` da) | Nom topilmaydi | `Rang r = Rang::KOK;` |
| Union da bir maydonga yozib, boshqasidan o'qish | Ma'nosiz qiymat | Faqat oxirgi yozilgan maydonni o'qi |
| `enum` nomlarini kichik harf bilan, o'zgaruvchilar kabi yozish | Chalkashlik | Odatda KATTA HARF yoki PascalCase |

### Boshqa tillarda

| | C++ | Java | Python | C# |
|---|---|---|---|---|
| enum | `enum class Rang { QIZIL };` | `enum Rang { QIZIL }` | `class Rang(Enum): QIZIL = 0` | `enum Rang { QIZIL }` |
| union | `union` | Yo'q | Yo'q | Yo'q (maxsus usullar bilan) |



`enum` deyarli barcha tillarda bor va bir xil maqsadda ishlatiladi. `union` esa past darajali C/C++ ga xos.

### Xulosa

- `enum` cheklangan variantlarga nom beradi va kodni tushunarli qiladi.
- `enum class` — zamonaviy, xavfsizroq varianti: nomlar to'qnashmaydi va avtomatik songa aylanmaydi.
- `union` ning barcha maydonlari bitta xotira joyini baham ko'radi; o'lchami eng katta maydonga teng.
- Zamonaviy C++ da `union` o'rniga `std::variant` tavsiya etiladi.

## 8-modul uchun mini-loyiha: "Krestik-nolik" o'yini

Massivlar, satrlar, enum va funksiyalarni birlashtirib, ikki kishi o'ynaydigan haqiqiy o'yin yasaymiz!

```cpp
#include <iostream>
using namespace std;

enum class Holat { DAVOM, GOLIB, DURANG };

char maydon[3][3] = {{'1','2','3'}, {'4','5','6'}, {'7','8','9'}};

void chiz() {
    cout << endl;
    for (int i = 0; i < 3; i++) {
        cout << " " << maydon[i][0] << " | " << maydon[i][1] << " | " << maydon[i][2] << endl;
        if (i < 2) cout << "---+---+---" << endl;
    }
    cout << endl;
}

Holat tekshir(char o) {
    for (int i = 0; i < 3; i++) {
        if (maydon[i][0] == o && maydon[i][1] == o && maydon[i][2] == o) return Holat::GOLIB;
        if (maydon[0][i] == o && maydon[1][i] == o && maydon[2][i] == o) return Holat::GOLIB;
    }
    if (maydon[0][0] == o && maydon[1][1] == o && maydon[2][2] == o) return Holat::GOLIB;
    if (maydon[0][2] == o && maydon[1][1] == o && maydon[2][0] == o) return Holat::GOLIB;
    for (int i = 0; i < 3; i++)
        for (int j = 0; j < 3; j++)
            if (maydon[i][j] != 'X' && maydon[i][j] != 'O') return Holat::DAVOM;
    return Holat::DURANG;
}

int main() {
    char oyinchi = 'X';
    cout << "=== KRESTIK-NOLIK ===" << endl;
    while (true) {
        chiz();
        int katak;
        cout << oyinchi << " o'yinchi, katak raqamini tanla (1-9): ";
        cin >> katak;
        if (katak < 1 || katak > 9) { cout << "1 dan 9 gacha!" << endl; continue; }
        int i = (katak - 1) / 3, j = (katak - 1) % 3;
        if (maydon[i][j] == 'X' || maydon[i][j] == 'O') { cout << "Bu katak band!" << endl; continue; }
        maydon[i][j] = oyinchi;
        Holat h = tekshir(oyinchi);
        if (h == Holat::GOLIB) { chiz(); cout << oyinchi << " yutdi! Tabriklaymiz!" << endl; break; }
        if (h == Holat::DURANG) { chiz(); cout << "Durang!" << endl; break; }
        oyinchi = (oyinchi == 'X') ? 'O' : 'X';
    }
    return 0;
}
```

```output
=== KRESTIK-NOLIK ===

 1 | 2 | 3
---+---+---
 4 | 5 | 6
---+---+---
 7 | 8 | 9

X o'yinchi, katak raqamini tanla (1-9): 5
...
 X | O | 3
---+---+---
 4 | X | O
---+---+---
 7 | 8 | X

X yutdi! Tabriklaymiz!
```
