Yaxshi dastur nafaqat ishlashi, balki o'qishga oson bo'lishi ham kerak. Bu modulda izohlar, kutubxonalar, nomlar fazosi, kod yozish qoidalari va C++ dagi ko'rsatmalar turlari bilan tanishasan.

## C++ da izohlar va C uslubidagi izohlar

### Umumiy ma'lumot

Tasavvur qil, sen daftaringga matematika masalasini yechding va yoniga kichik eslatma yozib qo'yding: "bu yerda avval ko'paytirish kerak". Bir oydan keyin daftarni ochsang, bu eslatma senga juda yordam beradi.

Dasturlashda ham shunday eslatmalar bor, ular **izohlar** (inglizcha *comments*) deb ataladi. Izohlar odamlar uchun yoziladi. **Kompilyator ularni butunlay e'tiborsiz qoldiradi** — xuddi ular umuman yo'qdek.

!img m3_comments.png | Yashil rangdagi satrlar — izohlar | 5.8

### Izohlar nima uchun kerak?

- Kod nima ish qilishini tushuntirish uchun.
- Boshqa dasturchilarga (yoki kelajakdagi o'zingga) yordam berish uchun.
- Kodning biror qismini vaqtincha "o'chirib qo'yish" uchun — uni o'chirib tashlamasdan.

### 1. Bir qatorli izoh: `//`

Ikkita qiya chiziq `//` dan keyin qator oxirigacha yozilgan hamma narsa izoh hisoblanadi.

```cpp
#include <iostream>
using namespace std;

int main() {
    // Bu yerda o'quvchining yoshini saqlaymiz
    int yosh = 12;
    cout << yosh << endl;   // yoshni ekranga chiqaramiz
    return 0;
}
```

```output
12
```

### 2. Ko'p qatorli izoh (C uslubidagi): `/* ... */`

Bu turdagi izoh C tilidan meros qolgan. U `/*` bilan boshlanib, `*/` bilan tugaydi va oralig'idagi barcha qatorlar izoh hisoblanadi.

```cpp
#include <iostream>
using namespace std;

int main() {
    /*
      Bu dastur doira yuzini hisoblaydi.
      Muallif: Malika
      Sana: 2026-yil
    */
    double r = 3.0;
    cout << 3.14 * r * r << endl;
    return 0;
}
```

```output
28.26
```

### Kodni vaqtincha o'chirib qo'yish

Ba'zan biror qator ishlashini xohlamaysan, lekin keyin kerak bo'lishi mumkin. Shunda uni izohga aylantirib qo'yasan:

```cpp
#include <iostream>
using namespace std;

int main() {
    cout << "Bu qator ishlaydi" << endl;
    // cout << "Bu qator hozircha ishlamaydi" << endl;
    return 0;
}
```

```output
Bu qator ishlaydi
```

!diqqat `/* ... */` izohlarni bir-birining ichiga joylashtirib bo'lmaydi. Birinchi uchragan `*/` izohni tugatadi, qolgan qism esa xatoga sabab bo'ladi.

!maslahat Yaxshi izoh kod *nima* qilishini emas, *nima uchun* shunday qilinganini tushuntiradi. `x = x + 1; // x ga 1 qo'shamiz` — bu foydasiz izoh, chunki bu kodning o'zidan ko'rinib turibdi.

!mashq Birinchi dasturingga uchta izoh qo'sh: dastur nima qilishi, muallif kimligi va sanasi haqida.

### Xulosa

- Izohlar odamlar uchun yoziladi, kompilyator ularni o'qimaydi.
- `//` — bir qatorli izoh, `/* ... */` — ko'p qatorli izoh.
- Izohlar kodni tushunarli qiladi va uni vaqtincha o'chirib qo'yishga yordam beradi.

## C++ dagi header (sarlavha) fayllar

### Umumiy ma'lumot

Tasavvur qil, sen rasm chizmoqchisan. Har safar qalam va bo'yoqlarni o'zing yasamaysan-ku, to'g'rimi? Tayyor qutini olib, ichidagi asboblardan foydalanasan.

C++ da ham shunday "asboblar qutilari" bor, ular **header fayllar** (sarlavha fayllari) deb ataladi. Ularning ichida boshqa dasturchilar allaqachon yozib qo'ygan tayyor funksiyalar va vositalar bor. Bizga faqat kerakli qutini **`#include`** buyrug'i bilan dasturga ulash qoladi.

!img m3_headers.png | Har bir header fayl — o'z asboblari bor quti | 6.3

### `#include` qanday ishlaydi?

`#include` — bu preprotsessor buyrug'i. U kompilyatsiyadan oldin ko'rsatilgan faylning butun mazmunini dasturing ichiga "nusxalab qo'yadi".

```cpp
#include <iostream>   // cin va cout uchun
#include <cmath>      // matematik funksiyalar uchun
using namespace std;

int main() {
    cout << "16 ning ildizi: " << sqrt(16) << endl;
    cout << "2 ning 5-darajasi: " << pow(2, 5) << endl;
    return 0;
}
```

```output
16 ning ildizi: 4
2 ning 5-darajasi: 32
```

Agar `#include <cmath>` qatorini olib tashlasang, kompilyator `sqrt` va `pow` nima ekanini bilmay qoladi va xato beradi.

### Header fayllarning ikki turi

**1. Standart (tizim) header fayllar.** Ular kompilyator bilan birga keladi va burchakli qavslar `< >` ichida yoziladi:

```cpp
#include <iostream>
```

**2. Foydalanuvchi header fayllari.** Bularni dasturchi o'zi yaratadi. Ular qo'shtirnoq `" "` ichida yoziladi:

```cpp
#include "mening_funksiyalarim.h"
```

### Eng ko'p ishlatiladigan header fayllar

| Header fayl | Nima uchun kerak |
|---|---|
| `<iostream>` | Ekranga chiqarish (`cout`) va klaviaturadan o'qish (`cin`) |
| `<cmath>` | Matematika: `sqrt`, `pow`, `sin`, `cos`, `abs` |
| `<string>` | Matnlar (satrlar) bilan ishlash |
| `<vector>` | O'lchami o'zgaradigan massivlar |
| `<algorithm>` | Saralash (`sort`), qidirish (`find`), `max`, `min` |
| `<fstream>` | Fayllardan o'qish va fayllarga yozish |
| `<ctime>` | Vaqt va sana bilan ishlash |

### O'z header faylingni yaratish

Katta dasturlarda kod bir nechta faylga bo'linadi. Masalan, `hisob.h` faylini yaratamiz:

```cpp
// hisob.h fayli
#ifndef HISOB_H
#define HISOB_H

int kvadrat(int x) {
    return x * x;
}

#endif
```

Endi uni asosiy dasturda ishlatamiz:

```cpp
// main.cpp fayli
#include <iostream>
#include "hisob.h"
using namespace std;

int main() {
    cout << kvadrat(7) << endl;
    return 0;
}
```

```output
49
```

!eslatma `#ifndef`, `#define` va `#endif` qatorlari "himoya qalqoni" vazifasini bajaradi. Ular bitta header fayl dasturga ikki marta qo'shilib qolishining oldini oladi. Buni "include guard" deyishadi.

!mashq `<cmath>` dan foydalanib, 81 ning kvadrat ildizini va 3 ning 4-darajasini ekranga chiqaruvchi dastur yoz.

### Xulosa

- Header fayllar — tayyor funksiyalar saqlanadigan "asboblar qutilari".
- Ular `#include` buyrug'i bilan ulanadi.
- Standart fayllar `< >` ichida, o'zing yaratgan fayllar `" "` ichida yoziladi.

## C++ da nomlar fazosi (namespace)

### Umumiy ma'lumot

Tasavvur qil, shahrimizda ikkita maktab bor va ikkalasida ham **Ali** ismli o'quvchi o'qiydi. Agar kimdir "Alini chaqiring" desa, qaysi Ali nazarda tutilganini bilmaymiz. Shuning uchun aniqlik kiritamiz: "1-maktabdagi Ali" yoki "2-maktabdagi Ali".

C++ da ham xuddi shunday muammo bo'lishi mumkin: ikki xil kutubxonada bir xil nomli funksiya bo'lishi mumkin. Bu muammoni **nomlar fazosi** (inglizcha *namespace*) hal qiladi. Namespace — bu nomlarni guruhlarga ajratuvchi "familiya" yoki "manzil".

!img m3_namespace.png | Bir xil ismlar turli "maktablar"da chalkashmaydi | 5.8

### Namespace yaratish va ishlatish

```cpp
#include <iostream>
using namespace std;

namespace maktab1 {
    void salomlash() {
        cout << "Salom, men 1-maktabdagi Aliman!" << endl;
    }
}

namespace maktab2 {
    void salomlash() {
        cout << "Salom, men 2-maktabdagi Aliman!" << endl;
    }
}

int main() {
    maktab1::salomlash();
    maktab2::salomlash();
    return 0;
}
```

```output
Salom, men 1-maktabdagi Aliman!
Salom, men 2-maktabdagi Aliman!
```

Bu yerda `::` belgisi **ko'lam operatori** (scope resolution operator) deb ataladi. U "falon namespace ichidagi" degan ma'noni bildiradi.

### `std` — standart nomlar fazosi

C++ ning barcha standart vositalari (`cout`, `cin`, `string`, `vector` va boshqalar) **`std`** nomli namespace ichida joylashgan. Shuning uchun to'liq yozilganda ular `std::cout`, `std::cin` ko'rinishida bo'ladi.

```cpp
#include <iostream>

int main() {
    std::cout << "Salom!" << std::endl;
    return 0;
}
```

### `using` kalit so'zi

Har safar `std::` yozish zerikarli bo'lishi mumkin. Shuning uchun `using` dan foydalanamiz.

**Butun namespace ni ochish:**

```cpp
#include <iostream>
using namespace std;   // endi std:: shart emas

int main() {
    cout << "Salom!" << endl;
    return 0;
}
```

**Faqat bitta nomni ochish:**

```cpp
#include <iostream>
using std::cout;
using std::endl;

int main() {
    cout << "Salom!" << endl;
    return 0;
}
```

!maslahat Kichik o'quv dasturlarida `using namespace std;` yozish qulay va bu kitobda ham shunday qilamiz. Lekin katta loyihalarda professional dasturchilar odatda `std::` ni to'liq yozishadi, chunki bu nomlar chalkashib ketishining oldini oladi.

### Ichma-ich namespace lar

Namespace ichida boshqa namespace yaratish ham mumkin:

```cpp
#include <iostream>
using namespace std;

namespace shahar {
    namespace maktab {
        int oquvchilar = 850;
    }
}

int main() {
    cout << shahar::maktab::oquvchilar << endl;
    return 0;
}
```

```output
850
```

!mashq `uy` va `maktab` nomli ikkita namespace yarat. Har birida `vazifa()` funksiyasi bo'lsin: biri "Xonamni yig'ishtiraman", ikkinchisi "Matematikadan uy vazifasini bajaraman" deb yozsin.

### Xulosa

- Namespace bir xil nomlarning chalkashib ketishining oldini oladi.
- `::` operatori orqali namespace ichidagi elementga murojaat qilinadi.
- C++ ning standart vositalari `std` namespace ida joylashgan.
- `using` yordamida `std::` ni har safar yozmasdan ishlash mumkin.

## C++ da kod yozish standartlari

### Umumiy ma'lumot

Ikki xil daftarni tasavvur qil: birida hamma narsa chiroyli, tartibli, sarlavhalar bilan yozilgan; ikkinchisida esa hamma narsa aralash-quralash. Qaysi biridan o'qish oson? Albatta birinchisidan!

Kod ham shunday. Kompyuter uchun chiroyli yoki xunuk kodning farqi yo'q, lekin **odamlar** uchun katta farq bor. **Kod yozish standartlari** — bu kodni tartibli va tushunarli yozish qoidalari to'plami.

!img m3_style.png | Bir xil kod: chapda tartibsiz, o'ngda tartibli | 5.8

### 1-qoida: Ma'noli nomlar tanla

O'zgaruvchi va funksiyalarga ular nima saqlashini yoki nima qilishini bildiruvchi nom ber.

```cpp
// Yomon
int a = 25;
int b = 4;

// Yaxshi
int oquvchilarSoni = 25;
int sinflarSoni = 4;
```

### 2-qoida: Nomlash uslubiga amal qil

Dasturchilar nomlarni yozishning bir nechta uslublaridan foydalanishadi:

| Uslub | Misol | Odatda nima uchun |
|---|---|---|
| camelCase | `oquvchiYoshi` | O'zgaruvchilar, funksiyalar |
| snake_case | `oquvchi_yoshi` | O'zgaruvchilar, funksiyalar |
| PascalCase | `OquvchiKarta` | Klasslar |
| KATTA_HARF | `MAX_BAHO` | O'zgarmaslar (konstantalar) |

Muhimi — bitta dastur ichida bitta uslubni tanlab, unga doim amal qilish.

### 3-qoida: Chekinishlardan (otstup) foydalan

Figurali qavslar `{ }` ichidagi kodni 4 ta probel (yoki bitta Tab) bilan o'ngga surib yoz. Bu kodning qaysi qismi qaysi blokka tegishli ekanini ko'rsatadi.

```cpp
#include <iostream>
using namespace std;

int main() {
    int baho = 5;
    if (baho == 5) {
        cout << "A'lo!" << endl;
    }
    return 0;
}
```

### 4-qoida: Bir qatorda bitta ish

```cpp
// Yomon
int x = 5; int y = 10; cout << x + y;

// Yaxshi
int x = 5;
int y = 10;
cout << x + y;
```

### 5-qoida: Operatorlar atrofida probel qoldir

```cpp
// Yomon
int jami=narx*soni+yetkazish;

// Yaxshi
int jami = narx * soni + yetkazish;
```

### 6-qoida: Sehrli raqamlardan qoch

Kod ichida ma'nosi tushunarsiz raqamlar ("sehrli raqamlar") o'rniga nomli o'zgarmaslardan foydalan:

```cpp
// Yomon: 7 nima degani?
int kunlar = haftalar * 7;

// Yaxshi
const int HAFTADAGI_KUNLAR = 7;
int kunlar = haftalar * HAFTADAGI_KUNLAR;
```

### 7-qoida: Funksiyalarni qisqa qil

Har bir funksiya faqat bitta ishni bajarsin. Agar funksiya juda uzun bo'lib ketsa, uni bir nechta kichik funksiyalarga bo'l.

!fakt Google, Microsoft kabi katta kompaniyalarning o'z kod yozish qoidalari bor. Masalan, "Google C++ Style Guide" internetda hamma uchun ochiq.

!mashq Quyidagi kodni yuqoridagi qoidalar asosida chiroyli qilib qayta yoz: `int a=10;int b=3;if(a>b){cout<<a;}`

### Xulosa

- Kod nafaqat kompyuter, balki odamlar uchun ham yoziladi.
- Ma'noli nomlar, chekinishlar, probellar va bir qatorda bitta ish — eng muhim qoidalar.
- Bitta uslub tanlab, unga doim amal qil.

## C++ dagi ko'rsatmalar (statements)

### Umumiy ma'lumot

Gapda har bir jumla nuqta bilan tugaganidek, C++ da ham har bir buyruq odatda **nuqtali vergul** `;` bilan tugaydi. Bunday buyruq **ko'rsatma** (inglizcha *statement*) deb ataladi. Ko'rsatma — bu kompyuterga "mana shu ishni bajar" degan bitta to'liq buyruq.

```cpp
int yosh = 12;            // ko'rsatma
cout << yosh;             // ko'rsatma
yosh = yosh + 1;          // ko'rsatma
```

!img m3_statements.png | C++ dagi ko'rsatmalarning asosiy turlari | 6.3

### 1. E'lon qilish ko'rsatmalari

Yangi o'zgaruvchi yoki o'zgarmas yaratadi:

```cpp
int son = 10;
double narx = 2500.5;
char harf = 'A';
```

### 2. Ifoda ko'rsatmalari

Biror amalni bajaradi: hisoblash, qiymat berish, funksiyani chaqirish:

```cpp
son = son * 2;
cout << son << endl;
son++;
```

### 3. Bo'sh ko'rsatma

Faqat nuqtali verguldan iborat bo'lib, hech narsa qilmaydi. Ba'zan maxsus holatlarda ishlatiladi:

```cpp
;
```

### 4. Blok (murakkab) ko'rsatma

Figurali qavslar `{ }` ichiga olingan bir nechta ko'rsatmalar guruhi. Kompilyator uni bitta ko'rsatma deb qabul qiladi:

```cpp
{
    int a = 5;
    int b = 7;
    cout << a + b;
}
```

!eslatma Blok ichida e'lon qilingan o'zgaruvchi faqat shu blok ichida "yashaydi". Blokdan tashqarida u mavjud emas.

### 5. Tanlash ko'rsatmalari

Shartga qarab qaysi kod bajarilishini tanlaydi: `if`, `else`, `switch`. Bu haqda 5-modulda batafsil gaplashamiz.

```cpp
if (yosh >= 12) {
    cout << "Sen 6-sinfdasan" << endl;
}
```

### 6. Takrorlash (tsikl) ko'rsatmalari

Kodni bir necha marta takrorlaydi: `for`, `while`, `do-while`.

```cpp
for (int i = 1; i <= 3; i++) {
    cout << "Salom!" << endl;
}
```

### 7. Sakrash ko'rsatmalari

Dastur bajarilishini boshqa joyga o'tkazadi: `break`, `continue`, `return`, `goto`.

```cpp
return 0;
```

### Hammasi birgalikda

```cpp
#include <iostream>
using namespace std;

int main() {
    int yulduzlar = 3;                  // e'lon qilish
    cout << "Yulduzlar: ";              // ifoda
    for (int i = 0; i < yulduzlar; i++) // takrorlash
    {                                   // blok
        cout << "* ";
    }
    cout << endl;
    if (yulduzlar == 3) {               // tanlash
        cout << "Ajoyib natija!" << endl;
    }
    return 0;                           // sakrash
}
```

```output
Yulduzlar: * * * 
Ajoyib natija!
```

!diqqat Eng ko'p uchraydigan xato — nuqtali vergulni unutish. Agar kompilyator "expected ';'" degan xato bersa, oldingi qator oxiriga `;` qo'yishni unutgansan.

!mashq Yuqoridagi dasturdagi har bir ko'rsatmaning turini daftaringga yozib chiq.

### Xulosa

- Ko'rsatma — kompyuterga beriladigan bitta to'liq buyruq, odatda `;` bilan tugaydi.
- Asosiy turlari: e'lon qilish, ifoda, blok, tanlash, takrorlash va sakrash ko'rsatmalari.
- Figurali qavslar bir nechta ko'rsatmani bitta blokka birlashtiradi.
