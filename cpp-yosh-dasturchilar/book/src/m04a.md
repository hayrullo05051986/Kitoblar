# 4-modul. C++ da ma'lumotlar bilan ishlash

!img banner04.png | | 5.5

Har qanday dastur ma'lumotlar bilan ishlaydi: sonlar, harflar, so'zlar, "ha" yoki "yo'q" javoblari. Bu modulda ma'lumot turlari, o'zgaruvchilar, o'zgarmaslar, operatorlar va boshqa ko'plab muhim tushunchalarni o'rganamiz. Bu kitobning eng muhim modullaridan biri!

## C++ da ma'lumot turlari

### Umumiy ma'lumot

Oshxonani tasavvur qil: shakar shakardonda, tuz tuzdonda, sut esa shishada saqlanadi. Har bir mahsulot uchun o'ziga mos idish bor. Shakarni sut shishasiga solish noqulay bo'lardi, to'g'rimi?

Kompyuter xotirasida ham shunday. Har xil ma'lumot uchun har xil "idish" kerak. Bu idishlarning turi **ma'lumot turi** (inglizcha *data type*) deb ataladi. Ma'lumot turi ikki narsani belgilaydi:

1. Qanday qiymat saqlanishi mumkinligini (butun son, kasr son, harf...).
2. Xotiradan qancha joy egallashini (necha bayt).

!img m4_types.png | Asosiy turlar va ularning xotiradagi o'lchami (har bir katakcha = 1 bayt) | 6.3

### Asosiy (ichki) ma'lumot turlari

| Tur | Nima saqlaydi | O'lchami | Misol |
|---|---|---|---|
| `int` | Butun sonlar | 4 bayt | `12`, `-7`, `2026` |
| `float` | Kasr sonlar (kamroq aniqlik) | 4 bayt | `3.14f` |
| `double` | Kasr sonlar (yuqori aniqlik) | 8 bayt | `3.14159265` |
| `char` | Bitta belgi | 1 bayt | `'A'`, `'7'`, `'!'` |
| `bool` | Mantiqiy qiymat | 1 bayt | `true`, `false` |
| `void` | "Hech narsa" | — | funksiyalarda ishlatiladi |

!eslatma Turlarning o'lchami kompyuter va kompilyatorga qarab biroz farq qilishi mumkin. Jadvalda eng ko'p uchraydigan qiymatlar keltirilgan.

### `int` — butun sonlar

Yosh, sinfdagi o'quvchilar soni, ball kabi butun qiymatlar uchun:

```cpp
int yosh = 12;
int harorat = -5;
```

### `float` va `double` — kasr sonlar

Bo'y, narx, harorat kabi kasr qismi bo'lgan sonlar uchun. `double` ikki barobar aniqroq, shuning uchun ko'proq ishlatiladi:

```cpp
float boy = 1.52f;     // f harfi "bu float" degani
double pi = 3.14159265;
```

!diqqat C++ da kasr qismi **vergul** bilan emas, **nuqta** bilan yoziladi: `3.14` to'g'ri, `3,14` noto'g'ri!

### `char` — bitta belgi

Bitta harf, raqam yoki belgi. Doim **bittalik qo'shtirnoq** ichida yoziladi:

```cpp
char baho = 'A';
char belgi = '?';
```

### `bool` — rost yoki yolg'on

Faqat ikki qiymatdan birini oladi: `true` (rost) yoki `false` (yolg'on). "Chiroq yoqilganmi?", "O'yin tugadimi?" kabi savollarga javob saqlash uchun qulay:

```cpp
bool chiroqYoniq = true;
bool oyinTugadi = false;
```

### `sizeof` — o'lchamni bilish

`sizeof` operatori biror tur yoki o'zgaruvchi xotirada necha bayt egallashini aytadi:

```cpp
#include <iostream>
using namespace std;

int main() {
    cout << "int:    " << sizeof(int) << " bayt" << endl;
    cout << "double: " << sizeof(double) << " bayt" << endl;
    cout << "char:   " << sizeof(char) << " bayt" << endl;
    cout << "bool:   " << sizeof(bool) << " bayt" << endl;
    return 0;
}
```

```output
int:    4 bayt
double: 8 bayt
char:   1 bayt
bool:   1 bayt
```

### Boshqa turlar guruhlari

Asosiy turlardan tashqari yana ikki guruh bor, ular bilan keyingi modullarda tanishamiz:

- **Hosila turlar** — asosiy turlardan yasaladi: massivlar, ko'rsatkichlar, havolalar, funksiyalar.
- **Foydalanuvchi turlari** — dasturchi o'zi yaratadi: `struct`, `class`, `union`, `enum`.

!mashq O'zing haqingda ma'lumot saqlaydigan dastur yoz: yoshing (`int`), bo'ying (`double`), ismingning birinchi harfi (`char`) va "uy hayvoning bormi?" savoliga javob (`bool`). Hammasini ekranga chiqar.

### Xulosa

- Ma'lumot turi qanday qiymat saqlanishi va qancha joy egallashini belgilaydi.
- Asosiy turlar: `int`, `float`, `double`, `char`, `bool`, `void`.
- `sizeof` yordamida turning o'lchamini bilish mumkin.

## C++ da modifikatorlar

### Umumiy ma'lumot

Kiyim do'konida bir xil ko'ylakning S, M, L, XL o'lchamlari bo'ladi. C++ da ham asosiy turlarning "o'lchamini" o'zgartirish mumkin. Buning uchun **modifikatorlar** ishlatiladi. Ular tur oldidan yoziladi va uning qanday qiymatlarni saqlay olishini o'zgartiradi.

C++ da to'rtta asosiy modifikator bor:

| Modifikator | Ma'nosi |
|---|---|
| `signed` | Ishorali — manfiy va musbat sonlar (odatiy holat) |
| `unsigned` | Ishorasiz — faqat musbat sonlar va nol |
| `short` | Qisqa — kamroq joy, kichikroq oraliq |
| `long` | Uzun — ko'proq joy, kattaroq oraliq |

!img m4_modifiers.png | Modifikatorlar sonlar oralig'ini qanday o'zgartiradi | 6.3

### `signed` va `unsigned`

Oddiy `int` ham manfiy, ham musbat sonlarni saqlaydi. Agar sen bilsangki, son hech qachon manfiy bo'lmaydi (masalan, odamlar soni), `unsigned` dan foydalanishing mumkin. Shunda musbat tomonda ikki barobar ko'p joy bo'ladi.

```cpp
#include <iostream>
using namespace std;

int main() {
    signed int harorat = -15;
    unsigned int sahifalar = 350;
    cout << "Harorat: " << harorat << endl;
    cout << "Sahifalar: " << sahifalar << endl;
    return 0;
}
```

```output
Harorat: -15
Sahifalar: 350
```

### `short` va `long`

```cpp
short sinfdagiPartalar = 15;                   // kichik son
long long yulduzlarSoni = 100000000000LL;      // juda katta son
```

### Oraliqlar jadvali

| Tur | O'lchami | Oralig'i (taxminan) |
|---|---|---|
| `short` | 2 bayt | -32 768 dan 32 767 gacha |
| `unsigned short` | 2 bayt | 0 dan 65 535 gacha |
| `int` | 4 bayt | -2.1 mlrd dan 2.1 mlrd gacha |
| `unsigned int` | 4 bayt | 0 dan 4.2 mlrd gacha |
| `long long` | 8 bayt | -9.2 × 10¹⁸ dan 9.2 × 10¹⁸ gacha |
| `unsigned long long` | 8 bayt | 0 dan 18.4 × 10¹⁸ gacha |
| `long double` | 8–16 bayt | `double` dan ham aniqroq kasr sonlar |

!fakt Yer yuzidagi odamlar soni 8 milliarddan oshgan. Bu son oddiy `int` ga sig'maydi! Uni saqlash uchun `long long` kerak bo'ladi.

### To'lib ketish (overflow)

Agar o'zgaruvchiga u sig'dira oladigan eng katta qiymatdan kattaroq son yozmoqchi bo'lsang, **to'lib ketish** sodir bo'ladi. `unsigned` turlarda bu xuddi avtomobil spidometriga o'xshaydi: eng katta qiymatdan keyin yana noldan boshlanadi.

```cpp
#include <iostream>
using namespace std;

int main() {
    unsigned short s = 65535;   // eng katta qiymat
    s = s + 1;
    cout << s << endl;           // yana 0 dan boshlandi!
    return 0;
}
```

```output
0
```

!diqqat Oddiy (signed) `int` da to'lib ketish "aniqlanmagan xatti-harakat" hisoblanadi — dastur nima qilishini oldindan aytib bo'lmaydi. Shuning uchun katta sonlar uchun har doim yetarlicha katta tur tanla.

!mashq `sizeof` yordamida `short`, `long` va `long long` turlarining o'lchamini ekranga chiqar.

### Xulosa

- Modifikatorlar asosiy turlarning oralig'i va o'lchamini o'zgartiradi.
- `unsigned` — faqat musbat sonlar, `short` — kichik, `long` — katta oraliq.
- Qiymat tur oralig'idan chiqib ketsa, to'lib ketish sodir bo'ladi.

## C++ da o'zgarmaslar (konstantalar)

### Umumiy ma'lumot

Ba'zi qiymatlar hech qachon o'zgarmaydi: haftada doim 7 kun, bir soatda doim 60 daqiqa, π soni doim 3.14159... ga teng. Bunday qiymatlarni dasturda **o'zgarmaslar** (konstantalar) sifatida saqlaymiz. O'zgarmasni bir marta yaratgandan keyin uni o'zgartirib bo'lmaydi — u xuddi qulflangan qutiga o'xshaydi.

!img m4_const.png | const — qulflangan quti: qiymatni o'qish mumkin, o'zgartirish mumkin emas | 5.8

### `const` kalit so'zi

O'zgarmas yaratishning eng keng tarqalgan usuli — turdan oldin `const` so'zini yozish:

```cpp
#include <iostream>
using namespace std;

int main() {
    const double PI = 3.14159;
    const int HAFTA_KUNLARI = 7;

    double r = 5;
    cout << "Doira yuzi: " << PI * r * r << endl;
    cout << "3 haftada " << 3 * HAFTA_KUNLARI << " kun bor" << endl;
    return 0;
}
```

```output
Doira yuzi: 78.5397
3 haftada 21 kun bor
```

Agar o'zgarmasni o'zgartirishga urinsang, kompilyator darhol xato beradi:

```cpp
const int MAX_BAHO = 5;
MAX_BAHO = 10;   // XATO! O'zgarmasni o'zgartirib bo'lmaydi
```

!eslatma `const` o'zgaruvchiga e'lon qilinayotgan paytda albatta qiymat berish kerak. `const int X;` deb yozib, keyin qiymat berib bo'lmaydi.

### `#define` yordamida o'zgarmas

Bu C tilidan qolgan eski usul. Preprotsessor kodni kompilyatsiyadan oldin ko'rib chiqadi va nomni qiymat bilan almashtiradi:

```cpp
#include <iostream>
#define MAKTAB_RAQAMI 42
using namespace std;

int main() {
    cout << "Men " << MAKTAB_RAQAMI << "-maktabda o'qiyman" << endl;
    return 0;
}
```

```output
Men 42-maktabda o'qiyman
```

!maslahat Zamonaviy C++ da `#define` o'rniga `const` (yoki `constexpr`) ishlatish tavsiya etiladi, chunki `const` ning turi bor va kompilyator uni yaxshiroq tekshiradi.

### `constexpr` — kompilyatsiya vaqtidagi o'zgarmas

`constexpr` — qiymati dastur ishga tushishidan oldin, kompilyatsiya paytidayoq hisoblanadigan o'zgarmas:

```cpp
constexpr int DAQIQA_SONIYALARI = 60;
constexpr int SOAT_SONIYALARI = 60 * DAQIQA_SONIYALARI;   // 3600
```

### Literallar — kod ichidagi tayyor qiymatlar

Kod ichiga to'g'ridan-to'g'ri yozilgan qiymatlar **literallar** deb ataladi:

| Literal turi | Misollar |
|---|---|
| Butun son | `42`, `-7`, `0` |
| Kasr son | `3.14`, `2.5e3` (= 2500) |
| Belgi | `'A'`, `'\n'` |
| Satr (matn) | `"Salom"` |
| Mantiqiy | `true`, `false` |

### Maxsus belgilar (escape ketma-ketliklar)

Ba'zi belgilarni to'g'ridan-to'g'ri yozib bo'lmaydi, ular teskari qiya chiziq `\` bilan yoziladi:

| Belgi | Ma'nosi |
|---|---|
| `\n` | Yangi qator |
| `\t` | Tabulyatsiya (katta bo'shliq) |
| `\"` | Qo'shtirnoq belgisi |
| `\\` | Teskari qiya chiziqning o'zi |

```cpp
#include <iostream>
using namespace std;

int main() {
    cout << "Ism:\tMalika\nYosh:\t12\n";
    cout << "U \"Salom!\" dedi." << endl;
    return 0;
}
```

```output
Ism:	Malika
Yosh:	12
U "Salom!" dedi.
```

!mashq `const` yordamida bir kundagi soatlar sonini (24) saqla va bir haftada necha soat borligini hisoblab chiqar.

### Xulosa

- O'zgarmas — bir marta qiymat berilgandan keyin o'zgartirib bo'lmaydigan qiymat.
- `const`, `constexpr` va `#define` — o'zgarmas yaratish usullari; zamonaviy C++ da `const` va `constexpr` afzal.
- Literallar — kod ichiga to'g'ridan-to'g'ri yozilgan qiymatlar.

## C++ dagi kalit so'zlar

### Umumiy ma'lumot

Har bir tilda alohida ma'noga ega so'zlar bor. C++ da ham kompilyator uchun maxsus ma'noga ega bo'lgan so'zlar mavjud, ular **kalit so'zlar** (inglizcha *keywords*) yoki **zahiralangan so'zlar** deb ataladi. Masalan, `int` so'zi "butun son turi", `if` esa "agar" degan ma'noni bildiradi.

Kalit so'zlarni o'zgaruvchi, funksiya yoki klass nomi sifatida ishlatib **bo'lmaydi**, chunki ular allaqachon "band".

!img m4_keywords.png | C++ ning eng ko'p ishlatiladigan kalit so'zlaridan ba'zilari | 6.3

```cpp
int int = 5;       // XATO! int — kalit so'z
int son = 5;       // To'g'ri
```

### Kalit so'zlar guruhlari

| Guruh | Kalit so'zlar |
|---|---|
| Ma'lumot turlari | `int`, `char`, `bool`, `float`, `double`, `void`, `wchar_t` |
| Modifikatorlar | `signed`, `unsigned`, `short`, `long`, `const` |
| Shartlar | `if`, `else`, `switch`, `case`, `default` |
| Tsikllar | `for`, `while`, `do` |
| Sakrash | `break`, `continue`, `return`, `goto` |
| Klasslar (OOP) | `class`, `struct`, `public`, `private`, `protected`, `this`, `virtual`, `friend` |
| Xotira | `new`, `delete` |
| Xatolar | `try`, `catch`, `throw` |
| Boshqalar | `namespace`, `using`, `auto`, `static`, `true`, `false`, `nullptr`, `template` |

!fakt C++ da 90 dan ortiq kalit so'z bor. Ularning hammasini yod olish shart emas — dastur yozgan sari ular o'z-o'zidan esda qoladi.

### Identifikatorlar — biz beradigan nomlar

O'zgaruvchi, funksiya, klass kabi narsalarga biz beradigan nomlar **identifikatorlar** deyiladi. Ular uchun qoidalar:

1. Faqat lotin harflari, raqamlar va pastki chiziq `_` dan iborat bo'lishi mumkin.
2. Raqam bilan boshlanishi mumkin emas.
3. Bo'sh joy (probel) bo'lishi mumkin emas.
4. Kalit so'z bo'lishi mumkin emas.
5. Katta va kichik harflar farqlanadi: `Yosh` va `yosh` — turli nomlar.

| Nom | To'g'rimi? | Sabab |
|---|---|---|
| `yosh` | Ha | Hammasi qoidaga mos |
| `oquvchi_soni` | Ha | Pastki chiziq mumkin |
| `son2` | Ha | Raqam oxirida — mumkin |
| `2son` | Yo'q | Raqam bilan boshlangan |
| `mening yoshim` | Yo'q | Probel bor |
| `class` | Yo'q | Kalit so'z |
| `o'quvchi` | Yo'q | Apostrof belgisi mumkin emas |

!diqqat O'zbekcha nomlarda `o'` va `g'` harflari uchrasa, apostrofni tashlab yoz: `o'quvchi` emas, `oquvchi`; `g'olib` emas, `golib`.

!mashq Quyidagi nomlardan qaysilari to'g'ri ekanini aniqla: `ball`, `1-joy`, `_maxfiy`, `return`, `uyVazifasi`, `sinf 6`.

### Xulosa

- Kalit so'zlar — C++ da maxsus ma'noga ega band so'zlar.
- Ularni o'zgaruvchi yoki funksiya nomi sifatida ishlatib bo'lmaydi.
- Identifikatorlar harf yoki `_` bilan boshlanadi, probel va maxsus belgilarsiz yoziladi.

## C++ da o'zgaruvchilar

### Umumiy ma'lumot

O'zgaruvchi — bu xotiradagi **nomlangan quti**. Uning ichiga qiymat solish, qiymatni ko'rish va kerak bo'lsa, boshqa qiymat bilan almashtirish mumkin. Shuning uchun u "o'zgaruvchi" deb ataladi — ichidagi qiymat o'zgarishi mumkin.

Har bir qutining:

- **nomi** bor (masalan, `yosh`),
- **turi** bor (masalan, `int` — faqat butun sonlar uchun quti),
- **qiymati** bor (masalan, `12`).

!img m4_variables.png | O'zgaruvchi — nomi, turi va qiymati bor quti | 5.8

### O'zgaruvchini e'lon qilish va qiymat berish

```cpp
int yosh;          // e'lon qilish: "yosh" nomli quti yaratdik
yosh = 12;         // qiymat berish: qutiga 12 ni soldik

int ball = 95;     // ikkalasini birdaniga qilish (initsializatsiya)
```

Bir nechta o'zgaruvchini bitta qatorda ham e'lon qilish mumkin:

```cpp
int a = 1, b = 2, c = 3;
```

### Initsializatsiya usullari

C++ da o'zgaruvchiga boshlang'ich qiymat berishning bir necha usuli bor:

```cpp
int x = 10;     // an'anaviy usul
int y(20);      // qavs bilan
int z{30};      // figurali qavs bilan (zamonaviy usul)
```

!maslahat Figurali qavs `{}` bilan initsializatsiya xavfsizroq: agar `int n{3.7};` deb yozsang, kompilyator kasr qism yo'qolishini sezib, ogohlantiradi.

!diqqat Qiymat berilmagan mahalliy o'zgaruvchi ichida "axlat" — tasodifiy qiymat bo'ladi. Shuning uchun o'zgaruvchiga har doim boshlang'ich qiymat ber.

### Qiymatni o'zgartirish

```cpp
#include <iostream>
using namespace std;

int main() {
    int tangalar = 10;
    cout << "Boshida: " << tangalar << endl;

    tangalar = tangalar + 5;     // 5 ta tanga topdik
    cout << "Topgandan keyin: " << tangalar << endl;

    tangalar = tangalar - 3;     // 3 tasini sarfladik
    cout << "Sarflagandan keyin: " << tangalar << endl;
    return 0;
}
```

```output
Boshida: 10
Topgandan keyin: 15
Sarflagandan keyin: 12
```

### Klaviaturadan qiymat o'qish: `cin`

O'zgaruvchiga qiymatni foydalanuvchi o'zi kiritishi mumkin. Buning uchun `cin` va `>>` ishlatiladi:

```cpp
#include <iostream>
using namespace std;

int main() {
    int yosh;
    cout << "Yoshingni kirit: ";
    cin >> yosh;
    cout << "Keyingi yili sen " << yosh + 1 << " yoshda bo'lasan!" << endl;
    return 0;
}
```

```output
Yoshingni kirit: 12
Keyingi yili sen 13 yoshda bo'lasan!
```

### O'zgaruvchilarning ko'lami (scope)

O'zgaruvchi qayerda e'lon qilinganiga qarab, dasturning ma'lum qismidagina "ko'rinadi":

- **Mahalliy (local) o'zgaruvchi** — funksiya yoki blok `{ }` ichida e'lon qilinadi va faqat o'sha yerda ishlaydi.
- **Global o'zgaruvchi** — barcha funksiyalardan tashqarida e'lon qilinadi va dasturning hamma joyida ko'rinadi.

```cpp
#include <iostream>
using namespace std;

int maktab = 42;            // global o'zgaruvchi

int main() {
    int sinf = 6;            // mahalliy o'zgaruvchi
    cout << maktab << "-maktab, " << sinf << "-sinf" << endl;
    {
        int parta = 3;       // faqat shu blok ichida
        cout << "Parta: " << parta << endl;
    }
    // bu yerda "parta" endi mavjud emas
    return 0;
}
```

```output
42-maktab, 6-sinf
Parta: 3
```

!eslatma Global o'zgaruvchilardan iloji boricha kam foydalan. Agar dasturning hamma qismi bitta o'zgaruvchini o'zgartira olsa, xatoni topish qiyinlashadi.

### Ikki o'zgaruvchi qiymatini almashtirish

Ikki stakandagi sharbatni almashtirish uchun uchinchi bo'sh stakan kerak bo'ladi. O'zgaruvchilar bilan ham shunday:

```cpp
#include <iostream>
using namespace std;

int main() {
    int a = 5, b = 9;
    int temp = a;   // a ni vaqtincha saqlab qo'yamiz
    a = b;
    b = temp;
    cout << "a = " << a << ", b = " << b << endl;
    return 0;
}
```

```output
a = 9, b = 5
```

!mashq Foydalanuvchidan ikki son so'rab, ularning yig'indisi, ayirmasi va ko'paytmasini ekranga chiqaruvchi dastur yoz.

### Xulosa

- O'zgaruvchi — nomi, turi va qiymati bor xotiradagi quti.
- `cin >>` yordamida qiymatni klaviaturadan o'qish mumkin.
- Mahalliy o'zgaruvchilar faqat o'z bloki ichida, globallari esa hamma joyda ko'rinadi.
- O'zgaruvchiga doim boshlang'ich qiymat berishni odat qil.

## C++ da `auto` kalit so'zi

### Umumiy ma'lumot

Tasavvur qil, senga sovg'a qutisi berishdi. Qutini ochib, ichida nima borligini ko'rib, darhol bilib olasan: "Bu kitob!". C++ dagi `auto` kalit so'zi ham shunday ishlaydi: kompilyator o'zgaruvchiga berilgan qiymatga qarab, uning turini **o'zi aniqlaydi**.

`auto` C++11 versiyasida qo'shilgan va dasturchilar orasida juda mashhur bo'lib ketgan.

!img m4_auto.png | auto — kompilyator turni qiymatga qarab o'zi topadi | 5.8

### Qanday ishlaydi?

```cpp
#include <iostream>
using namespace std;

int main() {
    auto son = 25;          // int
    auto narx = 9.99;       // double
    auto harf = 'K';        // char
    auto javob = true;      // bool

    cout << son << " " << narx << " " << harf << " " << javob << endl;
    return 0;
}
```

```output
25 9.99 K 1
```

!eslatma `bool` qiymat `cout` orqali chiqarilganda `true` o'rniga `1`, `false` o'rniga `0` ko'rinadi. So'z bilan chiqarish uchun `cout << boolalpha << javob;` deb yoz.

### `auto` ning qoidalari

1. `auto` bilan e'lon qilingan o'zgaruvchiga **albatta** darhol qiymat berish kerak, aks holda kompilyator turni aniqlay olmaydi.
2. Tur bir marta aniqlangandan keyin o'zgarmaydi.

```cpp
auto x;          // XATO! Qiymat yo'q — turni bilib bo'lmaydi
auto y = 10;     // y — int
y = 3.7;         // y baribir int, shuning uchun 3 saqlanadi
```

### `auto` qachon foydali?

Kichik turlar uchun `int` yoki `double` deb yozish oson. Lekin keyinroq (STL modulida) juda uzun nomli turlar bilan uchrashasan. Masalan:

```cpp
std::map<std::string, std::vector<int>>::iterator it = baholar.begin();
```

Buning o'rniga shunchaki quyidagicha yozish mumkin:


### `auto` va `for` tsikli

`auto` ayniqsa ro'yxatdagi elementlarni birma-bir ko'rib chiqishda qulay:

```cpp
#include <iostream>
#include <vector>
using namespace std;

int main() {
    vector<int> baholar = {5, 4, 5, 3, 5};
    for (auto b : baholar) {
        cout << b << " ";
    }
    cout << endl;
    return 0;
}
```

```output
5 4 5 3 5 
```

!maslahat `auto` ni turi aniq ko'rinib turgan yoki juda uzun bo'lgan joylarda ishlat. Agar kodni o'qiyotgan odam turni taxmin qila olmasa, turni to'liq yozgan ma'qul.

!mashq `auto` yordamida to'rtta o'zgaruvchi yarat: sevimli soning, sevimli harfing, bo'ying (kasr son) va "matematika yoqadimi?" degan savolga javob.

### Xulosa

- `auto` kompilyatorga o'zgaruvchi turini qiymatga qarab aniqlashni buyuradi.
- `auto` bilan e'lon qilingan o'zgaruvchiga darhol qiymat berish shart.
- U ayniqsa uzun tur nomlari va tsikllarda qulay.
