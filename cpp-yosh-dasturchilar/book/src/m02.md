# 2-modul. C++ da dastur yaratish mexanizmi

!img banner02.png | | 5.5

Dastur yozish uchun kompyuterga maxsus vositalarni o'rnatish kerak. Bu modulda ular nima ekanini, qanday o'rnatilishini va sen yozgan matn qanday qilib haqiqiy dasturga aylanishini bilib olasan.

## C++ muhitini sozlash

### Umumiy ma'lumot

Kompyuter aslida faqat **0 va 1** lardan iborat "mashina tili"ni tushunadi. Biz esa C++ da odamlarga tushunarli so'zlar bilan yozamiz: `int`, `if`, `cout` va hokazo. Demak, bizga "tarjimon" kerak. Bu tarjimon **kompilyator** deb ataladi.

C++ da dastur yozish uchun ikkita narsa kerak:

1. **Matn muharriri** — kodni yozish uchun dastur (oddiy Bloknot ham bo'laveradi, lekin maxsus muharrirlar ancha qulay).
2. **Kompilyator** — yozilgan kodni kompyuter tushunadigan tilga o'giruvchi dastur.

Ko'pincha bu ikkalasi bitta dasturga birlashtiriladi. Bunday dastur **IDE** (Integrated Development Environment — integrallashgan ishlab chiqish muhiti) deb ataladi.

### Kod qanday qilib dasturga aylanadi?

!img m2_compile.png | Sen yozgan .cpp fayldan tayyor dasturgacha bo'lgan yo'l | 6.5

1. **Sen kod yozasan** va uni `salom.cpp` nomli faylga saqlaysan.
2. **Preprotsessor** `#include` kabi `#` bilan boshlanadigan qatorlarni bajaradi: kerakli kutubxonalarni kodga qo'shib qo'yadi.
3. **Kompilyator** kodni tekshiradi. Agar xato bo'lsa, qaysi qatorda ekanini aytadi. Xato bo'lmasa, kodni mashina tiliga o'giradi.
4. **Linker** (bog'lovchi) sening kodingni tayyor kutubxonalar bilan birlashtiradi.
5. Natijada **tayyor dastur** paydo bo'ladi (Windows da `salom.exe`). Uni ishga tushirish mumkin!

!fakt Kompilyator juda sinchkov o'qituvchiga o'xshaydi: birorta nuqtali vergul (`;`) tushib qolsa ham, darrov "Xato!" deydi. Bundan xafa bo'lma — xatolarni topish ham dasturlashning bir qismi.

### Windows da o'rnatish (Code::Blocks misolida)

1. Brauzerda Code::Blocks rasmiy saytiga kir (codeblocks.org) va **Downloads** bo'limini och.
2. Nomi ichida **mingw-setup** so'zi bo'lgan faylni tanla. "MinGW" — bu Windows uchun GCC kompilyatori. U bilan birga yuklab olsang, alohida o'rnatish shart emas.
3. Yuklab olingan faylni ishga tushir va "Next" tugmalarini bosib o'rnatishni yakunla.
4. Code::Blocks ni och. **File → New → Project → Console application** ni tanla.
5. Tilni **C++** deb belgila, loyihaga nom ber va **Finish** ni bos.
6. Chap tomonda `main.cpp` fayli paydo bo'ladi. Uni ochib, **Build and Run** (F9) tugmasini bos.

!eslatma Dasturlarni internetdan yuklab olayotganda har doim kattalar bilan birga, faqat rasmiy saytlardan yuklab ol.

### Linux da o'rnatish

Linux da GCC kompilyatori ko'pincha oldindan o'rnatilgan bo'ladi. Bo'lmasa, terminalda quyidagi buyruq yetarli (Ubuntu misolida):

```terminal
sudo apt install g++
```

Keyin kodni kompilyatsiya qilish va ishga tushirish:

```terminal
g++ salom.cpp -o salom
./salom
```

### Onlayn kompilyatorlar

Agar kompyuterga hech narsa o'rnatishni xohlamasang, brauzerning o'zida ishlaydigan onlayn kompilyatorlardan foydalanish mumkin. Ularda chap tomonga kod yoziladi, "Run" tugmasi bosiladi va natija darhol ko'rinadi. Internetda "online C++ compiler" deb qidirsang, bunday saytlar ko'p chiqadi.

### Birinchi dasturimiz

Endi hammasi tayyor! Keling, birinchi dasturni yozamiz:

```cpp
#include <iostream>
using namespace std;

int main() {
    cout << "Salom! Men birinchi dasturimni yozdim!" << endl;
    return 0;
}
```

```output
Salom! Men birinchi dasturimni yozdim!
```

Har bir qatorni tushuntiramiz:

| Qator | Ma'nosi |
|---|---|
| `#include <iostream>` | Ekranga yozish va klaviaturadan o'qish uchun kutubxonani ulaymiz |
| `using namespace std;` | `std::` ni har safar yozmaslik uchun (bu haqda keyinroq batafsil) |
| `int main()` | Dastur shu yerdan boshlanadi. Har bir C++ dasturida `main` bo'lishi shart |
| `{ }` | Figurali qavslar ichida dastur tanasi joylashadi |
| `cout << "...";` | Qo'shtirnoq ichidagi matnni ekranga chiqaradi |
| `endl` | Yangi qatorga o'tadi |
| `return 0;` | "Dastur muvaffaqiyatli tugadi" degan xabar |

!diqqat C++ katta va kichik harflarni farqlaydi! `Main` va `main`, `Cout` va `cout` — bular turli so'zlar. Har doim kichik harf bilan yoz.

!mashq Dasturni o'zgartirib, ekranga o'z isming va yoshingni chiqar. Masalan: "Mening ismim Malika, men 12 yoshdaman."

### Xulosa

- Dastur yozish uchun matn muharriri va kompilyator kerak; ular birgalikda IDE deyiladi.
- Kod preprotsessor → kompilyator → linker bosqichlaridan o'tib, tayyor dasturga aylanadi.
- Boshlovchilar uchun Code::Blocks yoki onlayn kompilyator eng oson yo'l.
- Har bir C++ dasturi `main()` funksiyasidan boshlanadi.
