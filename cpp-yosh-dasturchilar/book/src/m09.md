# 9-modul. C++ da xotira sinflari

Har bir o'zgaruvchining o'z "hayoti" bor: u qachon tug'iladi, qachon yo'q bo'ladi va dasturning qaysi qismida ko'rinadi. Bularni **xotira sinflari** belgilaydi. Bu modul qisqa, lekin juda muhim: u dastur xotirasi qanday tashkil qilinganini tushunishga yordam beradi.

## C++ da xotira sinflari

!img c_storage.png | Har bir o'zgaruvchining o'z umri bor | 6.2

**Bu mavzuda nimani bilib olasan:**

- o'zgaruvchining "ko'lami", "umri" va "bog'lanishi" nima ekanini;
- `auto`, `register`, `static`, `extern`, `mutable`, `thread_local` xotira sinflarini;
- dastur xotirasi qanday qismlarga bo'linishini.

### Umumiy ma'lumot

Mehmonxonani tasavvur qil. Ba'zi mehmonlar bir kecha qolib, ertasi kuni ketadi. Ba'zilari esa u yerda doimiy yashaydi. Ba'zi xonalarga faqat o'sha qavatdagilar kira oladi, ba'zilariga esa hamma.

O'zgaruvchilar ham shunday. **Xotira sinfi** (inglizcha *storage class*) o'zgaruvchining uchta xususiyatini belgilaydi:

| Xususiyat | Savol | Hayotiy o'xshatish |
|---|---|---|
| **Ko'lam** (scope) | Dasturning qaysi qismida ko'rinadi? | Qaysi qavatdagilar xonaga kira oladi |
| **Umr** (lifetime) | Qachon yaratiladi va qachon yo'q qilinadi? | Mehmon necha kun qoladi |
| **Bog'lanish** (linkage) | Boshqa fayllardan ko'rinadimi? | Boshqa binodan kelib foydalansa bo'ladimi |

!img m9_storage.png | Xotira sinflariga qarab o'zgaruvchilarning "umri" | 6.3

### C++ dagi xotira sinflari

| Kalit so'z | Ko'lam | Umr | Qisqacha |
|---|---|---|---|
| (yo'q) / `auto` | Blok ichida | Blok tugaguncha | Oddiy mahalliy o'zgaruvchi |
| `register` | Blok ichida | Blok tugaguncha | Eskirgan; C++17 da olib tashlangan |
| `static` | Blok yoki fayl | Dastur oxirigacha | Qiymatini eslab qoladi |
| `extern` | Global | Dastur oxirigacha | Boshqa fayldagi o'zgaruvchiga murojaat |
| `mutable` | Klass ichida | Obyekt bilan birga | `const` obyektda ham o'zgara oladi |
| `thread_local` | Har bir oqim uchun | Oqim tugaguncha | Har bir oqimning o'z nusxasi |

### 1. Avtomatik (mahalliy) o'zgaruvchilar

Funksiya yoki blok ichida e'lon qilingan oddiy o'zgaruvchilar **avtomatik** hisoblanadi. Ular blokka kirilganda tug'iladi va blokdan chiqilganda avtomatik yo'q bo'ladi:

```cpp
#include <iostream>
using namespace std;

void sanash() {
    int hisob = 0;          // har safar qaytadan yaratiladi
    hisob++;
    cout << "hisob = " << hisob << endl;
}

int main() {
    sanash();
    sanash();
    sanash();
    return 0;
}
```

```output
hisob = 1
hisob = 1
hisob = 1
```

!eslatma C++11 gacha `auto` kalit so'zi aynan "avtomatik xotira sinfi" degan ma'noni bildirgan. Hozir esa u butunlay boshqa vazifani — turni avtomatik aniqlashni bajaradi (4-modulga qara).

### 2. `static` — xotirasi bor o'zgaruvchi

Agar mahalliy o'zgaruvchi oldiga `static` qo'yilsa, u **faqat bir marta** yaratiladi va funksiya tugaganda ham yo'q bo'lmaydi. Keyingi chaqiruvda u oldingi qiymatini eslab qoladi:

```cpp
#include <iostream>
using namespace std;

void sanash() {
    static int hisob = 0;   // faqat birinchi chaqiruvda 0 bo'ladi
    hisob++;
    cout << "Funksiya " << hisob << "-marta chaqirildi" << endl;
}

int main() {
    sanash();
    sanash();
    sanash();
    return 0;
}
```

```output
Funksiya 1-marta chaqirildi
Funksiya 2-marta chaqirildi
Funksiya 3-marta chaqirildi
```

Ko'rib turganingdek, `static` o'zgaruvchi funksiya ichida "yashirin" (tashqaridan ko'rinmaydi), lekin xuddi global o'zgaruvchidek uzoq yashaydi. Bu juda qulay: masalan, o'yinda nechta dushman yo'q qilinganini sanash uchun.

Global o'zgaruvchi oldidagi `static` esa boshqa ma'noga ega: u o'zgaruvchini **faqat shu fayl ichida** ko'rinadigan qiladi.

### 3. `extern` — boshqa fayldagi o'zgaruvchi

Katta loyihalar bir nechta `.cpp` fayldan iborat bo'ladi. Agar bitta faylda global o'zgaruvchi e'lon qilingan bo'lsa, boshqa faylda uni ishlatish uchun `extern` yoziladi. Bu kompilyatorga: "Bu o'zgaruvchi boshqa joyda yaratilgan, menga faqat uning nomi va turini ayt" degani:

```cpp
// sozlamalar.cpp
int maxOchko = 100;          // haqiqiy o'zgaruvchi shu yerda
```

```cppx
// main.cpp
#include <iostream>
using namespace std;

extern int maxOchko;         // "bu o'zgaruvchi boshqa faylda bor"

int main() {
    cout << "Maksimal ochko: " << maxOchko << endl;
    return 0;
}
```

Ikkala faylni birga kompilyatsiya qilish:

```terminal
g++ main.cpp sozlamalar.cpp -o oyin
```

### 4. `mutable` — `const` obyektda ham o'zgaradi

Bu klasslar bilan bog'liq (10-modulda o'rganamiz). Agar obyekt `const` bo'lsa, uning maydonlarini o'zgartirib bo'lmaydi. Lekin `mutable` deb belgilangan maydon bundan istisno:

```cpp
#include <iostream>
using namespace std;

class Kitob {
public:
    string nom;
    mutable int oqishlar = 0;     // const bo'lsa ham o'zgara oladi
    Kitob(string n) : nom(n) {}
    void oqi() const {
        oqishlar++;               // ruxsat bor, chunki mutable
        cout << nom << " o'qildi (" << oqishlar << "-marta)" << endl;
    }
};

int main() {
    const Kitob k("Alpomish");
    k.oqi();
    k.oqi();
    return 0;
}
```

```output
Alpomish o'qildi (1-marta)
Alpomish o'qildi (2-marta)
```

### 5. `thread_local` — har bir oqimga alohida nusxa

Zamonaviy dasturlar bir vaqtning o'zida bir nechta ishni parallel bajarishi mumkin — bular **oqimlar** (thread) deyiladi. `thread_local` o'zgaruvchining har bir oqim uchun alohida nusxasi bo'ladi. Bu murakkab mavzu, u haqida 13-modulda qisqacha gaplashamiz.

### 6. `register` (eskirgan)

Ilgari `register` kompilyatorga "bu o'zgaruvchini protsessorning eng tez xotirasi — registrda saqla" degan maslahat edi. Zamonaviy kompilyatorlar bu ishni dasturchidan ancha yaxshi bajaradi, shuning uchun C++17 da bu kalit so'z olib tashlangan.

### Ichkarida nima bo'ladi? Dastur xotirasining xaritasi

Dastur ishga tushganda operatsion tizim unga xotira ajratadi va bu xotira bir nechta "hududga" bo'linadi:

| Hudud | Nima saqlanadi | Umri |
|---|---|---|
| **Kod** | Dasturning mashina buyruqlari | Dastur oxirigacha |
| **Statik/global ma'lumotlar** | Global va `static` o'zgaruvchilar | Dastur oxirigacha |
| **Stek** (stack) | Mahalliy o'zgaruvchilar, funksiya parametrlari | Funksiya/blok tugaguncha |
| **Uyum** (heap) | `new` bilan yaratilgan ma'lumotlar | `delete` qilinguncha |

- **Stek** — juda tez, lekin kichik (odatda bir necha megabayt). Funksiya chaqirilganda u yerda joy ochiladi, tugaganda avtomatik yopiladi. 6-moduldagi rekursiya va likopchalar taxlamini esla!
- **Uyum** — katta, lekin sekinroq. U yerdagi xotirani dasturchi o'zi boshqaradi (yoki aqlli ko'rsatkichlar yordamida). Bu haqda 11-modulda batafsil.
- **Statik hudud** — dastur boshidan oxirigacha mavjud. Global va `static` o'zgaruvchilar shu yerda yashaydi va agar qiymat berilmagan bo'lsa, avtomatik 0 bo'ladi.

!fakt Mahalliy o'zgaruvchilar avtomatik 0 bo'lmaydi (ularda "axlat" bo'ladi), global va `static` o'zgaruvchilar esa doim 0 dan boshlanadi. Sababi — ular turli xotira hududlarida saqlanadi!

### Ko'p uchraydigan xatolar

| Xato | Muammo | To'g'risi |
|---|---|---|
| Mahalliy o'zgaruvchi qiymatini keyingi chaqiruvda kutish | Har safar qaytadan yaratiladi | `static` ishlat |
| Funksiyadan mahalliy o'zgaruvchiga ko'rsatkich qaytarish | Funksiya tugagach o'zgaruvchi yo'q — xavfli | `static` yoki dinamik xotira, yaxshisi qiymatni qaytar |
| `extern int x;` yozib, hech qayerda `int x;` yaratmaslik | Linker xatosi: `undefined reference` | Bitta faylda haqiqiy e'lon bo'lishi shart |
| Juda katta massivni funksiya ichida yaratish | Stek to'lib ketishi mumkin | `static`, global yoki `vector` (uyumda) |

### Boshqa tillarda

| Tushuncha | C++ | Java | Python |
|---|---|---|---|
| Mahalliy o'zgaruvchi | Funksiya ichida | Metod ichida | Funksiya ichida |
| Global o'zgaruvchi | Funksiyalardan tashqarida | Yo'q (faqat `static` klass maydonlari) | Modul darajasida, `global` kalit so'zi bilan o'zgartiriladi |
| Funksiyaning "xotirasi" | `static` mahalliy o'zgaruvchi | Klass maydoni | Funksiya atributi yoki yopilish (closure) |
| Stek va uyum | Dasturchi tanlaydi | Obyektlar har doim uyumda | Hammasi uyumda |

**Python** da global o'zgaruvchini o'zgartirish:

```python
hisob = 0
def sanash():
    global hisob
    hisob += 1
    print("Chaqiruvlar:", hisob)

sanash()
sanash()
```

Stek va uyum tushunchalari barcha tillarda bor. Java va Python da obyektlar har doim uyumda yaratiladi va axlat yig'uvchi ularni tozalaydi. C++ da esa qayerda yaratishni dasturchi tanlaydi — bu tezlik va nazorat beradi.

!mashq `static` o'zgaruvchi yordamida `keyingiId()` funksiyasini yoz: u har safar chaqirilganda yangi raqam qaytarsin (1, 2, 3, ...). Uni o'quvchilarga ID raqam berish uchun ishlat.

### Xulosa

- Xotira sinfi o'zgaruvchining ko'lami, umri va bog'lanishini belgilaydi.
- Mahalliy o'zgaruvchilar stekda yashaydi va blok tugashi bilan yo'q bo'ladi.
- `static` mahalliy o'zgaruvchi qiymatini chaqiruvlar orasida eslab qoladi.
- `extern` boshqa fayldagi global o'zgaruvchiga murojaat qiladi.
- Dastur xotirasi kod, statik ma'lumotlar, stek va uyum hududlariga bo'linadi.

## 9-modul uchun mini-loyiha: O'yin statistikasi hisoblagichi

`static` o'zgaruvchilar yordamida o'yindagi hodisalarni sanaydigan dastur:

```cpp
#include <iostream>
using namespace std;

int jamiOchko = 0;                 // global — hamma joyda ko'rinadi

void dushmanniYengish(int ochko) {
    static int yengilganlar = 0;   // funksiya xotirasi
    yengilganlar++;
    jamiOchko += ochko;
    cout << "Dushman yengildi! (jami: " << yengilganlar
         << " ta, ochko: " << jamiOchko << ")" << endl;
    if (yengilganlar % 3 == 0) {
        cout << "  *** Bonus: har 3-g'alaba uchun +50 ochko! ***" << endl;
        jamiOchko += 50;
    }
}

void tangaYigish() {
    static int tangalar = 0;
    tangalar++;
    jamiOchko += 5;
    cout << "Tanga yig'ildi: " << tangalar << " ta" << endl;
}

int main() {
    dushmanniYengish(10);
    tangaYigish();
    dushmanniYengish(20);
    tangaYigish();
    tangaYigish();
    dushmanniYengish(15);
    cout << "\nYakuniy ochko: " << jamiOchko << endl;
    return 0;
}
```

```output
Dushman yengildi! (jami: 1 ta, ochko: 10)
Tanga yig'ildi: 1 ta
Dushman yengildi! (jami: 2 ta, ochko: 35)
Tanga yig'ildi: 2 ta
Tanga yig'ildi: 3 ta
Dushman yengildi! (jami: 3 ta, ochko: 60)
  *** Bonus: har 3-g'alaba uchun +50 ochko! ***

Yakuniy ochko: 110
```

!mashq Dasturga `bonusOlish()` funksiyasini qo'sh: u faqat birinchi chaqirilganda 100 ochko bersin, keyingi chaqiruvlarda esa "Bonus allaqachon olingan!" deb yozsin. Maslahat: `static bool olindi = false;`.
