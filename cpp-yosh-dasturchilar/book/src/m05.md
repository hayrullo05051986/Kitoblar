## C++ dagi tanlash ko'rsatmalari (if, else, switch)

### Umumiy ma'lumot

Har kuni biz ko'plab qarorlar qabul qilamiz: "Agar yomg'ir yog'sa, soyabon olaman, aks holda olmayman." Dastur ham shunday qarorlar qabul qila olishi kerak. 3-modulda ko'rsatmalar turlari bilan tanishgan edik. Endi ularning eng muhimlaridan biri — **tanlash ko'rsatmalari**ni batafsil o'rganamiz.

!img m5_if.png | if ko'rsatmasi: shartga qarab ikki yo'ldan biri tanlanadi | 5.5

### 1. `if` — agar

Eng oddiy shakl: shart rost bo'lsa, blok ichidagi kod bajariladi; yolg'on bo'lsa, o'tkazib yuboriladi.

```cpp
#include <iostream>
using namespace std;

int main() {
    int harorat = 30;
    if (harorat > 25) {
        cout << "Bugun issiq, muzqaymoq yeymiz!" << endl;
    }
    cout << "Kun yaxshi o'tsin!" << endl;
    return 0;
}
```

```output
Bugun issiq, muzqaymoq yeymiz!
Kun yaxshi o'tsin!
```

### 2. `if-else` — agar ... aks holda

Shart yolg'on bo'lganda boshqa ish bajarish uchun `else` qo'shiladi:

```cpp
#include <iostream>
using namespace std;

int main() {
    int son;
    cout << "Son kirit: ";
    cin >> son;
    if (son % 2 == 0) {
        cout << son << " — juft son" << endl;
    } else {
        cout << son << " — toq son" << endl;
    }
    return 0;
}
```

```output
Son kirit: 7
7 — toq son
```

### 3. `else if` — bir nechta shart

Ikkidan ko'p variant bo'lsa, `else if` zanjiridan foydalanamiz. Shartlar yuqoridan pastga tekshiriladi va birinchi rost shart bajariladi:

```cpp
#include <iostream>
using namespace std;

int main() {
    int ball;
    cout << "Test ballingni kirit (0-100): ";
    cin >> ball;

    if (ball >= 86) {
        cout << "Baho: 5 (a'lo)" << endl;
    } else if (ball >= 71) {
        cout << "Baho: 4 (yaxshi)" << endl;
    } else if (ball >= 56) {
        cout << "Baho: 3 (qoniqarli)" << endl;
    } else {
        cout << "Baho: 2 — yana bir oz harakat qil!" << endl;
    }
    return 0;
}
```

```output
Test ballingni kirit (0-100): 78
Baho: 4 (yaxshi)
```

### 4. Ichma-ich `if`

`if` ichida boshqa `if` ham bo'lishi mumkin:

```cpp
#include <iostream>
using namespace std;

int main() {
    int yosh = 12;
    bool chiptaBor = true;
    if (chiptaBor) {
        if (yosh >= 12) {
            cout << "Kinoga kirishing mumkin!" << endl;
        } else {
            cout << "Kattalar bilan kirish kerak." << endl;
        }
    } else {
        cout << "Avval chipta ol." << endl;
    }
    return 0;
}
```

```output
Kinoga kirishing mumkin!
```

!diqqat `if (x = 5)` deb yozish — juda xavfli xato! Bu yerda taqqoslash emas, qiymat berish bo'lyapti va shart har doim rost bo'lib qoladi. To'g'risi: `if (x == 5)`.

!maslahat Agar `if` ichida faqat bitta qator bo'lsa ham, figurali qavslarni `{ }` qo'yishni odat qil. Bu keyinchalik qator qo'shganda xato qilishdan saqlaydi.

### 5. `switch` — ko'p variantli tanlash

Agar bitta o'zgaruvchi ko'p aniq qiymatlardan biriga teng ekanini tekshirish kerak bo'lsa, `switch` qulayroq. U liftdagi tugmalarga o'xshaydi: qaysi tugma bosilsa, o'sha qavatga borasan.

```cpp
#include <iostream>
using namespace std;

int main() {
    int kun;
    cout << "Hafta kunining raqamini kirit (1-7): ";
    cin >> kun;

    switch (kun) {
        case 1: cout << "Dushanba" << endl; break;
        case 2: cout << "Seshanba" << endl; break;
        case 3: cout << "Chorshanba" << endl; break;
        case 4: cout << "Payshanba" << endl; break;
        case 5: cout << "Juma" << endl; break;
        case 6:
        case 7: cout << "Dam olish kuni!" << endl; break;
        default: cout << "Bunday kun yo'q" << endl;
    }
    return 0;
}
```

```output
Hafta kunining raqamini kirit (1-7): 6
Dam olish kuni!
```

`switch` ning qismlari:

| Qism | Vazifasi |
|---|---|
| `switch (kun)` | Qaysi o'zgaruvchi tekshirilishini bildiradi |
| `case 1:` | "Agar qiymat 1 bo'lsa, shu yerdan boshla" |
| `break;` | `switch` dan chiqish |
| `default:` | Hech bir `case` mos kelmasa bajariladi |

!eslatma Agar `break` ni unutsang, dastur keyingi `case` larni ham bajarib ketaveradi. Yuqoridagi misolda 6 va 7 uchun bu ataylab qilingan: ikkalasi ham "Dam olish kuni!" ni chiqaradi.

!eslatma `switch` faqat butun sonlar, `char` va `enum` bilan ishlaydi. Kasr sonlar yoki `string` bilan ishlatib bo'lmaydi.

### `if` mi yoki `switch` mi?

| Vaziyat | Tanlov |
|---|---|
| Oraliqlarni tekshirish (`ball >= 86`) | `if-else` |
| Murakkab shartlar (`a > 0 && b < 10`) | `if-else` |
| Bitta o'zgaruvchining aniq qiymatlari (1, 2, 3...) | `switch` |
| Menyu tanlash | `switch` |

!mashq Oddiy kalkulyator yoz: foydalanuvchi ikki son va amal belgisini (`+`, `-`, `*`, `/`) kiritsin. `switch` yordamida natijani hisobla. Nolga bo'lishni tekshirishni unutma!

### Xulosa

- `if` — shart rost bo'lsa bajariladi, `else` — aks holda.
- `else if` bir nechta shartni ketma-ket tekshiradi.
- `switch` bitta o'zgaruvchining aniq qiymatlarini tekshirish uchun qulay; har `case` oxirida `break` kerak.

## C++ da tsikllar

### Umumiy ma'lumot

Tasavvur qil, o'qituvching senga jazo sifatida (albatta hazil!) "Men darsga kechikmayman" gapini 100 marta yozishni buyurdi. Qo'lda yozish uzoq va zerikarli. Kompyuter esa bunday takroriy ishlarni bir zumda bajara oladi.

**Tsikl** (inglizcha *loop*) — bir xil kodni ko'p marta takrorlash uchun ishlatiladigan tuzilma. C++ da uchta asosiy tsikl bor: `for`, `while` va `do-while`.

!img m5_loop.png | for tsikli qanday ishlaydi | 5.8

### 1. `for` tsikli

Takrorlashlar soni oldindan ma'lum bo'lganda ishlatiladi. Uning uchta qismi bor:

```cpp
for (boshlanish; shart; o'zgarish) {
    // takrorlanadigan kod
}
```

| Qism | Misol | Vazifasi |
|---|---|---|
| Boshlanish | `int i = 1` | Hisoblagichni yaratadi (bir marta bajariladi) |
| Shart | `i <= 5` | Har qadam oldidan tekshiriladi; yolg'on bo'lsa, tsikl tugaydi |
| O'zgarish | `i++` | Har qadamdan keyin bajariladi |

```cpp
#include <iostream>
using namespace std;

int main() {
    for (int i = 1; i <= 5; i++) {
        cout << i << "-marta: Men darsga kechikmayman" << endl;
    }
    return 0;
}
```

```output
1-marta: Men darsga kechikmayman
2-marta: Men darsga kechikmayman
3-marta: Men darsga kechikmayman
4-marta: Men darsga kechikmayman
5-marta: Men darsga kechikmayman
```

Yana bir misol — ko'paytirish jadvali:

```cpp
#include <iostream>
using namespace std;

int main() {
    int n = 7;
    for (int i = 1; i <= 10; i++) {
        cout << n << " x " << i << " = " << n * i << endl;
    }
    return 0;
}
```

```output
7 x 1 = 7
7 x 2 = 14
7 x 3 = 21
7 x 4 = 28
7 x 5 = 35
7 x 6 = 42
7 x 7 = 49
7 x 8 = 56
7 x 9 = 63
7 x 10 = 70
```

### 2. `while` tsikli

Takrorlashlar soni oldindan noma'lum bo'lib, faqat shart ma'lum bo'lganda ishlatiladi. "Shart rost ekan, takrorla":

```cpp
#include <iostream>
using namespace std;

int main() {
    int pul = 1000;      // cho'chqachada 1000 so'm bor
    int kun = 0;
    while (pul < 5000) {
        pul = pul + 700;  // har kuni 700 so'm qo'shamiz
        kun++;
    }
    cout << kun << " kunda " << pul << " so'm yig'ildi" << endl;
    return 0;
}
```

```output
6 kunda 5200 so'm yig'ildi
```

### 3. `do-while` tsikli

`while` ga o'xshaydi, lekin shart **oxirida** tekshiriladi. Shuning uchun tsikl tanasi **kamida bir marta** albatta bajariladi. Menyu va parol so'rash uchun juda qulay:

```cpp
#include <iostream>
using namespace std;

int main() {
    int parol;
    do {
        cout << "Parolni kirit: ";
        cin >> parol;
    } while (parol != 1234);
    cout << "Xush kelibsan!" << endl;
    return 0;
}
```

```output
Parolni kirit: 1111
Parolni kirit: 1234
Xush kelibsan!
```

### Uchala tsiklni taqqoslash

| Tsikl | Shart qachon tekshiriladi | Kamida necha marta bajariladi | Qachon ishlatiladi |
|---|---|---|---|
| `for` | Boshida | 0 | Takrorlashlar soni ma'lum |
| `while` | Boshida | 0 | Faqat shart ma'lum |
| `do-while` | Oxirida | 1 | Kamida bir marta bajarish kerak |

### Diapazonli `for` (range-based for)

C++11 dan boshlab ro'yxatdagi har bir elementni oson ko'rib chiqish mumkin:

```cpp
#include <iostream>
using namespace std;

int main() {
    int baholar[] = {5, 4, 5, 5, 3};
    int yigindi = 0;
    for (int b : baholar) {
        yigindi += b;
    }
    cout << "Baholar yig'indisi: " << yigindi << endl;
    return 0;
}
```

```output
Baholar yig'indisi: 22
```

### Ichma-ich tsikllar

Tsikl ichida boshqa tsikl bo'lishi mumkin. Masalan, yulduzchalardan uchburchak chizamiz:

```cpp
#include <iostream>
using namespace std;

int main() {
    for (int qator = 1; qator <= 5; qator++) {
        for (int j = 1; j <= qator; j++) {
            cout << "* ";
        }
        cout << endl;
    }
    return 0;
}
```

```output
* 
* * 
* * * 
* * * * 
* * * * * 
```

### Cheksiz tsikl

Agar shart hech qachon yolg'on bo'lmasa, tsikl abadiy davom etadi:

```cpp
while (true) {
    // bu yerdan faqat break orqali chiqish mumkin
}
```

!diqqat Agar dasturing "qotib" qolsa va to'xtamasa, ehtimol cheksiz tsikl yuz bergan. Shartdagi o'zgaruvchi tsikl ichida o'zgarayotganini tekshir. Dasturni to'xtatish uchun konsolda **Ctrl + C** ni bos.

!mashq 1 dan 100 gacha bo'lgan barcha juft sonlarning yig'indisini hisoblovchi dastur yoz. (Javob: 2550)

### Xulosa

- Tsikllar kodni ko'p marta takrorlash uchun ishlatiladi.
- `for` — takrorlashlar soni ma'lum bo'lganda, `while` — faqat shart ma'lum bo'lganda.
- `do-while` kamida bir marta bajariladi.
- Shart hech qachon yolg'on bo'lmasa, cheksiz tsikl yuzaga keladi.

## C++ dagi sakrash ko'rsatmalari

### Umumiy ma'lumot

Ba'zan dastur bajarilishining odatiy tartibini o'zgartirish kerak bo'ladi: tsiklni muddatidan oldin to'xtatish, bitta qadamni o'tkazib yuborish yoki funksiyadan darhol chiqish. Buning uchun **sakrash ko'rsatmalari** ishlatiladi. C++ da ular to'rtta: `break`, `continue`, `return` va `goto`.

!img m5_jump.png | continue bitta qadamni o'tkazib yuboradi, break esa tsiklni butunlay to'xtatadi | 6.3

### 1. `break` — to'xta!

`break` tsikl yoki `switch` dan darhol chiqib ketadi. Masalan, ro'yxatdan birinchi manfiy sonni qidiramiz va topishimiz bilan to'xtaymiz:

```cpp
#include <iostream>
using namespace std;

int main() {
    int sonlar[] = {4, 8, 15, -3, 23, 42};
    for (int s : sonlar) {
        if (s < 0) {
            cout << "Manfiy son topildi: " << s << endl;
            break;           // qolganlarini tekshirish shart emas
        }
        cout << s << " tekshirildi" << endl;
    }
    return 0;
}
```

```output
4 tekshirildi
8 tekshirildi
15 tekshirildi
Manfiy son topildi: -3
```

### 2. `continue` — bu qadamni o'tkazib yubor

`continue` tsiklning joriy qadamidagi qolgan kodni o'tkazib yuboradi va darhol keyingi qadamga o'tadi:

```cpp
#include <iostream>
using namespace std;

int main() {
    // 1 dan 10 gacha, 3 ga bo'linadigan sonlarsiz
    for (int i = 1; i <= 10; i++) {
        if (i % 3 == 0) {
            continue;        // 3, 6, 9 ni o'tkazib yuboramiz
        }
        cout << i << " ";
    }
    cout << endl;
    return 0;
}
```

```output
1 2 4 5 7 8 10 
```

### 3. `return` — funksiyadan chiq

`return` funksiya bajarilishini to'xtatadi va (kerak bo'lsa) natijani qaytaradi. `main` ichidagi `return 0;` butun dasturni tugatadi:

```cpp
#include <iostream>
using namespace std;

int main() {
    int yosh;
    cout << "Yoshingni kirit: ";
    cin >> yosh;
    if (yosh < 0) {
        cout << "Yosh manfiy bo'lishi mumkin emas!" << endl;
        return 1;            // dasturni shu yerda tugatamiz
    }
    cout << "Rahmat!" << endl;
    return 0;
}
```

```output
Yoshingni kirit: -5
Yosh manfiy bo'lishi mumkin emas!
```

### 4. `goto` — belgiga sakra

`goto` dasturning belgilangan joyiga (yorliqqa) sakraydi:

```cpp
#include <iostream>
using namespace std;

int main() {
    int i = 1;
boshi:                       // yorliq
    cout << i << " ";
    i++;
    if (i <= 5) goto boshi;
    cout << endl;
    return 0;
}
```

```output
1 2 3 4 5 
```

!diqqat `goto` dan foydalanish tavsiya etilmaydi! U kodni chalkash "spagetti"ga aylantiradi va xatolarni topish qiyinlashadi. Deyarli har doim uning o'rniga tsikl yoki funksiya ishlatish mumkin.

### Ichma-ich tsikllarda `break`

`break` faqat **o'zi turgan eng ichki** tsikldan chiqadi:

```cpp
#include <iostream>
using namespace std;

int main() {
    for (int i = 1; i <= 3; i++) {
        for (int j = 1; j <= 3; j++) {
            if (j == 2) break;   // faqat ichki tsikldan chiqadi
            cout << "(" << i << "," << j << ") ";
        }
    }
    cout << endl;
    return 0;
}
```

```output
(1,1) (2,1) (3,1) 
```

### Taqqoslash jadvali

| Ko'rsatma | Nima qiladi | Qayerda ishlatiladi |
|---|---|---|
| `break` | Tsikl yoki `switch` dan chiqadi | `for`, `while`, `do-while`, `switch` |
| `continue` | Keyingi qadamga o'tadi | `for`, `while`, `do-while` |
| `return` | Funksiyadan chiqadi | Har qanday funksiya |
| `goto` | Yorliqqa sakraydi | Funksiya ichida (tavsiya etilmaydi) |

### Amaliy misol: son topish o'yini

```cpp
#include <iostream>
using namespace std;

int main() {
    const int SIRLI_SON = 37;
    int urinish = 0;
    while (true) {
        int taxmin;
        cout << "1 dan 100 gacha son o'yladim. Top: ";
        cin >> taxmin;
        urinish++;
        if (taxmin < 1 || taxmin > 100) {
            cout << "Faqat 1-100 oralig'idagi son!" << endl;
            continue;
        }
        if (taxmin < SIRLI_SON) {
            cout << "Kattaroq son ayt!" << endl;
        } else if (taxmin > SIRLI_SON) {
            cout << "Kichikroq son ayt!" << endl;
        } else {
            cout << "Topding! " << urinish << " ta urinishda." << endl;
            break;
        }
    }
    return 0;
}
```

```output
1 dan 100 gacha son o'yladim. Top: 50
Kichikroq son ayt!
1 dan 100 gacha son o'yladim. Top: 30
Kattaroq son ayt!
1 dan 100 gacha son o'yladim. Top: 37
Topding! 3 ta urinishda.
```

!mashq Son topish o'yinini o'zgartir: foydalanuvchiga faqat 7 ta urinish ber. 7 ta urinishda topa olmasa, "Yutqazding! Sirli son 37 edi" deb yozib, o'yinni tugat.

### Xulosa

- `break` — tsikldan chiqish, `continue` — keyingi qadamga o'tish.
- `return` — funksiyadan chiqish va natija qaytarish.
- `goto` mavjud, lekin undan foydalanmaslik kerak.
- `break` faqat eng ichki tsikldan chiqadi.
