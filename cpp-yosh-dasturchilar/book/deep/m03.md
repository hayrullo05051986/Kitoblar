| Izoh turi | Qayerda | Misol |
|---|---|---|

### Chuqurroq o'rganamiz: funksiya izohlari (hujjatlashtirish)

Katta loyihalarda funksiyalar oldiga maxsus formatdagi izohlar yoziladi. Ulardan maxsus dasturlar (masalan, **Doxygen**) avtomatik ravishda chiroyli hujjatlar (veb-sahifalar) yaratadi:

```cpp
#include <iostream>

/**
 * @brief Ikki sondan kattasini qaytaradi.
 *
 * @param a  birinchi son
 * @param b  ikkinchi son
 * @return   a va b dan kattasi
 */
int kattasi(int a, int b) {
    return (a > b) ? a : b;
}

int main() {
    cout << kattasi(17, 42) << endl;
    return 0;
}
```

```output

```

### Qadamma-qadam tahlil: yaxshi izohlangan dastur

Quyidagi dasturni o'qib chiq. Izohlar unga qanday yordam berayotganiga e'tibor ber:

```cpp
// =====================================================
//  Fayl:     harorat.cpp
//  Vazifasi: haftalik haroratlar statistikasi
//  Muallif:  Malika, 2026-yil
// =====================================================
#include <iostream>
using namespace std;

int main() {
    // Haftaning 7 kunidagi harorat (°C)
    int harorat[7] = {12, 15, 9, 18, 21, 17, 14};

    int jami = 0;
    int eng_issiq = harorat[0];       // dastlab 1-kunni eng issiq deb olamiz

    for (int i = 0; i < 7; i++) {
        jami += harorat[i];
        // Agar bugun avvalgi rekorddan issiq bo'lsa — rekordni yangilaymiz
        if (harorat[i] > eng_issiq) {
            eng_issiq = harorat[i];
        }
    }

    /* Natijalarni chiqaramiz.
       O'rtacha haroratni kasr son ko'rinishida hisoblash uchun
       jami ni double ga aylantiramiz (aks holda kasr qism yo'qoladi). */
    cout << "O'rtacha harorat: " << (double)jami / 7 << endl;
    cout << "Eng issiq kun: " << eng_issiq << " daraja" << endl;
    return 0;
}
```

```output
O'rtacha harorat: 15.1429
Eng issiq kun: 21 daraja
```

| Izoh | Turi | Nima uchun foydali |
|---|---|---|
| Fayl boshidagi blok | Sarlavha | Fayl nima uchun ekanini darhol ko'rsatadi |
| `// Haftaning 7 kunidagi...` | Tushuntiruvchi | Massivda nima saqlanishini va o'lchov birligini aytadi |
| `// dastlab 1-kunni...` | Tushuntiruvchi | Algoritm g'oyasini tushuntiradi |
| `/* Natijalarni... */` | Tushuntiruvchi | **Nima uchun** `double` ishlatilganini tushuntiradi |

### Chuqurroq o'rganamiz: C va C++ header fayllari

C++ C tilidan ko'plab kutubxonalarni meros qilib olgan. Ularning ikki xil nomi bor:

| C uslubidagi nom | C++ uslubidagi nom | Vazifasi |
|---|---|---|
| `<math.h>` | `<cmath>` | Matematik funksiyalar |
| `<stdio.h>` | `<cstdio>` | C uslubidagi kirish-chiqish (`printf`, `scanf`) |
| `<stdlib.h>` | `<cstdlib>` | Umumiy funksiyalar (`rand`, `abs`, `exit`) |
| `<string.h>` | `<cstring>` | C uslubidagi satrlar (`strlen`, `strcpy`) |
| `<ctype.h>` | `<cctype>` | Belgilarni tekshirish (`isdigit`, `toupper`) |
| `<time.h>` | `<ctime>` | Vaqt va sana |

C++ da **`c` bilan boshlanadigan, `.h` siz** nomlardan foydalanish tavsiya etiladi. Ularda funksiyalar `std` nomlar fazosiga joylashtirilgan.

!diqqat `<string>` va `<cstring>` — butunlay boshqa kutubxonalar! `<string>` — C++ ning qulay `string` klassi, `<cstring>` — C uslubidagi `char` massivlari bilan ishlash funksiyalari.

### Chuqurroq o'rganamiz: `<iomanip>` — chiroyli chiqarish

`<iomanip>` (input/output manipulators) chiqarishni formatlash uchun ishlatiladi. Bu juda foydali kutubxona:

```cpp

int main() {
    double pi = 3.14159265;
    cout << "Oddiy:       " << pi << endl;
    cout << "2 xona:      " << fixed << setprecision(2) << pi << endl;
    cout << "4 xona:      " << setprecision(4) << pi << endl;

    cout << "\nJadval:" << endl;
    cout << left << setw(10) << "Ism" << right << setw(6) << "Ball" << endl;
    cout << left << setw(10) << "Malika" << right << setw(6) << 98 << endl;
    cout << left << setw(10) << "Jasur" << right << setw(6) << 85 << endl;
    cout << setfill('0') << setw(5) << 42 << endl;
    return 0;
}
```

```output
2 xona:      3.14
4 xona:      3.1416
 
Jadval:
Ism         Ball
Malika        98
Jasur         85
00042
```

|---|---|

| Qadam | Nima bo'ladi |

### Chuqurroq o'rganamiz: namespace ga laqab (alias) berish

### Chuqurroq o'rganamiz: namespace ni bir necha joyda to'ldirish

Bitta namespace ni bir necha qismda e'lon qilish mumkin — barcha qismlar birlashadi. Bu katta loyihalarda turli fayllardagi kodlarni bitta namespace ga yig'ish uchun ishlatiladi:

```cpp
#include <iostream>

    return 0;
}
```

### Chuqurroq o'rganamiz: nomsiz namespace

Nomsiz (anonim) namespace ichidagi narsalar **faqat shu fayl ichida** ko'rinadi. Bu boshqa fayllardagi bir xil nomlar bilan to'qnashuvning oldini oladi:

```cpp
#include <iostream>
```

### Chuqurroq o'rganamiz: global namespace va `::`

Har qanday namespace dan tashqarida e'lon qilingan narsalar **global namespace** da bo'ladi. Unga murojaat qilish uchun `::` oldiga hech narsa yozilmaydi:

```cpp
#include <iostream>
```

### Qadamma-qadam tahlil: `using namespace std;` ning xavfi

Nima uchun professional dasturchilar `using namespace std;` dan ehtiyot bo'lishadi? Misol:

```cppx
#include <iostream>
#include <algorithm>
using namespace std;

int count = 0;                  // o'z o'zgaruvchimiz

int main() {
    count++;                    // XATO: qaysi count? bizniki yoki std::count?
    cout << count << endl;
    return 0;
```

Bu kod kompilyatsiya xatosi beradi, chunki `<algorithm>` kutubxonasida ham `std::count` funksiyasi bor. `using namespace std;` tufayli ikkala nom ham "ochiq" bo'lib qoldi va kompilyator qaysi birini tanlashni bilmaydi.

**Yechimlar:**

| Usul | Misol | Afzalligi |
|---|---|---|
| `std::` ni to'liq yozish | `std::cout << x;` | Hech qanday to'qnashuv yo'q |
| Faqat keraklilarini ochish | `using std::cout;` | Qulay va xavfsiz |
| O'z nomlarini o'zgartirish | `int hisoblagich = 0;` | Oddiy, lekin har doim ham imkoni yo'q |
| `using namespace std;` faqat funksiya ichida | `int main() { using namespace std; ... }` | Ta'sir doirasi kichik |

### Chuqurroq o'rganamiz: ko'rsatmalar va kompilyator

Kompilyator dasturni o'qiganda, uni ko'rsatmalarga ajratadi va har birini alohida tahlil qiladi. Har bir ko'rsatma turi kompilyator uchun boshqacha ishni anglatadi:

| Ko'rsatma turi | Kompilyator nima qiladi |
|---|---|
| E'lon qilish | Xotiradan joy ajratadi va nomni eslab qoladi |
| Ifoda | Hisoblash uchun mashina buyruqlarini yaratadi |
| Blok | Yangi "ko'rinish doirasi" ochadi |
| Tanlash | Shartli sakrash buyruqlarini yaratadi |
| Takrorlash | Orqaga sakrash buyruqlarini yaratadi |
| Sakrash | To'g'ridan-to'g'ri sakrash buyrug'ini yaratadi |

### Chuqurroq o'rganamiz: e'lon ko'rsatmalari batafsil

E'lon ko'rsatmalarining bir nechta shakli bor:

```cpp
int a;                    // faqat e'lon (qiymatsiz)
int b = 5;                // e'lon va qiymat berish
int c(7), d{9};           // boshqa usullar
int x = 1, y = 2, z = 3;  // bir nechta o'zgaruvchi
const int MAX = 100;      // o'zgarmas
auto e = 3.14;            // tur avtomatik aniqlanadi
```

Shuningdek, funksiya va klasslar ham e'lon ko'rsatmalari orqali yaratiladi:

```cpp
int kvadrat(int x);       // funksiya e'loni
class Oquvchi;            // klass e'loni
```

### Chuqurroq o'rganamiz: ifoda ko'rsatmalari va ularning "yon ta'siri"

Har qanday ifodaning oxiriga `;` qo'ysang, u ko'rsatmaga aylanadi. Lekin hamma ifoda ko'rsatmalari foydali emas:

| Ko'rsatma | Foydalimi? | Sabab |
|---|---|---|
| `x = 5;` | Ha | `x` ning qiymati o'zgaradi |
| `x++;` | Ha | `x` ning qiymati oshadi |
| `cout << x;` | Ha | Ekranga chiqaradi |
| `x + 5;` | Yo'q! | Hisoblanadi, lekin natija hech qayerga saqlanmaydi |
| `5;` | Yo'q | Hech narsa qilmaydi |

Ifodaning dasturga ta'sir qiladigan natijasi (o'zgaruvchini o'zgartirish, ekranga chiqarish) **yon ta'sir** (side effect) deyiladi. Yon ta'siri yo'q ko'rsatmalar foydasiz — kompilyator ko'pincha ular haqida ogohlantiradi.

### Chuqurroq o'rganamiz: blok va ko'rinish doirasi

Har bir blok `{ }` o'zining **ko'rinish doirasi**ni (scope) yaratadi. Blok ichida e'lon qilingan o'zgaruvchi blokdan chiqishi bilan yo'q bo'ladi:

```cpp
#include <iostream>
using namespace std;

int main() {
    int x = 1;
    cout << "Tashqi x: " << x << endl;
    {
        int x = 2;                     // yangi, ichki x — tashqisini "yashiradi"
        int y = 10;
        cout << "Ichki x: " << x << ", y: " << y << endl;
    }                                  // ichki x va y shu yerda yo'q bo'ladi
    cout << "Yana tashqi x: " << x << endl;
    // cout << y;                      // XATO: y endi mavjud emas
    return 0;
}
```

```output
Tashqi x: 1
Ichki x: 2, y: 10
Yana tashqi x: 1
```

!eslatma Ichki blokda tashqi o'zgaruvchi bilan bir xil nomli o'zgaruvchi yaratish mumkin, lekin bu chalkashlikka olib keladi. Bunday "yashirishdan" qochish yaxshi odat.

### Qadamma-qadam tahlil: dastur ko'rsatmalarini tahlil qilish

Quyidagi dasturni olib, har bir ko'rsatmaning turini aniqlaymiz:

```cpp
#include <iostream>
using namespace std;

int main() {
    int ball;                                   // 1
    cout << "Ballingni kirit: ";                // 2
    cin >> ball;                                // 3
    int bonus = 0;                              // 4
    if (ball >= 90) {                           // 5
        bonus = 10;                             // 6
    }
    for (int i = 0; i < 3; i++) {               // 7
        cout << "*";                            // 8
    }
    cout << endl;                               // 9
    cout << "Jami: " << ball + bonus << endl;   // 10
    return 0;                                   // 11
}
```

```output
Ballingni kirit: 95
***
Jami: 105
```

| Qator | Ko'rsatma | Turi |
|---|---|---|
| 1 | `int ball;` | E'lon |
| 2 | `cout << "...";` | Ifoda |
| 3 | `cin >> ball;` | Ifoda |
| 4 | `int bonus = 0;` | E'lon |
| 5 | `if (ball >= 90) { ... }` | Tanlash (ichida blok) |
| 6 | `bonus = 10;` | Ifoda |
| 7 | `for (...) { ... }` | Takrorlash (ichida blok) |
| 8 | `cout << "*";` | Ifoda |
| 9–10 | `cout << ...;` | Ifoda |
| 11 | `return 0;` | Sakrash |

### Chuqurroq o'rganamiz: bir qatorda bir nechta ko'rsatma

C++ da bitta qatorga bir nechta ko'rsatma yozish mumkin, chunki kompilyator ko'rsatmalarni `;` bo'yicha ajratadi, qatorlar bo'yicha emas:

```cpp
int a = 1; int b = 2; cout << a + b;     // ishlaydi, lekin o'qish qiyin
```

Va aksincha, bitta ko'rsatmani bir necha qatorga bo'lish ham mumkin:

```cpp
cout << "Bu juda uzun "
     << "matn bo'lib, "
     << "uch qatorga bo'lingan" << endl;
```

Ikkinchi usul uzun ko'rsatmalarni o'qishga qulay qiladi va keng qo'llaniladi.
