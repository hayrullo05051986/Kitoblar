### Chuqurroq o'rganamiz: ko'rsatkich arifmetikasi batafsil

Ko'rsatkichlar ustida bir nechta amallarni bajarish mumkin:

| Amal | Ma'nosi | Misol |
|---|---|---|
| `p + n` | n ta element oldinga | `p + 2` — 2 ta element keyingi manzil |
| `p - n` | n ta element orqaga | |
| `p++`, `p--` | Keyingi / oldingi elementga o'tish | |
| `p2 - p1` | Ikki ko'rsatkich orasida nechta element bor | |
| `p1 == p2`, `p1 < p2` | Manzillarni solishtirish | |
| `p[i]` | `*(p + i)` ning qisqa yozilishi | |

```cpp
#include <iostream>
using namespace std;

int main() {
    int a[] = {10, 20, 30, 40, 50};
    int* bosh = a;              // birinchi element
    int* oxir = a + 4;          // oxirgi element

    cout << "Elementlar orasidagi masofa: " << oxir - bosh << endl;
    cout << "bosh[2] = " << bosh[2] << ", *(bosh + 2) = " << *(bosh + 2) << endl;

    cout << "Ko'rsatkich bilan yurish: ";
    for (int* p = bosh; p <= oxir; p++) cout << *p << " ";
    cout << endl;

    cout << "Teskari: ";
    for (int* p = oxir; p >= bosh; p--) cout << *p << " ";
    cout << endl;
    return 0;
}
```

```output
Elementlar orasidagi masofa: 4
bosh[2] = 30, *(bosh + 2) = 30
Ko'rsatkich bilan yurish: 10 20 30 40 50 
Teskari: 50 40 30 20 10 
```

!fakt `a[i]` yozuvi aslida `*(a + i)` ning qisqartmasi. Shuning uchun qiziq narsa: `a[2]` va `2[a]` bir xil natija beradi, chunki ikkalasi ham `*(a + 2)` ga teng! (Lekin buni haqiqiy kodda hech qachon yozma.)

### Chuqurroq o'rganamiz: `const` va ko'rsatkichlar

`const` ko'rsatkich bilan ikki xil ishlatilishi mumkin va ularni farqlash muhim:

| E'lon | Ko'rsatilgan qiymatni o'zgartirish | Ko'rsatkichni boshqa joyga burish |
|---|---|---|
| `int* p` | Mumkin | Mumkin |
| `const int* p` | **Mumkin emas** | Mumkin |
| `int* const p` | Mumkin | **Mumkin emas** |
| `const int* const p` | Mumkin emas | Mumkin emas |

O'qish qoidasi: o'ngdan chapga o'qi. `const int* p` — "p — const int ga ko'rsatkich". `int* const p` — "p — o'zgarmas ko'rsatkich, int ga".

```cpp
#include <iostream>
using namespace std;

int main() {
    int a = 5, b = 10;

    const int* p1 = &a;     // qiymatni o'zgartirib bo'lmaydi
    // *p1 = 7;             // XATO
    p1 = &b;                // lekin boshqa joyga burish mumkin

    int* const p2 = &a;     // ko'rsatkichni burib bo'lmaydi
    *p2 = 7;                // lekin qiymatni o'zgartirish mumkin
    // p2 = &b;             // XATO

    cout << "*p1 = " << *p1 << ", a = " << a << endl;
    return 0;
}
```

```output
*p1 = 10, a = 7
```

### Chuqurroq o'rganamiz: `void*` — istalgan turga ko'rsatkich

`void*` — turi noma'lum bo'lgan ma'lumotga ko'rsatkich. U istalgan turdagi manzilni saqlay oladi, lekin uni ishlatishdan oldin aniq turga aylantirish kerak:

```cpp
#include <iostream>
using namespace std;

int main() {
    int son = 42;
    double kasr = 3.14;
    void* p;

    p = &son;
    cout << "int: " << *(static_cast<int*>(p)) << endl;
    p = &kasr;
    cout << "double: " << *(static_cast<double*>(p)) << endl;
    return 0;
}
```

```output
int: 42
double: 3.14
```

`void*` C tilidan qolgan va asosan eski kutubxonalar bilan ishlashda uchraydi. Zamonaviy C++ da uning o'rniga shablonlar ishlatiladi.

### Qadamma-qadam tahlil: ko'rsatkichlar bilan xotirani kuzatish

Quyidagi dasturni qadamma-qadam bajarib, xotirada nima bo'layotganini kuzatamiz:

```cpp
#include <iostream>
using namespace std;

int main() {
    int x = 10;          // 1
    int y = 20;          // 2
    int* p = &x;         // 3
    *p = 15;             // 4
    p = &y;              // 5
    *p = *p + 5;         // 6
    int* q = p;          // 7
    *q = 100;            // 8
    cout << "x = " << x << ", y = " << y << ", *p = " << *p << ", *q = " << *q << endl;
    return 0;
}
```

```output
x = 15, y = 100, *p = 100, *q = 100
```

| Qadam | Ko'rsatma | x | y | p ko'rsatadi | q ko'rsatadi |
|---|---|---|---|---|---|
| 1 | `int x = 10;` | 10 | — | — | — |
| 2 | `int y = 20;` | 10 | 20 | — | — |
| 3 | `int* p = &x;` | 10 | 20 | x | — |
| 4 | `*p = 15;` | **15** | 20 | x | — |
| 5 | `p = &y;` | 15 | 20 | **y** | — |
| 6 | `*p = *p + 5;` | 15 | **25** | y | — |
| 7 | `int* q = p;` | 15 | 25 | y | **y** |
| 8 | `*q = 100;` | 15 | **100** | y | y |

E'tibor ber: 8-qadamda `q` orqali `y` o'zgardi va `p` ham `y` ni ko'rsatgani uchun `*p` ham 100 bo'ldi. Ikki ko'rsatkich bitta joyni ko'rsatishi mumkin!

### Chuqurroq o'rganamiz: havolani funksiyadan qaytarish

Funksiya havola qaytarishi mumkin. Bu holda funksiya chaqiruvining o'zi o'zgaruvchi kabi ishlatiladi — unga qiymat berish ham mumkin:

```cpp
#include <iostream>
using namespace std;

int baholar[5] = {5, 4, 3, 5, 4};

int& baho(int i) {                 // havola qaytaradi
    return baholar[i];
}

int main() {
    cout << "3-baho: " << baho(2) << endl;
    baho(2) = 5;                   // funksiya chaqiruviga qiymat beryapmiz!
    cout << "Tuzatilgan 3-baho: " << baho(2) << endl;
    return 0;
}
```

```output
3-baho: 3
Tuzatilgan 3-baho: 5
```

!diqqat Mahalliy o'zgaruvchiga havola qaytarish — juda xavfli xato! Funksiya tugaganda o'zgaruvchi yo'q bo'ladi va havola "hech narsaga" ishora qilib qoladi. Faqat global, `static` yoki parametr orqali kelgan o'zgaruvchilarga havola qaytar.

### Chuqurroq o'rganamiz: `const` havola — tez va xavfsiz

`const` havola uchta afzallikni birlashtiradi:

1. **Tez** — nusxa olinmaydi (katta obyektlar uchun muhim).
2. **Xavfsiz** — funksiya qiymatni o'zgartira olmaydi.
3. **Universal** — vaqtinchalik qiymatlarni ham qabul qiladi.

```cpp
#include <iostream>
#include <string>
using namespace std;

void salomlash(const string& ism) {
    cout << "Salom, " << ism << "!" << endl;
}

int main() {
    string a = "Malika";
    salomlash(a);                     // o'zgaruvchi
    salomlash("Jasur");               // literal — const havola qabul qiladi
    salomlash(a + " opa");            // vaqtinchalik qiymat — ham qabul qiladi
    return 0;
}
```

```output
Salom, Malika!
Salom, Jasur!
Salom, Malika opa!
```

Agar parametr `string&` (const siz) bo'lganda, ikkinchi va uchinchi chaqiruvlar kompilyatsiya xatosi berardi.

### Chuqurroq o'rganamiz: qachon nimani tanlash — qaror jadvali

| Vaziyat | Eng yaxshi tanlov | Misol |
|---|---|---|
| Kichik turni (int, double) o'qish uchun berish | Qiymat bo'yicha | `void f(int x)` |
| Katta obyektni o'qish uchun berish | `const` havola | `void f(const string& s)` |
| Funksiya argumentni o'zgartirishi kerak | Havola | `void f(int& x)` |

| Dinamik xotira, massivlar | Ko'rsatkich (yoki aqlli ko'rsatkich) | `int* a = new int[n];` |
| Ko'rsatilgan obyektni keyin almashtirish kerak | Ko'rsatkich | Bog'langan ro'yxat tugunlari |

### Qadamma-qadam tahlil: uchta usulda "o'yinchi sog'ligini tiklash"

```cpp
#include <iostream>
using namespace std;

struct Oyinchi {
    string ism;
    int hayot;
};

void tiklaQiymat(Oyinchi o)       { o.hayot = 100; }               // nusxa
void tiklaHavola(Oyinchi& o)      { o.hayot = 100; }               // asl
void tiklaKorsatkich(Oyinchi* o)  { if (o) o->hayot = 100; }       // asl (tekshiruv bilan)

int main() {
    Oyinchi a{"Ali", 30}, b{"Vali", 30}, c{"Laylo", 30};
    tiklaQiymat(a);
    tiklaHavola(b);
    tiklaKorsatkich(&c);
    tiklaKorsatkich(nullptr);          // xavfsiz: hech narsa qilmaydi
    cout << a.ism << ": " << a.hayot << endl;
    cout << b.ism << ": " << b.hayot << endl;
    cout << c.ism << ": " << c.hayot << endl;
    return 0;
}
```

```output
Ali: 30
Vali: 100
Laylo: 100
```

| Funksiya | Nima beriladi | Natija | Izoh |
|---|---|---|---|
| `tiklaQiymat(a)` | `a` ning nusxasi | Ali: 30 | Nusxa o'zgardi, asli emas |
| `tiklaHavola(b)` | `b` ning o'zi | Vali: 100 | Asli o'zgardi |
| `tiklaKorsatkich(&c)` | `c` ning manzili | Laylo: 100 | Manzil orqali asli o'zgardi |
| `tiklaKorsatkich(nullptr)` | "hech narsa" | — | Ko'rsatkich bo'sh bo'lishi mumkin, havola emas |

`o->hayot` — bu `(*o).hayot` ning qisqa yozilishi. Strelka `->` ko'rsatkich orqali struktura yoki obyekt maydoniga murojaat qilish uchun ishlatiladi.

### Chuqurroq o'rganamiz: haqiqiy hayotdagi opaque pointerlar

Opaque pointer g'oyasi ko'plab mashhur kutubxonalarda ishlatiladi:

| Kutubxona / tizim | Opaque tur | Qanday ishlatiladi |
|---|---|---|
| C standart kutubxonasi | `FILE*` | `fopen`, `fprintf`, `fclose` |
| Windows API | `HANDLE`, `HWND` | Oyna, fayl, jarayonlarni boshqarish |
| SQLite (ma'lumotlar bazasi) | `sqlite3*` | `sqlite3_open`, `sqlite3_exec`, `sqlite3_close` |
| OpenSSL (shifrlash) | `SSL*` | Xavfsiz ulanishlar |

`FILE*` misolida ko'raylik:

```cpp
#include <cstdio>

int main() {
    FILE* f = fopen("salom.txt", "w");      // "yarat"
    if (f) {
        fprintf(f, "Salom, fayl!\n");       // "ishlat"
        fclose(f);                           // "o'chir"
    }
    f = fopen("salom.txt", "r");
    char qator[100];
    if (f && fgets(qator, sizeof(qator), f)) printf("O'qildi: %s", qator);
    if (f) fclose(f);
    return 0;
}
```

```output
O'qildi: Salom, fayl!
```

Biz `FILE` tuzilmasi ichida nima borligini (bufer, fayl pozitsiyasi, xato bayroqlari va h.k.) umuman bilmaymiz va bilishimiz shart emas. Bu — opaque pointerning eng mashhur namunasi!

### Chuqurroq o'rganamiz: PIMPL to'liq misol

PIMPL usulini to'liq ko'rib chiqamiz. Foydalanuvchi faqat sarlavha qismini ko'radi:

```cpp
#include <iostream>
#include <string>
#include <memory>
using namespace std;

// ===== oyinchi.h (foydalanuvchi ko'radigan qism) =====
class Oyinchi {
public:
    Oyinchi(const string& ism);
    ~Oyinchi();
    void sakra();
    void holat() const;
private:
    struct Ichki;                    // ichki tuzilma faqat e'lon qilingan
    unique_ptr<Ichki> ichki;         // opaque pointer (aqlli ko'rsatkich ko'rinishida)
};

// ===== oyinchi.cpp (yashirin qism) =====
struct Oyinchi::Ichki {
    string ism;
    int balandlik = 0;
    int sakrashlar = 0;
};

Oyinchi::Oyinchi(const string& ism) : ichki(make_unique<Ichki>()) { ichki->ism = ism; }
Oyinchi::~Oyinchi() = default;
void Oyinchi::sakra() { ichki->balandlik += 2; ichki->sakrashlar++; }
void Oyinchi::holat() const {
    cout << ichki->ism << ": balandlik " << ichki->balandlik
         << ", sakrashlar " << ichki->sakrashlar << endl;
}

// ===== main.cpp =====
int main() {
    Oyinchi o("Kodi");
    o.sakra();
    o.sakra();
    o.holat();
    return 0;
}
```

```output
Kodi: balandlik 4, sakrashlar 2
```

| PIMPL dan foydasi | Tushuntirish |
|---|---|
| **Tez kompilyatsiya** | `Ichki` ga yangi maydon qo'shilsa, faqat `oyinchi.cpp` qayta kompilyatsiya qilinadi, uni ishlatuvchi yuzlab fayllar emas |
| **Yashirish** | Foydalanuvchi ichki maydonlarni ko'rmaydi va ularga bog'lanib qolmaydi |
| **Barqaror interfeys** | Kutubxona yangilanganda foydalanuvchi kodi o'zgarmaydi |

### Qadamma-qadam tahlil: "Seyf" moduli

```cpp
#include <iostream>
#include <string>
using namespace std;

// ---- seyf.h ----
struct Seyf;
Seyf* seyfYarat(int kod);
bool seyfOch(Seyf* s, int kod);
void seyfgaQoy(Seyf* s, const string& narsa);
void seyfniKorsat(const Seyf* s);
void seyfOchir(Seyf* s);

// ---- seyf.cpp ----
struct Seyf {
    int kod;
    bool ochiq = false;
    string ichida = "(bo'sh)";
    int notogriUrinishlar = 0;
};
Seyf* seyfYarat(int kod) { return new Seyf{kod}; }
bool seyfOch(Seyf* s, int kod) {
    if (s->notogriUrinishlar >= 3) { cout << "Seyf bloklangan!" << endl; return false; }
    if (kod == s->kod) { s->ochiq = true; cout << "Seyf ochildi" << endl; return true; }
    s->notogriUrinishlar++;
    cout << "Noto'g'ri kod (" << s->notogriUrinishlar << "/3)" << endl;
    return false;
}
void seyfgaQoy(Seyf* s, const string& narsa) {
    if (s->ochiq) s->ichida = narsa;
    else cout << "Avval seyfni och!" << endl;
}
void seyfniKorsat(const Seyf* s) {
    cout << "Seyfda: " << (s->ochiq ? s->ichida : "*** yopiq ***") << endl;
}
void seyfOchir(Seyf* s) { delete s; }

// ---- main.cpp ----
int main() {
    Seyf* s = seyfYarat(1234);
    seyfgaQoy(s, "kundalik");
    seyfOch(s, 1111);
    seyfOch(s, 1234);
    seyfgaQoy(s, "kundalik");
    seyfniKorsat(s);
    seyfOchir(s);
    return 0;
}
```

```output
Avval seyfni och!
Noto'g'ri kod (1/3)
Seyf ochildi
Seyfda: kundalik
```

Foydalanuvchi `s->kod` deb seyf kodini "o'g'irlab" ko'ra olmaydi (haqiqiy loyihada `struct Seyf` ichi yashirin bo'ladi). Seyf bilan faqat ruxsat etilgan funksiyalar orqali ishlash mumkin — mana inkapsulyatsiyaning kuchi!

### Chuqurroq o'rganamiz: `unique_ptr` bilan massivlar va funksiyalar

unique_ptr<int[]> massivYarat(int n) {

### Chuqurroq o'rganamiz: aqlli ko'rsatkichlar va funksiya parametrlari

| Funksiya nima qilmoqchi | Parametr turi |
|---|---|
| Obyektdan faqat foydalanish (egalik kerak emas) | `Robot&` yoki `Robot*` (oddiy havola/ko'rsatkich) |
| Egalikni olish (obyekt endi funksiyaga tegishli) | `unique_ptr<Robot>` (qiymat bo'yicha, `move` bilan beriladi) |
| Egalikni baham ko'rish | `shared_ptr<Robot>` (qiymat bo'yicha) |

```cpp
#include <iostream>
#include <memory>
#include <string>
using namespace std;

struct Robot {
    string ism;
    Robot(string i) : ism(i) {}
    ~Robot() { cout << ism << " o'chirildi" << endl; }
};

void salomlash(const Robot& r) {                      // faqat foydalanadi
    cout << "Salom, " << r.ism << "!" << endl;
}

void olibKet(unique_ptr<Robot> r) {                   // egalikni oladi
    cout << r->ism << " olib ketildi" << endl;
}                                                     // r shu yerda o'chiriladi

int main() {
    auto r = make_unique<Robot>("Kodi");
    salomlash(*r);                                    // egalik o'zgarmaydi
    olibKet(move(r));                                 // egalik funksiyaga o'tdi
    cout << "r bo'shmi? " << (r ? "yo'q" : "ha") << endl;
    return 0;
}
```

```output
Salom, Kodi!
Kodi olib ketildi
Kodi o'chirildi
r bo'shmi? ha
```

### Chuqurroq o'rganamiz: aylanma bog'lanish muammosi

Ikki `shared_ptr` bir-birini ko'rsatsa, ularning hisoblagichi hech qachon 0 ga tushmaydi va xotira hech qachon bo'shamaydi:

```cpp
#include <iostream>
#include <memory>
using namespace std;

struct Odam {
    string ism;
    shared_ptr<Odam> dost;           // kuchli bog'lanish
    // weak_ptr<Odam> dost;          // TO'G'RISI: kuchsiz bog'lanish
    Odam(string i) : ism(i) {}
    ~Odam() { cout << ism << " o'chirildi" << endl; }
};

int main() {
    {
        auto ali = make_shared<Odam>("Ali");
        auto vali = make_shared<Odam>("Vali");
        ali->dost = vali;
        vali->dost = ali;            // aylanma bog'lanish!
        cout << "Ali egalari: " << ali.use_count() << endl;
    }
    cout << "Blok tugadi, lekin hech kim o'chirilmadi!" << endl;
    return 0;
}
```

```output
Ali egalari: 2
Blok tugadi, lekin hech kim o'chirilmadi!
```

Destruktorlar chaqirilmadi — xotira oqishi! Agar `dost` maydoni `weak_ptr<Odam>` bo'lsa, muammo yo'qoladi, chunki `weak_ptr` egalar soniga qo'shilmaydi.

### Chuqurroq o'rganamiz: `make_unique` va `make_shared` nima uchun yaxshi?

| `new` bilan | `make_...` bilan | Afzalligi |
|---|---|---|
| `unique_ptr<Robot> r(new Robot("A"));` | `auto r = make_unique<Robot>("A");` | Qisqaroq, turni ikki marta yozish shart emas |
| `shared_ptr<Robot> s(new Robot("A"));` | `auto s = make_shared<Robot>("A");` | Obyekt va hisoblagich uchun bitta xotira ajratiladi — tezroq |

### Qadamma-qadam tahlil: `shared_ptr` hisoblagichini kuzatish

### Qadamma-qadam tahlil: "O'rtacha va eng katta" — uchta usulda

Bir xil vazifani uchta usulda yozib, ularni solishtiramiz:

```cpp
#include <iostream>
#include <initializer_list>
#include <cstdarg>
#include <algorithm>
using namespace std;

// 1-usul: initializer_list
double ortacha1(initializer_list<int> s) {
    double jami = 0;
    for (int x : s) jami += x;
    return jami / s.size();
}

// 2-usul: C uslubi
double ortacha2(int n, ...) {
    va_list args;
    va_start(args, n);
    double jami = 0;
    for (int i = 0; i < n; i++) jami += va_arg(args, int);
    va_end(args);
    return jami / n;
}

// 3-usul: variadik shablon
template <typename... T>
double ortacha3(T... s) {
    return (s + ...) / (double)sizeof...(s);
}

int main() {
    cout << ortacha1({5, 4, 5, 3}) << endl;
    cout << ortacha2(4, 5, 4, 5, 3) << endl;
    cout << ortacha3(5, 4, 5, 3) << endl;
    cout << "Eng kattasi: " << max({5, 4, 5, 3}) << endl;     // STL ham initializer_list qabul qiladi
    return 0;
}
```

```output
4.25
4.25
4.25
Eng kattasi: 5
```

| Usul | Chaqiruv | Afzalligi | Kamchiligi |
|---|---|---|---|
| `initializer_list` | `ortacha1({5, 4, 5, 3})` | Oddiy, xavfsiz | Qavslar kerak, faqat bir xil tur |
| C uslubi | `ortacha2(4, 5, 4, 5, 3)` | Eski C kodi bilan mos | Sonini qo'lda berish, tur tekshiruvi yo'q |

### Chuqurroq o'rganamiz: o'z `sort` funksiyamiz — callback bilan

Funksiyalarga ko'rsatkichlar yordamida universal saralash funksiyasi yozamiz — taqqoslash qoidasini tashqaridan beramiz:

void saralash(int a[], int n, bool (*oldinmi)(int, int)) {
    for (int i = 0; i < n - 1; i++)

            if (oldinmi(a[j + 1], a[j]))           // callback qaror qiladi
                swap(a[j], a[j + 1]);
}

bool osish(int x, int y)     { return x < y; }
bool kamayish(int x, int y)  { return x > y; }
bool juftOldin(int x, int y) { return (x % 2 == 0) && (y % 2 != 0); }

void chiqar(int a[], int n) { for (int i = 0; i < n; i++) cout << a[i] << " "; cout << endl; }

int main() {
    int a[] = {5, 2, 8, 1, 9, 4};
    saralash(a, 6, osish);     chiqar(a, 6);
    saralash(a, 6, kamayish);  chiqar(a, 6);
    saralash(a, 6, juftOldin); chiqar(a, 6);

}
```

    int son = 7;
    for (const auto& [nom, f] : amallar) {
        cout << nom << "(" << son << ") = " << f(son) << endl;
    }
    return 0;
}
```

```output
ikkilash(7) = 14
kvadrat(7) = 49
+100(7) = 107
```

| | Funksiyaga ko'rsatkich | `std::function` |
|---|---|---|
| Oddiy funksiyalar | Ha | Ha |
| Lambdalar (ushlashsiz) | Ha | Ha |
| Lambdalar (ushlash bilan) | Yo'q | Ha |
| Tezlik | Juda tez | Biroz sekinroq |
| Sintaksis | Murakkab: `int (*f)(int)` | Tushunarli: `function<int(int)>` |

### Qadamma-qadam tahlil: "Hodisalar tizimi" — o'yindagi tugmalar

Kompyuter o'yinlarida tugmalar bosilganda turli funksiyalar chaqiriladi. Buni funksiyalarga ko'rsatkichlar bilan qilamiz:

```cpp
#include <iostream>
#include <map>
#include <functional>
using namespace std;

int x = 0, y = 0;

void yuqori() { y++; cout << "Yuqoriga -> (" << x << ", " << y << ")" << endl; }
void past()   { y--; cout << "Pastga   -> (" << x << ", " << y << ")" << endl; }
void ong()    { x++; cout << "O'ngga   -> (" << x << ", " << y << ")" << endl; }
void chap()   { x--; cout << "Chapga   -> (" << x << ", " << y << ")" << endl; }

int main() {
    map<char, function<void()>> tugmalar = {
        {'w', yuqori}, {'s', past}, {'d', ong}, {'a', chap},
        {'q', []() { cout << "Sakrash!" << endl; }}
    };
    string bosilganlar = "wwdqsa";
    for (char t : bosilganlar) {
        if (tugmalar.count(t)) tugmalar[t]();     // tugmaga bog'langan funksiyani chaqiramiz
    }
    return 0;
}
```

```output
Yuqoriga -> (0, 1)
Yuqoriga -> (0, 2)
O'ngga   -> (1, 2)
Sakrash!
Pastga   -> (1, 1)
Chapga   -> (0, 1)
```

| Qadam | Tugma | `map` dan topilgan funksiya | Natija |
|---|---|---|---|
| 1 | `w` | `yuqori` | (0, 1) |
| 2 | `w` | `yuqori` | (0, 2) |
| 3 | `d` | `ong` | (1, 2) |
| 4 | `q` | lambda | Sakrash! |
| 5 | `s` | `past` | (1, 1) |
| 6 | `a` | `chap` | (0, 1) |

Bu usulning afzalligi: yangi tugma qo'shish uchun `if-else` zanjirini o'zgartirish shart emas — `map` ga bitta qator qo'shish kifoya. Haqiqiy o'yinlarda foydalanuvchi tugmalarni o'zi qayta sozlashi ham aynan shunday ishlaydi!

### Qo'shimcha mashqlar
