### Chuqurroq o'rganamiz: ma'lumot turlarining uch guruhi

C++ dagi barcha turlarni uchta katta guruhga bo'lish mumkin:

| Guruh | Ta'rif | Misollar |
|---|---|---|
| **Asosiy (ichki) turlar** | Tilning o'zida mavjud, oddiy turlar | `int`, `char`, `bool`, `float`, `double`, `void`, `wchar_t` |
| **Hosila turlar** | Asosiy turlardan yasaladi | Massivlar (`int[5]`), ko'rsatkichlar (`int*`), havolalar (`int&`), funksiyalar |
| **Foydalanuvchi turlari** | Dasturchi o'zi yaratadi | `struct`, `class`, `union`, `enum`, `typedef`/`using` bilan berilgan nomlar |

### Chuqurroq o'rganamiz: `float` va `double` ning aniqligi

Kasr sonlar kompyuterda aniq saqlanmaydi — ular ma'lum aniqlik bilan **taxminiy** saqlanadi. `float` taxminan 6–7 ta, `double` esa 15–16 ta to'g'ri raqamni saqlaydi:

```cpp
#include <iostream>
#include <iomanip>
using namespace std;

int main() {
    float f = 1.0f / 3;
    double d = 1.0 / 3;
    cout << setprecision(20);
    cout << "float:  " << f << endl;
    cout << "double: " << d << endl;
    return 0;
}
```

```output
float:  0.3333333432674407959
double: 0.33333333333333331483
```

Ko'rib turganingdek, `float` 7–8 raqamdan keyin "adashib" ketdi, `double` esa ancha uzoqroq to'g'ri qoldi. Shuning uchun ko'p hollarda `double` ishlatiladi.

!diqqat Kasr sonlarni `==` bilan solishtirish xavfli! Masalan, `0.1 + 0.2 == 0.3` — **yolg'on** chiqadi, chunki kompyuterda 0.1 + 0.2 aslida 0.30000000000000004 ga teng. Kasr sonlarni solishtirish uchun ularning ayirmasi juda kichikligini tekshirish kerak: `abs(a - b) < 0.000001`.

```cpp
#include <iostream>
#include <cmath>
using namespace std;

int main() {
    double a = 0.1 + 0.2;
    cout << boolalpha;
    cout << "0.1 + 0.2 == 0.3 ? " << (a == 0.3) << endl;
    cout << "Deyarli tengmi?   " << (fabs(a - 0.3) < 1e-9) << endl;
    return 0;
}
```

```output
0.1 + 0.2 == 0.3 ? false
Deyarli tengmi?   true
```

### Chuqurroq o'rganamiz: `char` — aslida kichik son

`char` turi bitta belgini saqlaydi, lekin ichkarida u **kichik butun son** (odatda −128 dan 127 gacha yoki 0 dan 255 gacha). Har bir belgiga maxsus raqam mos keladi (bu haqda keyingi mavzularda batafsil):

```cpp
#include <iostream>
using namespace std;

int main() {
    char c = 'A';
    cout << "Belgi: " << c << endl;
    cout << "Raqami: " << (int)c << endl;
    c = c + 2;                          // harfga son qo'shish mumkin!
    cout << "2 ta keyingi harf: " << c << endl;
    return 0;
}
```

```output
Belgi: A
Raqami: 65
2 ta keyingi harf: C
```

### Chuqurroq o'rganamiz: `void` — "hech narsa" turi

`void` — maxsus tur bo'lib, u "qiymat yo'q" degan ma'noni bildiradi. `void` turidagi o'zgaruvchi yaratib bo'lmaydi, lekin u ikki joyda ishlatiladi:

1. **Hech narsa qaytarmaydigan funksiyalarda:** `void salomlash() { ... }`.
2. **Istalgan turga ko'rsatkichda:** `void*` — "noma'lum turdagi ma'lumotga ko'rsatkich" (7-modul).

### Chuqurroq o'rganamiz: keng belgilar va boshqa turlar

| Tur | O'lchami | Vazifasi |
|---|---|---|
| `wchar_t` | 2 yoki 4 bayt | "Keng" belgilar — kirill, xitoy va boshqa yozuvlar uchun |
| `char16_t` | 2 bayt | UTF-16 belgilari (C++11) |
| `char32_t` | 4 bayt | UTF-32 belgilari (C++11) |
| `char8_t` | 1 bayt | UTF-8 belgilari (C++20) |
| `long double` | 8–16 bayt | `double` dan ham aniqroq kasr sonlar |

### Qadamma-qadam tahlil: "O'quvchi kartochkasi" dasturi

Barcha asosiy turlarni bitta dasturda ishlatib ko'ramiz:

```cpp
#include <iostream>
#include <string>
using namespace std;

int main() {
    string ism = "Malika";        // matn
    int yosh = 12;                // butun son
    int sinf = 6;
    double boy = 1.52;            // kasr son (metr)
    double ortachaBaho = 4.85;
    char guruh = 'A';             // bitta belgi
    bool alochi = true;           // ha/yo'q

    cout << "===== O'QUVCHI KARTOCHKASI =====" << endl;
    cout << "Ism:          " << ism << endl;
    cout << "Yosh:         " << yosh << endl;
    cout << "Sinf:         " << sinf << "-" << guruh << endl;
    cout << "Bo'y:         " << boy << " m" << endl;
    cout << "O'rtacha:     " << ortachaBaho << endl;
    cout << "A'lochimi:    " << (alochi ? "ha" : "yo'q") << endl;
    cout << "Xotirada: int=" << sizeof(yosh) << ", double=" << sizeof(boy)
         << ", char=" << sizeof(guruh) << ", bool=" << sizeof(alochi) << " bayt" << endl;
    return 0;
}
```

```output
===== O'QUVCHI KARTOCHKASI =====
Ism:          Malika
Yosh:         12
Sinf:         6-A
Bo'y:         1.52 m
O'rtacha:     4.85
A'lochimi:    ha
Xotirada: int=4, double=8, char=1, bool=1 bayt
```

| O'zgaruvchi | Nima uchun aynan shu tur tanlandi |
|---|---|
| `ism` | Bir nechta harfdan iborat — `string` |
| `yosh`, `sinf` | Har doim butun son — `int` |
| `boy`, `ortachaBaho` | Kasr qismi bor — `double` |
| `guruh` | Faqat bitta harf — `char` |
| `alochi` | Faqat ikki holat — `bool` |

### Chuqurroq o'rganamiz: modifikatorlarni birlashtirish

Modifikatorlarni bir-biri bilan birlashtirish mumkin. Quyidagi jadvalda barcha keng tarqalgan birikmalar keltirilgan:

| To'liq yozilishi | Qisqa yozilishi | O'lchami | Oralig'i |
|---|---|---|---|
| `signed char` | — | 1 bayt | −128 ... 127 |
| `unsigned char` | — | 1 bayt | 0 ... 255 |
| `short int` | `short` | 2 bayt | −32 768 ... 32 767 |
| `unsigned short int` | `unsigned short` | 2 bayt | 0 ... 65 535 |
| `signed int` | `int` | 4 bayt | −2 147 483 648 ... 2 147 483 647 |
| `unsigned int` | `unsigned` | 4 bayt | 0 ... 4 294 967 295 |
| `long int` | `long` | 4 yoki 8 bayt | Tizimga bog'liq |
| `long long int` | `long long` | 8 bayt | ≈ ±9.2 × 10¹⁸ |
| `unsigned long long int` | `unsigned long long` | 8 bayt | 0 ... ≈ 1.8 × 10¹⁹ |

!eslatma `long` turining o'lchami tizimga bog'liq: Windows da odatda 4 bayt, Linux da 8 bayt. Shuning uchun katta sonlar uchun har doim `long long` ishlatgan ma'qul — u hamma joyda 8 bayt.

### Chuqurroq o'rganamiz: aniq o'lchamli turlar

Agar turning o'lchami aniq bo'lishi muhim bo'lsa (masalan, fayl formatlari yoki tarmoq bilan ishlashda), `<cstdint>` kutubxonasidagi turlardan foydalaniladi:

| Tur | O'lchami | Oralig'i |
|---|---|---|
| `int8_t` / `uint8_t` | 1 bayt | −128...127 / 0...255 |
| `int16_t` / `uint16_t` | 2 bayt | −32 768...32 767 / 0...65 535 |
| `int32_t` / `uint32_t` | 4 bayt | ≈ ±2.1 mlrd / 0...4.2 mlrd |
| `int64_t` / `uint64_t` | 8 bayt | ≈ ±9.2 × 10¹⁸ / 0...1.8 × 10¹⁹ |

Bu turlarning nomi o'lchamini aniq aytadi: `int32_t` — "32 bitli butun son". Ular istalgan kompyuterda bir xil o'lchamda bo'ladi.

### Chuqurroq o'rganamiz: `numeric_limits` — chegaralarni bilish

C++ da har qanday turning chegaralarini `<limits>` kutubxonasidagi `numeric_limits` yordamida bilish mumkin:

```cpp
#include <iostream>
#include <limits>
using namespace std;

int main() {
    cout << "short:     " << numeric_limits<short>::min() << " ... "
         << numeric_limits<short>::max() << endl;
    cout << "int:       " << numeric_limits<int>::min() << " ... "
         << numeric_limits<int>::max() << endl;
    cout << "long long: " << numeric_limits<long long>::min() << " ... "
         << numeric_limits<long long>::max() << endl;
    cout << "unsigned:  0 ... " << numeric_limits<unsigned int>::max() << endl;
    return 0;
}
```

```output
short:     -32768 ... 32767
int:       -2147483648 ... 2147483647
long long: -9223372036854775808 ... 9223372036854775807
unsigned:  0 ... 4294967295
```

### Qadamma-qadam tahlil: to'lib ketishni ko'z bilan ko'rish

To'lib ketish qanday sodir bo'lishini kichik tur — `unsigned char` (0...255) misolida qadamma-qadam kuzatamiz:

```cpp
#include <iostream>
using namespace std;

int main() {
    unsigned char hisob = 250;
    for (int i = 0; i < 10; i++) {
        cout << (int)hisob << " ";
        hisob++;
    }
    cout << endl;
    return 0;
}
```

```output
250 251 252 253 254 255 0 1 2 3 
```

| Qadam | Qiymat (o'nlik) | Ikkilik ko'rinishi |
|---|---|---|
| 1 | 254 | `11111110` |
| 2 | 255 | `11111111` — 8 bitning hammasi 1 |
| 3 | 0 | `1 00000000` — 9-bit sig'madi va tashlab yuborildi |
| 4 | 1 | `00000001` |

Bu xuddi eski mashinalardagi mexanik spidometrga o'xshaydi: 999 999 km dan keyin 000 000 ga qaytadi!

!fakt 2014-yilda mashhur videoxostingda bitta klip shunchalik ko'p ko'rildiki, ko'rishlar soni 32 bitli `int` ning chegarasi — 2 147 483 647 dan oshib ketdi! Muhandislar hisoblagichni zudlik bilan 64 bitli turga o'tkazishga majbur bo'lishdi.

| Vaziyat | Tavsiya |
|---|---|
| Oddiy butun sonlar (yosh, ball, soni) | `int` |

### Chuqurroq o'rganamiz: literallar batafsil

Kod ichida yozilgan har bir qiymat — **literal** — o'z turiga ega. Turini o'zgartirish uchun maxsus qo'shimchalar (suffikslar) ishlatiladi:

| Literal | Turi | Izoh |
|---|---|---|
| `42` | `int` | Oddiy butun son |
| `42u` yoki `42U` | `unsigned int` | Ishorasiz |
| `42L` | `long` | Uzun |
| `42LL` | `long long` | Juda uzun |
| `42ULL` | `unsigned long long` | |
| `3.14` | `double` | Kasr son (standart) |
| `3.14f` | `float` | |
| `3.14L` | `long double` | |
| `'A'` | `char` | Bitta belgi |
| `"Salom"` | `const char[6]` | Satr (oxirida `\0` bilan 6 ta belgi) |
| `true`, `false` | `bool` | |
| `nullptr` | `nullptr_t` | Bo'sh ko'rsatkich |

### Chuqurroq o'rganamiz: sonlarni turli sanoq sistemalarida yozish

| Prefiks | Sanoq sistemasi | Misol | O'nlik qiymati |
|---|---|---|---|
| (yo'q) | O'nlik | `255` | 255 |
| `0x` | O'n oltilik | `0xFF` | 255 |
| `0` | Sakkizlik | `0377` | 255 |
| `0b` | Ikkilik (C++14) | `0b11111111` | 255 |

```cpp
#include <iostream>
using namespace std;

int main() {
    int a = 255, b = 0xFF, c = 0377, d = 0b11111111;
    cout << a << " " << b << " " << c << " " << d << endl;
    long long aholi = 8'100'000'000;        // C++14: raqamlarni ajratish
    cout << "Yer aholisi: " << aholi << endl;
    return 0;
}
```

```output
255 255 255 255
Yer aholisi: 8100000000
```

!maslahat C++14 dan boshlab katta sonlarni o'qishni osonlashtirish uchun raqamlar orasiga apostrof `'` qo'yish mumkin: `1'000'000`. Kompilyator apostroflarni e'tiborsiz qoldiradi.

!diqqat Sonni `0` bilan boshlash xavfli! `int x = 010;` — bu 10 emas, sakkizlik sanoq sistemasidagi 8 soni. Shuning uchun butun sonlar oldiga ortiqcha nol qo'yma.

### Chuqurroq o'rganamiz: `const` va `constexpr` farqi

| | `const` | `constexpr` |
|---|---|---|
| Qachon qiymat aniqlanadi | Kompilyatsiyada **yoki** dastur ishlayotganda | Faqat kompilyatsiyada |
| Foydalanuvchi kiritgan qiymat bilan | Mumkin | Mumkin emas |
| Massiv o'lchami sifatida | Faqat kompilyatsiyada ma'lum bo'lsa | Har doim |
| Funksiyalar uchun | — | `constexpr` funksiyalar kompilyatsiyada hisoblanadi |

```cpp
#include <iostream>
using namespace std;

constexpr int kvadrat(int x) { return x * x; }     // kompilyatsiyada hisoblanishi mumkin

int main() {
    int n;
    cout << "Son kirit: ";
    cin >> n;
    const int a = n * 2;              // to'g'ri: const dastur ishlayotganda ham bo'ladi
    // constexpr int b = n * 2;       // XATO: n kompilyatsiyada noma'lum
    constexpr int c = kvadrat(12);    // to'g'ri: 144 kompilyatsiyada hisoblanadi
    int massiv[c];                    // c ni massiv o'lchami sifatida ishlatish mumkin
    cout << "a = " << a << ", c = " << c << ", massiv o'lchami = "
         << sizeof(massiv) / sizeof(int) << endl;
    return 0;
}
```

```output
Son kirit: 5
a = 10, c = 144, massiv o'lchami = 144
```

### Qadamma-qadam tahlil: o'zgarmaslar bilan "Aylana kalkulyatori"

```cpp
#include <iostream>
#include <iomanip>
using namespace std;

const double PI = 3.14159265358979;
const int XONALAR = 2;               // natijadagi kasr xonalar soni

int main() {
    double r;
    cout << "Aylana radiusini kirit (sm): ";
    cin >> r;

    double uzunlik = 2 * PI * r;
    double yuza = PI * r * r;

    cout << fixed << setprecision(XONALAR);
    cout << "Aylana uzunligi: " << uzunlik << " sm" << endl;
    cout << "Doira yuzi:      " << yuza << " sm\u00B2" << endl;
    return 0;
}
```

```output
Aylana radiusini kirit (sm): 5
Aylana uzunligi: 31.42 sm
Doira yuzi:      78.54 sm²
```

| Qator | Nima bo'ladi |
|---|---|
| `const double PI = ...` | π soni bir marta, aniq yoziladi va dastur bo'ylab o'zgarmaydi |
| `const int XONALAR = 2` | Natija formatini bitta joyda boshqarish — 3 xona kerak bo'lsa, faqat shu qatorni o'zgartiramiz |
| `2 * PI * r` | Formulada "sehrli raqam" 3.14 o'rniga tushunarli nom |
| `fixed << setprecision(XONALAR)` | Natijani chiroyli formatlash |

### Chuqurroq o'rganamiz: maxsus ma'noli identifikatorlar

Ba'zi so'zlar kalit so'z emas, lekin ma'lum joylarda maxsus ma'noga ega. Ularni o'zgaruvchi nomi sifatida ishlatish **mumkin**, lekin tavsiya etilmaydi:

!diqqat Standart kutubxona nomlarini (`string`, `vector`, `count`, `max`) o'z o'zgaruvchilaring uchun ishlatma — ayniqsa `using namespace std;` yozilgan bo'lsa. Bu chalkash xatolarga olib keladi.

### Chuqurroq o'rganamiz: tokenlar — kodning "g'ishtlari"

Kompilyator kodni o'qishdan oldin uni **tokenlarga** ajratadi. Token — kodning ma'noga ega eng kichik bo'lagi. C++ da tokenlarning olti turi bor:

| Token turi | Misollar |
|---|---|
| Kalit so'zlar | `int`, `if`, `return` |
| Identifikatorlar | `yosh`, `hisobla`, `Oquvchi` |
| Literallar | `42`, `3.14`, `'A'`, `"Salom"` |
| Operatorlar | `+`, `=`, `==`, `<<`, `&&` |
| Ajratuvchilar (punktuatorlar) | `;`, `,`, `{`, `}`, `(`, `)`, `[`, `]` |
| Izohlar | `// ...`, `/* ... */` (preprotsessor bosqichida olib tashlanadi) |

### Qadamma-qadam tahlil: qatorni tokenlarga ajratish

`if (ball >= 86) cout << "A'lo";` qatorini kompilyator qanday "ko'radi":

| № | Token | Turi |
|---|---|---|
| 1 | `if` | Kalit so'z |
| 2 | `(` | Ajratuvchi |
| 3 | `ball` | Identifikator |
| 4 | `>=` | Operator |
| 5 | `86` | Literal (butun son) |
| 6 | `)` | Ajratuvchi |
| 7 | `cout` | Identifikator |
| 8 | `<<` | Operator |
| 9 | `"A'lo"` | Literal (satr) |
| 10 | `;` | Ajratuvchi |

E'tibor ber: `>=` bitta token (ikkita alohida `>` va `=` emas). Kompilyator har doim eng uzun mumkin bo'lgan tokenni tanlaydi.

### Chuqurroq o'rganamiz: nomlarning uzunligi va katta-kichik harflar

- C++ da identifikator uzunligiga amalda cheklov yo'q. `buOquvchiningYillikOrtachaBahosi` — to'g'ri nom (lekin juda uzun!).
- Katta va kichik harflar farqlanadi, shuning uchun `ball`, `Ball` va `BALL` — uchta turli o'zgaruvchi.
- Pastki chiziq bilan boshlanadigan va undan keyin katta harf keladigan nomlar (`_Nom`) hamda ikkita pastki chiziqli nomlar (`__nom`) **kompilyator uchun zahiralangan**. Ulardan foydalanmaslik kerak.

```cpp
#include <iostream>
using namespace std;

int main() {
    int ball = 90, Ball = 75, BALL = 60;     // uchta turli o'zgaruvchi!
    cout << ball << " " << Ball << " " << BALL << endl;
    return 0;
}
```

```output
90 75 60
```

Bu ishlaydi, lekin juda chalkash! Haqiqiy dasturda bunday qilma.

### Chuqurroq o'rganamiz: e'lon, ta'rif va initsializatsiya

Bu uchta atama ko'pincha chalkashtiriladi:

| Atama | Ma'nosi | Misol |
|---|---|---|
| **E'lon** (declaration) | Kompilyatorga nom va tur haqida xabar berish | `extern int x;` |
| **Ta'rif** (definition) | Xotiradan haqiqiy joy ajratish | `int x;` |
| **Initsializatsiya** | Yaratilish paytidayoq boshlang'ich qiymat berish | `int x = 5;` |
| **Qiymat berish** (assignment) | Mavjud o'zgaruvchiga yangi qiymat yozish | `x = 10;` |

Oddiy holatda `int x;` bir vaqtning o'zida ham e'lon, ham ta'rif bo'ladi.

### Chuqurroq o'rganamiz: initsializatsiya usullari batafsil

C++ da o'zgaruvchiga boshlang'ich qiymat berishning bir necha usuli bor va ularning farqlari bor:

| Usul | Misol | Xususiyati |
|---|---|---|
| Nusxa bilan | `int a = 3.7;` | Kasr qism jimgina tashlab yuboriladi: `a = 3` |
| To'g'ridan-to'g'ri | `int b(3.7);` | Xuddi shunday: `b = 3` |
| Ro'yxat bilan (figurali qavs) | `int c{3.7};` | **Xato yoki ogohlantirish** — kompilyator ma'lumot yo'qolishini sezadi |
| Qiymatsiz figurali qavs | `int d{};` | `d = 0` (nol bilan initsializatsiya) |

```cpp
#include <iostream>
using namespace std;

int main() {
    int a = 3.7;      // jimgina 3 bo'ladi
    int b(3.7);       // jimgina 3 bo'ladi
    int d{};          // 0
    double e{2.5};    // muammo yo'q
    cout << a << " " << b << " " << d << " " << e << endl;
    return 0;
}
```

```output
3 3 0 2.5
```

!maslahat Figurali qavs `{}` bilan initsializatsiya — eng xavfsiz usul. U ma'lumot yo'qolishi mumkin bo'lgan joylarda seni ogohlantiradi.

### Chuqurroq o'rganamiz: o'zgaruvchilar xotirada

Har bir o'zgaruvchining **manzili** bor — xotiradagi joyining raqami. Uni `&` operatori yordamida ko'rish mumkin:

```cpp
#include <iostream>
using namespace std;

int main() {
    int a = 10;
    int b = 20;
    double c = 3.5;
    cout << "a: qiymati " << a << ", hajmi " << sizeof(a) << " bayt" << endl;
    cout << "b: qiymati " << b << ", hajmi " << sizeof(b) << " bayt" << endl;
    cout << "c: qiymati " << c << ", hajmi " << sizeof(c) << " bayt" << endl;
    cout << "a ning manzili: " << &a << endl;
    return 0;
}
```

```output
a: qiymati 10, hajmi 4 bayt
b: qiymati 20, hajmi 4 bayt
c: qiymati 3.5, hajmi 8 bayt
a ning manzili: 0x7ffd8c2b1a4c
```

Manzil har safar boshqacha bo'lishi mumkin. Manzillar va ular bilan ishlash haqida 7-modulda (ko'rsatkichlar) batafsil gaplashamiz.

### Chuqurroq o'rganamiz: `auto` va havolalar, `const`

`auto` qiymatning turini aniqlaganda `const` va havolani (`&`) **tashlab yuboradi**. Ularni saqlash kerak bo'lsa, aniq yozish kerak:

```cpp
#include <iostream>
using namespace std;

int main() {
    const int MAX = 100;
    auto a = MAX;           // a — oddiy int (const emas!)
    a = 50;                 // ruxsat bor
    const auto b = MAX;     // b — const int
    // b = 50;              // XATO

    int x = 10;
    auto& r = x;            // r — x ga havola
    r = 99;                 // x ham o'zgaradi
    cout << "a = " << a << ", x = " << x << endl;
    return 0;
}
```

```output
a = 50, x = 99
```

| Yozuv | Natijaviy tur |
|---|---|
| `auto a = MAX;` | `int` |
| `const auto b = MAX;` | `const int` |
| `auto& r = x;` | `int&` (havola) |
| `const auto& cr = x;` | `const int&` |

### Chuqurroq o'rganamiz: `auto` bilan funksiyalar

C++14 dan boshlab funksiyaning qaytaruvchi turini ham `auto` qilib yozish mumkin — kompilyator uni `return` ga qarab aniqlaydi:

```cpp
#include <iostream>
using namespace std;

auto qoshish(int a, int b) {        // qaytaruvchi tur — int
    return a + b;
}

auto yarmi(double x) {              // qaytaruvchi tur — double
    return x / 2;
}

int main() {
    cout << qoshish(3, 4) << " " << yarmi(5) << endl;
    return 0;
}
```

```output
7 2.5
```

### Chuqurroq o'rganamiz: `decltype` — "turini menga ber"

`auto` ning "qarindoshi" — `decltype`. U ifodaning turini aniqlab beradi, lekin ifodani hisoblamaydi:

```cpp
#include <iostream>
using namespace std;

int main() {
    int a = 5;
    double b = 2.5;
    decltype(a) c = 10;          // c ning turi — a ning turi, ya'ni int
    decltype(a + b) d = 7.8;     // int + double = double
    cout << c << " " << d << endl;
    return 0;
}
```

```output
10 7.8
```

### Qadamma-qadam tahlil: `auto` qachon foydali, qachon zararli

**Foydali holat — uzun tur nomlari:**

```cpp
#include <iostream>
#include <map>
#include <string>
using namespace std;

int main() {
    map<string, int> ballar = {{"Malika", 98}, {"Jasur", 85}};

    // auto siz:
    for (map<string, int>::iterator it = ballar.begin(); it != ballar.end(); ++it)
        cout << it->first << ": " << it->second << endl;

    // auto bilan — ancha qisqa va tushunarli:
    for (auto it = ballar.begin(); it != ballar.end(); ++it)
        cout << it->first << ": " << it->second << endl;
    return 0;
}
```

```output
Jasur: 85
Malika: 98
Jasur: 85
Malika: 98
```

**Zararli holat — tur aniq emas:**

```cpp
auto x = hisobla();     // x ning turi nima? int mi? double mi? Kodni o'qigan odam bilmaydi.
auto n = 0;             // ehtimol int, lekin keyin katta son kerak bo'lsa?
```

| Vaziyat | `auto` ishlatish kerakmi? |
|---|---|
| Iteratorlar, uzun shablon turlari | Ha, albatta |
| `for (auto x : konteyner)` | Ha |
| `auto p = make_unique<Robot>();` — tur o'ng tomonda ko'rinib turibdi | Ha |
| Oddiy `int`, `double` o'zgaruvchilar | Odatda yo'q — turni aniq yoz |
| Funksiya natijasi, turi noaniq | Ehtiyot bo'l |

### Chuqurroq o'rganamiz: `auto` tarixi

Qiziq fakt: `auto` kalit so'zi C++ da **boshidan** bor edi, lekin butunlay boshqa ma'noda! Eski C++ da `auto int x;` — "x — avtomatik (mahalliy) o'zgaruvchi" degani edi. Bu shunchalik keraksiz ediki, deyarli hech kim ishlatmasdi. C++11 da qo'mita bu so'zga yangi, foydali ma'no berdi — "turni avtomatik aniqla". Natijada `auto` eng ko'p ishlatiladigan kalit so'zlardan biriga aylandi!
