### Chuqurroq o'rganamiz: C++ ning asosiy xususiyatlari

C++ nima uchun shunchalik mashhur? Uning eng muhim xususiyatlarini ko'rib chiqamiz:

| Xususiyat | Ma'nosi | Bu nima beradi |
|---|---|---|
| **Kompilyatsiya qilinadigan** | Kod oldindan mashina tiliga o'giriladi | Juda yuqori tezlik |
| **Statik turlash** | Har bir o'zgaruvchining turi oldindan ma'lum | Ko'p xatolar dastur ishga tushmasdan topiladi |
| **Ko'p paradigmali** | Protsedurali, obyektga yo'naltirilgan va generic uslublarni qo'llaydi | Har bir masalaga mos uslubni tanlash mumkin |
| **Obyektga yo'naltirilgan** | Klasslar, merosxo'rlik, polimorfizm | Katta loyihalarni tartibli qurish |
| **Past darajali boshqaruv** | Ko'rsatkichlar, xotirani qo'lda boshqarish | Apparat qismiga yaqin ishlash |
| **Boy standart kutubxona** | STL: tayyor konteynerlar va algoritmlar | Ko'p ishni tayyor vositalar bilan tez bajarish |
| **Ko'chuvchanlik** | Bitta kod turli kompyuter va tizimlarda ishlaydi | Windows, Linux, macOS, telefonlar, mikrokontrollerlar |
| **C bilan moslik** | C kodini C++ da ishlatish mumkin | Minglab tayyor C kutubxonalaridan foydalanish |

### Chuqurroq o'rganamiz: C++ standart kutubxonasi

C++ bilan birga **standart kutubxona** keladi — bu tayyor funksiya va klasslarning katta to'plami. Uni ikki asosiy qismga ajratish mumkin:

1. **C kutubxonasidan meros qolgan qism.** Bular C tilidan kelgan funksiyalar: matematik hisoblar (`<cmath>`), belgilar bilan ishlash (`<cctype>`), vaqt (`<ctime>`) va boshqalar. C++ da ularning nomi `c` harfi bilan boshlanadi: C dagi `math.h` C++ da `<cmath>` bo'ladi.
2. **C++ ning o'z kutubxonasi.** Bunga kirish-chiqish oqimlari (`<iostream>`, `<fstream>`), satrlar (`<string>`), STL konteynerlari va algoritmlari (`<vector>`, `<map>`, `<algorithm>`), aqlli ko'rsatkichlar (`<memory>`), oqimlar (`<thread>`) va boshqalar kiradi.

| Kutubxona guruhi | Asosiy header fayllar | Nima uchun |
|---|---|---|
| Kirish-chiqish | `<iostream>`, `<fstream>`, `<sstream>` | Ekran, klaviatura, fayllar bilan ishlash |
| Satrlar | `<string>`, `<cctype>` | Matnlar bilan ishlash |
| Konteynerlar | `<vector>`, `<list>`, `<map>`, `<set>`, `<stack>`, `<queue>` | Ma'lumotlarni saqlash |
| Algoritmlar | `<algorithm>`, `<numeric>` | Saralash, qidirish, hisoblash |
| Matematika | `<cmath>`, `<random>`, `<complex>` | Hisob-kitoblar, tasodifiy sonlar |
| Xotira | `<memory>`, `<new>` | Aqlli ko'rsatkichlar, dinamik xotira |
| Vaqt | `<chrono>`, `<ctime>` | Vaqtni o'lchash, sana |
| Parallel dasturlash | `<thread>`, `<mutex>`, `<atomic>` | Bir nechta ishni bir vaqtda bajarish |
| Xatolar | `<stdexcept>`, `<exception>` | Istisnolar |

Bu kutubxonalarning hammasini kitob davomida birma-bir o'rganib chiqasan.

### Chuqurroq o'rganamiz: `iostream` — C++ ning "og'zi va qulog'i"

Har bir C++ dasturida deyarli doim uchraydigan `<iostream>` kutubxonasi bilan yaqinroq tanishamiz. Uning nomi ikki qismdan iborat: **i**nput/**o**utput (kirish/chiqish) va **stream** (oqim).

**Oqim** — bu ma'lumotlarning ketma-ket "oqib" kelishi yoki ketishi. Uni suv quvuriga o'xshatish mumkin: klaviaturadan dasturga ma'lumot "oqib keladi" (kirish oqimi), dasturdan ekranga esa "oqib ketadi" (chiqish oqimi).

`<iostream>` dagi asosiy obyektlar:

| Obyekt | Vazifasi | Qayerga/qayerdan |
|---|---|---|
| `cin` | Ma'lumot o'qish (character input) | Klaviaturadan |
| `cout` | Ma'lumot chiqarish (character output) | Ekranga |
| `cerr` | Xato xabarlarini chiqarish (darhol, buferlanmagan) | Ekranga (xatolar oqimi) |
| `clog` | Jurnal (log) xabarlarini chiqarish (buferlangan) | Ekranga (xatolar oqimi) |

```cpp
#include <iostream>
using namespace std;

int main() {
    int yosh;
    cout << "Yoshingni kirit: ";
    cin >> yosh;
    if (yosh < 0) {
        cerr << "Xato: yosh manfiy bo'lishi mumkin emas!" << endl;
        return 1;
    }
    clog << "[jurnal] yosh muvaffaqiyatli o'qildi" << endl;
    cout << "Sen " << yosh << " yoshdasan." << endl;
    return 0;
}
```

```output
Yoshingni kirit: 12
[jurnal] yosh muvaffaqiyatli o'qildi
Sen 12 yoshdasan.
```

!eslatma `cerr` va `clog` ham ekranga yozadi, lekin ular **alohida oqim**ga yozadi. Bu katta dasturlarda juda foydali: oddiy natijalarni bir faylga, xatolarni esa boshqa faylga yo'naltirish mumkin.

**`<<` va `>>` operatorlari.** Ularni o'q deb tasavvur qil — o'q ma'lumot qaysi tomonga oqishini ko'rsatadi:

- `cout << x` — `x` dan ekranga (`cout` ga) qarab.
- `cin >> x` — klaviaturadan (`cin` dan) `x` ga qarab.

Bir nechta qiymatni zanjir qilib chiqarish yoki o'qish mumkin:

```cpp
#include <iostream>
using namespace std;

int main() {
    int a = 3, b = 4;
    cout << "a = " << a << ", b = " << b << ", yig'indi = " << a + b << endl;
    return 0;
}
```

```output
a = 3, b = 4, yig'indi = 7
```

**`endl` va `'\n'` farqi.** Ikkalasi ham yangi qatorga o'tkazadi, lekin `endl` qo'shimcha ravishda **buferni tozalaydi** — ya'ni to'plangan matnni darhol ekranga chiqaradi. `'\n'` esa tezroq, chunki buferni tozalamaydi. Ko'p qatorli chiqarishda `'\n'` ishlatish dasturni tezlashtiradi.

### Chuqurroq o'rganamiz: C++ interfeyslari

C++ falsafasining muhim g'oyasi — **interfeys va amalga oshirishni ajratish**. Interfeys — bu biror narsa **nima qila olishini** tavsiflovchi "shartnoma", amalga oshirish esa **qanday qilishini** ko'rsatadi.

Hayotiy misol: barcha mashinalarda "chiroqni yoqish" tugmasi bor. Bu — interfeys. Lekin har xil mashinalarda chiroq ichkarida har xil yoqiladi — bu amalga oshirish. Haydovchi uchun farqi yo'q, u faqat tugmani bosadi.

C++ da interfeyslar **abstrakt klasslar** yordamida yaratiladi. Kichik misol (klasslar haqida 10–11-modullarda batafsil o'rganasan):

```cpp
#include <iostream>
using namespace std;

class Transport {                          // interfeys
public:
    virtual void chiroqYoq() = 0;          // "= 0" — sof virtual funksiya
    virtual ~Transport() {}
};

class Mashina : public Transport {
public:
    void chiroqYoq() override { cout << "Mashina faralari yondi" << endl; }
};

class Skuter : public Transport {
public:
    void chiroqYoq() override { cout << "Skuter chirog'i yondi" << endl; }
};

int main() {
    Mashina m;
    Skuter s;
    Transport* transportlar[] = {&m, &s};
    for (Transport* t : transportlar) t->chiroqYoq();
    return 0;
}
```

```output
Mashina faralari yondi
Skuter chirog'i yondi
```

Interfeyslarning foydasi:

1. **Tushunish oson** — foydalanuvchi faqat "nima qilish mumkin"ligini bilsa yetarli.
2. **Xatolarga kam moyil** — ichki tafsilotlarni tasodifan buzib bo'lmaydi.
3. **Kengaytirish oson** — yangi transport turini qo'shish uchun mavjud kodni o'zgartirish shart emas.

### Qadamma-qadam tahlil: "Salom, dunyo!" dasturi ichida nima bor?

Eng birinchi dasturni har bir belgigacha tahlil qilamiz:

```cpp
#include <iostream>

int main() {
    std::cout << "Salom, dunyo!" << std::endl;
    return 0;
}
```

| Qism | Kim uchun | Ma'nosi |
|---|---|---|
| `#` | Preprotsessor | "Bu kompilyatsiyadan oldin bajariladigan buyruq" |
| `include` | Preprotsessor | "Faylni qo'sh" |
| `<iostream>` | Preprotsessor | Qaysi fayl: kirish-chiqish kutubxonasi |
| `int` | Kompilyator | `main` funksiyasi butun son qaytaradi |
| `main` | Kompilyator | Dastur boshlanadigan funksiya nomi |
| `()` | Kompilyator | Funksiya parametrlari (bu yerda yo'q) |
| `{` | Kompilyator | Funksiya tanasi boshlandi |
| `std::` | Kompilyator | "Standart nomlar fazosidan" |
| `cout` | Kompilyator | Ekranga chiqarish obyekti |
| `<<` | Kompilyator | "Chiqarishga yubor" operatori |
| `"Salom, dunyo!"` | Kompilyator | Satr literali — chiqariladigan matn |
| `std::endl` | Kompilyator | Yangi qator va buferni tozalash |
| `;` | Kompilyator | Ko'rsatma tugadi |
| `return 0;` | Operatsion tizim | "Dastur muvaffaqiyatli tugadi" (0 — xato yo'q) |

### Chuqurroq o'rganamiz: C++ standartlari qanday yaratiladi?

C++ ni bitta kompaniya yoki bitta odam boshqarmaydi. Uni **ISO** (Xalqaro standartlashtirish tashkiloti) huzuridagi xalqaro qo'mita rivojlantiradi. Qo'mitada butun dunyodan yuzlab mutaxassislar — yirik kompaniyalar xodimlari, olimlar va mustaqil dasturchilar ishlaydi.

Jarayon taxminan shunday:

1. Kimdir yangi imkoniyat taklif qiladi (masalan, "lambda ifodalar qo'shaylik").
2. Qo'mita taklifni muhokama qiladi, sinab ko'radi, kamchiliklarini tuzatadi.
3. Ovoz berish orqali qabul qilinadi.
4. Har uch yilda yangi standart e'lon qilinadi: C++11, C++14, C++17, C++20, C++23...
5. Kompilyator ishlab chiquvchilari (GCC, Clang, MSVC) yangi imkoniyatlarni o'z kompilyatorlariga qo'shishadi.

Shuning uchun C++ o'nlab yillar o'tsa ham eskirmaydi — u doimo zamonaviylashib boradi, lekin eski kodlar bilan moslikni ham saqlaydi.

### Chuqurroq o'rganamiz: C nima?

**C** — 1972-yilda Bell Labs laboratoriyasida **Dennis Ritchi** tomonidan yaratilgan dasturlash tili. U dastlab **UNIX** operatsion tizimini yozish uchun ishlab chiqilgan. C o'sha davr uchun inqilobiy til edi: u assembler tili kabi tez, lekin undan ancha tushunarli edi.

C ning asosiy xususiyatlari:

- **Protsedurali til** — dastur funksiyalar to'plamidan iborat.
- **O'rta darajali til** — ham yuqori darajali qulayliklar, ham apparat bilan to'g'ridan-to'g'ri ishlash imkoni bor.
- **Kichik va sodda** — atigi 30 dan ortiq kalit so'z.
- **Juda tez** — kod mashina tiliga to'g'ridan-to'g'ri o'giriladi.
- **Ko'chuvchan** — deyarli har qanday kompyuter uchun C kompilyatori bor.

!fakt Bugun ham Linux operatsion tizimining yadrosi, Windows ning ko'p qismlari, ko'plab mikrokontrollerlar dasturlari va Python tilining asosiy interpretatori C tilida yozilgan. 50 yildan oshgan til hali ham dunyodagi eng muhim tillardan biri!

### Chuqurroq o'rganamiz: C++ nima?

**C++** — C tilining kengaytirilgan versiyasi. U C ning barcha kuchli tomonlarini saqlab, unga **obyektga yo'naltirilgan dasturlash** va boshqa ko'plab imkoniyatlarni qo'shdi. C++ dagi OOP to'rtta asosiy tamoyilga tayanadi:

1. **Inkapsulyatsiya** — ma'lumot va uni qayta ishlovchi funksiyalarni bitta "kapsula"ga (klassga) joylash.
2. **Abstraksiya** — faqat muhim narsani ko'rsatib, murakkab tafsilotlarni yashirish.
3. **Merosxo'rlik** — mavjud klass asosida yangi klass yaratish.
4. **Polimorfizm** — bitta buyruqning turli obyektlarda turlicha bajarilishi.

Bu tushunchalarni 10–11-modullarda batafsil o'rganamiz.

### Chuqurroq o'rganamiz: C va C++ o'rtasidagi o'xshashliklar

Farqlari ko'p bo'lsa ham, ikki til juda ko'p umumiy jihatlarga ega:

| O'xshashlik | Izoh |
|---|---|
| Sintaksis | `if`, `for`, `while`, `switch`, `{ }`, `;` — bir xil yoziladi |
| Asosiy turlar | `int`, `char`, `float`, `double` — ikkalasida ham bor |
| Operatorlar | `+`, `-`, `*`, `/`, `%`, `&&`, `\|\|`, `==` — bir xil |
| Ko'rsatkichlar | Ikkalasida ham bor va bir xil ishlaydi |
| Massivlar | Bir xil e'lon qilinadi va ishlatiladi |
| Funksiyalar | Asosiy tuzilishi bir xil |
| Preprotsessor | `#include`, `#define` — ikkalasida ham |
| Kompilyatsiya | Ikkalasi ham mashina tiliga kompilyatsiya qilinadi |
| `main()` | Dastur ikkalasida ham `main` dan boshlanadi |

### Chuqurroq o'rganamiz: xotira bilan ishlash farqi

Ikki til orasidagi muhim amaliy farqlardan biri — dinamik xotira bilan ishlash:

**C tilida:**

```cpp
#include <cstdlib>
#include <cstdio>

int main() {
    int* sonlar = (int*)malloc(5 * sizeof(int));   // xotira olish
    for (int i = 0; i < 5; i++) sonlar[i] = i * 10;
    printf("%d\n", sonlar[3]);
    free(sonlar);                                   // xotirani qaytarish
    return 0;
}
```

```output
30
```

**C++ tilida:**

```cpp
#include <iostream>
#include <vector>
using namespace std;

int main() {
    vector<int> sonlar(5);                 // xotirani o'zi boshqaradi
    for (int i = 0; i < 5; i++) sonlar[i] = i * 10;
    cout << sonlar[3] << endl;
    return 0;                              // xotira avtomatik qaytariladi
}
```

```output
30
```

C da dasturchi xotira hajmini o'zi hisoblashi (`5 * sizeof(int)`), uni olishi (`malloc`) va qaytarishi (`free`) kerak. Unutsa — xato. C++ da esa `vector` hammasini o'zi bajaradi. Bu C++ dasturlarini xavfsizroq qiladi.

| | C | C++ |
|---|---|---|

| **Kamchiliklari** | OOP yo'q; satrlar va xotira bilan ishlash qiyin va xavfli; tayyor konteynerlar yo'q; katta loyihalarda kod chalkashadi | Til juda katta va murakkab; o'rganish uzoq davom etadi; ba'zi xatolar (masalan, shablon xatolari) tushunish qiyin; kompilyatsiya sekinroq |

### Qadamma-qadam tahlil: bir masala — ikki tilda

**Masala:** foydalanuvchidan ismini so'rab, unga salom berish.

**C tilida:**

```cpp
#include <cstdio>

int main() {
    char ism[50];                      // 50 belgilik joy
    printf("Isming nima? ");
    scanf("%49s", ism);                // ko'pi bilan 49 belgi o'qiymiz
    printf("Salom, %s!\n", ism);
    return 0;
}
```

**C++ tilida:**

```cpp
#include <iostream>
#include <string>
using namespace std;

int main() {
    string ism;                        // o'lchami o'zgaruvchan
    cout << "Isming nima? ";
    cin >> ism;
    cout << "Salom, " << ism << "!" << endl;
    return 0;
}
```

| Jihat | C | C++ |
|---|---|---|
| Ism uchun joy | Qat'iy massiv: `char ism[50]` | Moslashuvchan: `string ism` |
| Juda uzun ism kiritilsa | Massivdan chiqib ketish xavfi (shuning uchun `%49s`) | Xavf yo'q, `string` o'zi kattalashadi |
| Formatlash | `%s`, `%d` kabi maxsus belgilar | `<<` operatori, turni o'zi biladi |
| Xato qilish ehtimoli | Yuqori (`%d` o'rniga `%s` yozish va h.k.) | Pastroq |

!maslahat Agar kelajakda mikrokontrollerlar (Arduino), operatsion tizimlar yoki "temir"ga yaqin dasturlash bilan shug'ullanmoqchi bo'lsang, C ni ham o'rganish foydali. C++ ni bilsang, C ni bir-ikki hafta ichida o'rganib olasan!
