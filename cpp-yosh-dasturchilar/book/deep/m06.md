### Chuqurroq o'rganamiz: funksiya turlari

Funksiyalarni ikki belgi bo'yicha guruhlash mumkin: parametr qabul qiladimi va natija qaytaradimi:

| | Natija qaytaradi | Natija qaytarmaydi (`void`) |
|---|---|---|
| **Parametrli** | `int kvadrat(int x)` | `void chopEt(string matn)` |
| **Parametrsiz** | `int tasodifiySon()` | `void salomlash()` |

```cpp
#include <iostream>
#include <cstdlib>
using namespace std;

int kvadrat(int x) { return x * x; }                 // parametrli, qaytaradi
void chopEt(string matn) { cout << matn << endl; }   // parametrli, qaytarmaydi
int ettilik() { return 7; }                          // parametrsiz, qaytaradi
void chiziq() { cout << "----------" << endl; }      // parametrsiz, qaytarmaydi

int main() {
    chiziq();
    chopEt("Funksiyalar bilan tanishamiz");
    cout << "5 ning kvadrati: " << kvadrat(5) << endl;
    cout << "Omadli son: " << ettilik() << endl;
    chiziq();
    return 0;
}
```

```output
----------
Funksiyalar bilan tanishamiz
5 ning kvadrati: 25
Omadli son: 7
----------
```

### Chuqurroq o'rganamiz: funksiya natijasini qanday ishlatish mumkin?

Funksiya qaytargan qiymatni oddiy qiymat kabi istalgan joyda ishlatish mumkin:

```cpp
#include <iostream>
using namespace std;

int kvadrat(int x) { return x * x; }

int main() {
    int a = kvadrat(4);                          // o'zgaruvchiga saqlash
    cout << kvadrat(3) << endl;                  // to'g'ridan-to'g'ri chiqarish
    int b = kvadrat(2) + kvadrat(3);             // ifoda ichida
    int c = kvadrat(kvadrat(2));                 // boshqa funksiyaga argument sifatida
    if (kvadrat(5) > 20) cout << "25 > 20" << endl;   // shart ichida
    cout << a << " " << b << " " << c << endl;
    return 0;
}
```

```output
9
25 > 20
16 13 16
```

`kvadrat(kvadrat(2))` qanday hisoblanadi? Avval ichki chaqiruv: `kvadrat(2)` = 4. Keyin tashqi: `kvadrat(4)` = 16.

### Chuqurroq o'rganamiz: mahalliy o'zgaruvchilar va funksiyalar

Har bir funksiyaning o'z "xonasi" bor — uning ichida yaratilgan o'zgaruvchilar faqat shu funksiyaga tegishli. Ikki funksiyada bir xil nomli o'zgaruvchi bo'lsa ham, ular bir-biriga xalaqit bermaydi:

```cpp

    int x = 100;
    cout << "birinchi() ichida x = " << x << endl;
}

void ikkinchi() {
    int x = 200;                    // bu boshqa x!
    cout << "ikkinchi() ichida x = " << x << endl;
}

int main() {
    int x = 1;
    birinchi();
    ikkinchi();
    cout << "main() ichida x = " << x << endl;    // o'zgarmadi
    return 0;
}
```

```output
birinchi() ichida x = 100
ikkinchi() ichida x = 200
main() ichida x = 1
```

### Chuqurroq o'rganamiz: uchta uzatish usuli

Funksiyaga argument uchta usulda uzatilishi mumkin:

| Usul | Yozilishi | Asl o'zgaruvchi o'zgaradimi? | Qachon ishlatiladi |
|---|---|---|---|
| **Qiymat bo'yicha** | `void f(int x)` | Yo'q (nusxa) | Kichik turlar, o'zgartirish kerak bo'lmasa |
| **Havola bo'yicha** | `void f(int& x)` | Ha | Asl qiymatni o'zgartirish kerak bo'lsa |
| **Ko'rsatkich bo'yicha** | `void f(int* x)` | Ha (`*x` orqali) | C uslubidagi kod, "bo'sh" qiymat kerak bo'lsa |

```cpp
#include <iostream>
using namespace std;

void qiymat(int x)      { x = 0; }
void havola(int& x)     { x = 0; }
void korsatkich(int* x) { *x = 0; }

int main() {
    int a = 5, b = 5, c = 5;
    qiymat(a);
    havola(b);
    korsatkich(&c);
    cout << "a = " << a << ", b = " << b << ", c = " << c << endl;
    return 0;
}
```

```output
a = 5, b = 0, c = 0
```

Ko'rsatkichlar haqida 7-modulda batafsil o'rganasan.

### Qadamma-qadam tahlil: "Sinf statistikasi" dasturini funksiyalarga bo'lish

Katta masalani kichik funksiyalarga bo'lishni amalda ko'ramiz:

```cpp
#include <iostream>
using namespace std;

const int N = 5;

void baholarniChiqar(int baholar[], int n) {
    cout << "Baholar: ";
    for (int i = 0; i < n; i++) cout << baholar[i] << " ";
    cout << endl;
}

double ortacha(int baholar[], int n) {
    int jami = 0;
    for (int i = 0; i < n; i++) jami += baholar[i];
    return (double)jami / n;
}

int engYuqori(int baholar[], int n) {
    int eng = baholar[0];
    for (int i = 1; i < n; i++)
        if (baholar[i] > eng) eng = baholar[i];
    return eng;
}

int nechtaBesh(int baholar[], int n) {
    int soni = 0;
    for (int i = 0; i < n; i++)
        if (baholar[i] == 5) soni++;
    return soni;
}

int main() {
    int baholar[N] = {5, 4, 5, 3, 5};
    baholarniChiqar(baholar, N);
    cout << "O'rtacha: " << ortacha(baholar, N) << endl;
    cout << "Eng yuqori: " << engYuqori(baholar, N) << endl;
    cout << "\"5\" lar soni: " << nechtaBesh(baholar, N) << endl;
    return 0;
}
```

```output
Baholar: 5 4 5 3 5 
O'rtacha: 4.4
Eng yuqori: 5
"5" lar soni: 3
```

| Funksiya | Vazifasi | Qaytaradi |
|---|---|---|
| `baholarniChiqar` | Ekranga chiqarish | `void` |
| `ortacha` | O'rtacha hisoblash | `double` |
| `engYuqori` | Eng kattasini topish | `int` |
| `nechtaBesh` | "5" larni sanash | `int` |

E'tibor ber: `main` juda qisqa va tushunarli bo'lib qoldi — u shunchaki "rejani" bajaradi. Har bir funksiyani alohida tekshirish, tuzatish va boshqa dasturlarda qayta ishlatish mumkin.

### Chuqurroq o'rganamiz: zamonaviy tasodifiy sonlar — `<random>`

`rand()` eski va unchalik "tasodifiy" bo'lmagan usul. C++11 da yanada sifatli `<random>` kutubxonasi qo'shilgan:

```cpp
#include <iostream>
#include <random>
using namespace std;

int main() {
    random_device qurilma;                         // tasodifiylik manbai
    mt19937 generator(qurilma());                  // sifatli generator
    uniform_int_distribution<int> zar(1, 6);       // 1 dan 6 gacha teng ehtimollik

    cout << "5 marta zar tashlaymiz: ";
    for (int i = 0; i < 5; i++) cout << zar(generator) << " ";
    cout << endl;
    return 0;
}
```

```output
5 marta zar tashlaymiz: 4 1 6 3 3 
```

| Qism | Vazifasi |
|---|---|
| `random_device` | Kompyuterdan haqiqiy tasodifiy "urug'" oladi |
| `mt19937` | "Mersenne Twister" — mashhur va sifatli generator |
| `uniform_int_distribution<int>(a, b)` | a dan b gacha har bir son bir xil ehtimollik bilan chiqadi |

### Qadamma-qadam tahlil: "Ism generatori" — kutubxonalarni birlashtirish

```cpp
#include <iostream>
#include <string>

#include <algorithm>

    bool yangiSoz = true;
    for (char& c : ism) {

        if (c == ' ') yangiSoz = true;
    }
    cout << "Chiroyli yozilishi: " << ism << endl;

    // 2. Harflar sonini sanaymiz (probellarsiz)
    int harflar = count_if(ism.begin(), ism.end(), [](char c) { return isalpha(c); });
    cout << "Harflar soni: " << harflar << endl;

    // 3. Teskari o'qiymiz
    string teskari = ism;
    reverse(teskari.begin(), teskari.end());
    cout << "Teskarisi: " << teskari << endl;
    return 0;
}
```

### Chuqurroq o'rganamiz: rekursiyani qanday o'ylash kerak?

Rekursiv funksiya yozishning "retsepti" bor. Uchta savolga javob ber:

1. **Eng oddiy holat qanday?** (asosiy holat) — masalan, 0! = 1 yoki bo'sh ro'yxat yig'indisi = 0.
2. **Masalani qanday kichraytirish mumkin?** — masalan, n! ni (n−1)! orqali ifodalash.
3. **Kichikroq masala yechimidan kattasini qanday hosil qilaman?** — masalan, n! = n × (n−1)!.

Bu usul "**ishonch sakrashi**" deb ham ataladi: kichikroq masala to'g'ri yechilishiga **ishon** va faqat oxirgi qadamni o'yla.

### Chuqurroq o'rganamiz: rekursiya turlari

| Tur | Ta'rif | Misol |
|---|---|---|
| **Chiziqli** | Funksiya o'zini bir marta chaqiradi | Faktorial |
| **Daraxtsimon** | Funksiya o'zini bir necha marta chaqiradi | Fibonachchi, Hanoy minorasi |
| **Dum rekursiya** (tail recursion) | Rekursiv chaqiruv — eng oxirgi amal | Ba'zi kompilyatorlar uni tsiklga aylantira oladi |
| **O'zaro rekursiya** | A funksiya B ni, B esa A ni chaqiradi | Juft/toqni aniqlash |

O'zaro rekursiya misoli:

```cpp
#include <iostream>
using namespace std;

bool toqmi(int n);                   // prototip kerak, chunki juftmi uni chaqiradi

bool juftmi(int n) {
    if (n == 0) return true;
    return toqmi(n - 1);
}

bool toqmi(int n) {
    if (n == 0) return false;
    return juftmi(n - 1);
}

int main() {
    cout << "7 juftmi? " << (juftmi(7) ? "ha" : "yo'q") << endl;
    cout << "10 juftmi? " << (juftmi(10) ? "ha" : "yo'q") << endl;
    return 0;
}
```

```output
7 juftmi? yo'q
10 juftmi? ha
```

### Chuqurroq o'rganamiz: Fibonachchi muammosi va yechimi

Oddiy rekursiv Fibonachchi juda sekin, chunki bir xil qiymatlar qayta-qayta hisoblanadi. `fib(5)` uchun chaqiruvlar daraxti:

```text
                    fib(5)
                 /          \
            fib(4)          fib(3)
           /      \         /     \
       fib(3)   fib(2)   fib(2)  fib(1)
       /    \
   fib(2)  fib(1)
```

`fib(3)` ikki marta, `fib(2)` uch marta hisoblandi! `fib(40)` uchun esa yuz milliondan ortiq chaqiruv bo'ladi.

**Yechim — eslab qolish (memoizatsiya):** bir marta hisoblangan natijani saqlab qo'yamiz va keyingi safar tayyor javobni olamiz:

```cpp
#include <iostream>
using namespace std;

long long xotira[100] = {0};          // 0 — hali hisoblanmagan

long long fib(int n) {
    if (n <= 1) return n;
    if (xotira[n] != 0) return xotira[n];   // avval hisoblangan bo'lsa — tayyor javob
    xotira[n] = fib(n - 1) + fib(n - 2);
    return xotira[n];
}

int main() {
    cout << "fib(10) = " << fib(10) << endl;
    cout << "fib(50) = " << fib(50) << endl;     // bir zumda!
    cout << "fib(90) = " << fib(90) << endl;
    return 0;
}
```

```output
fib(10) = 55
fib(50) = 12586269025
fib(90) = 2880067194370816120
```

Eslab qolish bilan har bir qiymat faqat **bir marta** hisoblanadi. Bu g'oya **dinamik dasturlash** deb ataladigan kuchli usulning asosi — u olimpiada masalalarida juda ko'p ishlatiladi!

### Qadamma-qadam tahlil: satrni teskari aylantirish (rekursiv)

```cpp
#include <iostream>
#include <string>
using namespace std;

string teskari(const string& s) {
    if (s.length() <= 1) return s;                         // asosiy holat
    return teskari(s.substr(1)) + s[0];                    // qolganini aylantir + birinchi harf
}

bool palindrommi(const string& s, int chap, int ong) {
    if (chap >= ong) return true;                          // asosiy holat
    if (s[chap] != s[ong]) return false;
    return palindrommi(s, chap + 1, ong - 1);              // ichki qismni tekshir
}

int main() {
    cout << teskari("KODI") << endl;
    for (string soz : {"kiyik", "olma", "qoq"}) {
        cout << soz << ": " << (palindrommi(soz, 0, soz.length() - 1) ? "palindrom" : "palindrom emas") << endl;
    }
    return 0;
}
```

```output
IDOK
kiyik: palindrom
olma: palindrom emas
qoq: palindrom
```

`teskari("KODI")` qanday ishlaydi:

| Chaqiruv | Qaytaradi |
|---|---|
| `teskari("KODI")` | `teskari("ODI") + 'K'` |
| `teskari("ODI")` | `teskari("DI") + 'O'` |
| `teskari("DI")` | `teskari("I") + 'D'` |
| `teskari("I")` | `"I"` (asosiy holat) |
| Qaytish: | `"I" + 'D'` = `"ID"` → `"ID" + 'O'` = `"IDO"` → `"IDO" + 'K'` = **`"IDOK"`** |

### Chuqurroq o'rganamiz: ikkilik ko'rinish va darajaga ko'tarish

**Sonni ikkilikka rekursiv aylantirish:**

```cpp
#include <iostream>
using namespace std;

void ikkilik(int n) {
    if (n > 1) ikkilik(n / 2);       // avval yuqori bitlarni chiqaramiz
    cout << n % 2;
}

long long tezDaraja(long long a, int n) {
    if (n == 0) return 1;
    long long yarim = tezDaraja(a, n / 2);
    if (n % 2 == 0) return yarim * yarim;        // a^n = (a^(n/2))^2
    return yarim * yarim * a;                    // toq n uchun
}

int main() {
    cout << "13 = "; ikkilik(13); cout << endl;
    cout << "2^30 = " << tezDaraja(2, 30) << endl;
    cout << "3^20 = " << tezDaraja(3, 20) << endl;
    return 0;
}
```

```output
13 = 1101
2^30 = 1073741824
3^20 = 3486784401
```

`tezDaraja` juda aqlli: 2³⁰ ni hisoblash uchun 30 ta ko'paytirish emas, atigi 5–6 ta qadam kerak, chunki har qadamda daraja ikki barobar kichrayadi!

### Chuqurroq o'rganamiz: operatsion tizimga qarab turli kod

Shartli kompilyatsiyaning eng foydali qo'llanilishi — turli operatsion tizimlar uchun turli kod yozish. Kompilyatorlar avtomatik ravishda maxsus makroslarni aniqlaydi:

```cpp
    cout << "Dastur macOS da ishlayapti" << endl;
#elif defined(__linux__)
    cout << "Dastur Linux da ishlayapti" << endl;
#else
    cout << "Noma'lum tizim" << endl;
#endif
    return 0;
}
```

```output
Dastur Linux da ishlayapti
```

### Chuqurroq o'rganamiz: maxsus makros operatorlari `#` va `##`

Makroslar ichida ikkita maxsus operator ishlatiladi:

| Operator | Nomi | Vazifasi |
|---|---|---|
| `#` | Satrga aylantirish | Makros parametrini qo'shtirnoq ichidagi satrga aylantiradi |
| `##` | Yopishtirish | Ikki tokenni bitta tokenga birlashtiradi |

```cpp
#include <iostream>
using namespace std;

#define CHIQAR(x) cout << #x << " = " << (x) << endl
#define YOPISHTIR(a, b) a##b

int main() {
    int yosh = 12, ball = 95;
    CHIQAR(yosh);                 // cout << "yosh" << " = " << (yosh) << endl;
    CHIQAR(ball * 2);
    int oquvchi1 = 100;
    cout << YOPISHTIR(oquvchi, 1) << endl;     // oquvchi1
    return 0;
}
```

```output

ball * 2 = 190
100
```

`CHIQAR` makrosi xatolarni topishda juda qulay: u o'zgaruvchi nomini ham, qiymatini ham bir yo'la chiqaradi.

### Chuqurroq o'rganamiz: `assert` — o'zingni tekshir

`<cassert>` dagi `assert` makrosi "bu shart doim rost bo'lishi kerak" degan tekshiruvni qo'yadi. Agar shart yolg'on bo'lsa, dastur to'xtaydi va qaysi qatorda muammo borligini aytadi:

```cpp
#include <iostream>

int main() {

    // ortacha(15, 0);   // dastur to'xtaydi: "Assertion `soni > 0' failed"

}
```

```output
5
```

!maslahat `assert` — dasturchi uchun vosita, foydalanuvchi uchun emas. U dastur ishlab chiqilayotganda xatolarni erta topishga yordam beradi. Tayyor dasturda `NDEBUG` makrosi aniqlansa, barcha `assert` lar avtomatik o'chiriladi.

### Qadamma-qadam tahlil: "Sinov rejimi" bilan dastur

Preprotsessor yordamida dasturga sinov paytida qo'shimcha ma'lumot chiqaradigan, tayyor holatda esa jim ishlaydigan rejim qo'shamiz:

```cpp
#include <iostream>
using namespace std;

#define SINOV 1          // 1 — sinov rejimi yoqilgan, 0 — o'chirilgan

#if SINOV
    #define LOG(x) cout << "[sinov] " << #x << " = " << (x) << endl
#else
    #define LOG(x)
#endif

int faktorial(int n) {
    int natija = 1;
    for (int i = 2; i <= n; i++) {
        natija *= i;
        LOG(natija);
    }
    return natija;
}

int main() {
    int f = faktorial(5);       // avval hisoblaymiz, keyin chiqaramiz
    cout << "5! = " << f << endl;
    return 0;
}
```

```output
[sinov] natija = 2
[sinov] natija = 6
[sinov] natija = 24
[sinov] natija = 120
5! = 120
```

| `SINOV` qiymati | `LOG(natija)` nimaga aylanadi | Natija |
|---|---|---|
| 1 | `cout << "[sinov] " << "natija" << ...` | Har qadam ekranga chiqadi |
| 0 | (hech narsa — bo'sh qator) | Faqat yakuniy natija |

`#define SINOV 0` qilib qo'ysang, barcha `LOG` qatorlari kompilyatsiyadan oldin butunlay yo'qoladi va dasturni sekinlashtirmaydi.

### Chuqurroq o'rganamiz: funksiyadan bir nechta qiymat qaytarishning zamonaviy usullari

Havola parametrlardan tashqari, C++ da yana ikkita qulay usul bor:

**1. `pair` — ikki qiymat uchun:**

```cpp
#include <iostream>
#include <utility>
using namespace std;

pair<int, int> bolish(int a, int b) {
    return {a / b, a % b};
}

int main() {
    auto [butun, qoldiq] = bolish(17, 5);        // C++17: qismlarga ajratish
    cout << "17 = 5 * " << butun << " + " << qoldiq << endl;
    return 0;
}
```

```output
17 = 5 * 3 + 2
```

**2. `struct` — ko'p qiymatlar uchun:**

```cpp
#include <iostream>
using namespace std;

struct Statistika {
    int engKichik;
    int engKatta;
    double ortacha;
};

Statistika hisobla(int a[], int n) {
    Statistika s{a[0], a[0], 0};
    int jami = 0;
    for (int i = 0; i < n; i++) {
        if (a[i] < s.engKichik) s.engKichik = a[i];
        if (a[i] > s.engKatta) s.engKatta = a[i];
        jami += a[i];
    }
    s.ortacha = (double)jami / n;
    return s;
}

int main() {
    int harorat[] = {12, -3, 25, 8, 17};
    Statistika s = hisobla(harorat, 5);
    cout << "Min: " << s.engKichik << ", Max: " << s.engKatta
         << ", O'rtacha: " << s.ortacha << endl;
    return 0;
}
```

```output
Min: -3, Max: 25, O'rtacha: 11.8
```

### Chuqurroq o'rganamiz: qayta yuklashda kompilyator qanday tanlaydi?

Bir nechta mos variant bo'lganda, kompilyator eng "yaqin"ini tanlaydi:

```cpp
#include <iostream>
using namespace std;

void chop(int x)    { cout << "int: " << x << endl; }
void chop(double x) { cout << "double: " << x << endl; }
void chop(char x)   { cout << "char: " << x << endl; }

int main() {
    chop(5);          // aniq mos: int
    chop(5.5);        // aniq mos: double
    chop('A');        // aniq mos: char
    chop(5.5f);       // float — double ga eng yaqin
    chop(true);       // bool — int ga ko'tariladi
    return 0;
}
```

```output
int: 5
double: 5.5
char: A
double: 5.5
int: 1
```

| Argument | Tanlangan variant | Sabab |
|---|---|---|
| `5` | `int` | Aniq mos |
| `5.5f` (`float`) | `double` | `float` → `double` — "ko'tarish" (eng yaqin) |
| `true` (`bool`) | `int` | `bool` → `int` — "ko'tarish" |

### Chuqurroq o'rganamiz: `constexpr` funksiyalar

`constexpr` funksiya — kompilyatsiya paytida hisoblanishi mumkin bo'lgan funksiya. Agar argumentlar o'zgarmas bo'lsa, natija dastur ishga tushishidan oldin tayyor bo'ladi:

```cpp
#include <iostream>
using namespace std;

constexpr long long faktorial(int n) {
    return n <= 1 ? 1 : n * faktorial(n - 1);
}

int main() {
    constexpr long long f10 = faktorial(10);   // kompilyatsiyada hisoblandi!
    int massiv[faktorial(4)];                  // massiv o'lchami: 24
    cout << "10! = " << f10 << endl;
    cout << "Massiv o'lchami: " << sizeof(massiv) / sizeof(int) << endl;
    return 0;
}
```

```output
10! = 3628800
Massiv o'lchami: 24
```

### Chuqurroq o'rganamiz: `[[nodiscard]]` va boshqa atributlar

C++17 da funksiyalarga maxsus "belgilar" — **atributlar** qo'shish mumkin. Masalan, `[[nodiscard]]` funksiya natijasini e'tiborsiz qoldirish xato ekanini bildiradi:

```cpp
#include <iostream>
using namespace std;

[[nodiscard]] int kvadrat(int x) { return x * x; }

int main() {
    kvadrat(5);               // kompilyator ogohlantiradi: natija ishlatilmadi!
    int y = kvadrat(5);       // to'g'ri
    cout << y << endl;
    return 0;
}
```

```output
25
```

| Atribut | Ma'nosi |
|---|---|
| `[[nodiscard]]` | Natijani albatta ishlatish kerak |
| `[[deprecated]]` | Bu funksiya eskirgan, ishlatmaslik tavsiya etiladi |
| `[[maybe_unused]]` | Bu o'zgaruvchi ishlatilmasa ham ogohlantirma |
| `[[noreturn]]` | Funksiya hech qachon qaytmaydi (masalan, dasturni to'xtatadi) |

### Qadamma-qadam tahlil: "Geometriya kalkulyatori"

Funksiyalarning barcha imkoniyatlarini birlashtiramiz: qayta yuklash, standart argumentlar, `const` havolalar va `struct` qaytarish:

```cpp
#include <iostream>
#include <string>
#include <cmath>
using namespace std;

struct Natija {
    string shakl;
    double yuza;
    double perimetr;
};

Natija hisobla(double a) {                           // kvadrat
    return {"Kvadrat", a * a, 4 * a};
}

Natija hisobla(double a, double b) {                 // to'rtburchak
    return {"To'rtburchak", a * b, 2 * (a + b)};
}

Natija hisobla(double a, double b, double c) {       // uchburchak (Geron formulasi)
    double p = (a + b + c) / 2;
    return {"Uchburchak", sqrt(p * (p - a) * (p - b) * (p - c)), a + b + c};
}

void chiqar(const Natija& n, int xona = 2) {
    cout.precision(xona + 2);
    cout << n.shakl << ": yuza = " << n.yuza << ", perimetr = " << n.perimetr << endl;
}

int main() {
    chiqar(hisobla(5));
    chiqar(hisobla(4, 6));
    chiqar(hisobla(3, 4, 5));
    return 0;
}
```

```output
Kvadrat: yuza = 25, perimetr = 20
To'rtburchak: yuza = 24, perimetr = 20
Uchburchak: yuza = 6, perimetr = 12
```

| Imkoniyat | Qayerda |
|---|---|
| Qayta yuklash | Uchta `hisobla` funksiyasi — parametrlar soni har xil |
| `struct` qaytarish | Har bir `hisobla` uchta qiymatni birga qaytaradi |
| `const` havola | `chiqar(const Natija& n, ...)` — nusxalashsiz, xavfsiz |
| Standart argument | `int xona = 2` — berilmasa 2 ishlatiladi |
