### Chuqurroq o'rganamiz: kompilyatorning roli

Kompilyator — C++ dasturchisining eng muhim "yordamchisi". Uning vazifalari faqat tarjima qilish bilan cheklanmaydi:

| Vazifa | Tushuntirish |
|---|---|
| **Sintaksisni tekshirish** | Kod C++ qoidalariga mos yozilganmi? `;`, qavslar, kalit so'zlar to'g'rimi? |
| **Turlarni tekshirish** | `int` ga satr yozilmayaptimi? Funksiyaga to'g'ri turdagi argument berilganmi? |
| **Ogohlantirishlar berish** | Kod to'g'ri, lekin shubhali joylar bormi? (masalan, ishlatilmagan o'zgaruvchi) |
| **Optimallashtirish** | Kodni tezroq ishlashi uchun qayta tuzish (masalan, keraksiz hisob-kitoblarni olib tashlash) |
| **Mashina kodini yaratish** | Protsessor tushunadigan buyruqlarni hosil qilish |

Kompilyatorni sinchkov, lekin mehribon o'qituvchiga o'xshatish mumkin: u xatolaringni ko'rsatadi, maslahat beradi va ishingni yaxshilaydi.

### Chuqurroq o'rganamiz: IDE oynasi qanday tuzilgan?

Deyarli barcha IDE larda quyidagi asosiy qismlar bor:

| Qism | Joylashuvi | Vazifasi |
|---|---|---|
| **Kod muharriri** | Markazda | Kodni yozish joyi; so'zlarni rangli ko'rsatadi, xatolarni ostiga chizadi |
| **Loyiha daraxti** | Chapda | Loyihadagi barcha fayllar ro'yxati |
| **Asboblar paneli** | Tepada | "Build" (kompilyatsiya), "Run" (ishga tushirish), "Debug" (xato topish) tugmalari |
| **Xabarlar oynasi** | Pastda | Kompilyator xatolari va ogohlantirishlari |
| **Konsol (terminal)** | Alohida oynada yoki pastda | Dastur natijasi va klaviaturadan kiritish |

**Rangli ko'rsatish** (syntax highlighting) — IDE ning eng foydali imkoniyatlaridan biri. Kalit so'zlar (`int`, `return`) bir rangda, satrlar (`"Salom"`) boshqa rangda, izohlar (`// ...`) uchinchi rangda ko'rsatiladi. Bu kodni o'qishni osonlashtiradi va xatolarni darhol ko'rsatadi: masalan, qo'shtirnoqni yopishni unutsang, butun qolgan kod satr rangiga bo'yalib qoladi!

### Qadamma-qadam tahlil: kompilyatsiyani terminalda bajarish

IDE "Build and Run" tugmasini bosganingda ichkarida aslida terminal buyruqlari bajariladi. Ularni qo'lda bajarib ko'rish foydali — shunda nima bo'layotganini aniq tushunasan.

**1-qadam.** `salom.cpp` faylini yarat va unga kod yoz.

**2-qadam.** Terminalni (Windows da "Command Prompt" yoki "PowerShell") och va fayl joylashgan papkaga o't.

**3-qadam.** Kompilyatsiya qil:

```terminal
g++ salom.cpp -o salom
```

| Qism | Ma'nosi |
|---|---|
| `g++` | C++ kompilyatori nomi |
| `salom.cpp` | Kompilyatsiya qilinadigan fayl |
| `-o salom` | Natijaviy dastur nomi ("output") |

**4-qadam.** Dasturni ishga tushir:

```terminal
./salom
```

(Windows da shunchaki `salom` yoki `salom.exe` yoziladi.)

**Foydali qo'shimcha bayroqlar:**

| Bayroq | Vazifasi |
|---|---|
| `-Wall` | Barcha muhim ogohlantirishlarni yoqadi |
| `-Wextra` | Qo'shimcha ogohlantirishlar |
| `-std=c++17` | C++17 standartidan foydalanish |
| `-O2` | Kodni tezlik uchun optimallashtirish |
| `-g` | Xato topish (debug) uchun ma'lumot qo'shish |

```terminal
g++ -Wall -std=c++17 salom.cpp -o salom
```

!maslahat Har doim `-Wall` bayrog'i bilan kompilyatsiya qil. Kompilyator ogohlantirishlari ko'pincha kelajakdagi xatolarning birinchi belgisi bo'ladi!

### Chuqurroq o'rganamiz: xato topuvchi — debugger

**Debugger** (xato topuvchi) — dasturni **qadamma-qadam** bajarib, har bir qadamda o'zgaruvchilar qiymatini ko'rish imkonini beradigan vosita. U xuddi videoni sekin, kadrma-kadr ko'rishga o'xshaydi.

Debuggerning asosiy imkoniyatlari:

| Imkoniyat | Ma'nosi |
|---|---|
| **To'xtash nuqtasi** (breakpoint) | Dastur shu qatorga yetganda to'xtaydi (IDE da qator raqami yoniga bosiladi — qizil nuqta paydo bo'ladi) |
| **Keyingi qadam** (step over) | Bitta qatorni bajarib, keyingisida to'xtash |
| **Ichiga kirish** (step into) | Funksiya chaqirilsa, uning ichiga kirib, qadamma-qadam ko'rish |
| **O'zgaruvchilarni kuzatish** (watch) | Har bir qadamda o'zgaruvchilar qiymatini ko'rish |
| **Davom etish** (continue) | Keyingi to'xtash nuqtasigacha bajarish |

Debugger aslida 0-modulda o'rgangan **kuzatish jadvali**ning avtomatik versiyasi! Qog'ozda qo'lda qilgan ishingni kompyuter o'zi bajaradi.

### Chuqurroq o'rganamiz: onlayn kompilyatorlar bilan ishlash

Onlayn kompilyatorlar ayniqsa quyidagi hollarda qulay:

- kompyuterga dastur o'rnatish imkoni bo'lmasa (masalan, maktab kompyuterida);
- planshet yoki telefondan kod yozmoqchi bo'lsang;
- kichik kod parchasini tez sinab ko'rish kerak bo'lsa;
- kodni do'stingga havola orqali ulashmoqchi bo'lsang.

Ko'pchilik onlayn kompilyatorlarda quyidagi qismlar bor:

| Qism | Vazifasi |
|---|---|
| Kod maydoni | Kodni yozish joyi |
| "Run" tugmasi | Kompilyatsiya qilish va ishga tushirish |
| "Input" (stdin) maydoni | `cin` uchun kiritiladigan ma'lumotlar oldindan shu yerga yoziladi |
| "Output" maydoni | Dastur natijasi |
| Til va standart tanlash | C++ versiyasini (C++17, C++20) tanlash |

!eslatma Onlayn kompilyatorlarda `cin` bilan ishlashda ma'lumotlarni dastur ishga tushishidan **oldin** "Input" maydoniga yozib qo'yish kerak, chunki ko'pchiligida klaviaturadan "jonli" kiritish imkoni yo'q.

### Chuqurroq o'rganamiz: dastur qanday tugaydi? (`return 0`)

`main` funksiyasi oxiridagi `return 0;` operatsion tizimga "dastur muvaffaqiyatli tugadi" degan xabarni beradi. Agar dastur xato bilan tugasa, odatda noldan farqli son qaytariladi:

```cpp
#include <iostream>
using namespace std;

int main() {
    int son;
    cout << "Musbat son kirit: ";
    cin >> son;
    if (son <= 0) {
        cout << "Xato: son musbat emas!" << endl;
        return 1;                  // 1 — xato kodi
    }
    cout << "Rahmat! Sening soning: " << son << endl;
    return 0;                      // 0 — hammasi joyida
}
```

```output
Musbat son kirit: -3
Xato: son musbat emas!
```

Bu kodlarni boshqa dasturlar yoki skriptlar tekshirishi mumkin: "oldingi dastur muvaffaqiyatli tugadimi?". Qiziq fakt: agar `main` da `return` yozilmasa, C++ avtomatik ravishda `return 0;` deb hisoblaydi (faqat `main` uchun!).

### Qo'shimcha mashqlar

!mashq Birinchi dasturingni ataylab uch xil usulda "buz": (1) `;` ni o'chir; (2) `cout` ni `Cout` deb yoz; (3) yopuvchi `}` ni o'chir. Har safar kompilyator qanday xabar berganini daftaringga yozib qo'y. Bu xabarlarni keyinchalik tanib olish oson bo'ladi!

!mashq Agar Code::Blocks yoki boshqa IDE o'rnatgan bo'lsang, debugger yordamida quyidagi dasturni qadamma-qadam bajar va har qadamda `x` ning qiymatini kuzat: `int x = 1; x = x * 2; x = x + 5; x = x * x;` (Javob: 49.)
