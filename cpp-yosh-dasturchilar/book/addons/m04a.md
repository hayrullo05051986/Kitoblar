### Ichkarida nima bo'ladi? Xotira — bu kataklar qatori

Kompyuter xotirasini (operativ xotira, RAM) milliardlab kichik kataklardan iborat juda uzun qatorga o'xshatish mumkin. Har bir katak — **1 bayt**, ya'ni 8 bit (8 ta 0 yoki 1). Har bir katakning o'z raqami — **manzili** bor.

Sen `int yosh = 12;` deb yozganingda kompyuter quyidagilarni qiladi:

1. Xotiradan bo'sh joy qidiradi.
2. `int` 4 bayt bo'lgani uchun ketma-ket **4 ta katak** ajratadi.
3. Bu joyga `yosh` nomini "yopishtiradi".
4. 12 sonini ikkilik ko'rinishga (`00000000 00000000 00000000 00001100`) aylantirib, shu kataklarga yozadi.

Ma'lumot turi kompyuterga ikkita narsani aytadi: **nechta katak ajratish** va **kataklardagi 0 va 1 larni qanday tushunish** (butun son sifatidami, kasr sonmi yoki harf sifatidami).

### Qaysi ma'lumot uchun qaysi tur? Amaliy jadval

| Nima saqlamoqchisan | Tur | Misol |
|---|---|---|
| Yosh, sinf, ball, odamlar soni | `int` | `int sinf = 6;` |
| Bo'y, vazn, narx, harorat | `double` | `double vazn = 38.5;` |
| Baho harfi, javob varianti (A/B/C) | `char` | `char javob = 'B';` |
| Ha/yo'q savollar | `bool` | `bool tayyormi = true;` |
| Ism, so'z, gap (bir nechta harf) | `string` | `string ism = "Malika";` |

!eslatma `string` — asosiy tur emas, u `<string>` kutubxonasidan keladi. Lekin u shunchalik ko'p ishlatiladiki, uni hozirdan bilib qo'ygan ma'qul. Satrlar haqida 8-modulda batafsil gaplashamiz.

### Ichkarida nima bo'ladi? Nega `int` ning chegarasi aynan 2.1 milliard?

`int` 4 bayt, ya'ni 32 bit. 32 ta bit yordamida 2³² = 4 294 967 296 xil kombinatsiya yasash mumkin.

- **`unsigned int`** da barcha kombinatsiyalar musbat sonlarga beriladi: 0 dan 4 294 967 295 gacha.
- **`signed int`** da esa yarmi manfiy, yarmi musbat sonlarga bo'linadi: −2 147 483 648 dan 2 147 483 647 gacha. Eng chapdagi bit "ishora biti" vazifasini bajaradi: 0 — musbat, 1 — manfiy.

Kichikroq misol — 3 bitli son bilan ko'raylik. 3 bit bilan 2³ = 8 xil son yasash mumkin:

| Bitlar | unsigned (ishorasiz) | signed (ishorali) |
|---|---|---|
| `000` | 0 | 0 |
| `001` | 1 | 1 |
| `010` | 2 | 2 |
| `011` | 3 | 3 |
| `100` | 4 | −4 |
| `101` | 5 | −3 |
| `110` | 6 | −2 |
| `111` | 7 | −1 |

Ko'rib turganingdek, bitlar soni bir xil, lekin ularni "tushunish" usuli boshqacha!

### Chegaralarni dasturda bilish

C++ da har bir turning eng kichik va eng katta qiymatini `<climits>` kutubxonasi yordamida bilish mumkin:

```cpp
#include <iostream>
#include <climits>
using namespace std;

int main() {
    cout << "int eng kattasi:   " << INT_MAX << endl;
    cout << "int eng kichigi:   " << INT_MIN << endl;
    cout << "short eng kattasi: " << SHRT_MAX << endl;
    return 0;
}
```

```output
int eng kattasi:   2147483647
int eng kichigi:   -2147483648
short eng kattasi: 32767
```

### O'zingni tekshir

2. Yer yuzidagi odamlar sonini saqlash uchun qaysi tur kerak?

@@answers

### Ichkarida nima bo'ladi? `const` nima uchun foydali?

`const` kompyuterning o'zi uchun emas, ko'proq **dasturchi uchun himoya**. Kompilyator `const` o'zgaruvchiga yozishga uringan har qanday kodni darhol xato deb belgilaydi. Shunday qilib, dasturdagi muhim qiymatlar tasodifan buzilib qolmaydi.

Bundan tashqari, kompilyator `const` qiymatlarni ko'pincha to'g'ridan-to'g'ri kodga "joylashtirib" qo'yadi. Masalan, `const int HAFTA = 7;` bo'lsa, `kunlar = haftalar * HAFTA;` qatori aslida `kunlar = haftalar * 7;` kabi kompilyatsiya qilinadi. Bu dasturni biroz tezlashtiradi.

### `const` va `#define` farqi

| | `const` | `#define` |
|---|---|---|
| Kim bajaradi | Kompilyator | Preprotsessor |
| Turi bormi | Ha (`int`, `double`...) | Yo'q, oddiy matn almashtirish |
| Xatolarni tekshirish | Kompilyator turni tekshiradi | Tekshiruv yo'q |
| Ko'lam (scope) | Blokka bo'ysunadi | Butun fayl bo'ylab ishlaydi |
| Tavsiya | Zamonaviy C++ da shu | Eski C uslubi |

### Ko'p uchraydigan xatolar

| Xato | Natija | To'g'risi |
|---|---|---|
| `const int X;` | Xato: qiymat berilmagan | `const int X = 10;` |
| `#define PI = 3.14` | `PI` o'rniga `= 3.14` qo'yiladi — xato | `#define PI 3.14` |
| `#define MAX 100;` | `;` ham almashtiriladi va kutilmagan xatolar | `#define MAX 100` |
| `"\"` | Qo'shtirnoq yopilmay qoladi | `"\\"` yoki `"\""` |

### Ichkarida nima bo'ladi? `=` belgisi matematikadagidek emas!

Matematikada `x = x + 1` tenglama noto'g'ri (hech qanday son o'zidan 1 ga katta bo'lmaydi). Lekin dasturlashda bu juda odatiy qator! Chunki C++ da `=` — "teng" emas, balki **"qiymat ber"** degani. Kompyuter uni **o'ngdan chapga** bajaradi:

1. Avval o'ng tomon hisoblanadi: `x + 1` (masalan, 5 + 1 = 6).
2. Keyin natija chap tomondagi qutiga yoziladi: `x` endi 6.

Eski qiymat (5) butunlay o'chib ketadi — qutida bir vaqtning o'zida faqat bitta qiymat bo'ladi.

```cpp
#include <iostream>
using namespace std;

int main() {
    int x = 5;
    cout << "Boshida: " << x << endl;
    x = x + 1;      // 5 + 1 = 6
    cout << "1-qadam: " << x << endl;
    x = x * 3;      // 6 * 3 = 18
    cout << "2-qadam: " << x << endl;
    x = 100;        // eski qiymat o'chib ketdi
    cout << "3-qadam: " << x << endl;
    return 0;
}
```

```output
Boshida: 5
1-qadam: 6
2-qadam: 18
3-qadam: 100
```

### Qadamma-qadam kuzatish jadvali

Dasturchilar kodni tushunish uchun ko'pincha "kuzatish jadvali" chizishadi: har bir qatordan keyin o'zgaruvchilarda nima borligini yozib boradilar. Yuqoridagi `tangalar` dasturi uchun:

| Qator | Ko'rsatma | `tangalar` qiymati |
|---|---|---|
| 1 | `int tangalar = 10;` | 10 |
| 2 | `tangalar = tangalar + 5;` | 15 |
| 3 | `tangalar = tangalar - 3;` | 12 |

!maslahat Murakkab kodni tushunmasang, qog'ozga shunday jadval chiz. Bu professional dasturchilar ham ishlatadigan usul!

### Ko'p uchraydigan xatolar

| Xato | Natija | To'g'risi |
|---|---|---|
| E'lon qilmasdan ishlatish: `yosh = 12;` | `'yosh' was not declared` | Avval `int yosh;` |
| Ikki marta e'lon qilish | `redeclaration of 'int yosh'` | Bir marta e'lon qil, keyin faqat qiymat ber |
| Qiymatsiz o'zgaruvchini o'qish | Tasodifiy "axlat" son | Doim boshlang'ich qiymat ber |
| `cin << yosh;` | Xato | `cin >> yosh;` (o'qish — `>>`) |
| `cout >> yosh;` | Xato | `cout << yosh;` (chiqarish — `<<`) |

!eslatma `cin >>` va `cout <<` dagi o'qlarni eslab qolish oson: o'q ma'lumot qaysi tomonga "oqishini" ko'rsatadi. `cin >> x` — klaviaturadan `x` ga; `cout << x` — `x` dan ekranga.

@@topic C++ da `auto` kalit so'zi

### Ichkarida nima bo'ladi? Tur qachon aniqlanadi?

Muhim tushuncha: `auto` turni **kompilyatsiya paytida** aniqlaydi, dastur ishlayotganda emas. Kompilyator `auto x = 7;` ni ko'rganda, `7` ning `int` ekanini biladi va xuddi sen `int x = 7;` deb yozgandek kompilyatsiya qiladi. Tayyor dasturda `auto` degan narsa umuman qolmaydi.

Shuning uchun `auto`:

- dasturni sekinlashtirmaydi;
- C++ ni Python kabi "dinamik turli" tilga aylantirmaydi — tur baribir bir marta aniqlanib, o'zgarmaydi.

### Literallar turini bilib ol

`auto` to'g'ri ishlashi uchun qiymat qanday turda ekanini bilish foydali:

| Literal | Turi |
|---|---|
| `5` | `int` |
| `5.0` | `double` |
| `5.0f` | `float` |
| `5LL` | `long long` |
| `5u` | `unsigned int` |
| `'5'` | `char` |
| `"5"` | `const char*` (satr literali) |
| `true` | `bool` |

!diqqat `auto ism = "Malika";` deb yozsang, `ism` turi `string` emas, `const char*` bo'ladi! `string` kerak bo'lsa, aniq yoz: `string ism = "Malika";`.

### Ko'p uchraydigan xatolar

| Xato | Muammo | To'g'risi |
|---|---|---|
| `auto x;` | Qiymat yo'q — tur noma'lum | `auto x = 0;` |
| `auto narx = 10;` keyin `narx = 9.99;` | `narx` — `int`, 9 saqlanadi | `auto narx = 10.0;` |
| Hamma joyda `auto` | Kodni o'qish qiyinlashadi | Faqat tur aniq yoki juda uzun bo'lganda |
