@@topic C++ dagi konteyner turlari va ketma-ketliklar
@@answers
1. Konteynerlar, iteratorlar va algoritmlar.
2. Ketma-ket konteynerlar, assotsiativ konteynerlar va konteyner adapterlari.
3. Oxirgi elementdan keyingi joyni (chegara belgisini).
4. `vector`.
@@topic C++ da vector
@@answers
1. O'lchami avtomatik o'zgaradi, xotirani o'zi boshqaradi va chegarani tekshirish (`at`) imkoniyati bor.
2. `push_back` oxiriga element qo'shadi, `pop_back` oxirgi elementni o'chiradi.
3. `v[i]` chegarani tekshirmaydi; `v.at(i)` tekshiradi va chegaradan chiqilsa istisno otadi.
4. `size` — mavjud elementlar soni, `capacity` — ajratilgan joy hajmi.
@@topic C++ da list
@@answers
1. Ikki tomonlama bog'langan ro'yxat: har bir tugun qiymat va oldingi hamda keyingi tugunning manzilini saqlaydi.
2. Yo'q.
3. Ro'yxatning boshiga yoki o'rtasiga tez-tez element qo'shish yoki o'chirish kerak bo'lganda.
4. Uning o'z `sort()` metodi bilan: `l.sort();`.
@@topic C++ da deque
@@answers
1. "Double-ended queue" — ikki uchli navbat.
2. Boshiga ham tez element qo'shish va olish mumkin.
3. Ha, `[]` operatori bor.
@@topic C++ da pair
@@answers
1. Ikki qiymatni bitta obyektda saqlaydigan shablon struktura.
2. `first` va `second`.
3. Avval `first` bo'yicha, ular teng bo'lsa `second` bo'yicha.
4. `tuple`.
@@topic C++ da set
@@answers
1. Elementlar takrorlanmaydi va avtomatik saralanadi.
2. Hech narsa o'zgarmaydi — element ikkinchi marta qo'shilmaydi.
3. `s.count(x)` yoki `s.find(x) != s.end()` bilan.
4. Muvozanatlangan ikkilik qidiruv daraxtidan.
@@topic C++ da multiset
@@answers
1. `multiset` takrorlanuvchi elementlarga ruxsat beradi, `set` esa yo'q.
2. Ha.
3. `erase(5)` barcha 5 larni o'chiradi; `erase(find(5))` faqat bittasini.
@@topic C++ da map
@@answers
1. Kalit → qiymat juftliklarini.
2. Yo'q.
3. `m[k]` kalit yo'q bo'lsa uni yaratib yuboradi; `m.at(k)` esa istisno otadi.
4. `m.count(k)` yoki `m.find(k) != m.end()` bilan.
@@topic C++ da multimap
@@answers
1. `multimap` da bitta kalit bir necha marta takrorlanishi mumkin.
2. Yo'q, chunki bitta kalitga bir nechta qiymat mos kelgani uchun qaysi birini qaytarish noaniq bo'lardi.
3. `equal_range(k)` yordamida.
@@topic C++ da stack
@@answers
1. "Last In, First Out" — oxirgi kelgan birinchi ketadi.
2. `top()` eng ustki elementni qaytaradi (o'chirmaydi), `pop()` uni o'chiradi (qiymat qaytarmaydi).
3. Masalan: likopchalar taxlami, Ctrl+Z (bekor qilish), brauzerdagi "Orqaga" tugmasi, funksiya chaqiruvlari.
@@topic C++ da queue
@@answers
1. "First In, First Out" — birinchi kelgan birinchi ketadi.
2. Stekda oxirgi qo'shilgan element birinchi olinadi, navbatda esa birinchi qo'shilgani.
3. `front()` — navbat boshidagi, `back()` — navbat oxiridagi elementni.
@@topic C++ da priority_queue
@@answers
1. Elementlar qo'shilgan tartibda emas, ustuvorligi (kattaligi) bo'yicha chiqadi.
2. Eng katta element.
3. Uchinchi parametr sifatida `greater<T>` berish: `priority_queue<int, vector<int>, greater<int>>`.
4. Uyum (binary heap) daraxtidan.
