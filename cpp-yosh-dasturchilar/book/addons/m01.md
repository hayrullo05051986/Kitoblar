### Avval eng muhim savol: dasturlash tili nima?

Kompyuter — juda tez, lekin o'zicha hech narsa qila olmaydigan mashina. U faqat aniq buyruqlarni bajaradi. Buyruqlar ketma-ketligi **dastur**, dastur yozish jarayoni esa **dasturlash** deyiladi.

Muammo shundaki, kompyuter odamlar tilini (o'zbek, ingliz, rus) tushunmaydi. Uning "ona tili" — faqat 0 va 1 lardan iborat **mashina tili**. Unda yozish juda qiyin: bitta oddiy amal uchun ham uzun-uzun raqamlar qatorini yozish kerak bo'ladi.

Shuning uchun olimlar **dasturlash tillari**ni o'ylab topishgan. Ular odam tiliga yaqinroq, tushunarli so'zlardan iborat: `if` (agar), `while` (... ekan), `return` (qaytar). Dasturchi shu tilda yozadi, maxsus dastur esa uni mashina tiliga tarjima qiladi.

| Daraja | Misol | Odam uchun |
|---|---|---|
| Mashina tili | `10110000 01100001` | Juda qiyin |
| Assembler | `MOV AL, 61h` | Qiyin |
| Yuqori darajali til (C++, Python, Java) | `x = 97;` | Tushunarli |

!fakt Dunyoda 700 dan ortiq dasturlash tillari bor! Lekin ulardan 20–30 tasi keng tarqalgan. C++ eng mashhur o'ntalik ichida o'nlab yillardan beri turibdi.
@@end
### Ichkarida nima bo'ladi? Nega C++ shunchalik tez?

C++ ning eng katta afzalligi — tezligi. Buning sababi: C++ da yozilgan kod oldindan to'liq mashina tiliga **kompilyatsiya** qilinadi. Dastur ishga tushganda kompyuter tayyor mashina buyruqlarini to'g'ridan-to'g'ri bajaradi.

Ba'zi tillarda (masalan, Python da) esa kod dastur ishlayotgan paytda qatorma-qator tarjima qilinadi. Buni sinxron tarjimonga o'xshatish mumkin: u har bir gapni eshitib, darhol tarjima qiladi. C++ esa butun kitobni oldindan tarjima qilib qo'ygan tarjimonga o'xshaydi — o'qish ancha tezroq!

| | Kompilyatsiya qilinadigan til (C++) | Interpretatsiya qilinadigan til (Python) |
|---|---|---|
| Tarjima qachon | Dastur ishga tushishidan oldin, bir marta | Har safar ishlaganda, qatorma-qator |
| Tezlik | Juda tez | Sekinroq |
| Xatolarni topish | Ko'p xatolar kompilyatsiya paytida topiladi | Xato o'sha qatorga yetganda chiqadi |
| Natija | Tayyor `.exe` fayl | Fayl alohida dastur (interpretator) orqali ishlaydi |

### Boshqa tillarda: C++ ning "qarindoshlari"

C++ ko'plab boshqa tillarga ta'sir qilgan. Shuning uchun C++ ni o'rgansang, ularni ham oson o'rganasan. Ekranga "Salom!" yozuvchi dastur turli tillarda qanday ko'rinishini solishtir:

**C++:**

```cpp
#include <iostream>
int main() {
    std::cout << "Salom!";
}
```

**Java** (C++ dan ilhomlangan):

```java
public class Main {
    public static void main(String[] args) {
        System.out.println("Salom!");
    }
}
```

**C#** (Microsoft tili, C++ ga juda o'xshash):

```csharp
Console.WriteLine("Salom!");
```

**Python** (eng oddiy ko'rinishli tillardan biri):

```python
print("Salom!")
```

| Til | Yaratilgan yili | C++ bilan aloqasi |
|---|---|---|
| Java | 1995 | Sintaksisi C++ dan olingan, lekin soddalashtirilgan |
| C# | 2000 | C++ va Java g'oyalari asosida |
| JavaScript | 1995 | Sintaksisi (`{ }`, `;`, `if`, `for`) C oilasidan |
| Rust | 2015 | C++ ning zamonaviy, xavfsizroq "raqobatchisi" |

!maslahat Figurali qavslar `{ }`, nuqtali vergul `;`, `if`, `for`, `while` — bular C oilasidagi deyarli barcha tillarda bir xil. Ularni C++ da bir marta o'rganib olsang, Java, C#, JavaScript kodlarini ham o'qiy boshlaysan!

### Ichkarida nima bo'ladi? Protsedurali va obyektga yo'naltirilgan uslubni hayotiy misolda ko'raylik

Tasavvur qil, biz o'yin yozyapmiz va unda bitta mushuk bor.

**Protsedurali uslubda (C)** biz mushuk haqidagi ma'lumotni va u bilan nima qilish mumkinligini alohida-alohida saqlaymiz. Ma'lumotlar bir joyda, ular bilan ishlaydigan funksiyalar boshqa joyda:

```cpp
// Ma'lumotlar
char mushukIsmi[] = "Mosh";
int mushukOchligi = 5;

// Funksiyalar alohida
void ovqatlantir(int* ochlik) { *ochlik = 0; }
```

**Obyektga yo'naltirilgan uslubda (C++)** esa mushukning barcha ma'lumotlari va u qila oladigan ishlar **bitta "quti" — klass** ichida jamlanadi. Xuddi haqiqiy mushuk kabi: ismi ham, ochligi ham, "miyovlash" qobiliyati ham o'zida:

```cpp
#include <iostream>
#include <string>
using namespace std;

class Mushuk {
public:
    string ism;
    int ochlik;
    void miyovla() { cout << ism << ": Miyov!" << endl; }
    void ovqatlan() { ochlik = 0; cout << ism << " to'ydi." << endl; }
};

int main() {
    Mushuk m;
    m.ism = "Mosh";
    m.ochlik = 5;
    m.miyovla();
    m.ovqatlan();
    return 0;
}
```

```output
Mosh: Miyov!
Mosh to'ydi.
```

Agar o'yinda 100 ta mushuk bo'lsa, C++ da shunchaki 100 ta `Mushuk` obyekti yaratamiz. Har biri o'z ismi va ochligiga ega bo'ladi. Klasslar haqida 10-modulda batafsil gaplashamiz.

### Ko'p uchraydigan xatolar

| Xato | Nima uchun noto'g'ri | To'g'risi |
|---|---|---|
| C++ faylini `.c` kengaytmasi bilan saqlash | Kompilyator uni C kodi deb o'ylab, `cout` ni tanimasligi mumkin | `.cpp` kengaytmasidan foydalan |
| `#include <iostream.h>` yozish | Bu juda eski (1990-yillardagi) usul | `#include <iostream>` |
| C dagi `printf` va C++ dagi `cout` ni aralash ishlatish | Ishlaydi, lekin kod chalkash bo'ladi | Bitta uslubni tanla — C++ da `cout` |

### Boshqa tillarda

Obyektga yo'naltirilgan dasturlash (OOP) faqat C++ da emas. Bugun eng mashhur tillarning aksariyati klasslarni qo'llaydi. Yuqoridagi mushuk boshqa tillarda:

**Python:**

```python
class Mushuk:
    def __init__(self, ism):
        self.ism = ism
    def miyovla(self):
        print(self.ism + ": Miyov!")

m = Mushuk("Mosh")
m.miyovla()
```

**Java:**

```java
class Mushuk {
    String ism;
    void miyovla() { System.out.println(ism + ": Miyov!"); }
}
```

Ko'rib turganingdek, g'oya hamma joyda bir xil: **klass — chizma (shablon), obyekt — shu chizma asosida yasalgan narsa**. Bu tushunchani C++ da o'rgansang, istalgan zamonaviy tilda ishlata olasan.

## 1-modul uchun mini-loyiha: "Men haqimda" vizitka

Endi o'rganganlaringni amalda qo'llab ko'ramiz! Quyidagi dastur ekranga chiroyli "vizitka" chiqaradi. Uni ko'chirib yoz, ishga tushir, keyin o'z ma'lumotlaring bilan o'zgartir.

```cpp
#include <iostream>
using namespace std;

int main() {
    cout << "*********************************" << endl;
    cout << "*        MENING VIZITKAM        *" << endl;
    cout << "*********************************" << endl;
    cout << "*  Ism:     Malika              *" << endl;
    cout << "*  Yosh:    12                  *" << endl;
    cout << "*  Sinf:    6-sinf              *" << endl;
    cout << "*  Orzu:    dasturchi bo'lish   *" << endl;
    cout << "*  Til:     C++                 *" << endl;
    cout << "*********************************" << endl;
    return 0;
}
```

```output
*********************************
*        MENING VIZITKAM        *
*********************************
*  Ism:     Malika              *
*  Yosh:    12                  *
*  Sinf:    6-sinf              *
*  Orzu:    dasturchi bo'lish   *
*  Til:     C++                 *
*********************************
```

!mashq Vizitkaga yana uchta qator qo'sh: sevimli faning, sevimli o'yining va sevimli ranging. Yulduzchalar o'rniga boshqa belgilar (`#`, `=`, `~`) bilan ramka chizib ko'r.
