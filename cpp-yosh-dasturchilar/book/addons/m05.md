- `if`, `else`, `else if` yordamida qaror qabul qilishni;

### Ichkarida nima bo'ladi? Protsessor qanday "tanlaydi"?

Protsessor aslida juda oddiy ishlaydi. `if` ko'rsatmasi mashina tilida taxminan shunday ko'rinishga keladi:

1. Shartni hisobla (masalan, `harorat > 25`).
2. Agar natija **yolg'on** bo'lsa, blokdan keyingi joyga **sakra**.
3. Aks holda keyingi buyruqlarni (blok ichini) bajar.

Ya'ni `if` — bu shartli "sakrash". 5-modulning oxirgi mavzusida ko'radigan sakrash ko'rsatmalari bilan qarindosh!

**Muhim:** C++ da shart sifatida har qanday son ishlatilishi mumkin. **0 — yolg'on**, noldan farqli har qanday son — **rost**:

```cpp
#include <iostream>
using namespace std;

int main() {
    int olmalar = 3;
    if (olmalar) {                 // 3 != 0, demak rost
        cout << "Olma bor!" << endl;
    }
    int nok = 0;
    if (!nok) {                    // 0 — yolg'on, !0 — rost
        cout << "Nok qolmadi." << endl;
    }
    return 0;
}
```

```output
Olma bor!
Nok qolmadi.
```

### Shartlarni birlashtirish: hayotiy misollar

```cpp
#include <iostream>
using namespace std;

int main() {
    int yil = 2024;
    // Kabisa yili: 4 ga bo'linadi VA (100 ga bo'linmaydi YOKI 400 ga bo'linadi)
    if (yil % 4 == 0 && (yil % 100 != 0 || yil % 400 == 0)) {
        cout << yil << " — kabisa yili, fevralda 29 kun" << endl;
    } else {
        cout << yil << " — oddiy yil" << endl;
    }
    return 0;
}
```

```output
2024 — kabisa yili, fevralda 29 kun
```

### Ko'p uchraydigan xatolar

| Xato | Muammo | To'g'risi |
|---|---|---|
| `if (x = 5)` | Har doim rost | `if (x == 5)` |
| `if (x > 0);` | `;` blokni shartdan uzib qo'yadi | `;` qo'yma |
| `else if` larni noto'g'ri tartiblash | `ball >= 56` birinchi tursa, 90 ham "3" oladi | Kattadan kichikka tekshir |
| `switch` da `break` ni unutish | Keyingi `case` lar ham bajariladi | Har `case` oxiriga `break;` |
| `case "dushanba":` | `switch` satr bilan ishlamaydi | `if-else` ishlat |

### Ichkarida nima bo'ladi? `for` tsiklini qadamma-qadam kuzatamiz

`for (int i = 1; i <= 3; i++) { cout << i; }` tsikli qanday bajariladi:

| Qadam | Nima bo'ladi | `i` | Shart | Ekranda |
|---|---|---|---|---|
| 1 | `int i = 1` (faqat bir marta) | 1 | — | |
| 2 | Shart tekshiriladi: `1 <= 3` | 1 | rost | |
| 3 | Tana bajariladi | 1 | | `1` |
| 4 | `i++` | 2 | | |
| 5 | Shart: `2 <= 3` | 2 | rost | |
| 6 | Tana | 2 | | `12` |
| 7 | `i++` | 3 | | |
| 8 | Shart: `3 <= 3` | 3 | rost | |
| 9 | Tana | 3 | | `123` |
| 10 | `i++` | 4 | | |
| 11 | Shart: `4 <= 3` | 4 | **yolg'on** | tsikl tugadi |

Ko'rib turganingdek, shart tana bajarilgandan **ko'ra bir marta ko'proq** tekshiriladi — oxirgi tekshiruv tsiklni to'xtatadi.

### Tsikllar bilan klassik masalalar

**Sonning raqamlari soni:**

```cpp
#include <iostream>
using namespace std;

int main() {
    int n = 2026, raqamlar = 0;
    while (n > 0) {
        n /= 10;          // oxirgi raqamni "kesib" tashlaymiz
        raqamlar++;
    }
    cout << "Raqamlar soni: " << raqamlar << endl;
    return 0;
}
```

```output
Raqamlar soni: 4
```

**Tub sonmi?** (faqat 1 ga va o'ziga bo'linadigan son):

```cpp
#include <iostream>
using namespace std;

int main() {
    int n = 29;
    bool tub = n > 1;
    for (int d = 2; d * d <= n; d++) {
        if (n % d == 0) {
            tub = false;
            break;
        }
    }
    cout << n << (tub ? " — tub son" : " — tub emas") << endl;
    return 0;
}
```

```output
29 — tub son
```

**Bu mavzuda nimani bilib olasan:**

- `break`, `continue`, `return` va `goto` ko'rsatmalarini;

### Ichkarida nima bo'ladi?

Mashina tilida barcha boshqaruv tuzilmalari (`if`, `for`, `while`) aslida **sakrashlar** orqali ishlaydi. Masalan, `break` — bu "tsikldan keyingi birinchi buyruqqa sakra", `continue` esa — "tsiklning shart tekshiriladigan joyiga sakra" degani.

`for` tsiklida `continue` dan keyin ham `i++` qismi bajarilishini unutma:

```cpp
#include <iostream>
using namespace std;

int main() {
    for (int i = 1; i <= 5; i++) {
        if (i == 2 || i == 4) continue;   // i++ baribir bajariladi
        cout << "i = " << i << endl;
    }
    return 0;
}
```

```output
i = 1
i = 3
i = 5
```

!diqqat `while` tsiklida `continue` ishlatayotganda ehtiyot bo'l! Agar hisoblagichni oshirish `continue` dan keyin yozilgan bo'lsa, u bajarilmay qoladi va cheksiz tsikl hosil bo'ladi.

### Ko'p uchraydigan xatolar

| Xato | Muammo | To'g'risi |
|---|---|---|
| `break` ni `if` dan chiqish uchun ishlatish | `break` faqat tsikl va `switch` uchun | `if` dan chiqish shart emas, u o'zi tugaydi |
| Ichki tsikldagi `break` tashqi tsiklni ham to'xtatadi deb o'ylash | Faqat ichkisini to'xtatadi | Bayroq (`bool topildi`) o'zgaruvchisi ishlat |
| `void` funksiyada `return 5;` | Xato | `void` funksiyada shunchaki `return;` |

### Boshqa tillarda

`break`, `continue` va `return` deyarli barcha tillarda aynan shu nomlar bilan bor:

**Python:**

```python
for i in range(1, 11):
    if i % 3 == 0:
        continue
    if i > 8:
        break
    print(i, end=" ")
```

**JavaScript:**

```javascript
for (let i = 1; i <= 10; i++) {
    if (i % 3 === 0) continue;
    if (i > 8) break;
    console.log(i);
}
```

`goto` esa Java, Python va JavaScript da umuman yo'q! Zamonaviy tillar uni ataylab olib tashlagan.

## 5-modul uchun mini-loyiha: "Tosh, qaychi, qog'oz" o'yini

Endi shartlar, tsikllar va sakrash ko'rsatmalarini birlashtirib, haqiqiy o'yin yasaymiz! Kompyuter tasodifiy tanlov qiladi, sen esa unga qarshi o'ynaysan.

```cpp
#include <iostream>
#include <cstdlib>
#include <ctime>
using namespace std;

int main() {
    srand(time(0));
    int men = 0, kompyuter = 0;
    cout << "=== TOSH, QAYCHI, QOG'OZ ===" << endl;
    cout << "1 - tosh, 2 - qaychi, 3 - qog'oz, 0 - chiqish" << endl;

    while (true) {
        int tanlov;
        cout << "\nSening tanloving: ";
        cin >> tanlov;
        if (tanlov == 0) break;
        if (tanlov < 1 || tanlov > 3) {
            cout << "Faqat 1, 2 yoki 3!" << endl;
            continue;
        }
        int komp = rand() % 3 + 1;
        switch (komp) {
            case 1: cout << "Kompyuter: tosh" << endl; break;
            case 2: cout << "Kompyuter: qaychi" << endl; break;
            case 3: cout << "Kompyuter: qog'oz" << endl; break;
        }
        if (tanlov == komp) {
            cout << "Durang!" << endl;
        } else if ((tanlov == 1 && komp == 2) ||
                   (tanlov == 2 && komp == 3) ||
                   (tanlov == 3 && komp == 1)) {
            cout << "Sen yutding!" << endl;
            men++;
        } else {
            cout << "Kompyuter yutdi!" << endl;
            kompyuter++;
        }
        cout << "Hisob — Sen: " << men << ", Kompyuter: " << kompyuter << endl;
    }
    cout << "O'yin tugadi. Rahmat!" << endl;
    return 0;
}
```

```output
=== TOSH, QAYCHI, QOG'OZ ===
1 - tosh, 2 - qaychi, 3 - qog'oz, 0 - chiqish

Sening tanloving: 1
Kompyuter: qaychi
Sen yutding!
Hisob — Sen: 1, Kompyuter: 0

Sening tanloving: 0
O'yin tugadi. Rahmat!
```
