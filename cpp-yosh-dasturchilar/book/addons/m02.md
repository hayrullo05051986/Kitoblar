### Ichkarida nima bo'ladi? Har bir bosqichni yaqindan ko'ramiz

Keling, `salom.cpp` faylimiz bilan aslida nima sodir bo'lishini qadamma-qadam kuzatamiz.

**1. Preprotsessor.** U `#include <iostream>` qatorini ko'rib, `iostream` faylining butun mazmunini (minglab qatorlar!) shu joyga qo'yib qo'yadi. Izohlarni ham olib tashlaydi.

**2. Kompilyator.** U kodni sinchiklab tekshiradi:

- so'zlar to'g'ri yozilganmi (`cout` o'rniga `cuot` emasmi)?
- har bir buyruq `;` bilan tugaganmi?
- qavslar juft-juftmi?

Hammasi joyida bo'lsa, kodni **obyekt fayl**ga (`salom.o` yoki `salom.obj`) aylantiradi. Bu fayl allaqachon mashina tilida, lekin hali to'liq emas.

**3. Linker.** Dasturimizda `cout` ishlatilgan, lekin `cout` ning o'zi qanday ishlashi standart kutubxonada yozilgan. Linker o'sha tayyor qismni topib, bizning obyekt faylimizga "yopishtiradi".

**4. Natija.** Tayyor dastur — `salom.exe`. Endi uni ikki marta bosib, ishga tushirish mumkin. Bu faylni boshqa kompyuterga ko'chirsang, u yerda C++ o'rnatilmagan bo'lsa ham ishlaydi!

### Kompilyator xabarlarini o'qishni o'rgan

Xato qilish — dasturlashning odatiy qismi. Eng muhimi, kompilyator nima deyayotganini tushunish. Masalan, quyidagi kodda nuqtali vergul tushib qolgan:

```cppx
#include <iostream>
using namespace std;

int main() {
    cout << "Salom!" << endl
    return 0;
}
```

Kompilyator taxminan shunday javob beradi:

```terminal
salom.cpp: In function 'int main()':
salom.cpp:5:29: error: expected ';' before 'return'
```

Bu xabarni o'qishni o'rganamiz:

| Qism | Ma'nosi |
|---|---|
| `salom.cpp` | Xato qaysi faylda |
| `5:29` | 5-qator, 29-belgi |
| `error` | Bu xato (dastur yaratilmaydi). `warning` bo'lsa — ogohlantirish |
| `expected ';' before 'return'` | "`return` dan oldin `;` kutilgan edi" |

!maslahat Kompilyator ko'pincha xatoni u **sezgan** joyda ko'rsatadi, bu esa haqiqiy xatodan bitta qator keyin bo'lishi mumkin. Agar ko'rsatilgan qatorda xato ko'rmasang, bir qator yuqoriga qara!

### Ko'p uchraydigan xatolar

| Xato xabari (qisqacha) | Sababi | Yechimi |
|---|---|---|
| `expected ';'` | Nuqtali vergul unutilgan | Qator oxiriga `;` qo'y |
| `'cout' was not declared` | `#include <iostream>` yoki `std::` yo'q | Kutubxonani ula, `using namespace std;` yoz |
| `expected '}'` | Figurali qavs yopilmagan | Har bir `{` ning jufti `}` borligini tekshir |
| `undefined reference to 'main'` | `main` funksiyasi yo'q yoki nomi xato | `int main()` ni to'g'ri yoz |
| `missing terminating " character` | Qo'shtirnoq yopilmagan | Matn oxiriga `"` qo'y |

### Boshqa tillarda

Har bir tilning o'z "ish muhiti" bor, lekin g'oya bir xil: kod yozasan, keyin uni maxsus dastur orqali ishga tushirasan.

| Til | Nima o'rnatiladi | Qanday ishga tushiriladi |
|---|---|---|
| C++ | Kompilyator (g++, clang, MSVC) | `g++ salom.cpp -o salom` → `./salom` |
| Python | Python interpretatori | `python salom.py` |
| Java | JDK (Java Development Kit) | `javac Main.java` → `java Main` |
| JavaScript | Hech narsa (brauzer yetarli) yoki Node.js | `node salom.js` |

Java ham C++ kabi avval kompilyatsiya qilinadi, lekin to'g'ridan-to'g'ri mashina tiliga emas, balki maxsus "oraliq tilga" (bayt-kod). Python va JavaScript esa odatda qatorma-qator bajariladi.

### O'zingni tekshir

1. Kompilyator nima ish qiladi?
2. IDE nima va u qanday qismlardan iborat?
3. `#include` qatorlarini qaysi bosqich bajaradi?
4. Kompilyator `error` va `warning` xabarlarining farqi nimada?
5. `int main()` qatori nimani bildiradi?
@@answers
1. Odam yozgan C++ kodini kompyuter tushunadigan mashina tiliga tarjima qiladi va kodda xato bor-yo'qligini tekshiradi.
2. IDE — integrallashgan ishlab chiqish muhiti. U kod yozish uchun muharrir, kompilyator va xatolarni topish vositalarini bitta dasturda birlashtiradi.
3. Preprotsessor.
4. `error` — xato, u bo'lsa dastur yaratilmaydi; `warning` — ogohlantirish, dastur yaratiladi, lekin kodda shubhali joy bor.
5. Dastur shu yerdan boshlanadi; `main` — har bir C++ dasturida bo'lishi shart bo'lgan asosiy funksiya.

## 2-modul uchun mini-loyiha: Rasm chizuvchi dastur

`cout` yordamida belgilardan rasm chizish mumkin. Bunday rasmlar "ASCII-art" deyiladi. Quyidagi dastur ekranga uycha chizadi:

```cpp
#include <iostream>
using namespace std;

int main() {
    cout << "       /\\       " << endl;
    cout << "      /  \\      " << endl;
    cout << "     /    \\     " << endl;
    cout << "    /______\\    " << endl;
    cout << "    |  __  |    " << endl;
    cout << "    | |  | |    " << endl;
    cout << "    |_|__|_|    " << endl;
    cout << "  Mening uyim!  " << endl;
    return 0;
}
```

```output
       /\
      /  \
     /    \
    /______\
    |  __  |
    | |  | |
    |_|__|_|
  Mening uyim!
```

!eslatma Teskari qiya chiziqni `\` ekranga chiqarish uchun uni ikki marta yozish kerak: `\\`. Chunki C++ da `\` maxsus belgi hisoblanadi (masalan, `\n` — yangi qator).

!mashq O'zing rasm chiz: mushuk, daraxt, robot yoki ismingning bosh harfi. Masalan, mushuk yuzi uchun `/\_/\`, `( o.o )`, ` > ^ < ` qatorlaridan foydalanish mumkin.
