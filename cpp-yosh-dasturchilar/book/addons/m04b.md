### Mini-shifr: Sezar shifri

Qadimgi Rimda Yuliy Sezar maxfiy xatlarni shunday shifrlagan: har bir harfni alifboda 3 ta oldinga surgan (A → D, B → E). Buni C++ da oson qilish mumkin:

```cpp
#include <iostream>
#include <string>
using namespace std;

int main() {
    string xabar = "SALOM";
    string shifr = "";
    for (char c : xabar) {
        char yangi = (c - 'A' + 3) % 26 + 'A';   // 3 ta oldinga, Z dan keyin A
        shifr += yangi;
    }
    cout << "Asl xabar: " << xabar << endl;
    cout << "Shifrlangan: " << shifr << endl;
    return 0;
}
```

```output
Asl xabar: SALOM
Shifrlangan: VDORP
```

### 16 lik sanoq sistemasi

Dasturchilar ko'pincha **16 lik** (o'n oltilik) sistemadan ham foydalanishadi. Unda 16 ta raqam bor: 0–9 va A–F (A = 10, B = 11, ..., F = 15). Bitta 16 lik raqam aynan 4 ta bitga mos keladi, shuning uchun uzun ikkilik sonlarni qisqa yozish uchun qulay.

| O'nlik | Ikkilik | 16 lik |
|---|---|---|
| 5 | 0101 | 5 |
| 10 | 1010 | A |
| 15 | 1111 | F |
| 255 | 1111 1111 | FF |

```cpp
#include <iostream>
using namespace std;

int main() {
    int son = 255;
    cout << "O'nlik: " << dec << son << endl;
    cout << "16 lik: " << hex << son << endl;
    cout << "8 lik:  " << oct << son << endl;
    return 0;
}
```

```output
O'nlik: 255
16 lik: ff
8 lik:  377
```

!fakt Saytlardagi ranglar ham 16 lik sistemada yoziladi! Masalan, `#FF0000` — qizil (qizil = FF = 255, yashil = 0, ko'k = 0), `#00FF00` — yashil, `#FFFFFF` — oq.

### Ichkarida nima bo'ladi? "Kattalashtirish" va "kichraytirish"

Kompilyator turlarni "o'lchami" bo'yicha tartiblaydi:

`bool` → `char` → `short` → `int` → `long long` → `float` → `double`

- **Kattalashtirish** (chapdan o'ngga, masalan `int` → `double`) — xavfsiz. Ma'lumot yo'qolmaydi, xuddi kichik stakandagi suvni katta stakanga quygandek.
- **Kichraytirish** (o'ngdan chapga, masalan `double` → `int`) — xavfli. Ma'lumotning bir qismi yo'qolishi mumkin.

Aralash ifodalarda kompilyator avtomatik ravishda "kichik" turni "kattaroq"iga aylantiradi. Masalan, `int + double` hisoblanayotganda `int` avval `double` ga aylanadi, natija ham `double` bo'ladi.

### Belgi va son o'rtasida aylantirish

```cpp
#include <iostream>
#include <string>
using namespace std;

int main() {
    char raqam = '7';
    int son = raqam - '0';                 // belgidan songa
    cout << son + 1 << endl;               // 8

    string matn = "125";
    int n = stoi(matn);                    // satrdan butun songa
    cout << n * 2 << endl;                 // 250

    double d = stod("3.5");                // satrdan kasr songa
    cout << d + 1 << endl;                 // 4.5

    string s = to_string(2026);            // sondan satrga
    cout << s + " yil" << endl;
    return 0;
}
```

```output
8
250
4.5
2026 yil
```

| Funksiya | Nimadan → nimaga |
|---|---|
| `stoi("42")` | satr → `int` |
| `stod("3.14")` | satr → `double` |
| `to_string(42)` | son → satr |

### Ko'p uchraydigan xatolar

| Xato | Natija | To'g'risi |
|---|---|---|
| `double o = (5 + 4) / 2;` | 4 (butun bo'lish) | `(5 + 4) / 2.0` → 4.5 |
| `double o = (double)(7 / 2);` | 3 (bo'lish allaqachon butun bo'lgan) | `(double)7 / 2` → 3.5 |

| `"5" + 3` | Kutilmagan natija | `stoi("5") + 3` |

### Ichkarida nima bo'ladi? `%` operatorining sehrli imkoniyatlari

Qoldiq operatori `%` boshlovchilarga oddiy ko'rinadi, lekin dasturchilar undan juda ko'p foydalanishadi:

| Vazifa | Kod | Tushuntirish |
|---|---|---|
| Son juftmi? | `n % 2 == 0` | Juft son 2 ga qoldiqsiz bo'linadi |
| Oxirgi raqam | `n % 10` | 2026 % 10 = 6 |
| Oxirgi ikki raqam | `n % 100` | 2026 % 100 = 26 |
| 3 ga bo'linadimi? | `n % 3 == 0` | Qoldiq 0 bo'lsa, bo'linadi |
| Aylanma sanash | `(kun + 1) % 7` | Yakshanbadan keyin yana dushanba |
| Soniyalarni daqiqaga | `s / 60` va `s % 60` | 135 s = 2 daqiqa 15 soniya |

    int qolgan = soniyalar % 60;
    cout << soniyalar << " soniya = " << soat << " soat " << daqiqa
         << " daqiqa " << qolgan << " soniya" << endl;

}

### Mantiqiy operatorlar uchun "rostlik jadvali"

| A | B | A && B (VA) | A \|\| B (YOKI) | !A (EMAS) |
|---|---|---|---|---|
| false | false | false | false | true |
| false | true | false | true | true |
| true | false | false | true | false |
| true | true | true | true | false |

Hayotiy misol: "Bayramga borish uchun **uy vazifasi tayyor bo'lishi VA xona yig'ishtirilgan bo'lishi** kerak" — ikkalasi ham rost bo'lishi shart. "Muzqaymoq yoki shokolad olaman" — bittasi bo'lsa ham yetarli.

### Ko'p uchraydigan xatolar

| Xato | Muammo | To'g'risi |
|---|---|---|
| `if (x = 5)` | Taqqoslash emas, qiymat berish | `if (x == 5)` |
| `if (1 < x < 10)` | Matematikadagidek ishlamaydi! | `if (x > 1 && x < 10)` |
| `x =+ 3;` | `x = +3` deb tushuniladi | `x += 3;` |
| `5 % 2.0` | `%` faqat butun sonlar uchun | `fmod(5, 2.0)` (`<cmath>`) |
| `a & b` ni `&&` o'rniga yozish | Bitli VA — boshqa amal | Mantiqiy VA: `a && b` |

### Ichkarida nima bo'ladi? Kompyuter ifodani qanday hisoblaydi?

Kompilyator ifodani **daraxt** ko'rinishiga keltiradi (yuqoridagi rasmga qara). Daraxtning barglarida sonlar va o'zgaruvchilar, tugunlarida esa operatorlar turadi. Hisoblash pastdan yuqoriga boradi: avval eng pastki amallar bajariladi, keyin ularning natijalari yuqoriga uzatiladi.

`a + b * c - d` ifodasi uchun kompyuter ichkarida taxminan shunday ishlaydi:

1. `b * c` ni hisobla va natijani vaqtinchalik joyga saqla (masalan, `t1`).
2. `a + t1` ni hisobla → `t2`.
3. `t2 - d` ni hisobla → yakuniy natija.

Protsessor bunday kichik amallarni bir soniyada milliardlab marta bajara oladi.

### Ifodani qadamma-qadam hisoblash mashqi

`int x = 3, y = 4;` bo'lsin. Quyidagi ifodani hisoblaymiz: `x * 2 + y % 3 > 5 && y != 0`

| 2 | `y % 3` | 1 |
| 3 | `6 + 1` | 7 |
| 4 | `7 > 5` | true |
| 5 | `y != 0` | true |
| 6 | `true && true` | **true** |
