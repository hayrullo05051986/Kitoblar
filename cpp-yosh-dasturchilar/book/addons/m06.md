### Ichkarida nima bo'ladi? Funksiya chaqirilganda kompyuter nima qiladi?

`qoshish(3, 4)` chaqirilganda kompyuter ichida quyidagilar sodir bo'ladi:

1. Kompyuter hozir qayerda turganini (qaytib kelish manzilini) eslab qoladi.
2. Xotiraning **stek** deb ataladigan qismida funksiya uchun yangi "xona" ochiladi.
3. Bu xonada parametrlar uchun joy ajratiladi va ularga argumentlar nusxalanadi: `a = 3`, `b = 4`.
4. Funksiya tanasi bajariladi.
5. `return` natijani (7) qaytaradi, funksiya xonasi yopiladi va o'chiriladi.
6. Kompyuter eslab qolgan joyiga qaytadi va ishni davom ettiradi.

Shuning uchun funksiya ichida yaratilgan o'zgaruvchilar funksiya tugashi bilan yo'q bo'lib ketadi — ularning "xonasi" yopiladi.

### Funksiyalarni loyihalash: katta masalani bo'laklarga bo'lish

Tasavvur qil, "Sinf o'quvchilarining o'rtacha bahosini hisoblab, eng yaxshi o'quvchini aniqla" degan masala bor. Uni funksiyalarga bo'lamiz:

| Funksiya | Vazifasi |
|---|---|
| `bahoKirit()` | Foydalanuvchidan baholarni o'qiydi |
| `ortacha()` | O'rtacha bahoni hisoblaydi |
| `engYaxshi()` | Eng yuqori bahoni topadi |
| `natijaChiqar()` | Hammasini chiroyli qilib ekranga chiqaradi |

`main()` esa shunchaki ularni navbat bilan chaqiradi. Bunday kodni o'qish ham, tuzatish ham ancha oson! Bu yondashuv **"bo'lib tashla va hukmronlik qil"** deyiladi va barcha dasturlash tillarida ishlatiladi.

### Ichkarida nima bo'ladi? Stekni likopchalar bilan tasavvur qil

Oshxonada likopchalar ustma-ust taxlangan. Yangi likopchani faqat **eng ustiga** qo'yish mumkin va olayotganda ham faqat **eng ustidagini** olasan. Bu **stek** (inglizcha *stack* — taxlam) deyiladi: "oxirgi kelgan — birinchi ketadi".

Funksiya chaqiruvlari aynan shunday saqlanadi. `faktorial(3)` uchun:

| Qadam | Stek holati (yuqoridan pastga) | Izoh |
|---|---|---|
| 1 | `faktorial(3)` | Birinchi chaqiruv |
| 2 | `faktorial(2)`, `faktorial(3)` | 3 javob kutyapti |
| 3 | `faktorial(1)`, `faktorial(2)`, `faktorial(3)` | Asosiy holatga yetdik |
| 4 | `faktorial(2)`, `faktorial(3)` | `faktorial(1)` 1 qaytardi va olib tashlandi |
| 5 | `faktorial(3)` | `faktorial(2)` 2 × 1 = 2 qaytardi |
| 6 | (bo'sh) | `faktorial(3)` 3 × 2 = 6 qaytardi |

Stekning hajmi cheklangan. Agar rekursiya juda chuqur ketsa (masalan, asosiy holat unutilsa), likopchalar shiftga tegadi — stek to'lib ketadi!

### Klassik masala: Hanoy minorasi

Uchta ustun bor. Birinchisida turli o'lchamdagi disklar kattadan kichikka qarab taxlangan. Barcha disklarni uchinchi ustunga ko'chirish kerak. Qoidalar: bir vaqtda faqat bitta disk ko'chiriladi va katta disk kichigining ustiga qo'yilmaydi.

Rekursiv g'oya: n ta diskni ko'chirish uchun (1) yuqoridagi n−1 tasini yordamchi ustunga ko'chir, (2) eng kattasini maqsadga ko'chir, (3) n−1 tasini yordamchidan maqsadga ko'chir.

```cpp
#include <iostream>
using namespace std;

void hanoy(int n, char dan, char ga, char yordamchi) {
    if (n == 0) return;                       // asosiy holat
    hanoy(n - 1, dan, yordamchi, ga);
    cout << n << "-diskni " << dan << " dan " << ga << " ga" << endl;
    hanoy(n - 1, yordamchi, ga, dan);
}

int main() {
    hanoy(3, 'A', 'C', 'B');
    return 0;
}
```

```output
1-diskni A dan C ga
2-diskni A dan B ga
1-diskni C dan B ga
3-diskni A dan C ga
1-diskni B dan A ga
2-diskni B dan C ga
1-diskni A dan C ga
```

!fakt Afsonaga ko'ra, bir ibodatxonada rohiblar 64 ta oltin diskli Hanoy minorasini ko'chirishmoqda. Buning uchun 2⁶⁴ − 1 ≈ 18 kvintillion harakat kerak. Har soniyada bitta harakat qilinsa ham, bu 580 milliard yildan ortiq vaqt oladi!

### Ko'p uchraydigan xatolar

| Xato | Muammo | To'g'risi |
|---|---|---|
| Asosiy holat yo'q | Stack overflow | Har doim to'xtash shartini yoz |
| `faktorial(n)` ichida yana `faktorial(n)` | Masala kichraymaydi — cheksiz | `faktorial(n - 1)` |
| Katta `n` bilan `fib(n)` | Juda sekin (bir xil qiymatlar qayta-qayta hisoblanadi) | Tsikl yoki natijalarni saqlash |
| `int` bilan katta faktorial | 13! dan keyin to'lib ketadi | `long long` ishlat |

### Boshqa tillarda

### Makros va funksiya: farqni tushunish

| | Makros | Funksiya |
|---|---|---|
| Qachon ishlaydi | Kompilyatsiyadan oldin, matn almashtirish | Dastur ishlayotganda |
| Turlarni tekshirish | Yo'q | Bor |
| Argument necha marta hisoblanadi | Har uchragan joyda (xavfli!) | Bir marta |
| Xatolarni topish | Qiyin | Oson |

Xavfli holatga misol:

```cpp
#include <iostream>
#define KV(x) ((x) * (x))
using namespace std;

int kv(int x) { return x * x; }

int main() {
    int a = 3, b = 3;
    cout << KV(a++) << endl;    // a++ ikki marta bajariladi!
    cout << "a = " << a << endl;
    cout << kv(b++) << endl;    // b++ bir marta
    cout << "b = " << b << endl;
    return 0;
}
```

```output
12
a = 5
9
b = 4
```

Makrosda `KV(a++)` → `((a++) * (a++))` ga aylandi va `a` ikki marta oshdi. Natija ham 9 emas, 12 bo'ldi! Funksiyada esa hammasi to'g'ri.

### Ko'p uchraydigan xatolar

| Xato | Muammo | To'g'risi |
|---|---|---|
| `#define KV(x) x*x` | `KV(1+2)` → `1+2*1+2` = 5 | `#define KV(x) ((x)*(x))` |
| `#define KV (x) ...` | Nom va qavs orasida probel — makros parametrsiz bo'lib qoladi | `#define KV(x) ...` |
| `#endif` ni unutish | `unterminated #ifdef` | Har bir `#if...` ni `#endif` bilan yop |
| Makros ichida `;` | Ikki marta `;` yoki kutilmagan xato | Makros oxiriga `;` qo'yma |

### Ichkarida nima bo'ladi? Kompilyator qayta yuklangan funksiyalarni qanday ajratadi?

Sen uchta `yuza` funksiyasi yozding, lekin kompilyator uchun ular butunlay boshqa-boshqa nomlarga ega! Kompilyator har bir funksiya nomiga uning parametr turlarini "qo'shib" yozadi. Bu **nomlarni bezash** (name mangling) deyiladi. Taxminan shunday:

| Sen yozgan | Kompilyator ichida (soddalashtirilgan) |
|---|---|
| `yuza(int)` | `yuza_int` |
| `yuza(int, int)` | `yuza_int_int` |
| `yuza(double)` | `yuza_double` |

`yuza(4, 6)` chaqirilganda kompilyator argumentlar turiga qaraydi: ikkita `int` — demak, `yuza_int_int` kerak.

**Qaysi variant tanlanadi?** Kompilyator eng mos keladiganini qidiradi:

1. Turlari aynan mos keladigan variant.
2. Kichik "kattalashtirish" bilan mos keladigan variant (masalan, `char` → `int`).
3. Boshqa o'zgartirishlar bilan mos keladigan variant.

Agar ikkita variant bir xil darajada mos kelsa, kompilyator "ambiguous" (noaniq) xatosini beradi.

### Ko'p uchraydigan xatolar

| Xato | Muammo | To'g'risi |
|---|---|---|
| `void f(int a = 5, int b)` | Standart qiymat o'rtada | Standart qiymatlar faqat oxirida |
| Faqat qaytaruvchi turi farq qiluvchi funksiyalar | Kompilyator ajrata olmaydi | Parametrlar ham farq qilishi kerak |
| `f(int)` va `f(long)` bo'lsa, `f(5.5)` chaqirish | Noaniqlik (ambiguous) | Aniq turni ber: `f(5)` |
| Massiv o'lchamini funksiya ichida `sizeof` bilan topish | Ko'rsatkich o'lchami chiqadi | O'lchamni alohida parametr qilib ber |

| Nomli argumentlar | Yo'q | Yo'q | Bor: `f(b=3, a=1)` |

## 6-modul uchun mini-loyiha: Matematik viktorina

Funksiyalar, tasodifiy sonlar va tsikllarni birlashtirib, o'zingni sinaydigan viktorina yasaymiz. Har bir vazifa alohida funksiyada!

```cpp
#include <iostream>
#include <cstdlib>
#include <ctime>
using namespace std;

int tasodifiy(int dan, int gacha) {
    return rand() % (gacha - dan + 1) + dan;
}

bool savolBer(int raqam) {
    int a = tasodifiy(1, 12);
    int b = tasodifiy(1, 12);
    cout << raqam << "-savol: " << a << " x " << b << " = ";
    int javob;
    cin >> javob;
    return javob == a * b;
}

void natijaniBaholash(int togri, int jami) {
    cout << "\nNatija: " << togri << " / " << jami << endl;
    if (togri == jami) cout << "Ajoyib! Sen haqiqiy matematiksan!" << endl;
    else if (togri >= jami / 2) cout << "Yaxshi! Yana bir oz mashq qil." << endl;
    else cout << "Ko'paytirish jadvalini takrorlab chiq!" << endl;
}

int main() {
    srand(time(0));
    const int SAVOLLAR = 5;
    int togri = 0;
    cout << "=== KO'PAYTIRISH VIKTORINASI ===" << endl;
    for (int i = 1; i <= SAVOLLAR; i++) {
        if (savolBer(i)) {
            cout << "To'g'ri!" << endl;
            togri++;
        } else {
            cout << "Noto'g'ri." << endl;
        }
    }
    natijaniBaholash(togri, SAVOLLAR);
    return 0;
}
```

```output
=== KO'PAYTIRISH VIKTORINASI ===
1-savol: 7 x 8 = 56
To'g'ri!
2-savol: 6 x 9 = 54
To'g'ri!
3-savol: 12 x 4 = 46
Noto'g'ri.
4-savol: 3 x 11 = 33
To'g'ri!
5-savol: 9 x 9 = 81
To'g'ri!

Natija: 4 / 5
Yaxshi! Yana bir oz mashq qil.
```

!mashq Viktorinani rivojlantir: (1) qo'shish va ayirish savollarini ham qo'sh (tasodifiy tanlansin); (2) noto'g'ri javobdan keyin to'g'ri javobni ko'rsat; (3) qiyinlik darajasini tanlash imkonini ber — oson (1–5), o'rta (1–12), qiyin (10–20).
