### Ichkarida nima bo'ladi? Ko'rsatkichning o'zi ham o'zgaruvchi!

Ko'rsatkich — sehrli narsa emas, u ham oddiy o'zgaruvchi. Faqat uning ichida son emas, **manzil** saqlanadi. Ko'rsatkichning o'zi ham xotirada joy egallaydi (zamonaviy 64 bitli kompyuterlarda odatda 8 bayt) va uning ham o'z manzili bor.

```cpp
#include <iostream>
using namespace std;

int main() {
    int yosh = 12;
    int* p = &yosh;
    cout << "sizeof(yosh) = " << sizeof(yosh) << endl;   // int — 4 bayt
    cout << "sizeof(p) = " << sizeof(p) << endl;         // ko'rsatkich — 8 bayt
    return 0;
}
```

```output
sizeof(yosh) = 4
sizeof(p) = 8
```

Qiziq: `double*`, `char*`, `int*` — barcha ko'rsatkichlar bir xil o'lchamda, chunki manzil har doim bir xil uzunlikdagi son. Ko'rsatkich turi esa kompilyatorga manzildagi ma'lumotni **qanday o'qishni** aytadi.

### `*` belgisining uch xil vazifasi

Boshlovchilarni eng ko'p chalkashtiradigan narsa — `*` belgisi turli joyda turli ma'noga ega:

| Qayerda | Misol | Ma'nosi |
|---|---|---|
| E'londa (tur bilan) | `int* p;` | "p — ko'rsatkich" |
| Ifodada (o'zgaruvchi oldida) | `*p = 5;` | "p ko'rsatgan joydagi qiymat" |
| Ikki son orasida | `a * b` | Ko'paytirish |

### Ko'p uchraydigan xatolar

| Xato | Muammo | To'g'risi |
|---|---|---|
| `int* p; *p = 5;` | `p` noma'lum joyni ko'rsatadi — qulash | `int* p = &x;` yoki `nullptr` |
| `int* p = 5;` | Songa emas, manzilga ko'rsatish kerak | `int* p = &x;` |
| `int* a, b;` | Faqat `a` ko'rsatkich, `b` — oddiy `int`! | `int *a, *b;` yoki alohida qatorlarda |
| `double d; int* p = &d;` | Turlar mos emas | `double* p = &d;` |
| Funksiyadan mahalliy o'zgaruvchi manzilini qaytarish | Funksiya tugaganda o'zgaruvchi yo'qoladi | Bunday qilma (yoki dinamik xotira ishlat) |

Qiziq fakt: ko'pchilik kompilyatorlar havolani ichkarida aslida ko'rsatkich sifatida amalga oshiradi! Lekin C++ tili havolaga qattiq qoidalar qo'yadi:

### `for` tsiklida havola

Havolalar ayniqsa ro'yxat elementlarini o'zgartirishda qulay:

```cpp
#include <iostream>
using namespace std;

int main() {
    int ballar[] = {70, 85, 90};
    for (int& b : ballar) {     // & — har bir elementning o'zi
        b += 5;                 // bonus ball!
    }
    for (int b : ballar) cout << b << " ";
    cout << endl;
    return 0;
}
```

```output
75 90 95 
```

Agar `int& b` o'rniga `int b` yozilsa, har safar elementning nusxasi olinadi va massiv o'zgarmaydi.

| Xato | Muammo | To'g'risi |
|---|---|---|
| `int& r;` | Havola darhol bog'lanishi shart | `int& r = x;` |
| `int& r = 5;` | Oddiy havola songa bog'lanmaydi | `const int& r = 5;` yoki o'zgaruvchiga bog'la |
| Havolani "qayta bog'lash" urinishi | Aslida qiymat ko'chiriladi | Boshqasiga bog'lash kerak bo'lsa — ko'rsatkich |

### Ichkarida nima bo'ladi? Aqlli ko'rsatkich qanday "aqlli"?

Aqlli ko'rsatkich — aslida oddiy ko'rsatkichni o'rab olgan kichik **klass**. Uning siri — **destruktor** (obyekt yo'q bo'layotganda avtomatik chaqiriladigan maxsus funksiya, 10-modulda o'rganamiz). Aqlli ko'rsatkich o'z ko'lamidan chiqqanda destruktor avtomatik ishlaydi va ichida `delete` ni chaqiradi.

`shared_ptr` ichida esa qo'shimcha **hisoblagich** bor:

- yangi nusxa yaratilganda hisoblagich 1 ga oshadi;
- nusxa yo'q bo'lganda 1 ga kamayadi;
- hisoblagich 0 ga yetganda — obyekt o'chiriladi.

Bu usul **havolalarni sanash** (reference counting) deyiladi.

### Obyekt qachon o'chishini ko'raylik

```cpp
#include <iostream>
#include <memory>
using namespace std;

struct Robot {
    string ism;
    Robot(string i) : ism(i) { cout << ism << " yaratildi" << endl; }
    ~Robot() { cout << ism << " o'chirildi" << endl; }
};

int main() {
    cout << "Dastur boshlandi" << endl;
    {
        auto r = make_unique<Robot>("Kodi");
        cout << "Blok ichida ishlayapmiz..." << endl;
    }   // r shu yerda avtomatik o'chiriladi
    cout << "Dastur tugadi" << endl;
    return 0;
}
```

```output
Dastur boshlandi
Kodi yaratildi
Blok ichida ishlayapmiz...
Kodi o'chirildi
Dastur tugadi
```

Biz hech qayerda `delete` yozmadik, lekin robot o'z vaqtida o'chirildi!

### Ko'p uchraydigan xatolar

| Xato | Muammo | To'g'risi |
|---|---|---|
| `unique_ptr` ni nusxalash | Kompilyatsiya xatosi | `move(p)` |
| `move` dan keyin eski ko'rsatkichni ishlatish | U endi bo'sh (`nullptr`) | Ko'chirilgandan keyin ishlatma |
| `shared_ptr` lar bir-birini ko'rsatsa | Aylanma bog'lanish — xotira hech qachon bo'shamaydi | Bittasini `weak_ptr` qil |
| Bitta oddiy ko'rsatkichdan ikkita `shared_ptr` yaratish | Obyekt ikki marta o'chiriladi | `make_shared` ishlat |

### Ichkarida nima bo'ladi? Xotira xaritasi

`int x = 7; int* p = &x; int** pp = &p;` dan keyin xotira taxminan shunday ko'rinadi:

| Manzil | Nomi | Ichida |
|---|---|---|
| `0x100` | `x` | `7` |
| `0x200` | `p` | `0x100` (x ning manzili) |
| `0x300` | `pp` | `0x200` (p ning manzili) |

`**pp` hisoblanganda kompyuter: (1) `pp` ichidan `0x200` ni oladi, (2) `0x200` manzilga borib, `0x100` ni oladi, (3) `0x100` manzilga borib, `7` ni oladi. Ikki marta "sakrash"!

Bu g'oya mantiqiy, lekin murakkab hollarda e'lonlarni o'qishni qiyinlashtiradi. Shuning uchun zamonaviy C++ da `using` bilan soddalashtirish tavsiya etiladi.

### Real hayotda: tugma bosilganda nima bo'ladi?

Kompyuter o'yinlari va dasturlarda callback lar hamma joyda! Masalan, "Boshlash" tugmasini yaratayotganda dasturchi unga "bosilganda mana bu funksiyani chaqir" deb funksiyaga ko'rsatkich beradi:

```cpp
#include <iostream>
#include <string>
using namespace std;

struct Tugma {
    string yozuv;
    void (*bosilganda)();       // callback
    void bos() {
        cout << "[" << yozuv << "] bosildi -> ";
        bosilganda();
    }
};

void oyinniBoshla() { cout << "O'yin boshlandi!" << endl; }
void chiqish()      { cout << "Xayr!" << endl; }

int main() {
    Tugma t1{"Boshlash", oyinniBoshla};
    Tugma t2{"Chiqish", chiqish};
    t1.bos();
    t2.bos();
    return 0;
}
```

```output
[Boshlash] bosildi -> O'yin boshlandi!
[Chiqish] bosildi -> Xayr!
```

### Ko'p uchraydigan xatolar

| Xato | Muammo | To'g'risi |
|---|---|---|
| `int *f(int, int);` | Bu funksiya e'loni, ko'rsatkich emas | `int (*f)(int, int);` |
| Parametrlari mos kelmaydigan funksiyani berish | Kompilyatsiya xatosi | Turlar va parametrlar aynan mos bo'lsin |
| `f = qoshish();` | Funksiya chaqirilib, natijasi beriladi | `f = qoshish;` (qavssiz) |
| `nullptr` ko'rsatkich orqali chaqirish | Qulash | Avval `if (f)` bilan tekshir |

### Boshqa tillarda

Ko'p zamonaviy tillarda funksiyalar "birinchi darajali fuqaro" — ularni oddiy qiymat kabi o'zgaruvchiga saqlash va uzatish mumkin:

**Python:**

```python
def kvadrat(x):
    return x * x

f = kvadrat
print(f(7))                          # 49
print(list(map(kvadrat, [1, 2, 3]))) # [1, 4, 9]
```

**JavaScript:**

```javascript
const kvadrat = x => x * x;
console.log([1, 2, 3].map(kvadrat));   // [1, 4, 9]
```

C++ da funksiyaga ko'rsatkichlarni tushunsang, JavaScript dagi callback lar va Python dagi `map` kabi tushunchalar senga juda tanish bo'ladi.

### O'zingni tekshir

1. Funksiyaga ko'rsatkich nima saqlaydi?
2. `int (*f)(int, int);` qanday funksiyalarni ko'rsata oladi?
3. Callback nima?
4. `f = qoshish;` va `f = qoshish();` ning farqi nimada?
@@answers
1. Funksiyaning xotiradagi manzilini.
2. Ikkita `int` qabul qilib, `int` qaytaradigan funksiyalarni.
3. Boshqa funksiyaga argument sifatida beriladigan va kerakli paytda chaqiriladigan funksiya.
4. `f = qoshish;` — funksiya manzilini beradi; `f = qoshish();` — funksiyani chaqirib, uning natijasini berishga urinadi (xato).

## 7-modul uchun mini-loyiha: Robot yo'nalishlarini boshqarish

Bu loyihada ko'rsatkichlar, havolalar va funksiyalarga ko'rsatkichlarni birga ishlatamiz. Robot katakli maydonda buyruqlar bo'yicha harakatlanadi:

```cpp
#include <iostream>
#include <string>
using namespace std;

struct Robot {
    int x = 0, y = 0;
    string ism;
};

void yuqoriga(Robot& r) { r.y++; }
void pastga(Robot& r)   { r.y--; }
void ongga(Robot& r)    { r.x++; }
void chapga(Robot& r)   { r.x--; }

void holat(const Robot* r) {
    cout << r->ism << " joylashuvi: (" << r->x << ", " << r->y << ")" << endl;
}

int main() {
    Robot kodi;
    kodi.ism = "Kodi";
    void (*buyruqlar[4])(Robot&) = {yuqoriga, pastga, ongga, chapga};
    const char* nomlar[4] = {"yuqoriga", "pastga", "o'ngga", "chapga"};

    string dastur = "UURRRDL";     // U-yuqori, D-past, R-o'ng, L-chap
    for (char c : dastur) {
        int k = (c == 'U') ? 0 : (c == 'D') ? 1 : (c == 'R') ? 2 : 3;
        buyruqlar[k](kodi);
        cout << nomlar[k] << " -> ";
        holat(&kodi);
    }
    return 0;
}
```

```output
yuqoriga -> Kodi joylashuvi: (0, 1)
yuqoriga -> Kodi joylashuvi: (0, 2)
o'ngga -> Kodi joylashuvi: (1, 2)
o'ngga -> Kodi joylashuvi: (2, 2)
o'ngga -> Kodi joylashuvi: (3, 2)
pastga -> Kodi joylashuvi: (3, 1)
chapga -> Kodi joylashuvi: (2, 1)
```
