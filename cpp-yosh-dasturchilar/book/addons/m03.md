@@start

**Bu mavzuda nimani bilib olasan:**

- izoh nima ekanini va u nima uchun kerakligini;
- bir qatorli va ko'p qatorli izohlarni yozishni;
- yaxshi izohni yomonidan ajratishni.
@@end
### Ichkarida nima bo'ladi?

Izohlar bilan nima sodir bo'lishini bilasanmi? Ular kompilyatorgacha ham yetib bormaydi! Preprotsessor bosqichidayoq har bir izoh bitta probelga almashtiriladi. Shuning uchun:

- izohlar dasturni **sekinlashtirmaydi**;
- tayyor `.exe` fayl hajmini **oshirmaydi**;
- dasturning ishlashiga **hech qanday ta'sir qilmaydi**.

Demak, izohni ayamasdan, kerakli joyga yozaver. Kompyuter uchun ular yo'q, odamlar uchun esa juda foydali.

### Yaxshi va yomon izohlar

| Yomon izoh | Nega yomon | Yaxshi izoh |
|---|---|---|
| `i++; // i ni oshiramiz` | Koddan allaqachon ko'rinib turibdi | `i++; // keyingi o'quvchiga o'tamiz` |
| `int x; // x` | Hech narsa tushuntirmaydi | `int ball; // test natijasi, 0-100` |
| Eski, kodga mos kelmay qolgan izoh | Chalg'itadi | Kodni o'zgartirganda izohni ham yangila |

### Ko'p uchraydigan xatolar

| Xato | Natija | To'g'risi |
|---|---|---|
| `/* ... ` ni yopishni unutish | Keyingi butun kod izohga aylanib qoladi | Har doim `*/` bilan yop |
| `/* /* ichki */ */` | Birinchi `*/` izohni tugatadi, ikkinchisi xato beradi | Ichma-ich izoh yozma |
| `/ izoh` (bitta chiziq) | Kompilyator buni bo'lish deb tushunadi | Ikkita chiziq: `//` |

### Boshqa tillarda

Izohlar deyarli barcha tillarda bor, faqat belgilari farq qiladi:

| Til | Bir qatorli | Ko'p qatorli |
|---|---|---|
| C++, Java, C#, JavaScript | `// izoh` | `/* izoh */` |
| Python | `# izoh` | `""" izoh """` |
| HTML | — | `<!-- izoh -->` |
| SQL | `-- izoh` | `/* izoh */` |

**Python:**

```python
# Bu Python dagi izoh
yosh = 12  # yoshni saqlaymiz
```

### O'zingni tekshir

1. Kompilyator izohlarni o'qiydimi?
2. Bir qatorli izoh qaysi belgilar bilan boshlanadi?
3. Ko'p qatorli izoh qanday yoziladi?
4. Izohlar dastur tezligiga ta'sir qiladimi?
@@answers
1. Yo'q, izohlar preprotsessor bosqichida olib tashlanadi.
2. Ikkita qiya chiziq: `//`.
3. `/*` bilan boshlanib, `*/` bilan tugaydi.
4. Yo'q, chunki ular tayyor dasturga umuman kirmaydi.
@@topic C++ dagi header (sarlavha) fayllar
@@start
!img c_headers.png | Header fayl — tayyor asboblar qutisi | 6.2

**Bu mavzuda nimani bilib olasan:**

- header fayl nima ekanini va u nima uchun kerakligini;
- `#include` qanday ishlashini;
- eng ko'p ishlatiladigan standart header fayllarni;
- o'z header faylingni yaratishni.
@@end
### Ichkarida nima bo'ladi? `#include` — bu shunchaki "nusxa ko'chir va qo'y"

Preprotsessor `#include <iostream>` qatorini uchratganda nima qiladi? U kompyuterdan `iostream` nomli faylni topadi va uning **butun mazmunini** shu qator o'rniga joylashtiradi. Xuddi kitobga boshqa kitobdan bir bobni yopishtirib qo'ygandek.

Qiziq fakt: `<iostream>` ning o'zi ham ichida boshqa fayllarni `#include` qiladi, ular esa yana boshqalarini... Natijada sening 5 qatorli "Salom" dasturing kompilyatorga yetib borganda o'n minglab qatorga aylanadi!

**Burchakli qavs va qo'shtirnoq farqi:**

- `#include <fayl>` — preprotsessor faylni **tizim papkalaridan** (kompilyator o'rnatilgan joydan) qidiradi.
- `#include "fayl"` — avval **sening loyihang papkasidan**, topa olmasa tizim papkalaridan qidiradi.

### `.h` va `.cpp` fayllar: e'lon va amalga oshirish

Katta loyihalarda odatda shunday qilinadi:

- `.h` faylda funksiya **e'lon qilinadi** (faqat "shunday funksiya bor" deyiladi);
- `.cpp` faylda funksiya **amalga oshiriladi** (u nima qilishi yoziladi).

Bu kitobning mundarijasi va boblariga o'xshaydi: mundarijada (`.h`) faqat bob nomlari, boblarda (`.cpp`) esa to'liq matn bor.

```cpp
// matematika.h — e'lonlar
int kvadrat(int x);
int kub(int x);
```

```cpp
// matematika.cpp — amalga oshirish
#include "matematika.h"
int kvadrat(int x) { return x * x; }
int kub(int x)     { return x * x * x; }
```

### Ko'p uchraydigan xatolar

| Xato | Natija | Yechim |
|---|---|---|
| `#include <iostream>;` (oxirida `;`) | Ogohlantirish yoki xato | Preprotsessor buyruqlaridan keyin `;` qo'yilmaydi |
| `#include <iostream.h>` | Fayl topilmaydi | Zamonaviy C++ da `.h` yozilmaydi: `<iostream>` |
| `sqrt` ishlatib, `<cmath>` ni ulamaslik | `'sqrt' was not declared` | Kerakli header faylni qo'sh |
| O'z faylini `< >` ichida yozish | Fayl topilmaydi | O'z fayllaring uchun `" "` ishlat |

### Boshqa tillarda

Boshqa tillarda ham tayyor kutubxonalarni ulash bor, faqat boshqacha nomlanadi:

| Til | Qanday ulanadi | Misol |
|---|---|---|
| C++ | `#include` | `#include <cmath>` |
| Python | `import` | `import math` |
| Java | `import` | `import java.util.Scanner;` |
| JavaScript | `import` yoki `require` | `import fs from 'fs';` |

**Python** da ildiz chiqarish:

```python
import math
print(math.sqrt(16))
```

**Java** da:

```java
System.out.println(Math.sqrt(16));
```

### O'zingni tekshir

1. `#include` buyrug'i aslida nima qiladi?
2. `<cmath>` header fayli nima uchun kerak?
3. `#include <...>` va `#include "..."` ning farqi nimada?
4. Include guard (`#ifndef ... #endif`) nima uchun ishlatiladi?
@@answers
1. Ko'rsatilgan faylning butun mazmunini shu qator o'rniga nusxalab qo'yadi.
2. Matematik funksiyalar uchun: `sqrt`, `pow`, `abs`, `sin`, `cos` va boshqalar.
3. `< >` — standart (tizim) fayllari uchun, `" "` — o'zing yaratgan fayllar uchun; qo'shtirnoqda avval loyiha papkasidan qidiriladi.
4. Bitta header fayl dasturga ikki marta qo'shilib qolishining oldini olish uchun.

@@end
### Ichkarida nima bo'ladi? Nomlar to'qnashuvi

Tasavvur qil, sen ikkita tayyor kutubxonadan foydalanyapsan: biri grafika uchun, ikkinchisi tovush uchun. Ikkalasining ichida ham `boshla()` degan funksiya bor. Sen `boshla();` deb yozsang, kompilyator qaysi birini chaqirishni bilmaydi va xato beradi. Bu **nomlar to'qnashuvi** deyiladi.

Agar kutubxonalar o'z funksiyalarini namespace ichiga joylashtirgan bo'lsa, muammo yo'q:

```cpp
#include <iostream>
using namespace std;

namespace grafika {
    void boshla() { cout << "Rasm chizish boshlandi" << endl; }
}
namespace tovush {
    void boshla() { cout << "Musiqa yangradi" << endl; }
}

int main() {
    grafika::boshla();
    tovush::boshla();
    return 0;
}
```

```output
Rasm chizish boshlandi
Musiqa yangradi
```

Kompilyator ichkarida har bir nomga uning namespace ini "familiya" sifatida qo'shib saqlaydi: `grafika::boshla` va `tovush::boshla` — uning uchun butunlay boshqa-boshqa nomlar.

### Ko'p uchraydigan xatolar

| Xato | Sababi | Yechim |
|---|---|---|
| `'cout' was not declared` | `std::` ham, `using namespace std;` ham yozilmagan | Ikkalasidan birini qo'sh |
| `std:cout` (bitta ikki nuqta) | Ko'lam operatori `::` — ikkita ikki nuqta | `std::cout` |
| `using namespace std` (oxirida `;` yo'q) | Ko'rsatma tugallanmagan | `using namespace std;` |
| Header faylga `using namespace std;` yozish | Bu faylni ulagan hamma joyga ta'sir qiladi | Header fayllarda `std::` ni to'liq yoz |

### Boshqa tillarda

Namespace g'oyasi ko'p tillarda bor, lekin boshqacha nomlanadi:

| Til | Nomi | Misol |
|---|---|---|
| C++ | namespace | `std::cout` |
| Java | package (paket) | `java.util.Scanner` |
| Python | module (modul) | `math.sqrt(16)` |
| C# | namespace | `System.Console` |

Ko'rib turganingdek, hammasida "katta guruh nomi + nuqta/ikki nuqta + ichidagi element" ko'rinishi ishlatiladi.

### O'zingni tekshir

1. Namespace qanday muammoni hal qiladi?
2. `::` operatori qanday nomlanadi va nima qiladi?
3. `cout` qaysi namespace da joylashgan?
4. `using namespace std;` nima uchun yoziladi?
@@answers
1. Bir xil nomli funksiya yoki o'zgaruvchilarning to'qnashuvini (chalkashishini).
2. Ko'lam operatori; u namespace yoki klass ichidagi elementga murojaat qiladi.
3. `std` namespace ida.
4. `std::` ni har safar yozmasdan, `cout`, `cin`, `endl` kabi nomlarni to'g'ridan-to'g'ri ishlatish uchun.

### Ichkarida nima bo'ladi? Kompilyator uchun farqi yo'q!

Qiziq fakt: kompilyator uchun quyidagi ikki kod **mutlaqo bir xil**:

```cpp
int main(){int a=5;if(a>3){a=a*2;}return a;}
```

```cpp
int main() {
    int a = 5;
    if (a > 3) {
        a = a * 2;
    }
    return a;
}
```

Kompilyator probel, bo'sh qator va chekinishlarga e'tibor bermaydi. Bu qoidalar butunlay **odamlar uchun**. Dasturchilar o'z ish vaqtining katta qismini yangi kod yozishga emas, balki mavjud kodni **o'qishga** sarflashadi. Shuning uchun o'qishga qulay kod juda qadrlanadi.

### Ichkarida nima bo'ladi? Kompyuter ko'rsatmalarni qanday bajaradi?

Kompyuterning "miyasi" — **protsessor**. U ko'rsatmalarni birin-ketin, juda tez bajaradi: zamonaviy protsessor bir soniyada **milliardlab** oddiy amallarni bajara oladi!

Odatda ko'rsatmalar yuqoridan pastga, yozilgan tartibda bajariladi. Bu **ketma-ket bajarish** deyiladi. Tanlash, takrorlash va sakrash ko'rsatmalari esa bu tartibni o'zgartirib, dasturni "aqlli" qiladi.

```cpp
#include <iostream>
using namespace std;

int main() {
    cout << "1-qadam" << endl;   // avval bu
    cout << "2-qadam" << endl;   // keyin bu
    cout << "3-qadam" << endl;   // oxirida bu
    return 0;
}
```

```output
1-qadam
2-qadam
3-qadam
```

### Qayerda `;` kerak, qayerda kerak emas?

| Qator | `;` kerakmi? | Sabab |
|---|---|---|
| `int x = 5` | Ha | E'lon ko'rsatmasi |
| `cout << x` | Ha | Ifoda ko'rsatmasi |
| `if (x > 0)` | Yo'q! | Shartdan keyin blok keladi |
| `for (int i = 0; i < 5; i++)` | Oxirida yo'q! | Ichidagi `;` lar — qismlarni ajratadi |
| `}` (blok oxiri) | Yo'q | Blok o'zi tugaydi |
| `#include <iostream>` | Yo'q | Preprotsessor buyrug'i |

!diqqat `if (x > 0);` — juda yashirin xato! Shartdan keyingi `;` bo'sh ko'rsatma hisoblanadi, ya'ni "agar x musbat bo'lsa — hech narsa qilma". Keyingi blok esa shartdan qat'i nazar har doim bajariladi.

### Boshqa tillarda

| Til | Ko'rsatma oxiri | Blok |
|---|---|---|
| C++, Java, C#, JavaScript | `;` | `{ }` |
| Python | Qator oxiri (`;` shart emas) | Chekinish |
| Go | Qator oxiri (`;` avtomatik qo'yiladi) | `{ }` |

**Python:**

```python
yulduzlar = 3
for i in range(yulduzlar):
    print("*", end=" ")
```

**Java:**

```java
int yulduzlar = 3;
for (int i = 0; i < yulduzlar; i++) {
    System.out.print("* ");
}
```

Java kodi C++ ga deyarli bir xil ekanini ko'rdingmi?

## 3-modul uchun mini-loyiha: Kichik sehrgar-kalkulyator

Bu loyihada izohlar, header fayllar, namespace va yaxshi kod yozish qoidalarini birga ishlatamiz:

```cpp
// =============================================
//  Sehrgar-kalkulyator
//  Muallif: Malika
//  Vazifasi: o'ylangan sonni "topish" fokusi
// =============================================
#include <iostream>
using namespace std;

namespace fokus {
    const int QOSHILADIGAN = 10;
    const int KOPAYTIRILADIGAN = 2;
}

int main() {
    int oylanganSon = 7;    // tomoshabin o'ylagan son

    // 1-qadam: songa 10 qo'shamiz
    int natija = oylanganSon + fokus::QOSHILADIGAN;
    // 2-qadam: 2 ga ko'paytiramiz
    natija = natija * fokus::KOPAYTIRILADIGAN;
    // 3-qadam: 20 ni ayiramiz
    natija = natija - 20;
    // 4-qadam: 2 ga bo'lamiz — o'ylangan son qaytib chiqadi!
    natija = natija / 2;

    cout << "Siz o'ylagan son: " << natija << endl;
    return 0;
}
```

```output
Siz o'ylagan son: 7
```

!fakt Bu fokus har qanday son bilan ishlaydi! Sababi oddiy matematika: (x + 10) × 2 − 20 = 2x, keyin 2x ÷ 2 = x.

!mashq `oylanganSon` qiymatini 15, 42, 100 ga o'zgartirib, fokus har doim ishlashini tekshir. Keyin o'z fokusingni o'ylab top va izohlar bilan yoz.
